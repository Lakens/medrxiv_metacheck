Reporting p values imprecisely (e.g., p < .05) reduces transparency, reproducibility, and re-use (e.g., in p value meta-analyses). Best practice is to report exact p-values with three decimal places (e.g., p = .032) unless p values are smaller than 0.001, in which case you can use p < .001.

What we found

Show details

Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

How Power Analysis Check works

This module uses regular expressions to identify sentences that contain a statistical power analysis. If specified by the user, it also uses a large language model (LLM) to extract information reported in power analyses, including the statistical test, sample size, alpha level, desired level of power, and magnitude and type of effect size.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. With the use of an LLM, it checks if the power analysis is reported with all required information.

The regular expressions can miss power analyses, or fail to classify them correctly. The type of power analysis is often difficult to classify, which can easily be solved by explicitly specifying the type of power analysis as ‘a-priori’, ‘sensitivity’, or ‘post-hoc’. The LLM can fail to identify information in the paper, and will not have access to information in paragraphs in the paper other than those that contain the word ‘power’. How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Abstract

Purpose: We investigated the mechanisms behind the generation of Neural Distortion Responses (NDRs) measured with electroencephalography when interleaving amplitudemodulated (AM) pulse trains in cochlear implant (CI) users.

Methods: Previous experiments measured NDRs using interleaved pulse trains in which oddand even-numbered pulses were respectively modulated at F1 and F2 Hz, where F1=2*F2/3 and F1≈80Hz. Experiment 1 separated quadratic and cubic distortion products using a relationship of F1 and F2 such that F1 = (2*F2/3)+2. Experiment 2 retained the original F1=2*F2/3 relationship but shifted the starting AM phase of F2 relative to that of F1.

Experiment 3 simultaneously separated the quadratic and cubic distortion products and varied the relative phase of F1 and F2. Experiment 4 flipped the leading polarity of the second pulse in each pulse-pair such that the central phase of the resulting pseudo-triphasic pulses was anodic. All experiments were conducted with Cochlear CI users and interpreted using two computational models of the electrically stimulated auditory nerve.

Results: Both quadratic (QDR) and cubic distortion products (CDR) were observed. Varying relative AM phase had an effect on NDR amplitudes, with the largest amplitude when maxima of the 2 AM patterns were aligned. Stimulating with an anodic central phase within the AM pulse pairs resulted in stronger responses for 4 of 9 CI users. Computational modelling suggested a stronger role for refractoriness than for facilitation in generating the NDR, but failed to fully account for the effect of flipping the polarity.

Conclusion: NDRs consist of both quadratic and cubic components, and are greatest when maxima of the F1 and F2 pulse trains align. Refractoriness is likely more important than facilitation for generating the NDR.

Introduction

Cochlear implants (CIs) are neuro-prosthetic devices that have provided a sense of sound to over one million users worldwide by directly stimulating the auditory nerve [1]. Although many listeners achieve improved speech-perception using their CI there is a lot of variability between users [2]. This variability has inspired numerous research studies investigating its causes and ways in which CI stimulation can be optimised for improved speech-perception outcomes [3], [4]. One approach is development of fitting procedures that leverage objective electrophysiological measures reflective of perceptual reports of loudness, with the aim of optimising the stimulation current levels of the CI. This has been tried primarily using evoked potential recordings from the auditory nerve (electrically evoked compound action potentials, or ECAPs) and brainstem (electrically evoked auditory brainstem responses, or EABRs), with limited and variable correlations with loudness perception [5], [6], [7]. A key limitation of these approaches is that they usually present electrical-current stimulation pulses at a slow rate (< 80 pulses per second, or pps) and measure the responses in the gaps between the stimuli [8].

These slow rates are necessary in part to extract the neural response from contamination by the large electrical artefact produced by CI stimulation, but they render the stimulation very different to that used in CI users' every-day 'coding strategies.' It is therefore desirable to have a technique for measuring neural responses to electrical stimulation in CIs that is as close as possible to those leveraged in everyday use and that isolates these responses from the ubiquitous electrical artefacts.

Carlyon et al proposed the ALternating Frequency Interleaved Electrical Stimulation (ALFIES)

technique as a way to measure the sustained neural response of CI users to high-rate, amplitude-modulated (AM) pulse trains presented to one or two electrodes in an interleaved manner [9]. The high rate and the amplitude modulation both render the stimulus more similar to stimulation CI users listen to every day, compared to the stimuli used for ECAPs and EABRs.

In ALFIES, two interleaved pulse trains are amplitude-modulated at different frequencies F1 and F2 Hz. When F1 and F2 were 80 and 120 Hz, respectively, electroencephalography (EEG) recordings revealed the presence of a neural distortion response (NDR) at 40 Hz. This component is unlikely to reflect nonlinearities in the CI stimulation system because the two AM pulse trains are interleaved in time and nonlinearities from the device occur almost instantaneously. Conversely, the auditory system responds to each pulse in the stimulation pattern in a way that is not independent of adjacent pulses, via mechanisms that include refractoriness and facilitation at the level of the auditory nerve [10]. This "undoes" the independence of the F1 and F2 pulse trains, allowing subsequent and/or simultaneous nonlinearities within the auditory system to produce NDRs at composite frequencies such as F2-F1. The NDR had a group delay of approximately 45 milliseconds (ms), consistent with a thalamic and/or cortical neural generator and inconsistent with the zero delay expected from an electrical artefact. Furthermore, Guérit et al suggested that the temporal integration mechanism that precedes neural nonlinearities to generate an NDR likely occurs as early as the auditory nerve membrane and cochlear nucleus, with these NDRs being propagated to cortical/thalamic generators where they can be detected using EEG [11]. This was evidenced by the decrease in NDR amplitude as the inter-pulse interval (IPI) between F1 and F2 pulses . was increased above 200-400 μs, with no measurable response > 900μs [11]. Thalamic and cortical integration mechanisms would be expected to have longer time constants.

The experiments described here had two broad goals. The first was to improve our understanding of the neural processes revealed by the ALFIES method. As noted above, the presence of the NDR demonstrates the operation of some between-pulse temporal dependency or dependencies, followed by one or more nonlinearities. Understanding the temporal dependencies between pulses is of particular interest given the trend of increasing CI stimulation rates, and hence shorter inter-pulse intervals, in modern CI processing strategies. Although Guérit et al showed that the dependencies responsible for the NDR had a short time constant reflective of a peripheral basis [11], those data do not distinguish between specific mechanisms. We therefore use two computational models that, respectively, incorporate facilitation and refractoriness, and evaluate their predictions of the effect of the relative phase of the F1 and F2 modulations on the NDR. Our experimental results suggest that refractoriness plays the greater role. We also build on previous ALFIES studies to investigate the nature of the nonlinearity responsible for NDR generation. The NDR investigated previously could have reflected either a quadratic (F2-F1) and/or a cubic (2*F1-F2) distortion component, as both give rise to distortions at the same frequency when F2 = 1.5*F1. While these components were intentionally confounded for the purpose of maximising potential SNR, it was not known whether the NDR is quadratic in nature, cubic, or a mixture of both. In our first experiment, we separated the quadratic (QDR) and cubic distortion responses (CDR) by changing F1 to 82 Hz while keeping F2 at 120 Hz, resulting in separated quadratic and cubic distortion products at 38 and 44 Hz, respectively. We found both QDRs and CDRs with group delays consistent with thalamo-cortical neural generators. Given this new evidence that both distortions contribute to the NDR, the importance of optimising parameters such that they interfere constructively became clear, both to maximise SNR and to achieve the most faithful representation of the response of the auditory system.

Experiments 2 to 4 addressed our second motivation, which was to maximise the size of the NDR and to refine the use of ALFIES as a clinical technique. ALFIES already shows promise in this regard: it measures the sustained response to high-rate pulse-trains while avoiding electrical artefact, requires only a single pair of recording electrodes and standard EEG equipment, has a steep amplitude growth function, and -by presenting the F1 and F2 pulse trains to electrodes separated by varying amounts -has the potential to measure the selectivity as well as sensitivity to CI stimulation [9], [11]. A potential limitation is that the amplitude of the NDR reported in previous studies was lower than that of the electrically evoked steady-state response (eASSR). We show here that by presenting both the F1 and F2 modulations such that their maxima are aligned, it is possible to produce an NDR amplitude that is comparable to that produced by the eASSR, thereby combining the benefits of the two techniques. Experiment 4 also shows that the NDR may be further increased for some participants by presenting the F1 and F2 pulses in opposite leading polarity.

Methods

A total of 16 CI users implanted with devices from Cochlear Ltd (Sydney, Australia) took part (Table 1). General Experimental Approach

All experiments involved direct stimulation of an adjacent pair of electrodes with interleaved, amplitude-modulated pulse trains using the Nucleus Implant Communicator research software version 4.3 (NIC4.3, nice22.1) provided by Cochlear Ltd. The stimulation parameters were controlled by a laptop using custom software developed in Python version 3.9 (Wilmington, Delaware, USA) that used the NIC4.3 python libraries, and communicated with a CP910 cochlear-implant processor via a programming cable and POD connected to the laptop via USB.

The interleaved AM pulse trains used for stimulation are depicted in Figure 1a-b. Each AM pulse train had a carrier rate of 480 pps, usually with a stimulus onset asynchrony (SOA) of 200 μs (except for experiment 4). These parameters were selected for consistency with previous work and from evidence of no reduction in the NDR amplitude when the AM pulse trains are presented on adjacent electrodes compared to a single electrode, or when the SOA was set to 200-400 μs compared to shorter values [9], [11]. Some experiments (2, 4) used an F1:F2 ratio of 2:3 as in previous work (see Figure 1a), whereas other experiments (1, 3) added 2 Hz to F1 such that the quadratic and cubic distortion product frequencies were isolated but both still fell within ≈ 40 ± 10 Hz, the optimal range for eliciting a cortical response (see Figure 1b; [12], [13]). The precise frequencies used for each experiment are described in each corresponding section. inter-phase gap (IPG), unless otherwise indicated. The phase durations and stimulating electrodes differed somewhat across participants (Table 1), with a preference for more-apical electrodes and phase durations that matched those used in the participants' clinical program.

Longer phase durations were used when compliance limits were reached without achieving a loudness rating of "most-comfortable level" (MCL). More-basal electrodes were employed when apical electrodes were switched off in the CI user's clinical programme or showed atypically high impedance values.

Prior to commencing, impedances were recorded and the upper limit of compliance was calculated for stimulating electrodes. A loudness-scaling procedure was then employed using an 11-point chart where0 = 'inaudible' and10 = 'too loud.' Starting with 0.5-second duration, unmodulated pairs of pulse trains on one electrode that were presented below threshold with slowly increasing current level (with steps of 6 Current Levels or CLs, where 6 CL ≈ 1 dB) until the sounds were just audible. This level was set as the threshold (T), and then the two interleaved trains were amplitude modulated respectively at 80 and 120 Hz between T and a higher current level that was increased in steps of 6 CLs until level '4' (comfortable but too soft) was achieved, steps of 4 CLs until level '5' (comfortable but soft) was achieved, and steps of 2 CLs until level '7' (loud but comfortable) was achieved. The upper modulation current level was then decreased in steps of 1 or 2 CLs to find the highest current level that was considered '6' (most comfortable), and this current level was set as MCL for that electrode. The same procedure was then repeated with the second, adjacent electrode. These two sets of T and MCL levels were then used as the minimum and maximum current between which the pulse trains were amplitude modulated for the interleaved stimulation. The participant was played a 5-10 second segment of the interleaved stimulus to confirm that the level was comfortable to listen to for an extended period of time, and the MCL levels were decreased in steps of 2 CLs if necessary to accommodate this.

Research participants were then asked to remove the research processor, and were fit with an electroencephalography (EEG) cap fitted with 10 contacts (including 2 ground electrodes), placed as depicted in Figure 1c. By default, montages of Cz vs P9 or P10 were used for participants with implants on the Right and Left sides, respectively, leveraging the contact behind the ear contralateral to the stimulating CI. Montages were sometimes adjusted, replacing P9 or P10 with the neighbouring mastoid contact (M1 and M2, respectively), if the default montage provided noisy data with many rejected epochs (see Table 1). The EEG system was custom built by BioSemi B.V. (Amsterdam, Netherlands) with a 262,144 kHz sampling rate.

Stimuli were delivered to the CI via direct stimulation using a CP910 processor in the manner described above, in segments of 31 seconds. A trigger was included in the stimulation code at each 1-second interval (excluding the first second to avoid onset responses) throughout stimulation, for use in the analysis pipeline that organised the EEG data into 1-second epochs.

The analysis pipeline was employed in real time during data collection as described in Guérit et al (2023) and followed the procedure laid out in both Carlyon et al (2021) and Guérit et al (2023), with some small adjustments described below. It used custom software developed in MATLAB 2020b (Mathworks, Natick, Massachusetts, USA) that reads in and processes EEG data files saved by the ActiView software (ActiHyper version 804) from Biosemi. As a brief summary, . this involved averaging the 1-second EEG epochs and converting from the time domain to the frequency domain by calculating a fast Fourier transform (fft) with 1-Hz frequency-bin resolution. Amplitudes in decibels (dB) re 1 μV and phase in radians (rad) were then extracted at frequencies of interest, including both the F1 and F2 AM frequencies (e.g. 80 and 120 Hz, respectively) and the distortion product frequencies (e.g. 40 Hz). A standard procedure was also employed to remove noisy epochs as described in Arzounian et al [14], and epochs with noise estimates higher than 2 μV were rejected. A standard of 300 epochs with triggers (5 minutes of steady-state recordings) were recorded for each condition, and real-time analysis of the significance of amplitudes at the NDR frequencies was employed. This standard number of epochs was sometimes extended to 450 or 600 if time allowed in the cases where insignificant responses for the distortion product frequencies were observed after 300 epochs, or reduced to a minimum of 90 epochs in some rare cases if significant and stable responses were observed quickly.

The method for significance testing differed from prior analyses pipelines [9], [11], where significance was confirmed by comparing the amplitude of the target frequency bin in the fft power spectrum to the amplitude in the 3 neighbouring frequencies below and above it. For example, in previous work the amplitude of 40 Hz was compared to the amplitudes of 37 -39 and 41 -43 Hz using a criterion F ratio of 10.92 (p < 0.01, approx. 10 dB SNR [15]). Instead, we employed a significance test based on Hotelling T 2 that compares the amplitude of the target frequency bin to its variation across epochs [13], [16], [17], [18]. This alternative method has the benefit of avoiding the inclusion of (or being close to) 50 Hz in the 'noise' frequencies, since some of our frequencies of interest were as high as 47 Hz, and recordings sometimes exhibited the U.K. 50-Hz mains power despite the shielding of the EEG recording booth. Similar to our previous F-ratio approach, the alpha threshold for significance was set to 0.01 instead of the standard 0.05 to reduce the chance of type 1 errors (false positives).

We additionally employed bootstrapping [19] to visualise significance and robustness of individual conditions, as has been used previously for evoked potentials [20] and employed here for steady-state responses in the frequency domain. The analysis pipeline was conducted on subsets of the full-epoch datasets by sampling 1-second epochs with replacement to retain the same total number of epochs. During data collection and for use with real-time analysis, this bootstrapping procedure was only conducted with 10-50 repetitions to allow the computer sufficient time to plot the results in real time. However in post-processing this was done 1000 times. This allowed for calculations of 95% confidence intervals for amplitude and phase values of target frequency bins by ordering the 1000 permutated amplitude and/or phase values in ascending order and identifying the minimum and maximum from the central 950 values. This procedure was also employed for the group delay calculations described below (see experiment 1 methods).

Modelling Approach

Two phenomenological models of the auditory nerve's response to electrical stimulation were used. The first model is based on Brochier et al (BR22) and includes spike-rate adaptation and refractoriness [21], while the second is based on Joshi et al (JO17) and also includes facilitation and accommodation [22]. These served as complementary investigations for each experiment, . and were used either to investigate mechanistic explanations for observed results, or to guide parameters for following experiments. This follows work from a preliminary study where we investigated the possible contribution of auditory-nerve refractoriness and/or facilitation to NDR generation at different IPIs [23]. The simulations showed that at short inter-pulse intervals such as used here, NDR generation was primarily driven by facilitation / summation between the F1 and F2 primaries in the JO17 model, while it was primarily driven by refractoriness / masking in the BR22 model.

The BR22 model consists of 1500 neurons distributed along the cochlea. For each combination of stimulating electrode and neuron, a look-up table (re-used from Brochier et al.) gives a probability of firing as a function of input current level, based on an inverse cumulative density function of a normal distribution. The 50-% point of each of these functions was derived in that study using single pulses and a combination of a finite-element method conduction model and a cable model of the auditory nerve. The relative spread (~slope) of these functions differs from neuron to neuron and matches group statistics from cat auditory nerve recordings. A stochastic process generates spikes based on such probabilities of firing / look-up table, and if a spike is generated, the input level is elevated to reflect refractoriness and spike-rate adaptation. Absolute refractoriness lasts 700 μs [24], [25], relative refractoriness is modelled by a 6-dB decreased in input current level going back to 0 dB with a time constant of 1.5 ms.

We adjusted both the absolute refractory period and relative refractory time constant to 200 μs, as described in Guérit et al [23], to better fit the effect of inter-pulse interval on the NDR as reported by Guérit et al [11], [26]. This modification is also roughly consistent with recent evidence from ECAP experiments that auditory nerve populations may have absolute refractory periods as short as 300 μs [27]. This however had negligible impact in this study, where all the IPIs where < 200 µs. Adaptation is modelled by two exponential decreases in input stimulation level thresholds with respective time constants of 23 and 212 ms. In the original publication, this was followed by a central integration window and an automatic speech recognition stage, but we ignored these stages here and only analysed the raw "auditory-nerve" spike neurograms.

We created a population-response version of the JO17 model by creating 1500 neurons, matching the single-pulse 50-% firing probabilities of the BR22 model as a function of neuron, stimulating electrode, and level. The original JO17 model consists of two leaky-integrate-andfire neurons, respectively anodic-and cathodic-sensitive. Time constants of facilitation (~200 µs), refractoriness (600 µs absolute, up to 4-5 ms relative), accommodation and spike-rate adaptation are not parameters per se, but consequences of the time constants of integration, amounts of leakiness and type of noise in the leaky integrate-and-fire process. They match single-fibre cat recordings.

For both models, across all experiments and unless otherwise stated, two seconds of interleaved, amplitude-modulated biphasic pulse-train stimuli (designed to replicate the experimental stimuli) were processed with 60 repetitions. The first second of each segment was ignored to omit any contribution of an onset response and capture only the steady-state output. The modelled neural responses were then cut in 1-second epochs, averaged, summed across all neurons, and the amplitude and phase at the frequencies of interest were extracted . with an fft with 1-Hz resolution, as was done for the EEG analysis. Levels were set to recruit approximately 10% of the neurons, which also meant that all modelled NDRs were significantly above the noise floor (assessed with an F test). Both original models are available in open access (BR22: https://gitlab.developers.cam.ac.uk/chg/models/brochier-phenomenological; JO17: https://github.com/neurongeek/ANF-model), as are the modified versions used here [28].

Experiment 1: quadratic vs cubic nature of the neural distortion

Experimental Methods:

Experiment 1 separated the quadratic and cubic distortion products so as to determine whether both contributed to the observed NDR described by Carlyon et al [9] and Guérit et al [11], and if so, if they differed in amplitude, phase, and group delay. Twelve CI users took part, two of whom were bilaterally implanted and participated with both ears for a total of fourteen ears (see Table 1).

The nominal-frequency pairs for isolated quadratic (F2-F1) and cubic (2*F1-F2) distortionproduct frequencies were 82 & 120 Hz for F1 and F2, respectively, likewise shifted to 76 & 111 Hz and 88 & 129 Hz to calculate the group delays for the QDR (35, 38, and 41 Hz) and CDR (41, 44, and 47 Hz). The AM pulse train carrier rate for each F1 & F2 pair was always set to 4*F2 (444, 480, and 516 Hz), resulting in overall stimulation rates of 888, 920, and 1032 pps, respectively. Amplitude modulation was applied using 0.5*[1 + sin(2π * fmod*t + ϕ)], initiated with ϕ = 0π at the start of each 1-second epoch (see Figure 1b), consistent with the AM approach used in previous work presented by Carlyon et al and Guérit et al [9], [11].

Experiment 2: maximising constructive interference; the effects of relative AM phase

The objective of experiment 2 was to determine whether there was an effect of the relative AM phase of the two AM pulse trains on the amplitude of the neural distortion response when the QDR and CDR were confounded (i.e. at the same frequency). If this effect exists, it was also of interest to determine the optimal relative AM phase of the two AM pulse trains to achieve the highest NDR amplitude and therefore also the highest SNR.

In earlier experiments (i.e. Carlyon et al, 2021; Guérit et al, 2023) the amplitude modulation of the F1 and F2 pulse trains was implemented using sin() with starting phases of ϕ=0, resulting in the mid-amplitude portions of the two envelopes being temporally aligned (as in Figure 5b).

For simplicity and for Experiment 2 onward, the amplitude modulation was implemented using cos() to allow for maxima to be aligned with starting phases of ϕ=0. This experiment was guided by modelling predictions done prior to the experimental portion.

The second objective was therefore to compare the observed results with the modelling predictions to investigate which temporal dependency (i.e. refractoriness or facilitation) is most likely to undo the interleaving of the stimulus and give rise to the distortion response.

Experiment 4: The effect of alternating polarity

The objective of the fourth and final experiment was to assess the effect on the NDR of alternating the leading polarity of the two interleaved, AM pulse trains. In all of the experiments reported so far the biphasic F1 and F2 pulses were always in cathodic-leading polarity, with the result that for each pulse pair the adjacent phases of the two pulses had opposite polarity. Here we compare this "fixed polarity" stimulation to an "alternating polarity" condition where the second pulse in each pair was anodic-leading, potentially producing summation between the two central anodic phases. Evidence for this increased facilitation or summation comes from a psychophysical experiment by Macherey et al who reported substantially lower MCLs for trains of pulse pairs where the central phases were anodic compared to when one was anodic and the other cathodic [29].

The hypothesis was that for the same stimulating current levels, the constructive betweenpulse interaction in this second 'alternating-polarity' condition would result in a larger NDR amplitude than in the control condition where both stimulating pulses had a cathodic-leading polarity. Another model-based hypothesis was that if the alternating polarity leads to a large amount of facilitation, such that this mechanism comes to dominate the between-pulse interaction between F1 and F2 components, the phase of the NDR response may change compared to the same-polarity condition. This is because the models predicted that if facilitation dominates the NDR generation (as in JO17) in the alternating-polarity condition, the NDR phase should be shifted by π compared to the fixed-polarity condition where refractoriness dominates NDR generation (as in BR22, see Figure 6b).

Modelling Methods:

For this experiment, two conditions were assessed with the JO17 model. Both used a stimulus onset asynchrony (SOA) of 100 μs instead of the 200 μs used in experiments 1-3. This was shortened to reduce the time between stimulating pulse phases in the F1-F2 pulse pairs to a range where the responsive neurons may more-effectively integrate the charge of temporally adjacent pulses. The control "fixed polarity" (FP) condition used biphasic stimulating pulses using an anodic leading polarity, whereas in the 'alternating-polarity' (AP) condition the second (F2) biphasic pulses' leading polarities were set to cathodic and the resulting F1-F2 pulse-pairs contained a central cathodic phase. This was done because the JO17 model is fit using parameters determined from deafened animals, where cathodic stimulation is more effective than anodic stimulation [30], opposite to what is commonly seen in humans [31]. Phase durations of 25 μs and inter-phase-gaps of 8 μs were used, resulting in an inter-pulse interval (IPI) of 42 μs. The BR22 model was not included because it does not contain polarity sensitivity and therefore would not be able to assess the effect of this manipulation.

As in experiments 2 and 4, the JO17 model was run for 2 seconds (with the 1 st onset second discarded from analysis) for 60 repetitions, to allow for characterisation of variability.

For the experimental stimulation, a control condition was included with all biphasic stimulating pulses using a cathodic leading polarity, as in all previous experiments. Discussion

Summary

We explored mechanisms underlying the generation of neural distortions (NDRs) to stimulation with alternating-frequency, interleaved, amplitude-modulated pulse trains ("ALFIES" stimuli) in cochlear implant users. The results provide insight into the temporal integrations at play, in addition to highlighting stimulation parameters important for optimising the SNR of NDRs.

The first experiment demonstrated that both quadratic and cubic neural-distortion responses can be observed using the ALFIES technique. Previous work had not isolated multiple distortion products [9], [11], whereas here the F1 frequency was shifted from 80 to 82 to isolate QDRs (38 Hz) and CDRs (44 Hz) from each other. Quadratic distortions were generally larger and more frequently observed than cubic distortions.

The observation of a relatively consistent phase difference between the QDR and CDRs (and therefore of possible cancellation between the two) inspired the second experiment. That revealed an effect of relative AM phase between the F1-and F2-AM modulated pulse trains on the amplitude of the NDR (when QDR and CDR are constrained to the same frequency). At the group level, the highest SNRs were observed when the maxima of the AM were aligned between the two interleaved pulse trains. A comparison of the data to the predictions of two computational models provided evidence that refractoriness (but not facilitation) was likely responsible for the interaction between F1 and F2 pulse trains that was necessary for NDR generation. Experiment 2 also showed that optimal selection of relative-AM phase can give rise to ALFIES NDR amplitudes comparable to those observed from eASSRs with the same stimulation parameters (within a 2.65 dB window).

The third experiment investigated interaction effects between separated distortion products and relative AM phase. It showed that, at the group level, the NDRs when the CDR and QDR fell at the frequency were consistent with a simple sum of the two components. However this conclusion was tempered by the small sample size and idiosyncratic effects of relative phase in some participants. The fourth and final experiment investigated the effects of alternating the leading polarity between the F1 and F2 pulses to create a centrally effective phase. This manipulation produced idiosyncratic effects across participants, resulting in increases ranging between 3.2 and 11.1 dB in the NDR amplitude relative to the fixed-phase condition in 4 participants, with no effect in the remaining 5; this effect did not survive correction for multiple comparisons at the group level.

Limitations and theoretical implications

The experimental and modelling results presented here indicate that refractoriness could account both for the interaction between F1 and F2 pulses and the nonlinearity that are necessary for the generation of an NDR. If this is correct, it shows that the NDR can arise from a single process in which the temporal dependency and nonlinearity are not separate processes, as originally assumed, but intertwined. In the context of the BR22 model, this arises from spike generation which is inherently nonlinear (incorporating rectification, as there are no 'negative spikes') on one hand, and leads to refractoriness (a temporal dependency) on the . other. However, it is not possible to rule out alternative or additional mechanisms. For example, at the level of the auditory nerve the effects of accommodation may be qualitatively similar to those of refractoriness, in that the response to a pulse may be reduced by the presentation of a preceding, high-amplitude pulse. However, evidence against this explanation comes from findings that accommodation -at least in animal studies -increases with increasing inter-pulse interval up to about 500 μs, whereas the NDR is constant for IPIs between 8 and about 200-400 us, after which it decreases [11]. In addition, the fact that scalpbased EEG recordings are less sensitive to auditory-nerve and brainstem responses than to cortical responses means that we are necessarily recording the cumulative effects of multiple processing stages, any or all of which may be highly nonlinear. What we can conclude, however, is that the temporal dependencies necessary for the NDR generation are likely present at the level of the auditory nerve, and that the spike generation and refractoriness known to operate at that level are sufficient to explain the pattern of results described here and previously. Future experiments either with implanted recording electrodes in animals or perhaps tympanic-membrane electrodes with humans may be able to more selectively measure the effects of peripheral processes in isolation.

A second consideration is that the present results were obtained at a single pulse rate and (except for experiment 4) a single IPI of 200 μs. It is therefore possible that the relative roles of refractoriness and facilitation would be different at either shorter or longer IPIs. However, a re-analysis of the data reported by Guérit et al [11] revealed that the phase of the NDR was approximately constant for IPIs ranging from 8 to 948 μs (not shown here). As argued due to the modelling results from Experiment 2, a change in dominant mechanism between refractoriness and facilitation would lead to a phase shift, and this was not observed here.

Practical and clinical implications

Both the eASSR and ALFIES have been proposed as objective measures of loudness [11], [14], [32], with the potential clinical application of informing the audiological fitting of MCLs in patients unable to make reliable subjective responses. For example, the eASSR has been shown to correlate with acoustic ASSRs and subjective loudness judgements in patients with a CI in one ear and normal hearing in the other [33], and the slope of the eASSR amplitude growth function correlates with the subjective dynamic range in long-term CI users [14]. However the eASSR requires high-rate sampling systems to isolate the neural response from the CI electrical artefacts, is limited to moderate carrier pulse rates, and produces artefacts that are larger when recorded ipsilateral compared to contralateral to the CI. ALFIES overcomes these problems but, in previous studies, produced an NDR that had a lower amplitude than the eASSR. The present study shows that a judicious choice of relative phase increases the NDR amplitude so as to be comparable to the eASSR, while largely avoiding the electrical artefact and allowing measurement using a technique that permits wide range of pulse rates and recording montages.
