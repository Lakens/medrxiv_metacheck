Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

This module searches for statements of ethics approval, IRB approval, institutional review board approval, and related terms.

Patterns are designed to capture:

IRB and IEC are kept unconstrained as they are not observed to collide in practice. - Dutch: Medisch-ethische toetsingscommissie (METC) - French: Comité d'éthique / Comité d'Ethique

Animal research committee names - Institutional Animal Care and Use Committee / IACUC (US standard) - Any sentence containing animal(s) and committee (or board/panel) within ~5 words of each other — catches Experimental Animal Care and Use Committee, Animal Ethics Committee, Animal Welfare Board, Animal Welfare Ethical Review Body, etc. - UK: Animal Welfare Ethical Review Body / AWERB - Dutch: Dierexperimentencommissie / DEC (see DEC constraint above); Instantie voor Dierenwelzijn / IvD - German: Tierversuchskommission / TvK (advisory committee under §15 Tierschutzgesetz) - French: Comité d'éthique en expérimentation animale / CEEA; Comité d'éthique animale - Spanish: Comité de ética en experimentación animal / CEEA

Waiver / exemption - Ethics/Ethical (waiver|exemption) - IRB (waiver|exemption|exempt) - Exempted from (ethics|irb|institutional review) - Waived by the (ethics|irb|institutional|review) (committee|board) - Deemed exempt

Declaration of Helsinki - Declaration of Helsinki / Helsinki Declaration

How Power Analysis Check works

This module uses regular expressions to identify sentences that contain a statistical power analysis. If specified by the user, it also uses a large language model (LLM) to extract information reported in power analyses, including the statistical test, sample size, alpha level, desired level of power, and magnitude and type of effect size.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.), reported as exactly zero (e.g., p = .000), or impossible (below 0 or above 1, e.g., p = -.22).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold”, “legend” or “named”).

A p-value with the name of a correction or a test after the p (“pFWE < .05”, “padj < 0.05”, “p Wilcoxon = .02”) is flagged only when a test statistic comes before it in its clause (“t(37) = 7.17, p FWE < .05”). Without one it is mostly the rule that decided what was significant (“genes with padj < 0.05 were selected”); such a p-value is “named” in not_a_test. Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

A p-value below 0 or above 1 is impossible; it is listed apart and not also as imprecise. Often the statistic before it, or its minus sign, was copied into it (“t(134) = -2.32, p = -.13”, “Z = 3.091, P = 3.091”). A value above 1 is listed only after a test statistic in its clause: without one, a “P” above 1 was nearly always another quantity (a proportion, pH, a group’s mean, a model parameter). A number in scientific notation whose power of ten was lost when the PDF was read (“p = 2.4 x 10 -9” read as 2.4) is not listed. A “p” that is the subscript of another symbol (“r p = .64”, “²p = .02” for partial eta squared, “Δp = .33”), or a quantity with a unit, a logarithm or a ratio (“P = 2.9 µm”, “-log10 P = 7.5”, “Ca/P = 1.67”), is not read as a p-value at all (see extract_p_values()). Each p-value has its own row, also when the same one is written twice in a sentence.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

This module retrieves information from repositories.

A Handle link (hdl.handle.net/...) that leads to a repository read here is checked as a link to that repository ([handle_links()]).

Listing a repository’s files never requires an API key, but some hosts answer faster or more completely with one: OSF allows 100 requests/hour unauthenticated versus 10,000/day with a token (see [osf_pat()]), and Dryad enforces a strict per-IP daily quota on repeated listing (see cache below). Dryad is a special case beyond rate limits: listing a Dryad dataset’s files works without a key, but actually downloading file CONTENTS from Dryad fails with HTTP 401 unless a key is set, even for a fully public dataset (see [dryad_pat()] or [dryad_auth()]). The ownership table gives, for every repository linked in the text and (with references = TRUE) every deposit cited in the reference list, one of six labels: own_this (made by the authors for this paper), own_earlier_data or own_earlier_code (the authors’ own, from earlier work), others_data or others_code (made by other people, reused here), or not_data (a publication such as a preprint, not a deposit), with ownership_group (“own”, “others”, “not_data”) and the reason. It is decided without a language model, from the sentence or reference that cites the link, the paper’s authors (names, ORCID iDs, affiliations), and what the deposit’s own record and files say (who made it, what it names, when, whether it is a software package; for an OSF project cited only in the reference list, its record alone). Telling this paper’s own deposit from the authors’ earlier one is less certain.

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Column extraction requires files to be readable from disk. Files fetched by repo_check from OSF/GitHub/etc. without a local copy (file_location is NA) are classified but not column-extracted; pass local_path to point at a downloaded copy of the repository.

For a paper whose repository is on Dryad, this means column extraction never happens unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (dataset listing and metadata do not need one). Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

Every downloaded text file the authors wrote (code, settings, survey definitions such as Qualtrics .qsf files, documentation, outputs) is searched for keys: API keys, access tokens and private keys, which let anyone who downloads the file use a paid service at the authors’ cost. Of a tabular data file only the column names and first 3 rows of the table as read are searched: its values come from participants, but a key the authors set for a whole survey (as embedded data in a Qualtrics survey flow) is exported in every response. The search uses the rules of the secret scanner betterleaks (https://github.com/betterleaks/betterleaks, MIT licence) of high and medium confidence. A key found turns the traffic light red; the report and the keys table give its file, line and type, and only its beginning. Other files over 25 MB and binary files are not searched. A key is never tested with its provider. Every module’s result has any whole key replaced by “keyremoved” (see module_run()).

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability).

Provenance, kept so that a TRACE Research Object (TRO) declaration of the run can be written later from a stored result (metacheck #404; the helpers are in R/provenance.R). Only when code was run (execute = TRUE): * run_results$started_at, run_results$ended_at: when each run of a script started and ended (ISO 8601, UTC, milliseconds); NA for a script that was not started. A script run again in a later pass has the times of its last run. A TRO uses them for each trov:TransparentResearchPerformance. * run_results$exit_status: the exit status of the process that ran the script (0 = ended normally); NA when the process did not report one (a time limit, or Docker failing to start the container). * artifacts: one row per file, with stage (deposit: as downloaded from the repository, hashed from the downloaded file; before_run: the run folder just before the first script ran, after metacheck’s own changes, such as rewritten paths and unpacked archives; after_run: only the files the scripts made (status new), changed (changed) or removed (removed), as an unchanged file is the one listed before the run), path (relative to the run folder, as valid UTF-8, a byte of another encoding written as <xx>), size (bytes), sha256, mime_type (by extension, NA when unknown), source (the file’s address in the repository, for deposit). The package libraries metacheck installs in the run folder are left out, as are metacheck’s own files there (a script’s runner, and the statistical output it writes in statistical_output/). Files metacheck itself copied or made between passes (see modifications, output_copied, file_placed) show in after_run too. A TRO uses the rows as trov:ResearchArtifacts and each stage as a trov:ArtifactArrangement. * modifications$sha256_before, modifications$sha256_after: the hash of the changed script as downloaded and as it ran; NA when the script is not at the same path in both (a script made from an R Markdown file). * environment: the system that ran the code (trov:TransparentResearchSystem in a TRO): metacheck_version, started_at, ended_at, host (R version, platform, operating system), sandbox, network_isolated (TRUE only when every Docker run had --network none; the process sandbox does not stop the network), internet, timeout_per_script, total_timeout, python_local (the Python run outside Docker and its version), and docker: runs (for each kind of run, r_run, r_install, python_run, python_install, the image and the docker run arguments, such as --network none, --read-only, --cap-drop ALL, no-new-privileges, the process limit and the memory and processor limits) and images (for each image, its ID and digests from docker image inspect, its creation time and the R and Python versions its environment declares).

run_results$checked says what the run of each script shows about the code, in five groups, so that a script that does not reproduce is kept apart from one the check could not test: ran (it ran to the end); code_error (it did not reproduce: it stopped with an error of the code or the deposit, could not be read, or needs a file the deposit does not hold); dependency (a package or program was not available: a package that could not be installed or was not loaded, a program outside R and Python, a system library, or R crashing in a package’s compiled code); time (it did not finish within the time limit for one script, or was not started because the time for all scripts had run out); and not_checkable (it could not be checked automatically: it needs a person, the internet, a key or another setting of the authors’ computer, one platform such as Google Colab, Windows or OpenSAFELY, more memory than the run allows, a file that was not downloaded, a screen, or a program that runs it, or it is a file of a package of the code that Python runs only as a module of that package). It is NA for files run inside another script, files that are not an analysis, files not read, and a Docker failure. summary_table counts each group (repro_ran_n, repro_code_error_n, repro_dependency_n, repro_time_n, repro_not_checkable_n), and the report’s first sentence gives them. The traffic light reflects the static readiness signals by default; a script in code_error that stopped with an error makes it red, as a script that crashes on its own analysis is a genuine reproduction failure, and a script in one of the other three groups keeps it from being green. Calls that need a screen, which the run does not have (dev.print(), dev.copy2pdf(), dev.copy2eps(), savePlot(), windows(), win.graph(), x11(), quartz(), View()), are replaced before the run by calls that need none, which modifications records as screen_call_replaced. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Full text

Abstract

Preterm birth (PTB) affects 11% of pregnancies worldwide, yet the biological mechanisms underlying its etiology remain unclear. We conducted a sex-stratified epigenome-wide association study of newborn saliva DNA methylation in 273 mother-child pairs from the Peruvian Placental Abruption Genetic Epidemiology (PAGE) study. Robust linear regression models adjusted for maternal, cellular, and technical factors identified 318 and 542 ePTBassociated CpG sites and 784 and 1,401 differentially methylated regions in boys and girls, respectively, with limited overlap between sexes. Functional analyses revealed enrichment of signals in Open Sea regions and pathways related to neurodevelopment, neural function, fetal growth, cellular organization, transcription factors, and microRNAs. Several associations replicated findings from prior studies of PTB, gestational age, and postmenstrual age. These results identify sex-specific epigenetic signatures of ePTB in an Admixed-American population and highlight developmental and regulatory pathways associated with ePTB.

Introduction

Preterm birth (PTB) is a leading cause of neonatal and infant morbidity and mortality. PTB is associated with long-term health impairments for the newborn, including respiratory distress syndrome, necrotizing enterocolitis, intraventricular hemorrhage, neurodevelopmental delays and mortality in adulthood. [1] [2] [3] [4] [5] PTB affects around 11% of pregnancies worldwide, totaling nearly 15 million births. 6 Despite its substantial public health impact, the biological mechanisms underlying PTB and early PTB (ePTB), a more extreme outcome representing births occurring 34 weeks of gestation, remain insufficiently understood. Epigenetic processes, particularly DNA methylation (DNAm), are increasingly recognized as central in fetal development and may provide insight into biological pathways associated with PTB and its subsequent health consequences.

Maternal psychosocial stressors, including history of trauma exposure and mood disorders, are known risk factors for PTB and adverse neonatal outcomes. 1, [7] [8] [9] These exposures have been linked to DNAm variation in pathways related to stress regulation, immune function, and neurodevelopment, suggesting a plausible biological route through which maternal experiences shape offspring health. [10] [11] [12] [13] Although these maternal factors are not the primary focus of the present paper, they provide important context for interpreting DNAm signatures associated with PTB, particularly in populations with high psychosocial burden.

Prior epigenome-wide association studies (EWAS) have identified DNAm variation associated with gestational age, 14, 15 PTB, [16] [17] [18] postnatal morbidity, 19 and early-life neurobehavioral outcomes. 20 However, DNAm associations with ePTB specifically remain understudied. Additionally, evidence from high-risk and under-represented populations is particularly limited, even though there is a disproportionate burden of ePTB in many low-and middle-income settings. 1, 21, 22 To this end, we conducted an EWAS to identify DNAm differences between infants born early preterm compared to term-born peers using neonatal saliva DNAm collected at delivery. Our study is conducted in a deeply phenotyped cohort recruited in Lima, Peru, a population that is characterized by high rates of both maternal psychosocial stressors and of ePTB. 23, 24 By characterizing DNAm signatures of ePTB, we sought to identify biological pathways represented among ePTB-associated signals and provide a foundation for future work examining links among maternal stress, DNAm variation, and neonatal health.

Results

Baseline characteristics of the study population

The 273 mother-child dyads included in the analytic sample were similar to eligible PAGE participants on most baseline characteristics, with differences observed in newborn sex, cesarean delivery, and perceived maternal health during pregnancy (Supplementary Table 1). Description of baseline characteristics of participants included in this study is shown in Table 1. Specifically, women with an early preterm pregnancy were on average older than controls and were more likely to give birth to a boy than a girl. Infants born early preterm were on average smaller, more frequently remained in a neonatal intensive care unit (NICU), had a lower APGAR score, and were more prone to experience neonatal death than their term-born counterparts.

Genome-wide difference in newborn DNAm is associated with ePTB

We conducted EWAS stratified by sex to account for underlying variation in DNAm driven by this variable in our sample. In the boys' analysis, we identified 318 CpGs differentially methylated in association with ePTB (=1.41, Fig 1A) with effect estimates ranging from -0.22 to 0.17. There was an almost equal distribution between hypomethylated and hypermethylated signals (55% vs 45%). The strongest association based on the p-value was detected at cg00861010, located near the long non-coding RNA SLFNL1-AS1. In the girls' analysis, we identified 542 CpGs (=1.61, Fig 1B), most of them hypomethylated in relation to ePTB (64%). The effect estimates ranged from -0.22 to 0.21, and the strongest signal based on the p-value was seen at cg00221747, mapping near the maternally expressed transcript of the long non-coding RNA H19. We identified 24 CpGs in common between boys and girls, with the smallest p-value seen at cg13933718, mapping near the UNQ6494 gene.

Overall, for top CpGs, there was low correlation in the effect estimates across sex-analyses (r ranged from 0.03 to 0.08, p > 0.10). Complete results of the sex-stratified EWAS of ePTB are presented in Supplementary Tables 2 3, while Table 2 shows the top ten signals selected by p-value and effect size (absolute effect estimate > 0.1) for each sex-stratified analysis.

The negative control analysis showed lambda values considerably smaller than in the main analyses (=1.05 vs 1.4-1.6 in sex-stratified EWAS), and only two sites surpassed EWAS significance (cg20654161 and cg02294020), none of them overlapping with ePTB sites detected in our main analyses. These findings provide evidence that the main EWAS results were unlikely to be explained entirely by systematic features of the data detectable using this negative-control approach.

Identification of DMRs

We performed a DMR screen with Bonferroni correction for each sex-stratified EWAS result. This analysis revealed 1,401 DMRs in girls and 784 in boys, collectively comprising 3,482 and 2,197 CpG sites, respectively (Supplementary Tables 4 5). Among male samples, the largest DMR mapped to EGFL8 and encompassed 16 probes, all of which exhibited negative coefficients. Notably, one probe within this region was independently associated with ePTB in boys. For females, the two largest DMRs mapped to KCNQ1 and APBB1IP, each harboring 12 probes; however, neither of these DMRs contained probes significantly linked to ePTB in girls.

Enrichment analysis for genomic regions and biological pathways

Compared to other CpGs analyzed across the genome, the top CpGs associated with ePTB in the boys' and girls' analyses were more likely to be found in open sea regions than expected by chance (p<0.005; Supplementary Fig 1), rather than within CpG islands, or any other genomic region. In the boys' analysis, inspection across different functional databases revealed enrichment of ePTB-associated CpGs for various Gene Ontology (GO) biological processes (neuron development, neuron projection development, neuron differentiation, signal transduction, and cell communication), molecular functions (protein binding), cellular components (synapse, cell junction, cytoplasm), and for transcription factors (HES2, ZXDL, MAZ, ED2F3, CKROX), micro RNAs, and pathways affecting insulin-like growth factor IGF1 Akt signaling (Supplementary Fig 2, Supplementary Table 6). In the girls' analysis, genes mapping to ePTB-associated CpGs were particularly enriched for transcription factors (n=100 terms), micro-RNAs (n=28 terms), cerebral cortex and hippocampus proteins (n=4 terms), GO cellular components (cytosol, nucleoplasm, cytoplasm, cell junction) and biological processes (cellular response to stimulus and organelle organization). Enrichment was also seen for the KCNQ2 and KCNQ3 related epilepsy pathway in girls (Supplementary Fig 3, Supplementary Table 7).

Comparison of ePTB-associated CpGs with previous EWAS

We compared signals in common between our sex-stratified EWAS of ePTB and previous EWAS of gestational age (GA) and post-menstrual age (PMA) in very preterm infants (< 30 gestational weeks) 25 , PTB 6, 26 , and gestational age continuous. 27, 28 PMA is a measure of aging and neonatal development defined as the period from conception to saliva sample collection at NICU discharge. 25 We identified the largest overlap with associations reported with GA (n=35 sites in common) and PMA (n=348) in the study by Hodge et al. 25 . Most of the signals identified in common with GA were directionally consistent with our study, particularly when the comparison was done with the boys-identified ePTB associations. Some GA CpGs in common to highlight are cg07164639 (DDO), cg21658153 (TPM4), and cg00187327 (MN1), mapping to known age-related and PTB loci (Supplementary Table 8). As expected, there was disparity in the direction of associations for CpGs detected in common between ePTB and PMA across studies. Some PMA CpGs in common to highlight are cg07164639 (DDO), cg00187327, cg07222631, cg19034820 (MN1), cg09253641 (SMIM2), cg03185144 (KIAA0513), and cg17806418 (GABBR1), all located in known loci related with age, neurodevelopment, and PTB. 25, 26, 29 When looking at signals previously reported in a large meta-analysis of GA continuous (27-42 weeks) using cord-blood DNAm 28 , we found 16 CpGs in common with our ePTB study (Supplementary Table 9). More than half of these 16

CpGs showed opposite direction of association with our study, and absolute effect estimates were consistently larger in our EWAS.

We also identified some overlap between our ePTB signals and PTB-related DMRs reported by Winchester et al. 6 using buccal cell DNAm from triads. These PTB-DMR genes have a role in transcription (LDB2, CAMTA1, ZNF717, ZFHX3), cytoskeleton (CTNNA3, BTBD11), receptors (MERTK), cellular signaling (PRKDC), or other roles (CRTAC1, GPC6, LINC01170); however, there were few directional consistencies in these associations with our study. Similarly, we found an overlap at the SMIM2 gene reported by Weather et al. 27 in association with GA. Even though CpGs detected at SMIM2 differed between studies, there was consistency in the direction of associations at this locus across studies. Lastly, in the comparison with findings from Fernando et al. 26 , loci but not specific CpGs associated with PTB, were found in common at KRT78, CHN2, TBCD, KIAA0513, UVRAG, GALNT9, UVRAG, and DNAH10; 66% of these loci showed the same direction of association as in our study.

Discussion

Our study analyzed data from 273 mother-child dyads, of which 139 were cases of ePTB. Sex-stratified analyses identified 318 and 542 CpG sites with saliva methylation levels associated with ePTB in boys and girls, respectively. Most of these sites were hypomethylated, which is consistent with the literature, as increasing gestational age is associated with more hypermethylated sites. 25 Only 24 of these sites overlapped between sexes, indicating substantial sex heterogeneity in the observed associations. In secondary analyses, we identified 784 and 1,401 DMRs associated with ePTB for boys and girls, respectively. Enrichment analyses revealed further distinctions: boys exhibited enrichment of ePTB-associated pathways across well-defined biological processes, with a focus on neurodevelopment, whereas girls predominantly showed enrichment for regulatory pathways, with transcription factors and micro-RNAs being the most common pathways identified. We discuss the results separately for each sex.

Forty-five percent of the CpG sites significantly associated with ePTB in boys were hypermethylated. The most significant hypermethylated CpG site by p-value is a novel site for ePTB mapping to a long non-coding RNA region near SLFNL1 Antisense RNA 1 (SLFNL1-AS1). Experimental evidence has shown that SLFNL1-AS1 interacts with proteins encoded by HNRNPH1, a gene that plays a critical role in cancer development. 30 The two most significant hypomethylated sites were also previously unreported CpG sites, both mapping to an intergenic region near the Dopamine Receptor D1 (DRD1), which encodes the most abundant dopamine receptor in the brain and has been implicated in mental and neuronal diseases 31 . The largest DMR in boys mapped to EGF Like Domain Multiple 8 (EGFL8), a protein-coding gene associated with immune system-related diseases such as asthma and Type 1 diabetes mellitus through genome-wide association studies (GWAS). 32, 33 Up to 209 ePTB-associated CpG sites identified in boys overlapped with CpGs that were previously reported in an EWAS of GA and PMA by Hodge et al. 34 , and 12% of them showed consistent directionality between studies. Genes replicated in our study include DDO, which controls neurological homeostasis 35 , and MN1, which has evidence of tumor suppression. 36 Enrichment analysis of pathways identified many GO biological processes related to neurodevelopment in boys. Some of these pathways, such as neuron projection development and cell morphogenesis involved in neuron differentiation, were replicated by Hodge et al. 25 , while others, including neuron development and neuron differentiation, were previously unreported but clearly linked to known associated pathways. Lastly, a pathway related to insulin-like growth factor 1 (IGF1) and Akt signaling was found with enrichment among ePTB-associated CpGs in boys. This pathway is important because proteins in the IGF-axis are associated with cellular growth, proliferation, and metabolism throughout the life course, and IGF1 is particularly related with fetal growth and development 37 , and with postnatal growth. 38 These findings suggest that DNAm differences associated with ePTB may involve pathways relevant to fetal and postnatal growth.

In girls, thirty-six percent of CpG sites associated with ePTB were hypermethylated. The most significant hypermethylated CpG site was a previously unreported site mapping to an intergenic region near Ribosomal Protein S6 Kinase A5 (RPS6KA5), which regulates inflammatory response and early gene expression and can promote neuronal death. 39 The most significant hypomethylated site was a previously unreported CpG mapping to an intergenic region near the H19 Imprinted Maternally Expressed Transcript (H19) and the paternally expressed Insulin Like Growth Factor 2 (IGF2) genes. These genes are implicated in tumor suppression and fetal growth, respectively, thus pointing to their interrelated role in postnatal development and growth. 40 H19/IGF2 were also overrepresented in several significant DMRs, providing more evidence of their involvement in fetal-growth regulatory pathways linked to ePTB. The two largest DMRs, with 12 CpGs each, were nearest to KCNQ1 and APBB1IP. KCNQ1 is associated with Jervell and Lange-Nielsen Syndrome 1, a fetal cardiovascular disease. 41 APBB1IP plays a central role in T-cell activation and thus affects immune response, as well as being linked to cancer. 42 There was less replication and directional consistency of associations identified in girls with previous studies of PTB and GA. Nonetheless, we found notable overlap with Hodge et al. 34 for GABBR1. This gene has previously been linked to epilepsy. 43 Pathway enrichment analysis for ePTB-associated CpGs in girls mainly identified enrichment for micro-RNAs and transcription factors. Most micro-RNAs identified in this way were replicated by Winchester et al. 16 . Lastly, we identified a KCNQ2 and KCNQ3-related epilepsy pathway. KCNQ2 and KCNQ3 are part of a family of voltage-gated potassium channel proteins with a function in cellular excitatory activity, particularly in the brain. 44 Pathogenic variants in these genes have been associated with neonatal-onset developmental and epileptic encephalopathy (NEO-DEE), self-limited (benign) familial neonatal epilepsy (SLFNE), and with neurodevelopmental disorder with or without seizures (NDD) 45 . Benign forms of epilepsies may also occur in preterm infants. 46 Thus, findings among girls highlight epigenetic signals involving pathways relevant to fetal growth, energy regulation, and neurodevelopment.

Our study provides novel CpG sites, DMRs, and pathways associated with ePTB in an Admixed-American population. Additionally, several signals overlapped with findings from studies conducted predominantly in populations of European ancestry, suggesting that some ePTB-associated DNAm patterns may be shared across population groups. To ensure our results were robust, we controlled for cell composition and batch effects and used Bacon adjustment to reduce genomic inflation. We also thoroughly inspected for data structure and reduced latent variation in DNAm by stratifying our data and analyses by sex. To verify the reliability of our findings, we applied a negative control analysis, corrected for multiple testing using an epigenome-wide significance threshold recommended for the EPIC array, and compared our results with existing evidence. To the best of our knowledge, this is the first such study in a South American population, helping to reduce gaps in epigenetic research across populations.

Our study also has some limitations. Due to the cross-sectional study design, we cannot make causal claims, as we cannot determine from these data when DNAm differences occurred, whether before or after delivery. Even though timing of sample collection relative to delivery was known for these participants (within 72 hours), precise assessment of PMA and other markers of aging and development among preterms was not possible as we did not have information about time of discharge from the NICU. In relation to the above, differences in DNAm observed could have been associated with other pregnancy complications related to ePTB, or with stressful exposures occurring at or around delivery rather than by ePTB alone; this possibility warrants further examination. The methylation data were obtained from saliva, which may not reflect methylation in other tissues, like brain, blood, or placenta which are more often utilized for the study of fetal neurodevelopment. We identified many novel associations that may be attributable to population differences 47 and/or to higher rates of maternal prenatal stressors that could influence the relationship between ePTB and dysregulation in newborn DNAm. These possibilities require further study in similar populations.

Our study identified multiple novel epigenetic associations with ePTB in an admixed-Amerindian sample of Peruvian women, while also replicating some associations previously reported in European samples. These results suggest that ePTB-associated DNAm patterns include both signals shared with previous population groups and signals that may be population-specific or phenotype-specific. We also observed sex-specific associations with ePTB, with few signals shared between boys and girls. In both cases, most differentially methylated sites were hypomethylated in relation to ePTB, which is consistent with the existing literature (hypermethylation with increasing GA or aging). Although pathways enriched in differentially methylated genes for ePTB consistently pointed to neurodevelopment, cellular growth and function, immune response, and neurological outcomes, our results showed that for girls these processes were more influenced by regulatory elements like transcription factors and micro-RNAs, while for boys it was by the biological process or molecular function itself, suggesting sex-specific patterns in the epigenetic features associated with ePTB. Replication in independent and diverse populations, ideally with longitudinal biospecimen collection, will be important for determining the timing, reproducibility, and potential biological relevance of these associations.

Materials and Methods

Study population

Mother-child pairs included in the study were part of the Placental Abruption Genetic Epidemiology (PAGE) study, a case-control study conducted in Lima, Peru. Description of the study can be found elsewhere. 48, 49 Briefly, eligible women were recruited at delivery from seven hospitals in Lima, Peru, by reviewing admission logbooks for the emergency room, labor and delivery wards, prenatal wards, emergency, and surgery rooms of the study hospitals, between March 2013 and December 2015. Eligibility criteria included speaking Spanish, being > 18 years old, having a singleton pregnancy, and complete medical information to define ePTB status. All study participants gave their written informed consent; the study protocols were approved by the IRB of the seven participating hospitals in Lima, the Swedish Medical Center, Seattle, WA, and the Harvard T.H. Chan School of Public Health.

Data collection

Information on sociodemographic (age, employment, marital status), lifestyle (smoking and alcohol use in pregnancy), behavioral, and anthropometric variables (pre-pregnancy BMI), were gathered using structured questionnaires. Obstetric history and medical information of the current pregnancy (gestational age at delivery, gravidity, planned pregnancy, mode of delivery, birthweight, sex, discharge status, and APGAR score) were abstracted from medical records.

Definition of ePTB

Gestational age at delivery (weeks) was calculated using information from the date of the last menstrual period, and from an early fetal ultrasound and fundal height examinations performed < 20 weeks of gestation. Early preterm birth was defined following the American College of Obstetrics and Gynecology criteria as a delivery occurring 20-34 weeks of gestation. 50 Based on their pathophysiology, 51 cases are either grouped as spontaneous (45%) or with preterm premature rupture of fetal membranes (PPROM; 54%). There were no cases of medically induced PTB. Controls were women who delivered at term (> 37 weeks and < 42 weeks of gestation) and were randomly selected from the participating hospitals within 48 hours of the identification of a case.

Analytic Population

For the current study, we randomly selected 152 mom-child dyads with ePTB and 152 matched controls from the entire cohort with complete covariates of interest, and archived newborn biosamples with the highest quality of genomic DNA extracted from saliva samples collected 72 hours post-delivery (total eligible N=1,009 , n=468 with ePTB).

Processing of DNA methylation data

Newborn buccal cells were collected post-delivery, plated, and stored using the Oragene™saliva cell collection kits (OGR250, DNA Genotek Ottawa, Canada). Samples were processed at Roswell Park Comprehensive Cancer Center (Buffalo, NY) for DNA extraction using Qiagen DNeasy™ system (Qiagen, Valencia, CA), and DNA methylation quantification using llumina MethylationEPIC v2 Beadarray (Illumina, San Diego, CA). For DNAm assessment, 500 ng of genomic DNA from each sample was plated at random into 96-well plates, followed by bisulphite conversion treatment using the Zymo EZ DNA methylation kit. This was followed by amplification, fragmentation, hybridization, single-base extension, and staining. Methylation levels were analyzed at 937,055 CpGs across the genome.

Before analyses, DNAm data were pre-processed using the meffil R package, 52 where probes were quantile normalized using the first twenty principal components (PC) from the control probe matrix, and samples excluded based on outliers for the median methylated or unmethylated signal (n=1), sex-mismatch between reported and predicted sex (n=15), and X-Y ratio outliers (n=5). Probes with detection p-value > 0.01 (n=1,937) and bead number lower than three (n=90) in more than 20% of the samples were excluded. In addition, n=824 probes (nv-GRCh3 probes) with missing values for all the samples were excluded. After exclusions, 284 samples and 927,761 probes remained for the analysis. The proportion of epithelial cells and seven immune cell types was calculated from DNAm using a saliva reference panel. 53 We inspected for factors driving underlying variation in DNAm by plotting the first two PCs derived from the 20,000 most variable probes, against different confounding factors. We identified that sex was driving a large proportion of the underlying variation in DNAm. Thus, our main analysis was stratified by sex.

Covariates

We selected covariates a priori based on supporting literature, and by inspection of variability and multicollinearity. We included as covariates maternal age (missing n=2), gravidity (missing n=3), pre-pregnancy BMI (Kg/m 2 ) (missing n=5), and employment in pregnancy (missing n=1), as these are established confounders in prenatal epigenetic studies, and known risk factors for PTB. 28, 54, 55 In addition, we adjusted for batch effects and the proportion of epithelial cells and seven immune cell types predicted using DNAm data. 53 We did not include ethnicity (most participants were mixed Amerindian and European descent by genetic ancestry analysis) 48 and maternal smoking (< 3% smokers) as covariates, as they showed low variability in our sample. Newborn sex was used as the stratification factor in our main analysis. After exclusion of missing values for covariates, 273 (ePTB=139, controls=134) samples with high-quality DNAm remained in the study for analysis.

Statistical Analysis

We described the characteristics of participants using the mean and standard deviation (SD), or frequency and proportions. We conducted epigenome-wide assessment of differential methylation at the individual CpG sites in relation to ePTB using fitted robust linear regressions stratified by sex (boys=139, girls=134) in the ewaff R package. 56 In this analysis, DNAm Beta (range 0 to 1) were modelled as the response variable, and the binary event of ePTB as the predictor. The confounders described above were included in the models. We controlled for batch effects and non-biological variability remaining in the DNAm matrix using a surrogate variable analysis (n=10 SVs). 57 Fitted robust linear regression was used to account for potential heteroskedasticity in the DNAm distribution. We calculated the genomic inflation factor (γ) using the ratio of the median observed versus the median expected chi-square test statistic distribution from the EWAS p-values. To reduce remaining variance in the test statistic and the likelihood of false positives, estimates of the EWAS were further corrected using bacon adjustment. 58 To account for multiple testing, statistical significance was defined using a p-value threshold < 9.4x10 -8 , consistent with recommendations for the Illumina EPIC array. 59 "Top CpGs" were defined based on p-value and an absolute effect estimate > 0.1. EWAS results were visualized using Manhattan, volcano, and Q-Q plots generated using the meffil and ggplot2 R packages. Association estimates were presented for top CpGs unique to each sex-stratified analysis, and for signals shared between analyses. All analyses were conducted in R 4.5.1.

In a sensitivity analysis, we checked for systematic sources of bias in our data by conducting a negative control analysis. In this analysis, we used the complete sample (N=273 dyads), permuted ePTB status, adjusted for the same covariates as in the main analysis, and tested for genome-wide associations. Obtaining similar results between the negative control analysis and the main analysis would suggest the presence of residual confounding in the main analysis or other systematic sources of bias still present in the data.

Secondary analyses

We examined the biological function of signals detected in the EWAS of ePTB by conducting a series of functional inspections. First, to account for the correlation between CpGs across the genome, and to more comprehensively examine associations, we looked at genomic regions rather than individual CpGs by conducting a differentially methylated regional (DMR) analysis using dmrff R package. 60 We selected robustly associated DMRs at regional Bonferroni-adjusted p < 0.05 and CpG count above one. For top CpGs of the sex-stratified EWAS, we performed enrichment analysis for genomic regions using Illumina annotations, and enrichment for genes and biological pathways using gprofiler2 R package. 61 Enrichment was deemed at FDR < 0.05 after multiple-testing correction from log 2 (OR) tests. We also identified overlap between top CpGs identified in our EWAS, and top sites reported in previous epigenetic studies of PTB and/or ePTB and gestational age. 6, [25] [26] [27] For associations identified in common, we compared directionality consistency between studies.
