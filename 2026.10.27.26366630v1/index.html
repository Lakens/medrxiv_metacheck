Reporting p values imprecisely (e.g., p < .05) reduces transparency, reproducibility, and re-use (e.g., in p value meta-analyses). Best practice is to report exact p-values with three decimal places (e.g., p = .032) unless p values are smaller than 0.001, in which case you can use p < .001.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (e.g., “decreased at the p < .05 significance threshold”).

How Power Analysis Check works

This module uses regular expressions to identify sentences that contain a statistical power analysis. If specified by the user, it also uses a large language model (LLM) to extract information reported in power analyses, including the statistical test, sample size, alpha level, desired level of power, and magnitude and type of effect size.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. With the use of an LLM, it checks if the power analysis is reported with all required information.

The regular expressions can miss power analyses, or fail to classify them correctly. The type of power analysis is often difficult to classify, which can easily be solved by explicitly specifying the type of power analysis as ‘a-priori’, ‘sensitivity’, or ‘post-hoc’. Note that ‘post-hoc’ or ‘observed’ power is rarely useful. The LLM can fail to identify information in the paper, and will not have access to information in paragraphs in the paper other than those that contain the word ‘power’. The Preregistration Check module identifies preregistrations on the OSF and AsPredicted based on links in the manuscript, retrieves the preregistration text, and organizes the information into a template. How Marginal Significance works

List all sentences that describe an effect as ‘marginally significant’.

The marginal module searches for regular expressions that match a predefined pattern. The list of terms is a subset of those listed in a blog post by Matthew Hankins. The module returns all sentences that match terms describing ‘marginally significant’ results.

Some of the terms identified might not be problematic in some contexts, and there are ways to describe ‘marginal significance’ that are not detected by the module.

How StatCheck works

Check consistency of p-values and test statistics

The Statcheck module runs Statcheck. Statcheck searches for regular expressions that match a predefined pattern, and identifies APA reported statistical tests. More information on the package can be found at https://github.com/cran/statcheck. The module only returns Statcheck results for t-tests and F-tests, as these are the only tests which have been validated, see https://osf.io/preprints/psyarxiv/tcxaj_v1/.

Statcheck was developed by Michèle Nuijten and Sascha Epskamp.

Statcheck considers p = 0.000 an error, as you should report p < 0.001. Furthermore, p < 0.03 is an error if the p-value was 0.031, and one should simply report exact p-values (p = 0.031). When the sentence of a test says it is one-sided (“one-tailed”, “one-sided” or “directional”), a p-value that fits a one-sided test counts as consistent (statcheck’s OneTailedTxt setting; #695). When the paper says anywhere that its tests are one-sided, a p-value that fits a one-sided test in either direction counts as consistent too: half the two-sided p, or 1 minus that half for an effect against the predicted direction. Equivalence tests (TOST) are left out, as their p-values do not test the difference. A statistic written with “<” or “>” is read as a bound, and in a sentence about equal variances an F-test’s two-sided p (twice the one-tailed p) counts as consistent. For more information, see StatCheck.

This module only checks statistical results reported in the running text of the manuscript. It cannot (yet) process statistics reported only in tables.

This module was developed by Daniel Lakens and Lisa DeBruine

Read more in the metacheck manual.

Validation: In a sample of 685 tests with 34 instances of inconsistent reporting, Statcheck correctly detected 34 of them, and incorrectly identified 26. Therefore 0% of true instances were missed, and 43% of detections were false positives. See https://osf.io/preprints/psyarxiv/tcxaj_v1/ for more details of the validation.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.), reported as exactly zero (e.g., p = .000), or impossible (below 0 or above 1, e.g., p = -.22).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold”, “legend” or “named”).

A p-value with the name of a correction or a test after the p (“pFWE < .05”, “padj < 0.05”, “p Wilcoxon = .02”) is flagged only when a test statistic comes before it in its clause (“t(37) = 7.17, p FWE < .05”). Without one it is mostly the rule that decided what was significant (“genes with padj < 0.05 were selected”); such a p-value is “named” in not_a_test. Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

A p-value below 0 or above 1 is impossible; it is listed apart and not also as imprecise. Often the statistic before it, or its minus sign, was copied into it (“t(134) = -2.32, p = -.13”, “Z = 3.091, P = 3.091”). A value above 1 is listed only after a test statistic in its clause: without one, a “P” above 1 was nearly always another quantity (a proportion, pH, a group’s mean, a model parameter). A number in scientific notation whose power of ten was lost when the PDF was read (“p = 2.4 x 10 -9” read as 2.4) is not listed. A “p” that is the subscript of another symbol (“r p = .64”, “²p = .02” for partial eta squared, “Δp = .33”), or a quantity with a unit, a logarithm or a ratio (“P = 2.9 µm”, “-log10 P = 7.5”, “Ca/P = 1.67”), is not read as a p-value at all (see extract_p_values()). Each p-value has its own row, also when the same one is written twice in a sentence.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

This module was developed by Lisa DeBruine and Daniel Lakens

Read more in the metacheck manual.

How Non-Significant P Value Check works

This module checks for imprecisely reported p values. If p > .05 is detected, it warns for misinterpretations.

The nonsignificant p-value check searches for regular expressions that match a predefined pattern. The module identifies all p-values in a manuscript and selects those that are not reported to be smaller than or equal to 0.05. It returns all sentences containing non-significant p-values.

In the future, the Metacheck team aims to incorporate a machine learning classifier to only return sentences likely to contain misinterpretations. If you want to help to improve the module, reach out to the Metacheck development team.

A p-value in a table note (“† p < .10, * p < .05”) or a figure legend (“dashed lines indicate non-significant paths (p > .05)”) is left out, as in stat_p_exact; the column not_a_test says why. A p-value next to words that state a threshold is kept, because such sentences often report a result against that level (“not significant at the conventional threshold (p = .054)”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables.

How codebook_check works

This module checks whether the data columns in a repository are documented in a codebook or README. It locates codebook/readme files, extracts the variable definitions they contain, matches those definitions against the data columns extracted by data_check, and reports documentation coverage: how many data columns are documented, and which documented variables are never used.

The Codebook Check module consumes the columns and file classification produced by data_check (and, transitively, repo_check). Files classified as codebook or readme are parsed with parse_codebook(), which reads structured tables (CSV/TSV/Excel with a variable-name column and a label column), embedded labels in haven files (SPSS/Stata/SAS), and plain text from rich-text formats (docx/pdf/rtf/odt). Embedded haven labels from data files are also harvested directly.

Each data column is then matched against the parsed variable definitions with match_column_labels(), using normalised-name matching with experiment-group scoping, haven-label priority, and rule-based label-equivalence merging.

Beyond the variable label, the module harvests the DDI-style per-variable properties a source supplies: the value labels / code list (the 1=“Strongly disagree”…5=“Strongly agree” mapping — from SPSS/Stata value labels and from a codebook “values”/“coding” column), the missing-value scheme (which codes denote missingness, from haven declared missings and labels that read as “refused”/“n/a”), and question text and columns when present. These are carried onto the matched data columns and exported into the Psych-DS variableMeasured (as a schema.org code list plus namespaced metacheck: fields).

The module defaults to rules-only when llm_use(FALSE). When llm_use(TRUE), three optional LLM tiers run: parsing unstructured codebook text that the rules could not handle, fuzzy-matching still-unlabelled columns to still-unmatched codebook variables, and merging conflicting label definitions into a single canonical label.

How repo_check works

This module retrieves information from repositories.

The Repository Check module lists files on the OSF, GitHub, ResearchBox, DSpace (PsychArchives and other legacy- and DSpace 7-based installations), Zenodo, Dataverse, Figshare, Dryad, ReShare, 4TU.ResearchData, Mendeley Data, DataONE (Arctic Data Center, KNB, and other member nodes), and LDbase based on links in the manuscript.

A link to a file-sharing service (Google Drive, Dropbox, OneDrive, Box, WeTransfer, MEGA, iCloud Drive, Baidu Netdisk, SURFdrive; see [file_share_links()]) gets a warning and makes the light yellow: such services are not repositories, as files can be changed or deleted at any time, get no DOI, and the link stops working when the account is closed. The report advises a stable repository such as Zenodo instead. Their files are not read, and summary_table$file_share_n counts the links.

Deposits in archives for sequence and expression data (GEO, the INSDC archives BioProject, SRA, ENA and DDBJ, and ArrayExpress; see [seq_archive_links()]), mostly named by accession number, are read for whose deposit they are. The authors’ own are listed with what they hold ([seq_archive_size()]) and are not downloaded or checked as data and code; summary_table$archive_own_n counts them.

R packages on CRAN ([cran_links()], [cran_info()]) are the paper’s own when a paper author is a package author and the paper presents the package; the paper’s own are listed with their version and not checked (summary_table$cran_own_n). A Handle link (hdl.handle.net/...) that leads to a repository read here is checked as a link to that repository ([handle_links()]).

Listing a repository’s files never requires an API key, but some hosts answer faster or more completely with one: OSF allows 100 requests/hour unauthenticated versus 10,000/day with a token (see [osf_pat()]), and Dryad enforces a strict per-IP daily quota on repeated listing (see cache below). Dryad is a special case beyond rate limits: listing a Dryad dataset’s files works without a key, but actually downloading file CONTENTS from Dryad fails with HTTP 401 unless a key is set, even for a fully public dataset (see [dryad_pat()] or [dryad_auth()]). Since this module only lists files and never downloads their contents itself, that limitation applies to data_check and code_check (which do download content), not here – see their own documentation.

When a linked OSF page is a registration, its registered_from project (the one it was registered from, which the manuscript itself may never link directly) is also checked: if that project is public its files are listed under its own URL, and if it is closed or otherwise inaccessible the report flags it explicitly, since some registrations only describe their content rather than mirroring it.

Whose deposit is each link? The ownership table gives, for every repository linked in the text and (with references = TRUE) every deposit cited in the reference list, one of six labels: own_this (made by the authors for this paper), own_earlier_data or own_earlier_code (the authors’ own, from earlier work), others_data or others_code (made by other people, reused here), or not_data (a publication such as a preprint, not a deposit), with ownership_group (“own”, “others”, “not_data”) and the reason. It is decided without a language model, from the sentence or reference that cites the link, the paper’s authors (names, ORCID iDs, affiliations), and what the deposit’s own record and files say (who made it, what it names, when, whether it is a software package; for an OSF project cited only in the reference list, its record alone). On a round of labelled links the rules had not been written from, the three groups were right for 98% of links in the main text (93 of 95) and 90% in reference lists (74 of 82); the labels were made by Claude agents from each link’s evidence, and disputed ones checked against the deposits. Telling this paper’s own deposit from the authors’ earlier one is less certain.

Only the deposits that are this paper’s own are checked. A deposit linked in the text that holds other people’s work (others_data, others_code) or the authors’ earlier work (own_earlier_data, own_earlier_code) is listed in the report, with the reason, but its files are left out of table and kept in table_not_checked: they count toward nothing here (files that do not belong in a repository, naming, READMEs, studies, the traffic light), and code_check, data_check and reproducibility_check, which read table, do not check them either. reproducibility_check still puts the files of theirs that the paper’s code names in the folder the code runs in, as a re-analysis needs the data it re-analyses. When every linked deposit is set aside, the traffic light is “na”. A deposit that is the paper’s own is counted as such when its README, title or description names the paper (its title or DOI).

How code_check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

The module also checks whether the repository pins the R/package versions the analysis actually depended on: an renv.lock file (parsed for the R version and every locked package + its version/source), a sessionInfo()/sessioninfo::session_info() text dump (matched by filename — sessionInfo.txt/session_info.txt and similar, or embedded in a README), or a groundhog::groundhog.library()/checkpoint::checkpoint() date-pin call in the code (a bare library(groundhog)/library(checkpoint) does not count — the pinning call itself must be present). When none of these is found, the report flags it as a reproducibility gap: package versions may drift between when the analysis was run and any later reproduction attempt.

If you want to extend the package to perform additional checks on code files, or make the checks work on other types of code files, reach out to the Metacheck development team.

Checking code requires downloading its file contents. For a paper whose repository is on Dryad, this never succeeds unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (listing the repository’s files does not need one). Without a key, every Dryad-hosted code file is listed but unchecked, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures recorded in the manifest.

How data_check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Column extraction requires files to be readable from disk. Files fetched by repo_check from OSF/GitHub/etc. without a local copy (file_location is NA) are classified but not column-extracted; pass local_path to point at a downloaded copy of the repository.

For a paper whose repository is on Dryad, this means column extraction never happens unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (dataset listing and metadata do not need one). Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

Every downloaded text file the authors wrote (code, settings, survey definitions such as Qualtrics .qsf files, documentation, outputs) is searched for keys: API keys, access tokens and private keys, which let anyone who downloads the file use a paid service at the authors’ cost. Of a tabular data file only the column names and first 3 rows of the table as read are searched: its values come from participants, but a key the authors set for a whole survey (as embedded data in a Qualtrics survey flow) is exported in every response. The search uses the rules of the secret scanner betterleaks (https://github.com/betterleaks/betterleaks, MIT licence) of high and medium confidence. A key found turns the traffic light red; the report and the keys table give its file, line and type, and only its beginning. Other files over 25 MB and binary files are not searched. A key is never tested with its provider. Every module’s result has any whole key replaced by “keyremoved” (see module_run()).

How reproducibility_check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. Abstract

Change in cognitive control is a candidate transdiagnostic mechanism of psychedelic therapy. One account predicts that, once acute effects resolve, psilocybin shifts control toward flexibility while sparing inhibition and working memory. A motivational account (PRISM) predicts that psilocybin increases the willingness to exert control rather than the ability to do so. We tested both in patients with co-occurring alcohol use disorder (AUD) and major depression.

In this secondary analysis of a randomized, double-blind, placebo-controlled trial of psilocybin for AUD with comorbid major depressive disorder (MDD; ClinicalTrials.gov NCT04620759), a subset of participants (placebo n=13, psilocybin n=12) completed five cognitive tasks before drug administration and again about one week after it (mean 6.7 days, SD 1.1). Outcome measures spanned the stabilityflexibility continuum. Free choice between levels of cognitive demand indexed the participant's willingness to exert control. Effect sizes and Bayes factors were used to estimate drug effects and associations with change in drinking and depressive symptoms across 34 retest measures.

Results. Relative to placebo, psilocybin slowed responding in cued task switching (learning-phase RT d=1.01, BF10=7.7; switch trials d=1.12, BF10=17). Psilocybin effects on feedback-driven measures were inconsistent in direction (7 of 11 toward flexibility); the largest was on perseveration, which rose less with practice under psilocybin than under placebo (d=-0.79, BF10=1.1). Other drug effects on the 34 retest measures had inconclusive Bayes factors (BF10=0.40-2.4), and none survived false discovery rate correction. Demand avoidance, analyzed separately from the 34 measures, showed no detectable drug effect (BF01=2.0). Baseline demand avoidance showed no detectable relation to performance but tracked depressive symptoms (rs=.71, BF10=24). Drinking fell in both arms, and on 15 of 17 stabilityflexibility measures change toward stability accompanied drinking reduction (stability composite rs=-.64, BF10=29; rs=-.43 when change was adjusted for baseline scores). Lower baseline working-memory span predicted larger drinking reductions (BF10=19-25). Depressive symptoms fell more after psilocybin than after placebo (PHQ-9, d=-0.88, BF10=2.7), but their change was not associated with cognitive change or predicted by working-memory span.

Conclusions. About one week after dosing, psilocybin slowed cued task switching but had no consistent effect on feedback-driven flexibility, and there was no evidence of an effect on the willingness to exert effort. Drinking reduction was associated with increased, not reduced, cognitive stability, whereas improvement in depressive symptoms was not associated with cognitive change. These pilot estimates can guide adequately powered trials.

Introduction

Alcohol use disorder (AUD) and major depression (MDD) frequently co-occur, and each worsens the course of the other (Boden & Fergusson, 2011). Psilocybin-assisted therapy has shown promise for both: it reduced heavy drinking relative to placebo in AUD (Bogenschutz et al., 2022) and produced rapid and sustained antidepressant effects in patients with MDD and treatment-resistant depression (Goodwin et al., 2022; Gukasyan et al., 2022). However, effects of psilocybin on reducing drinking in patients with AUD are mixed (Rieser et al., 2025). Mechanisms by which psilocybin may reduce either depression or alcohol use remain unclear. Without a mechanistic account of these effects, it is difficult to predict who will benefit, or whether a single mechanism can underlie therapeutic response in disorders as different as AUD and depression.

Cognitive control is a candidate shared therapeutic target of psychedelics, and change in control a candidate mechanism of their effects, because deficits in control processes are observed in patients with both depression and substance use disorders (Goschke, 2014; McTeague et al., 2016). Control is not a single function, however, but a family of related processes, and psychedelics need not change all of them in the same way. The unity/diversity model distinguishes response inhibition, working-memory updating and set shifting, which share a common factor but dissociate behaviorally and neurally (Miyake et al., 2000; Miyake & Friedman, 2012). Control can also be described by the balance it strikes between stability and flexibility (Goschke & Bolte, 2014; Sayalı & Barrett, 2023). Stability maintains a goal and shields it from interference; flexibility updates goals and strategies when circumstances change. Each has a cost at its extreme: too much stability produces rigid, perseverative behavior, and too much flexibility produces distractibility and goal neglect.

One account of the cognitive mechanisms underlying psychedelic effects proposed that psychedelics act on control in a component-specific and time-dependent way (Sayalı et al., 2026). During the acute psychedelic experience, inhibition, working memory and structured set shifting are impaired. Once acute effects resolve, flexibility is selectively enhanced while inhibition and working memory return to baseline. The clearest clinical evidence for this account comes from a study of patients with MDD (Doss et al., 2021). This study found fewer perseverative errors on a card-sorting task one week and one month after two doses of psilocybin, with no observed change in inhibition performance during a Stroop task. This has been interpreted as a recalibration of the stability-flexibility balance toward a more exploratory mode, with reduced perseveration and greater behavioral adaptability after intervention (Sayalı et al., 2026). This leads to two open questions: does the same hold for other forms of flexibility, such as task switching, which have not been systematically studied? And, does the early post-acute period, in the first days after dosing, differ from later time periods? Performance on a control task reflects how much control a person deploys. That depends both on what they are able to do and on how much control they choose to invest, which is set by weighing the expected benefits of control against its subjective costs (Shenhav et al., 2013; Botvinick & Braver, 2015). The willingness to invest control (motivation) can be measured separately from the capacity to exert that control by comparing choices between tasks that differ in demand (Westbrook et al., 2013; Sayalı & Badre, 2019), and motivation dissociates from performance behaviorally and neurally (Westbrook et al., 2020; Sayalı & Badre, 2019 , 2021). In patients with depression, reduced willingness to invest effort can occur even when the ability to perform is preserved (Grahek et al., 2019). Building on this distinction, the PRISM model (Psychedelic Recalibration of Internal Salience and Mental Effort Costs; Sayalı, 2026) proposes that post-acute cognitive change after psychedelics reflects a recalibrated valuation of effort, with lower perceived costs and greater salience of meaningful goals, rather than increased capacity. Sayalı (2026) names the Demand Selection Task, in which participants choose freely between levels of demand, as a direct test. The PRISM model predicts that psilocybin will increase the willingness to choose demanding tasks without a corresponding change in capacity, and that people with high effort avoidance but preserved performance will benefit most from psychedelic intervention. It also states a boundary condition: the increase is expected mainly for personally meaningful goals.

AUD adds a further complication, because the direction of change that would support recovery is not obvious. Some accounts of substance use disorder emphasize excessive stability, in the form of habitual responding to alcohol cues that resists change (Everitt & Robbins, 2016; Sjoerds et al., 2013). Others emphasize insufficient stability, in the form of impulsive choice and weak maintenance of abstinence goals (MacKillop et al., 2011). When AUD co-occurs with depression, it is unclear which direction along the continuum supports reduced drinking. Drinking also often falls substantially in the placebo arms of trials in patients with AUD (Litten et al., 2013). Therefore, recovery may not depend on drug-induced cognitive change at all. Rather, individual differences in cognitive function may predict who benefits from treatment regardless of arm (Bates et al., 2013).

We examined these questions with a five-task battery administered before and about one week after double-blind drug administration in a randomized, placebo-controlled trial of psilocybin for co-occurring AUD and MDD. The battery sampled components of the unity/diversity model of cognitive control. Inhibition was measured with the Multi-Source Interference Task (MSIT). Shifting was measured in two forms: probabilistic rule switching, in which rule changes must be inferred from feedback, and cued task switching, in which the task is signaled on every trial. Value-based learning and the stability of choice were estimated with a computational model of probabilistic reward and punishment learning, and working memory with operation span. The cued task-switching paradigm was the Parametric Demand Selection Task (Sayalı & Badre, 2019), which also offers free choice between demand levels and therefore provides the battery's only measure of the willingness to exert control. Rather than selecting a few summary scores, we placed every measure on the stability-flexibility continuum according to its construct definition (Table 1) and examined the battery as a whole. Because every task was repeated, practice effects are expected on every measure; the placebo arm provides the reference against which drug effects are judged.

We asked four questions. First, does psilocybin move feedback-driven and cued shifting toward flexibility relative to placebo, while leaving inhibition unchanged? Second, does psilocybin increase the willingness to exert control, and is that willingness separable from performance? Third, does change in stability, flexibility or willingness to exert control track change in drinking and depressive symptoms, and in which direction? Methods

Participants and design

This is a secondary analysis of a randomized, double-blind, placebo-controlled trial of psilocybin in adults with AUD and comorbid MDD (ClinicalTrials.gov NCT04620759). Twenty-five participants completed baseline cognitive testing (placebo n=13, psilocybin n=12). Twenty-three also completed post-dose cognitive testing (two placebo participants completed only baseline testing and contributed only to baseline analyses). Baseline testing took place a median of 1 day before double-blind drug administration (range 1-8 days), and post-dose testing a mean of 6.7 days after it (SD 1.1; median 7, range 4-9; median 7 days in each arm). The two testing sessions were a median of 8 days apart (range 5-13). Sample characteristics are given in Table 2.

Cognitive battery

Tasks were administered in a fixed order within each session: emotional memory practice, the Parametric Demand Selection Task (learning phase, then decision phase), emotional memory encoding, probabilistic reward learning, MSIT, operation span, probabilistic rule switching and emotional memory retrieval. The emotional memory task is not reported here.

Probabilistic reward learning (PRL).

Participants were presented with a series of trials containing two figures (cues) on a computer screen. Participants were asked to choose between two abstract cues on gain trials (win or no win) and loss trials (loss or no loss). In each pair, one cue led to the better outcome on 75% of trials (Pessiglione et al., 2006). A training run was followed by two test runs with new cue pairs (112 responded test trials; missed trials were re-presented and excluded). Accuracy was calculated as the proportion of choices of the better cue, separately for gain and loss trials. Choices were fitted to a Rescorla-Wagner model with a softmax choice rule, separate learning rates and inverse temperatures for gain and loss trials, and a perseveration parameter that biases choice toward repeating the previous choice regardless of its outcome. Values were reset at the start of each run and trial type, and parameters were estimated by maximum likelihood (best of 50 random starts). Adding perseveration improved AIC (mean ΔAIC=-2.5, t(46)=-2.70, p=.010, over all 47 sessions) but not BIC (p=.78).

Probabilistic rule switching.

This task was adapted from the low-volatility condition of Wen et al. (2023; https://github.com/tanya-wen/Meta-flexibility). Participants categorized images by one of two stimulus dimensions, guided by feedback that was valid on 80% of trials. The relevant dimension changed without warning. A 120-trial learning phase (rule change every 30 trials) was followed by a 120-trial transfer phase with two new dimensions (rule change every 20 trials). Accuracy was computed for each phase on the five trials before each rule change (pre-switch accuracy) and the five trials after it (postswitch accuracy), averaged over the three (learning) or five (transfer) changes. Switch cost was calculated as pre-switch minus post-switch accuracy.

Parametric Demand Selection Task. This task followed Sayalı and Badre (2019; github.com/zceydas/ParametricEffortSelectionTask). Participants were presented with a sequence of individual playing cards (one per trial). Their task was to make cued parity (e.g. is the number even or odd?) or magnitude (e.g. is the number greater or less than 5) judgments, with the task signaled on every trial. Demand was manipulated as the probability of a task switch (.13, .38, .63 or .88), each associated with a card deck (e.g. the color of the back of a given deck) that was displayed at the beginning of each block of trials (each block containing 8 trials). In a learning phase (320 trials), participants performed every demand level. In a decision phase (72 trials), they chose freely between two decks on each trial and then performed the chosen deck. No external incentive was attached to this choice. Performance was indexed by accuracy, response time (RT), and task-switch costs (switch minus repeat trials) in each phase. The willingness to exert control was indexed by demand avoidance, defined as the proportion of choices of the less demanding deck across all pairings (0.5 = indifference; Sayalı & Badre, 2019). The probabilities of choosing the least and the most demanding deck, the mean chosen level, and selection RT are reported as secondary choice measures.

MSIT. On each trial, three digits were shown, and participants identified the digit that differed from the other two (Bush & Shin, 2006). On control trials, the other two digits were zeros and the target appeared in the position matching its value; on interference trials, the other two digits were non-zero and the target's position did not match its value. Eight alternating blocks of control and interference trials yielded 192 trials. Interference effects (interference minus control) were computed for RT (correct trials) and accuracy.

Operation span.

The automated operation span task (Unsworth et al., 2005) was scored from trial-level data as the sum, across 15 test sets, of correctly recalled letters divided by set size (range 0-15). Primary analyses used baseline scores from all valid sessions; post-dose scores, available for a subset, are reported in the Supplement (Table S8).

Classifying measures on the stability-flexibility continuum

Each measure was classified by its position on the stability-flexibility continuum (Table 1). Scores also differ in what they can reveal about control. Every score other than free choice is a performance score: it reflects control as deployed, which depends jointly on ability and on how much control the participant chooses to invest (Shenhav et al., 2013). Performance scores therefore cannot isolate capacity. Free choice between demand levels without incentives indexes the willingness to engage control more directly (Sayalı & Badre, 2019), although choices can still be shaped by how demanding each level feels. We use "motivation" only for that choice measure. Because demand avoidance is the battery's only measure of motivation, score type is shown in Table 1 but not used as a classification dimension; demand avoidance is analyzed separately, as the test of PRISM's prediction. Following convention, we refer to operation span, a performance score, as an index of working-memory capacity, with the same caveat.

On the continuum, stability measures index the maintenance of a current choice, rule or task set: perseveration, high inverse temperature (exploitation of learned values), switch costs, and pre-switch accuracy. Flexibility measures index updating and openness to change: higher learning rates, post-switch accuracy, and MSIT interference effects. Interference effects index susceptibility to task-irrelevant information and can be read as weaker shielding of the goal; flexibility in the sense of adapting to relevant change is captured by learning rates and post-switch accuracy. Overall accuracy, speed, span, and choice measures were not assigned a pole. For model parameters, the pole refers to the direction of the scale: lower learning rates and higher inverse temperatures indicate greater stability. Placements followed construct definitions rather than results, but the classification was finalized after data collection, so all analyses that depend on it are exploratory.

Data quality

Missed PRL trials were excluded before model fitting. In the demand selection task, missed responses and presses of non-task keys were counted as errors and excluded from RT. In the same task, the baseline sessions of six participants whose learning-phase accuracy was not above chance (binomial p≥.05 over 320 trials; accuracy .48-.54) were excluded from all measures of that task, because deckdemand associations could not have been learned. In the rule-switching task, three baseline sessions and one post-dose session whose overall accuracy did not exceed chance (binomial p≥.05 over 240 trials; accuracy .45-.53) were excluded from all measures of that task, because rule-dependent indices cannot be interpreted when the rule was not followed; results with these sessions included, and with the stricter criterion of Wen et al. (2023; overall accuracy below 65%), are reported as sensitivity analyses. In two post-dose sessions, decision-phase responses were inverted on 95-96% of answered trials, consistent with a reversed key mapping, and accuracy was scored accordingly. In the MSIT, the key mapping was determined per block as the rule that reproduced at least 70% of responses (one block with a mid-session change of mapping could not be resolved and was not scored); two post-dose sessions in which 98-99% of interference trials were answered by the target's position rather than its identity were excluded. Details are given in the Supplementary Methods.

Clinical measures

Drinking was assessed with the Timeline Followback (Sobell & Sobell, 1992) at baseline (90 days leading up to screening) and over the 30 and 90 days after experimental drug administration. Because the windows differed in length, drinking was expressed as the proportion of drinking days, the proportion of heavy-drinking days, and the number of drinks per drinking day. Heavy-drinking days were days with five or more drinks for men and four or more for women. The primary drinking outcome was the change from baseline to the 30-day window, which contained the post-dose cognitive session. Drinking over time was compared between arms with a linear mixed model of each drinking proportion with arm, window (baseline, 30 days and 90 days after experimental drug administration) and their interaction as fixed effects with a random intercept per participant. Depressive symptoms were measured with the 9item Patient Health Questionnaire (PHQ-9; Kroenke et al., 2001) at the baseline and post-dose cognitive visits, and with the 16-item Quick Inventory of Depressive Symptomatology-Self-Report (QIDS-SR; Rush et al., 2003) at screening.

Statistical analysis

Drug effects. Analysis of covariance (ANCOVA) was used to estimate the effect of allocation (psilocybin vs placebo) on post-dosing score when controlling for baseline score for each of the 34 retest measures (Vickers & Altman, 2001). Effects are reported as the baseline-adjusted arm difference in pooled-SD units (d; psilocybin minus placebo) with 95% confidence intervals, and p values were corrected for the false discovery rate (FDR) across the 34 tests (Benjamini & Hochberg, 1995); FDR-adjusted p values are reported as q. Within-arm change was tested with paired t-tests. As a sensitivity analysis, the number of days between drug administration and post-dose testing was added as a covariate.

Position on the continuum. For the 17 measures with an assigned pole, drug effects and clinical couplings were re-signed so that positive values indicate movement toward stability. Consistency of direction was summarized with sign tests, which are descriptive because measures from the same task are correlated. As a summary index, we computed a stability composite from the principal stability measure of each feedback-driven task: perseveration and transfer-phase switch cost. Change in each measure (post-dose minus baseline) was z-scored across all participants, with both arms pooled, and the composite was the mean of the available z-scores, so that higher values indicate movement toward stability. Participants with only one of the two measures contributed that measure. Because ruleswitching change was available for fewer participants, 13 of the 22 participants contributed both measures and 9 contributed perseveration only; analyses of the composite were therefore repeated in the 13 participants with both measures. The composite was compared between arms with Welch's ttest. As a sensitivity analysis, a broader composite was computed by averaging eight indices spanning all four tasks (perseveration, mean inverse temperature, mean learning rate, both rule-switching costs, both cued RT switch costs and the MSIT RT interference effect), each z-scored as previously described, aligned so that positive values indicate movement toward stability (flexibility-pole indices signreversed), and requiring at least three included measures per participant. Because the arms differed at baseline on transfer-phase switch cost, the stability composite was also recomputed from baselineadjusted change, with each measure's post-dose score residualized on its baseline score (pooled across arms) before z-scoring.

Baseline construct validation.

To test whether the classification captured individual differences that are shared across measures, we correlated scores across measures assessed at the baseline session, which preceded randomization and is independent of drug effects or clinical outcomes. We selected one index per construct and task: perseveration, mean inverse temperature and mean learning rate (PRL); preswitch and post-switch accuracy averaged over phases (rule switching, sessions above chance); taskswitch costs in RT and in accuracy averaged over phases (demand selection, sessions above chance); and the MSIT RT interference effect. Each index was aligned so that higher values indicate greater stability, with flexibility-pole indices sign-reversed. If the classification is valid, aligned indices from different tasks should correlate positively. We tested the mean Spearman correlation across the 23 cross-task pairs against a null distribution from 10,000 permutations in which participants were shuffled independently within each index, preserving missing data. Within-task pairs were excluded from the test because they share trials or, for model parameters, estimation trade-offs. Test-retest reliability of each index was estimated as the Spearman correlation between baseline and post-dose scores after removing arm means. The classification was not revised in light of these results. Factor analysis was not attempted, because only 12 participants contributed all eight indices.

Associating change in cognition with clinical outcomes.

For every cognitive measure, change (post minus pre) was related to change in the proportion of drinking days with Spearman correlations (rs; all correlations are Spearman unless stated otherwise) pooled across arms, with rank-based regression adjusting for arm, and with a rank-based regression that added an arm × change interaction. FDR correction was applied across the 34 couplings. The same models, and the same re-signing and sign test on the continuum, were applied to change in PHQ-9 between the baseline and post-dose visits.

Prediction of drinking change. Each baseline measure, including operation span (35 measures), was entered into a rank-based regression of drinking change on the measure, arm, and baseline drinking, for drinking days and heavy-drinking days (70 tests, FDR-corrected). The same 35 baseline measures were tested as predictors of PHQ-9 change, adjusting for arm and baseline PHQ-9 (35 tests, FDR-corrected).

Robustness checks for the strongest predictor included Pearson models, assessment of the 90-day outcome, leave-one-out samples, adjustment for age, sex, baseline depression, and antidepressant use, exclusion of baseline-only participants, and a processing-accuracy criterion of 85% on the operation span math component.

Willingness to exert control. PRISM's predictions were examined with demand avoidance as the single index. Demand avoidance is not one of the 34 retest measures and was therefore not part of their FDR correction. We tested the drug effect at post-dose testing (ANCOVA); the relation of baseline avoidance to performance (operation span and every performance measure of the same task) and to depressive symptoms; the coupling of change in avoidance with change in drinking and PHQ; and whether baseline avoidance, alone or in interaction with arm, predicted drinking or PHQ change (rank-based regression adjusted for the baseline outcome). These analyses were specified after data collection and are exploratory.

Effect sizes and Bayes factors.

Because this is a pilot study, we report effect sizes with 95% confidence intervals for all comparisons and, to quantify evidence for the absence as well as the presence of effects, Bayes factors (BayesFactor package; Morey & Rouder, 2026). Drug effects compared an ANCOVA model including arm with a model including only the baseline score, using default priors (Rouder et al., 2012).

Correlations used the default stretched-beta prior (Ly et al., 2016), applied to ranks for Spearman correlations, and rank-based regressions compared models with and without the predictor of interest. BF10 expresses the evidence for an effect and BF01 = 1/BF10 the evidence for its absence. Values between 1/3 and 3 were treated as inconclusive and values above 3 as at least moderate evidence (Lee & Wagenmakers, 2013). Table S7 summarizes effect sizes and Bayes factors for the main claims.

Analyses used R 4.4.1 (lme4, lmerTest, BayesFactor, ggplot2) and Python 3.12 (NumPy, pandas, SciPy). The analysis code, which reproduces every statistic from the trial-level files, is available at https://github.com/zceydas/MDDAUD_cogtasks

All five tasks produced the effects they are designed to elicit. Table 3 summarizes these effects and compares them with published values from comparable versions of each task where such values exist.

Probabilistic reward learning.

Participants chose the better cue on 80% of gain trials (SD 18) and 70% of loss trials (SD 12; both above chance, t(23)=8.16 and 8.36, both p<10⁻⁷, n=24), and learned more accurately from gains than from losses (t(23)=2.88, p=.008). Healthy adults learning comparable 75:25 contingencies choose the better option on about 73-74% of trials, with no difference between reward and punishment (Palminteri et al., 2015; see also Pessiglione et al., 2006). Overall accuracy observed within our sample was in that range, but the advantage for gains over losses is not typical of healthy samples. The reinforcement-learning model predicted choices better than a random-choice model in 22 of 24 participants (likelihood-ratio tests, 5 df, each p<.05; mean per-trial choice likelihood .64). Median learning rates were 0.15 for gains and 0.43 for losses. Inverse temperature reached its upper bound of 10 in 14 of 24 participants on gain trials and 7 of 24 on loss trials, indicating near-deterministic choice once values were learned. Perseveration was small and varied in sign across participants (median 0.12, interquartile range -0.18 to 0.39). Both perseveration and loss-trial inverse temperature were close to the values typical of this model class: pooled across two-armed bandit studies, choice stickiness is centered at 0.15 and inverse temperature has a mode of about 3.4 (Gershman, 2016). Gain-trial inverse temperatures were higher than typical, consistent with near-deterministic choice once reward values had been learned.

Probabilistic rule switching.

Participants performed above chance in 17 baseline sessions. Accuracy in these sessions was above chance in both the learning phase (.75) and the transfer phase (.76; t(16)=10.26 and 15.50, both p<10⁻⁷) and did not differ between phases (t(16)=-0.96, p=.35). Each unannounced rule change produced the expected drop in accuracy, from .82 before to .40 after a change in the learning phase and from .89 to .43 in the transfer phase (switch costs .43 and .46; t(16)=6.27 and 9.53, both p<10⁻⁴). Post-switch accuracy below .5 indicates that participants initially continued to apply the previous rule before adapting to the new one. Participants did not exceed chance in three of 20 baseline sessions and one of 16 post-dose sessions (one-sided binomial test over 240 trials, p≥.05; accuracy .45-.53), and data from these sessions were excluded (see Data quality). Six of the 20 baseline sessions, including these three, fell below the 65% overall-accuracy criterion that Wen et al. (2023) used for exclusion. Excluding every session below 65% (nine sessions) left the rule-switching results unchanged in direction: 7 of 11 feedback-driven measures moved toward flexibility, as in the primary analysis, and the stability composite still tracked drinking change (rs=-.54, p=.009).

Parametric Demand Selection Task. Participants did not exceed chance in the learning phase in six of 25 baseline sessions, and data from these sessions were excluded (see Data quality). In the remaining 19 baseline sessions, accuracy was .84 in the learning phase and .90 in the decision phase. Raising the taskswitch probability from .13 to .88 slowed responses from 0.59 to 0.77 s (t(18)=8.81, p<10⁻⁷) and reduced accuracy from .88 to .82 (t(18)=-3.14, p=.006). This reflects the parametric demand effect that the task is designed to produce (Sayalı & Badre, 2019 , 2021). Task-switch costs, the signature effect of cued task switching (Monsell, 2003), were robust in both phases (RT 0.19 s in the learning phase and 0.15 s in the decision phase; accuracy 6.6 and 3.6 percentage points respectively; t(18)=8.60 and t(17)=6.68 for RT, t(18)=5.07 and t(17)=4.39 for accuracy, all p≤.0004). In free choice (during the decision phase), participants were on average close to indifference (demand avoidance .54, SD .14; vs .5, t(17)=1.14, p=.27, n=18): nine participants avoided demand, eight sought it and one was indifferent. This is consistent with performance in the second sample of Sayalı and Badre (2019), which divided almost equally into demand avoiders and demand seekers, and is lower than the 67% avoidance reported by Sayalı and Badre (2021). Unlike Sayalı and Badre (2021), avoidance did not increase with greater difference in demand between the offered decks (.52, .57 and .53 for differences of one, two and three levels, respectively; three vs one level, t(17)=0.11, p=.91), although the probability of choosing a deck fell slightly from the least (.56) to the most demanding deck (.48). Choices therefore discriminated only weakly between demand levels in this sample, which limits the precision of demand avoidance as an index.

MSIT. Participants were slower (922 vs 605 ms) and less accurate (.92 vs .97) during interference trials than during control trials (n=23). The interference effect in RT was 317 ms (SD = 62; t(22)=24.56, p<10⁻¹⁶), closely matching the 312 ms (SD = 61) reported in the original validation of the task in healthy adults (Bush et al., 2003). The accuracy cost was 5.4 percentage points (t(22)=5.87, p<10⁻⁵).

Operation span.

The mean partial-credit score was 9.9 of 15 (SD = 2.4, n=18), equivalent to 66% of letters recalled in the correct position per set. Recall declined with set size, from 86% for three-letter sets to 42% for seven-letter sets (linear decline of 9.5 percentage points per additional letter, t(16)=-8.60, p<10⁻⁶, n=17). Math accuracy averaged 87% (SD 7), and 11 of 18 participants met the conventional 85% criterion (Unsworth et al., 2005). In a large, mostly young normative sample, the partial-credit score averaged 57.4 of 75 letters, or 76% (Redick et al., 2012). That score counts letters rather than set proportions, so the comparison is approximate, but span in this older clinical sample was somewhat lower.

Construct validation. At baseline, indices assigned to the same pole shared a small amount of variance across tasks, more than expected by chance (Figure S1A; Table S6). The mean cross-task correlation among aligned indices was rs=+.11 (permutation p=.032), and 16 of 23 cross-task pairs were positive. The clearest convergences fit the classification. Participants who perseverated more showed smaller MSIT interference reflecting stronger goal shielding (rs=.57, p=.006, n=22), and larger cued switch costs in accuracy were associated with smaller MSIT interference (rs=.49, p=.047, n=17). Perseveration was only weakly related to rule-switching cost (rs=+.21 for the transfer phase, n=16; BF01=1.5, inconclusive). Two features limited coherence. Pre-switch accuracy and the cued RT switch cost tracked general task accuracy (rs=.53 and -.39 with a composite of overall accuracy across the four tasks, which partly overlaps with these indices by construction), indicating that they index ability as well as stability. Testretest reliability within arm was modest to low (Figure S1B): rs=.40 to .45 for MSIT interference, preswitch accuracy and the cued RT switch cost, and below .30 for the PRL indices and the cued accuracy switch cost. Post-switch accuracy showed no test-retest correlation (rs=-.01, n=13).

Overall clinical outcomes

Drinking fell substantially in both allocations (psilocybin and placebo). Over the 30 days after drug administration, the overall proportion of drinking days fell from .62 to .30 and the proportion of heavydrinking days from .39 to .12 (n=25), with no difference between arms across the baseline, 30-day, and 90-day windows (arm × window, F(2, 45.0)=0.72, p=.49 for drinking days and F(2, 45.0)=0.30, p=.74 for heavy-drinking days; at 30 days, BF01=2.4-2.6, inconclusive). Depressive symptoms fell more after psilocybin (PHQ 9.2 to 2.9) than after placebo (7.5 to 6.1; ANCOVA, d=-0.88 [-1.62, -0.14], t(20)=-2.47, p=.023, BF10=2.7, n=23). Change in PHQ was unrelated to change in drinking (rs=-.15, p=.48, BF01=1.8).

Drug effects across the battery

No effect of allocation (psilocybin vs placebo) on task performance survived FDR correction across the 34 analyzed measures (smallest q=.29; Figure 2; Table S1). Effects on the stability-flexibility measures (the first question) are reported in the next section and on the willingness to exert control (the second question) in the section after; this paragraph summarizes the measures outside the continuum. We found no evidence that psilocybin altered inhibition (MSIT interference effect in RT, d=0.20 [95% CI -0.72, 1.12]; accuracy, d=0.35 [-0.47, 1.17]) or value learning (reward-learning accuracy, d=0.16 [-0.79, 1.12]; punishment-learning accuracy, d=0.00 [-0.72, 0.71]). These intervals do not exclude moderate effects, and Bayes factors favored the null hypothesis only weakly (BF01=2.0-2.5). Across all 34 measures, no null result reached even moderate evidence for the absence of a drug effect (largest BF01=2.5; Table S1). Three differences between allocation groups reached uncorrected significance, all in the demand selection task. Two were performance effects: slower learning-phase responding (d=1.01 [0.30, 1.73], t(13)=3.09, p=.009, BF10=7.7) and a larger task-switch cost in RT (d=0.89 [0.07, 1.71], t(13)=2.35, p=.035, BF10=2.4) in the psilocybin arm relative to placebo. The third was a choice effect: a higher baseline-adjusted probability of choosing the least demanding deck in the psilocybin arm relative to placebo (d=1.31 [0.06, 2.55], t(12)=2.29, p=.041, BF10=1.3). The raw means for this measure did not change in the placebo arm (.45 to .44) and fell in the psilocybin arm (.62 to .56). With a baseline imbalance and the strongest baseline-change correlation in the battery (r=-.78), this estimate mainly reflects the baseline adjustment and should not be interpreted as a change in effort choice due to drug administration. Cued task switching slowed; feedback-driven effects were inconsistent

Re-signing each effect by its position on the continuum showed no consistent direction on the feedbackdriven tasks (Figure 3A). On the 11 stability-flexibility measures from PRL and rule switching, psilocybin moved performance toward flexibility relative to placebo in 7 cases (sign test p=.55). The largest effects pointed in different directions: toward flexibility for perseveration (d=-0.79 [-1.77, 0.19], t(19)=-1.69, p=.11) and transfer-phase post-switch accuracy (d=+0.79 [-0.43, 2.01], t(10)=1.45, p=.18), and toward stability for learning-phase pre-switch accuracy (d=+0.98 [-0.25, 2.20], t(10)=1.77, p=.11), all with inconclusive Bayes factors (BF10=0.7-1.2). For perseveration, the difference arose because placebo participants became more stable at post-dose testing, whereas psilocybin participants changed less (Figure 4A): perseveration rose under placebo (0.22 to 0.99, t(10)=3.04, p=.012, n=11) but rose less under psilocybin (0.14 to 0.45, t(10)=1.79, p=.10, n=11). Transfer switch cost showed a similar pattern (d=-0.48 [-1.61, 0.65], t(10)=-0.95, p=.37): it rose under placebo (.35 to .48, t(5)=2.99, p=.031, n=6) but not under psilocybin (.57 to .52, t(6)=-0.66, p=.54, n=7; Figure 4B). No measure moved significantly toward flexibility within the psilocybin arm. The stability composite moved toward stability in the placebo arm (mean z=+0.23, n=11) and toward flexibility in the psilocybin arm (-0.36, n=11), but the difference was not significant (Welch t(19.9)=1.70, p=.10, BF10=1.0; Welch t(10.9)=2.78, p=.018 among the 13 participants with both measures; baseline-adjusted composite, Welch t(19.7)=1.43, p=.17). The broader eight-index composite showed no difference between allocation groups (Welch t(17.7)=0.48, p=.64, BF01=2.4). When including the four rule-switching sessions in which participants performed at chance, 8 of 11 feedback-driven measures moved toward flexibility (sign test p=.23), and the composite difference was larger (Welch t(20.7)=1.96, p=.063).

Cued task switching showed a consistent pattern. All four task-switch costs in the demand selection task moved toward stability under psilocybin relative to placebo (accuracy and RT, learning and decision phases; d=0.17 to 0.89). The learning-phase RT cost rose after psilocybin (0.199 to 0.253 s) and fell after placebo (0.173 to 0.148 s; d=0.89, t(13)=2.35, p=.035; Figure 4C). RT increased overall in the psilocybin arm and decreased in the placebo arm (0.733 to 0.775 s vs 0.637 to 0.591 s; d=1.01, t(13)=3.09, p=.009, BF10=7.7; Figure 4D). Increases in RT were largest on switch trials (d=1.12 [0.46, 1.77], t(13)=3.69, p=.003, BF10=17) and smaller on repeat trials (d=0.64 [-0.08, 1.36], t(13)=1.92, p=.078, BF10=1.5). The slower responses were not accompanied by higher accuracy (learning-phase accuracy d=-0.58, t(13)=-1.22, p=.24), so the slowing did not reflect a shift toward accuracy at the expense of speed. Participants who received psilocybin were slower at baseline; regression to the mean would predict a larger reduction in RT in that arm, but the opposite was observed. After the exclusion of chance-level sessions, these analyses rest on 7 participants who received placebo and 9 participants who received psilocybin. Adjusting for the number of days between drug administration and post-dose testing (median 7 in each arm) did not change these effects (learning-phase RT, t(12)=3.34, p=.006; task-switch cost in RT, t(12)=2.25, p=.044). In mixed models across the four demand levels, the arm × session interaction for learning-phase RT pointed the same way but was weaker (F(1, 16.0)=3.38, p=.084), and the drug did not change how RT, accuracy or choice varied with demand level (arm × level × session, all p≥.21; Table S9). No evidence that psilocybin changed the willingness to exert control At baseline, participants were close to indifference between less and more demanding decks (mean demand avoidance .54, where .5 indicates indifference; t(17)=1.14, p=.27, BF01=2.3, n=18), with wide individual differences. Baseline demand avoidance showed no detectable relation to performance: it was unrelated to operation span (rs=+.10, p=.75, BF01=1.7, n=13; Figure 5B) and to accuracy, RT and switch costs in the same task (all |rs|≤.36, all p≥.14, BF01=0.9-2.0, n=18), although with these sample sizes moderate correlations cannot be excluded (95% CI for operation span -.48 to .62). Baseline demand avoidance was not significantly related to stability measures from the other tasks (largest rs=+.48, with rule-switching cost, p=.12, n=12). It was, however, strongly related to depressive symptoms measured with the PHQ at the same visit: participants with more severe depressive symptoms (higher PHQ-9 scores) avoided demand more (rs=+.71 [.30, .90], p=.001, BF10=24, n=17; Figure 5A; rs=+.68, p<.001, n=22 including chance-level sessions). This association was specific to that visit. Baseline demand avoidance was unrelated to depressive symptoms measured at screening with a different instrument, the QIDS-SR (rs=+.06, n=18), and demand avoidance at post-dose testing was unrelated to PHQ at that visit (rs=-.16, p=.51, BF01=1.8, n=20). The test-retest reliability of demand avoidance was low (rs=-.27 after removing arm means, n=15; -.13, n=20 including chance-level sessions), so the baseline association may not generalize beyond that session.

There was no evidence that psilocybin increased the willingness to exert control (Table S5). Baselineadjusted demand avoidance at post-dose testing was, if anything, higher after psilocybin than after placebo (d=+0.47 [-1.06, 2.00], t(12)=0.67, p=.52, n=6/9; Figure 5C), but the Bayes factor was inconclusive (BF01=2.0), so the data neither support nor rule out a drug effect of moderate size. Participants in the psilocybin arm were more avoidant at baseline than those who received placebo (.60 vs .43) and participants in both arms regressed to near .53 after treatment, providing evidence that the estimate is dominated by regression to the mean (baseline-change r=-.77). Change in demand avoidance was unrelated to change in drinking (rs=-.02, p=.94, BF01=1.9, n=15) and to change in PHQ (rs=+.27, p=.33, BF01=1.3). Adjusting for treatment allocation and baseline measures on the given outcome, baseline avoidance predicted neither drinking change (rank-partial β=-0.08, t(14)=-0.33, p=.74 for drinking days; β=-0.32, t(14)=-1.48, p=.16 for heavy-drinking days; BF01=2.3 and 2.0) nor PHQ change (β=+0.08, t(13)=0.64, p=.54), and it did not interact with allocation (interaction |t|≤0.54, p=.60-.75). For PHQ change, the Bayes factors provided moderate evidence against both the main effect of baseline avoidance (BF01=3.4) and the interaction of avoidance with allocation (BF01=3.3). Without adjustment, more avoidant participants showed larger PHQ reductions (rs=-.61, p=.009, n=17), an association explained by their higher baseline PHQ. Within the psilocybin arm, more avoidant participants showed somewhat larger PHQ reductions (unadjusted rs=-.50, p=.14, n=10).

Change toward stability accompanied drinking reduction

No association between cognitive change and drinking change survived FDR correction across the 34 measures (smallest q=.49; Table S2). Here and below, drinking change is the change in the proportion of drinking days from baseline to the 30 days after drug administration. The sign of the correlations was nevertheless consistent. On 15 of the 17 stability-flexibility measures, change toward stability was associated with larger drinking reductions (descriptive sign test, 15 of 17, p=.002; Figure 3B). This held for all 11 feedback-driven measures and for 2 of the 4 cued switch costs. The strongest correlations with drinking change were for reward-learning accuracy (rs=-.48, p=.022, BF10=3.7, n=22; adjusted for arm, t(19)=-2.27, p=.035; Figure 6B) and perseveration (rs=-.46, p=.031, BF10=2.9, n=22; adjusted for arm, t(19)=-2.11, p=.048). Among the rule-switching measures, the largest correlation, for transfer-phase switch cost, was similar in size (rs=-.47) but less certain, because only 13 participants contributed (p=.11). Lower working-memory span predicted larger drinking reduction

Of 70 prognostic tests (35 baseline measures × 2 drinking outcomes), baseline operation span was the strongest predictor. Greater span predicted smaller reductions in heavy-drinking days (rank-partial β=+0.57, t(14)=3.94, p=.0015, BF10=25) and total drinking days (β=+0.63, t(14)=3.76, p=.0021, BF10=19), adjusting for arm and baseline drinking (n=18; q=.074 for both; Figure 7). The next strongest predictor showed the same direction of association: higher decision-phase accuracy in the demand selection task predicted smaller reductions in drinking days (β=+0.53, t(14)=3.28, p=.0055, q=.13).

The relationship between operation span and drinking change was present in both arms (placebo rs=.67-.70, n=10; psilocybin rs=.83-.90, n=8) and did not differ significantly between them (arm × span interaction, t(13)=1.61, p=.13 for heavy-drinking days and t(13)=1.03, p=.32 for drinking days; BF01=1.3-1.9). It held for the 90-day window (t(13)=4.00, p=.0015, and t(13)=4.27, p=.0009, for heavy-drinking and drinking days), in linear (Pearson) models (t(14)=3.95, p=.0015, and t(14)=2.84, p=.013), in every leaveone-out sample (all t≥3.00, largest p=.010), without the baseline-only participant who had a span score (n=17; t(13)=3.82, p=.0021, and t(13)=3.69, p=.0027) and after adjustment for age, sex, depressive symptoms at screening or antidepressant use (t(13)=2.27-4.26, p=.0009-.041; Table S4). Among the 11 participants who met the 85% processing-accuracy criterion, the estimates remained positive but were less precise: β=+0.56 for heavy-drinking days (t(7)=1.99, p=.087) and β=+0.83 for drinking days (t(7)=2.97, p=.021). Participants with lower span tended to drink more often at baseline (rs=-.42). Lower span was also associated with larger increases in reward-learning accuracy after drug administration (rs=-.63, p=.006, n=17), but not detectably with change in rule-switching cost (rs=-.18, n=12).

Change in depressive symptoms was not associated with cognitive change

We applied the same analyses to depressive symptoms. Change in PHQ-9 between the baseline and post-dose visits was not associated with change in any cognitive measure (no pooled correlation reached p<.05; smallest q=.94; n=13-22). After adjustment for arm, one association reached uncorrected significance: larger increases in the decision-phase RT switch cost accompanied larger PHQ-9 reductions (rank-partial β=-0.37, t(12)=-2.98, p=.011, n=15; Table S2), but it did not survive correction (q=.39). Unlike drinking, PHQ-9 change showed no consistent direction on the continuum: change toward stability accompanied PHQ-9 reduction on 11 of 17 measures (sign test p=.33), including 6 of the 11 feedback-driven measures, compared with 15 of 17 for drinking reduction. Change in PHQ-9 was also unrelated to change in the stability composite (rs=+.04, p=.85; adjusted for arm, t(19)=-0.88, p=.39; BF01=2.2) and in drinking (rs=-.15, p=.48). None of the 35 baseline performance measures predicted PHQ-9 change after adjustment for arm and baseline PHQ-9 (smallest q=.24). In particular, operation span, the strongest predictor of drinking reduction, did not predict PHQ-9 change (rank-partial β=-0.04, t(13)=-0.20, p=.84, BF01=2.9, n=17). The battery's one correlate of depressive symptoms was a baseline level of a choice measure, not a performance measure or a change: baseline demand avoidance tracked PHQ-9 at the same visit (rs=+.71, BF10=24; see above). This did not extend to change. Change in avoidance was unrelated to change in PHQ-9 (rs=+.27, p=.33), and baseline avoidance did not predict PHQ-9 change once baseline PHQ-9 was taken into account (β=+0.08, p=.54, BF01=3.4). Because PHQ-9 was measured at the two cognitive visits, these are associations between concurrent changes over about one week, whereas drinking change was measured over the 30 days after drug administration.

Associations between baseline measures and baseline drinking behavior

No baseline association between cognition and drinking survived correction across 105 comparisons (smallest q=.41; Table S3). Participants who perseverated more at baseline drank on fewer days but drank more on the days they drank (drinking days rs=-.42, p=.043; drinks per drinking day rs=+.57, p=.004). A smaller MSIT interference effect showed the same association with drinks per drinking day (rs=-.55, p=.008) but not with drinking days (rs=+.12, p=.58). Perseveration and the MSIT interference effect were themselves correlated (rs=-.57, p=.006). Participants who perseverated more and were less affected by interference at baseline therefore tended to drink less often but more heavily.

Discussion

We examined two cognitive-control accounts of the effects of psilocybin in patients with co-occurring AUD and depression, using every measure a five-task battery produced. In this pilot study, no single drug effect or clinical coupling survived correction across the battery, so our conclusions rest on effect sizes, on the consistency of direction across measures, and on the few effects with at least moderate Bayesian support. Within those limits, four findings emerged. Approximately one week after dosing, psilocybin slowed cued task switching relative to placebo, whereas its effects on feedback-driven measures were inconsistent in direction; the largest was on perseveration, which rose less with practice under psilocybin than under placebo. We found no evidence of change in inhibition, value learning, or the willingness to exert control, although Bayes factors showed that these null results are inconclusive rather than evidence of absence. Drinking fell in both arms, and on nearly every stability-flexibility measure the change that accompanied drinking reduction was toward stability, not flexibility; no such pattern was found for depressive symptoms. Lower baseline working-memory span predicted larger drinking reductions in either arm.

Placing the battery on the stability-flexibility continuum

Figure 3 shows, for every measure with a position on the continuum, both the drug effect and the coupling with drinking.

Probabilistic reward learning. Perseveration is the clearest stability index in the battery, because it captures the tendency to repeat a choice regardless of its outcome. It rose at post-dose testing under placebo and less under psilocybin, and larger increases were associated with larger drinking reductions. Inverse temperature, the exploitation of learned values, showed no consistent drug effect, but change in inverse temperature was associated with change in drinking in the same direction as perseveration.

Learning rates, the flexibility side of value learning, showed small drug effects toward flexibility; however, the association between change in drinking rates and change in learning rates pointed toward stability, in that faster updating was associated with smaller drinking reductions.

Rule switching. Decomposing the switch cost was informative, although with 6 placebo and 7 psilocybin participants the estimates are imprecise. The drug effect on switch cost came mainly from an effect of drug on post-switch accuracy, observed as faster adaptation to a new rule (transfer phase d=+0.79), whereas pre-switch accuracy, which reflects maintenance of the current rule, showed effects in opposite directions in the two phases (d=+0.98 in the learning phase and -0.25 in the transfer phase). In their coupling with drinking, both components pointed toward stability: better rule maintenance and slower adaptation were associated with drinking reduction, although no single rule-switching coupling was significant (the largest was for transfer-phase switch cost, rs=-.47, p=.11).

Cued task switching.

All four task-switch costs moved toward stability under psilocybin, in contrast to the mixed feedback-driven measures, and their coupling with drinking was mixed (2 of 4 pointed toward stability, and none was significant). Changes in cued switch costs were unrelated to changes in ruleswitching costs (rs=-.02, n=9), so the two tasks do not appear to index a single shifting ability.

MSIT.

Interference effects showed no drug effect and weak couplings in the stability direction. We placed them at the flexibility pole as an index of weaker goal shielding. Change across tasks was consistent with this placement, although not significantly: as rule-switching costs rose, MSIT interference tended to fall (rs=-.49, p=.13, n=11), so greater stability in one task tended to be associated with stronger goal shielding in the other.

Integrating findings across tasks in the battery. Two conclusions follow. First, the classification captured a modest amount of variance common to measures from different tasks: participants who were more stable on one task tended, weakly, to be more stable on others. At baseline, indices assigned to the same pole correlated weakly across tasks (mean rs=+.11, p=.032), with the clearest convergence between perseveration and goal shielding in the MSIT (Figure S1). Limited test-retest reliability, a common property of behavioral control measures (Hedge et al., 2018), and ability-related variance in accuracy-based indices constrain how coherent stability and flexibility can appear as traits in a battery of this size; perseveration and rule-switching cost, for example, were only weakly correlated (rs=+.21). The contrast between the consistent drug effect on cued switching and the mixed drug effects on feedbackdriven measures is therefore better interpreted as a difference between forms of flexibility than as evidence against the classification. For the same reason, the primary stability composite combined only the two feedback-driven stability measures; the broader composite, which also included cued switch costs and MSIT interference, showed weaker effects. Second, associations with drinking were strikingly uniform across feedback-driven measures: more stable performance at post-dose testing was associated with less drinking.

Feedback-driven and cued flexibility after psilocybin Sayalı et al. (2026) predicted a selective post-acute gain in flexibility, most clearly in feedback-driven set shifting of the kind measured by card-sorting tasks, with reduced perseveration and no change in inhibition. Our data offer at most weak support for this prediction. We found no evidence of change in inhibition, but feedback-driven measures did not move consistently toward flexibility relative to placebo (7 of 11). The largest effect was on perseveration, the measure closest to the perseverative errors previously found to reduce after treatment with psilocybin (Doss et al., 2021), and this effect took the form of a smaller practice-related rise rather than a treatment-related gain: perseveration rose at postdose testing under placebo and less under psilocybin, and no measure improved above baseline within the psilocybin arm. This estimate (d=-0.79) was imprecise and its Bayes factor inconclusive. The overall pattern also depended on four rule-switching sessions in which accuracy did not exceed chance: with these sessions included, 8 of 11 feedback-driven measures moved toward flexibility, but such sessions cannot index rule-based control. A larger trial with a placebo arm is needed to establish whether psilocybin prevents the practice-related stabilization of feedback-driven choice, an effect that a design without a placebo arm would miss.

Cued task switching showed the clearest drug effect, in a form of flexibility whose response to psychedelics had not been systematically studied (Sayalı et al., 2026): switching between instructed task sets became slower and costlier. The two forms of shifting, explicitly cued and feedback-inferred, differ in what signals the switch. In feedback-inferred switching (the rule-switching task), the need to switch must be inferred from probabilistic feedback, so performance depends on how readily current commitments are relaxed. In explicitly cued switching (the demand selection task), the switch is instructed and performance depends on how efficiently a task set is reconfigured. Meta-control accounts posit that affective and motivational states shift the balance between stability and flexibility (Goschke, 2003), and positive affect, for example, reduces perseveration at the cost of greater distractibility (Dreisbach & Goschke, 2004). A loosening of learned, value-based commitments after psilocybin would predict reduced perseveration, the direction of the largest feedback-driven effect. We did not, however, observe the distractibility cost that such accounts predict, as MSIT interference was unchanged, although our power to detect it was limited.

Two differences may explain why we did not observe the reduced perseveration that Doss et al. (2021) found one week and one month after treatment. The more likely is the treatment and the population: their participants received two doses of psilocybin rather than one, and had MDD without co-occurring AUD. Timing is a second possibility. Our post-dose session (4-9 days after a single dose) overlapped their one-week assessment, but that assessment followed a second dose, and Sayalı et al. (2026) note that early post-acute effects can diverge from later ones: one day after a low dose of LSD, cognitive flexibility was still impaired while verbal fluency had improved (Wiessner et al., 2022), and in the pig brain, serotonin 2A receptor density was reduced one day after psilocybin and back at baseline one week later (Raval et al., 2021). Whether the pattern we observed changes at later time points requires repeated testing.

What performance changes can and cannot reveal

Because performance reflects both ability and the control a person chooses to invest, the slowing of cued task switching has more than one explanation. It may reflect less efficient reconfiguration of task sets, or a change in capacity. Alternatively, it may reflect less intense engagement within the task: reduced response vigour, of the kind expected when the opportunity cost of time changes (Niv et al., 2007; Kurzban et al., 2013; Otto & Daw, 2019). Or it may reflect general psychomotor slowing, which in acute studies affects overall response time more than process-specific executive measures (Yousefi et al., 2025). Three features of the current data constrain these explanations without selecting between them. Slowing was largest on switch trials but remained present on repeat trials; accuracy did not improve as slowing increased; and free choice between demand levels did not shift toward easier decks.

If reduced engagement is the explanation, it likely operated on the intensity of control within trials rather than on the decision to take on demanding work. The baseline-adjusted increase in choices of the least demanding deck is consistent with this, but the baseline imbalance in choice behavior and raw means make it difficult to confidently support this interpretation.

The same caveat applies to every performance measure in the battery, including the feedback-driven effects and operation span. Distinguishing motivation from other aspects of performance requires measures that vary the value of control directly, such as incentive manipulations, effort-discounting choices (Westbrook et al., 2013), or ratings of effort and task salience collected alongside performance. Thus, one cannot infer motivation from performance after the fact (Sayalı, 2026).

The willingness to exert control

The demand selection task provided the battery's one direct measure of the willingness to exert control.

First, willingness to exert control and performance were separable at baseline. Demand avoidance showed no detectable relation to operation span or to performance in the task being chosen, consistent with earlier evidence that avoidant participants are not less able (Sayalı & Badre, 2019). With 13 to 18 participants, this is an absence of evidence rather than proof of independence (BF01=0.9-2.0). Avoidance, however, was strongly related to depressive symptoms at the same visit (BF10=24), matching the profile of behavior that is predicted by motivational accounts of depression (Grahek et al., 2019). Two observations temper this result. The association was not present at post-dose testing, when many participants' symptoms had fallen, and test-retest stability of avoidance was low. Avoidance in this sample therefore behaved either as a state measure or as a measure with limited reliability over repeated administration; Sayalı (2026) cites evidence that avoidance on this task tracks trait need for cognition. A stable trait would predict higher test-retest reliability than we observed, so the low reliability here more likely reflects measurement noise in a small sample than a change in the trait; a larger sample could test this directly. The baseline association was exploratory and needs replication.

Second, we found no evidence that psilocybin increased willingness to exert control about one week after dosing, although it reduced depressive symptoms more than placebo. Sayalı (2026) identifies this pattern (no increase in willingness to engage effortful tasks on a demand-selection paradigm despite symptom improvement) as evidence that would challenge the model's core hypothesis. The model also states that increased engagement is expected for personally meaningful goals and that increased engagement with tasks lacking personal meaning would contradict it. Our task was neutral, so this boundary condition could explain the null result. Invoking it after the fact, however, would be the kind of post hoc reasoning Sayalı (2026) warns against, particularly as the model itself proposes this neutral paradigm as its test. Our data therefore provide no support for a general post-acute increase in the willingness to exert cognitive effort about one week after dosing, but they are not strong evidence against such a change in willingness: the sample for comparison between allocations was small (6 vs 9), estimated confidence intervals were wide (d from -1.06 to 2.00), and the estimated Bayes factor for the comparison between allocations was inconclusive (BF01=2.0). The personal meaningfulness of goals was not measured at either session. The prediction therefore remains open for a larger trial that offers both meaningful and neutral demanding choices.

Third, the prediction that participants with high effort avoidance and preserved performance would benefit most was not supported: in models adjusted for arm and for the baseline value of each outcome, baseline avoidance predicted neither drinking nor PHQ change, alone or in interaction with allocation, and for PHQ change the evidence against the prediction was moderate (BF01=3.3-3.4). Without this adjustment, more avoidant participants in the psilocybin arm showed larger PHQ reductions (rs=-.50, p=.14), the direction the prediction expects. However, more avoidant participants also had higher baseline PHQ scores, and participants with higher baseline scores had more room to improve; once baseline PHQ was taken into account, baseline avoidance no longer predicted PHQ change (β=+0.08, p=.54). The unadjusted pattern therefore most likely reflects higher baseline symptoms rather than a benefit of avoidance.

Drinking reduction and cognitive stability

If psilocybin reduces drinking by increasing flexibility, increases in flexibility should accompany drinking reductions. Across the battery, the opposite was observed, in both arms. Greater perseveration, larger switch costs, better rule maintenance, greater exploitation, and better reward learning were all associated with larger drinking reductions, and higher perseveration at post-dose testing was associated with fewer concurrent heavy-drinking days. Drinking reduction was thus associated with more stable, consistent, and value-guided choice. This fits accounts in which AUD involves weak goal maintenance and in which reducing drinking requires a newly adopted goal to be shielded from competing cues (Goschke, 2014). The evidence is correlational and rests mainly on the feedback-driven measures; the broader composite, which included cued switch costs and MSIT interference, showed a weaker relationship, and the association with the stability composite was also weaker when change was adjusted for baseline scores. The direction of influence is also unknown. Drinking less may itself make performance more consistent, for example through fewer residual effects of alcohol on testing days.

Depressive symptoms demonstrated a different relationship with cognition. Psilocybin reduced depressive symptoms in this sample more than placebo, although the Bayesian evidence for this was only anecdotal (BF10=2.7). Change in depressive symptoms was unrelated to change in drinking, was not associated with change on any cognitive measure or with the stability composite, showed no consistent direction on the stability-flexibility continuum (11 of 17 measures, against 15 of 17 for drinking), and was not predicted by working-memory span. One possibility is that change in cognitive control is a transdiagnostic mechanism whose beneficial direction differs between disorders: depression is often characterized by rigidity that may benefit from greater flexibility (Sayalı et al., 2026), whereas reduced drinking may require greater stability. Our data do not test this directly, as we did not find evidence that mood change was associated with either pole of the stability-flexibility continuum. At baseline, depressive symptoms were associated with the willingness to exert control rather than with any performance measure, and this is a link that future work could investigate longitudinally. The comparison between the two outcomes is limited by design: depressive symptoms were measured by self-report at the two cognitive visits, about one week apart, whereas drinking change covered 30 days, and the parent trial's clinician-rated depression outcome was not analyzed here.

Working-memory span as a predictor of drinking reduction

Lower baseline working-memory span predicted larger drinking reductions in both allocations. It was the strongest of 70 prognostic tests (q=.074; BF10=19-25) and survived every robustness check, and baseline accuracy in the demand selection task yielded the same direction of association with change in drinking behavior. This is contrary to the common expectation that better cognitive function supports better treatment outcomes (Bates et al., 2013). Several explanations are possible. Participants with lower span tended to drink more often at baseline, and although baseline drinking was included as a covariate, residual regression effects cannot be excluded with 18 participants. Extrapharmacological factors may also be relevant: people with lower span may rely more on external structure, so the frequent assessment and therapeutic contact of a trial may benefit them more (Clifford & Maisto, 2000). Lower span was also associated with larger increases in reward-learning accuracy, although not detectably with change in rule-switching cost, which may suggest that participants with the most room to improve changed most. Finally, as a performance measure, span reflects engagement as well as capacity. The effect of baseline working-memory span predicting reductions in drinking held among participants who met the processing-accuracy criterion, and span showed no detectable relation to demand avoidance, which argues against an explanation in terms of effort, but does not exclude it. Because the effect did not depend on allocation, span appears to be a general prognostic marker rather than a marker of response to psilocybin. It did not predict change in depressive symptoms (BF01=2.9), so its prognostic value may be specific to drinking.

Effect sizes for future trials

Because this is a pilot study, its main contribution is the size and precision of effects rather than tests of significance, and we report standardized effect sizes with confidence intervals and Bayes factors for every comparison (Tables S1 and S7). Four findings were supported by at least moderate evidence: the slowing of cued task switching after psilocybin (switch trials d=1.12, BF10=17; learning-phase RT d=1.01, BF10=7.7), the association between baseline demand avoidance and baseline depressive symptoms (BF10=24), the prediction of drinking reduction by working-memory span (BF10=19-25), and the coupling of drinking reduction with change in the stability composite (BF10=29, weaker after adjustment for baseline scores) and in reward-learning accuracy (BF10=3.7). For depressive symptoms, there was also moderate evidence against the prediction that baseline demand avoidance would forecast improvement (BF01=3.4). No drug effect, by contrast, was supported by even moderate evidence for its absence: Bayes factors for the null did not exceed 2.5, so these results are insensitive rather than negative. Effect sizes from pilot studies are imprecise and should not be used directly for power calculations (Leon et al., 2011). Future trials should instead be powered for the smallest effect of interest, using the confidence intervals reported here as a guide to plausible ranges. On that basis, the results most worth confirming are the slowing of cued switching, the association between change toward stability and drinking reduction, and the prognostic value of working-memory span. The smaller practice-related rise in perseveration under psilocybin than under placebo (d=-0.79, with an interval that includes zero) is a candidate effect rather than a finding.

Limitations

• The sample was small: 12 to 25 participants per analysis. After the exclusion of chance-level sessions, drug effects rested on 6 placebo and 7 psilocybin participants for rule switching, 7 and 9 for demand selection performance and 6 and 9 for demand avoidance. No single drug effect or coupling survived correction across the battery, and confidence intervals around null effects were wide; Bayes factors showed that these null results are inconclusive rather than evidence of absence.

• The classification of measures followed construct definitions but was finalized after data collection, and some placements are debatable. Inverse temperature conflates exploitation with choice noise, and cued switch costs may reflect reconfiguration efficiency or engagement as much as task-set inertia. The sign tests treat correlated measures as independent and are descriptive. At baseline, indices assigned to the same pole shared only modest variance across tasks, and several had low test-retest reliability (Figure S1).

• The stability composite was defined after data inspection. A broader composite showed weaker effects, and adjusting change for baseline scores weakened the composite's association with drinking reduction. The composite, the motivation analyses and the clinical-coupling analyses are exploratory.

• Every score except free choice is a performance measure and reflects both ability and the control invested. Willingness to exert control was measured with a single neutral choice task whose test-retest stability was low. Task salience, subjective effort and personal meaning were not measured, so PRISM's specificity claim could not be tested. Depressive symptoms were measured by self-report (PHQ-9) at the cognitive visits only.

Conclusions

In this pilot study, about one week after dosing, psilocybin did not uniformly enhance cognitive flexibility, and there was no evidence that it increased the willingness to exert control. Relative to placebo, it slowed cued task switching, had no consistent effect on feedback-driven measures, and showed no detectable effect on inhibition or value learning. Drinking fell in both arms, and its reduction was associated with movement toward stability on nearly every measure and was predicted by lower working-memory span. Depressive symptoms improved more after psilocybin, but their improvement was not associated with cognitive change. A transdiagnostic cognitive-control account of psychedelic therapy may therefore need to specify the form of flexibility involved, to distinguish performance from the willingness to exert control, and to specify the direction of change that recovery requires in each disorder.
