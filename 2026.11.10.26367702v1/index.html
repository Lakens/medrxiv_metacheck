Reporting p values imprecisely (e.g., p < .05) reduces transparency, reproducibility, and re-use (e.g., in p value meta-analyses). Best practice is to report exact p-values with three decimal places (e.g., p = .032) unless p values are smaller than 0.001, in which case you can use p < .001.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (e.g., “decreased at the p < .05 significance threshold”).

To check Non-Significant P Value Check

What we found

We found 12 non-significant p values that should be checked for appropriate interpretation.

Show details

Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Abstract

Neuroinflammation is increasingly recognised as a key contributor to frontotemporal dementia (FTD) pathophysiology, yet how inflammatory processes relate to neurodegeneration and clinical progression remains poorly defined. This study aimed to identify a multivariate cerebrospinal fluid (CSF) inflammatory signature covarying with brain atrophy, and to determine its relevance to clinical and cognitive outcomes in genetic FTD.

We recruited 234 participants (non-carrier controls n=78, presymptomatic carriers n=115, symptomatic carriers n=41) with CSF, MRI, and clinical (CDR ® + NACC FTLD sum of boxes [CDR-SB]) and executive (Wechsler Adult Intelligence Scale-Revised Digit Symbol Substitution Task [DSST] assessments. A regularised canonical correlation analysis (rCCA) was used to derive a shared protein-brain covariance axis. Participants were followed annually for up to 8.6 years (CDR-SB) and 11.5 years (DSST), and linear mixed-effects models were used to estimate individual rates of clinical progression (CDR slope) and executive decline (DSST slope). The predictive value of the inflammation-and MRI-based profiles for cross-sectional CDR-SB, CDR slope, DSST and DSST slope were tested in linear models. Due to floor effects and violations of parametric assumptions, Bias-corrected and accelerated (BCa) confidence intervals (CI) and bootstrap CIs (95%, 5000 replicates) were utilised as the primary inferential criterion in the 2 nd -level linear models; effects were considered non-significant if the 95% BCa CI crossed zero.

The rCCA identified a robust inflammation-brain axis (r=0.89, p<0.001), driven by CXCL9, FLT3L, CCL3, and frontotemporal-insular atrophy pattern. In symptomatic carriers, the MRI canonical variate was associated with CDR-SB (β=3.80, CI: [0.64, 6.20]) at baseline, whereas the inflammatory protein canonical variate was predictive of CDR-SB slope (β=0.24, CI: [0.02, 0.46]). Whereas both MRI ( = -7.27, CI:[-14.20, -1.00]) and protein ( = -7.83, CI:[-14.00, -2.16]) canonical variates were linked to DSST cross-sectionally, but not longitudinally. No significant associations were found in pre-symptomatic carriers or non-carrier controls.

A data-driven CSF inflammatory signature, covarying with frontotemporal-insular atrophy, tracks with clinical severity and cognitive impairment in people with genetic FTD, highlighting inflammation as a candidate therapeutic target and progression biomarker in the earliest clinically manifest stages of disease.

Introduction

Frontotemporal dementia (FTD) encapsulates a heterogeneous group of clinical syndromes linked to neurodegenerative diseases, ranging from pronounced language symptoms (Primary Progressive Aphasia [PPA]) 1 to behavioural changes (behavioural variant FTD [bvFTD]) 2 , and motor problems 3 . Approximately 10-20% of people with FTD carry an autosomal pathogenic mutation 3 that cause the disease, referred to as genetic FTD. The most common mutations include the hexanucleotide (GGGGCC) repeat expansion in Chromosome 9 open reading frame 72 (C9orf72) 4 5 , a loss-of-function mutation in progranulin (GRN) causing haploinsufficiency 6 7 , and missense and splice site mutations in the microtubule-associated protein tau (MAPT) 8 . C9orf79 and GRN mutations are related to TDP43 pathology, while MAPT mutations are linked to tauopathies 9 . Presymptomatic people carrying these genetic mutations show marked changes that can be detected years prior to symptom onset in imaging 10 11 , cognition and behaviour 10 12 13 14 , or proteomic profiles 15 16.

Neuroinflammation is now recognised as a central and dynamic component of the pathogenesis of FTD 17 , and is associated with faster clinical decline 18 19 . This disease process reflects a highly coordinated cascade of cellular and molecular events involving central nervous system-resident glia (astrocytes and microglia), peripheral immune cells (including monocytes and lymphocytes), and diverse signalling mediators such as cytokines and chemokines 17 20 21 22 23 . Dysregulated cytokine secretion is a key feature of FTD, with converging evidence from blood, CSF, and post-mortem brain tissue 24 25 26 23 . In a retrospective cohort of genetic FTD, Fenoglio et al (2024) 27 showed that several plasma cytokines, including Tumour Necrosis Factor (TNFα) and interleukins (IL-7, IL-15, IL-16, IL-17A) are significantly upregulated in symptomatic MAPT and GRN mutation carriers 27 . Complementing these findings, largescale CSF proteomic studies in genetic FTD have demonstrated that the three most common mutation groups exhibit distinct pathogenic signatures, with immune-related pathways particularly enriched in symptomatic MAPT carriers 28 . In sporadic FTD, multiple studies report upregulation of TNFα, interleukins and chemokines in blood and CSF relative to unaffected controls 29 30 . In sporadic FTD, proinflammatory cytokines in blood have been found to be strongly associated with central inflammation and shorter survival 23 . Taken together, there is substantial evidence for dysregulated immune pathways in FTD, but their relationships with clinical trajectories and neurodegeneration remain incompletely understood. In a large multicentre FTD consortium study of more than 390 participants, Asken and colleagues 31 quantified IL-6, TNFα and YKL-40 in plasma from presymptomatic and symptomatic mutation carriers and healthy controls, directly linking inflammatory markers to disease progression. Higher TNFα levels were associated with faster clinical decline and temporal lobe atrophy, both cross-sectionally and longitudinally, in MAPT carriers, whereas in C9orf72 carriers, elevated TNFα was related to accelerated cognitive and clinical decline without a clear longitudinal atrophy signature. These genotype-specific associations highlight the need to better characterise how inflammatory protein abundance maps onto patterns of neurodegeneration across the FTD spectrum. In line with this, Ullgren and colleagues reported that individual immune-related CSF proteins, such as SERPINA3, are associated with brain atrophy and clinical severity in people with FTD 32 . However, no study has yet captured the multidimensional structure of immune-associated multi-protein profiles and their covariance with atrophy patterns and clinical changes over time, leaving a critical gap in our understanding of immune-brain coupling in FTD. Univariate statistical approaches often cannot capture complex links between modalities, and analysing multidimensional patterns allows us to potentially derive clinically relevant therapeutic target(s) even in presymptomatic stages.

In this study, we aimed to identify a data-driven proteomic profile associated with regional atrophy in genetic FTD, using multivariate statistics of CSF and MRI data from the Genetic FTD Initiative (GENFI) study. We evaluated whether atrophy-related inflammatory signatures are associated with clinical and executive decline, under the hypothesis that greater inflammatory burden would track with faster deterioration.

We also tested whether these inflammation-atrophy-clinical relationships are already detectable in the presymptomatic phase by comparing healthy non-carrier controls with presymptomatic and symptomatic mutation carriers.

Materials and methods

Participants

From the GENFI (Genetic Frontotemporal dementia Initiative [https://www.genfi.org]) study (data freeze 8) 10 , n=234 participants who underwent CSF sampling and volumetric T1-weighted MRI acquisition at the same visit, as well as standardised GENFI assessments, were included in this study. Specifically, we included n=41 symptomatic carriers (9 with mutation in MAPT, 12 in GRN, and 20 in C9orf72), n=115 presymptomatic (defined as the absence of a formal diagnosis) mutation carriers (23 with mutation in MAPT, 40 in GRN, and 52 in C9orf72), and n=78 family members without mutations (non-carrier control group). Participants with another significant medical or psychiatric condition that would interfere with their completion of assessments or impair their safety in the study, or participants who were pregnant or had contraindications to MRI, were excluded.

Clinical Outcomes

Participants underwent clinical and cognitive assessments at baseline and annually for up to 11.5 years.

To evaluate clinical decline, we utilised the Sum of Boxes score from the CDR+NACC FTLD, as it has been widely used in FTD clinical trials as primary clinical outcome 33 34 . The CDR® +NACC FTLD captures eight domains, which are particularly affected in FTD phenotypes 35 36 35-37 . The CDR® +NACCFTLD (referred to as CDR-SB onwards) ranges from 0-24, where higher scores indicate more severe symptomology 38.

Executive decline was indexed using the Wechsler Adult Intelligence Scale-Revised Digit Symbol Substitution Task (DSST) 39 ,ranging from 100 (no executive dysfunction) to 0 (executive dysfunction). For more details on clinical outcomes, see supplementary methods.

MRI acquisition has been described elsewhere 40 . Briefly, T1-weighted volumetric (1.1 mm isotropic resolution) scans were acquired on 3 Tesla scanners (Siemens Trio

CSF sample collection and processing

CSF samples were collected by lumbar puncture into polypropylene tubes and stored at -80 °C at each site. CSF proteins were measured using the proprietary Olink® Target 96 platform. For more details on the processing of the proteomic data, see supplementary methods.

Statistical analyses

Statistical analyses were performed in R version 4.5.2 and MATLAB (version R2023b).

For descriptive statistics, chi-square and analysis of variance tests compared variables between groups.

Canonical Correlation Analysis of the inflammation-atrophy profile.

To investigate the inflammation-brain covariance axis, we applied a two-level approach previously deployed in our studies 41 42 43 12 23 . In the first step, we applied a regularised Canonical Correlation Analysis (rCCA) in MATLAB with classical bootstrapping (1000 replicates) to ensure solution stability (supplementary methods for more details on rCCA). In the second step, we imported the canonical variates (CV) and associated loadings from the previous step into R and constructed a linear model with the "lm" function to model MRI-CV using an interaction term between protein-CV and groups (factor with the following levels; controls=0, presymptomatic carriers=1, and symptomatic carriers=2) as the predictor, with age, sex and scanner model as covariates (MRI-CV~Protein-CV*Group+Age+Sex+scanner model). Next, we tested for group differences in the resulting CV variables from the protein and MRI data and ran an Analysis of Covariance (ANCOVA) controlling for age and sex. The ANCOVA was implemented as a linear model using the "lm" function, tested with Type III ANOVA from the car package, and post hoc contrasts were computed using the emmeans package with Bonferroni correction.

Second -level analyses linking the inflammation-atrophy axis to clinical outcomes.

To estimate longitudinal trajectories, we fitted linear mixed-effects models (lme4 "lmer") to CDR-SB and DSST scores separately, modelling each as a function of years since baseline (MRI/CSF visit) with random intercepts and slopes per participant. Participant-specific slopes (CDR slope, DSST slope), and cross-sectional scores and slopes were then compared across the three clinical groups using one-way ANOVAs (supplementary Figure 2). The predictive value of the protein and MRI latent factors (or CVs) on clinical outcomes was tested in linear models using the CDR-SB, CDR-SB-slope, DSST, and DSST-slope as dependent variables, and CV values*group (factor levels: controls=0, presymptomatic carriers=1, symptomatic carriers=2) as an interaction term. First, we ran separate models with the protein-CV and MRI-CV as single predictors. Then, we tested the combined predictive values of the two variables in a three-way interaction model (protein-CV*MRI-CV*Group). Age, sex, years of education and scanner model were entered as covariates, with controls as the reference group. To directly test whether the association between the canonical variates and outcomes also differed between symptomatic carrier and presymptomatic carrier groups, the group variable was relevelled with presymptomatic carriers as the reference category (factor levels: presymptomatic carrier=0, control=1, symptomatic carriers=2) and the above models were refitted (referred to as "relevelled model").

Inflammation protein signatures independent of atrophy.

To isolate the protein-only signal from the atrophy-linked protein profiles (protein-CV), we residualised the 92 proteins. For more details on residualisation analyses and consequent application of PCA's, see supplementary methods Symptomatic-carrier group-specific analyses. Within the symptomatic carrier group, we also tested associations between clinical outcomes and both the residualised protein component and the protein-CV using non-parametric Spearman's rank correlations. Given the smaller sample size of the symptomatic carrier subgroup, we additionally computed one-tailed Bayesian Spearman's correlations (https://osf.io/gny35/), which enable a more robust statistical interpretation by com-puting Bayes Factors (BF). These correlations were complemented by linear models including covariates.

Group stratification by clinical severity.

To better capture presymptomatic clinical spectrum effects, we re-stratified groups by CDR-SB score rather than diagnosis alone, following previously established criteria for mutation carriers 40 10 36 : asymptomatic (CDR-SB=0, n=78), prodromal (CDR-SB=0.5, n=19), and symptomatic (CDR-SB≥1, n=44). Models were re-run substituting disease status with clinical stage (controls=0, asymptomatic=1, prodromal=2, symptomatic=3).

Due to floor effects and violations of parametric assumptions, Bias-corrected and accelerated (BCa) 44 confidence intervals (CI), bootstrap CIs (95%, 5000 replicates) were utilised as the primary inferential criterion in the 2 nd level linear models using the "boot" function from the boot package: effects were considered non-significant if the 95% BCa CI crossed zero.

For the interpretation of the Bayesian approach, we set a BF≥3 to evaluate the evidence supporting the alternative hypothesis (a correlation) under the Lee and Wagenmakers criteria 45.

Discussion

Our study integrates multiplex CSF proteomics and MRI to investigate the relationship between inflammatory and atrophy profiles, and their clinical relevance and predictive value in genetic FTD. Our data-driven approach identified a robust inflammation-atrophy covariance axis that predicts clinical decline over time in people with symptomatic FTD. Specifically, the atrophy-related CSF inflammation pattern predicted worse CDR-SB scores over time in symptomatic FTD gene carriers. Inflammatory markers and fronto-insular atrophy measures differentiated symptomatic from presymptomatic and control participants, but could not separate presymptomatic from control participants. To further elucidate protein-brain covariance across the presymptomatic continuum, we re-stratified participants by CDR-SB scores, which more sensitively capture granular clinical changes than the simple absence of a formal clinical diagnosis. When deploying this approach, we found that inflammatory protein and MRI covarying scores trended towards stepwise divergence between the prodromal and asymptomatic stages. Examining single protein levels of both CXCL9 (the highest loaded protein derived from the rCCA) and NfL, we detected statistically discernible increases in prodromal stages. For the 2 nd -level analyses, both group stratification strategies yielded convergent interpretations. However, within the prodromal FTD cohort, associations with executive dysfunction and clinical progression did not reach statistical significance.

Applying a CCA across proteomics and MRI data, we identified an atrophy-related inflammatory profile that was driven by chemokines (CXCL9, CCL3, CCL2 or MCP-1 and CCL25) that are involved in the recruitment of T-cells and Natural Killer cells 46 , monocytes and macrophages 47 , as well as FLT3L, which promotes the development of dendritic, B, and natural killer cells, and MMP10, which is involved in tissue remodelling 48 49 . The CCA also identified an atrophy pattern linked with inflammation, which encompassed frontal and temporal regions and the insula, consistent with their central and early involvement in FTD 50 51 10 . Notably, interpretation of rCCAderived canonical variates differs from other dimensionality reduction techniques such as PCA: rCCA assigns weights to maximise correlation between modalities, rather than reducing dimensionality within each modality independently. In this context, higher CSF protein-CV scores indicate increased inflammatory signalling asso-ciated with regional brain atrophy, while higher MRI-CV scores reflect more pronounced atrophy in regions that most strongly covary with the inflammatory profile.

The primary advantage of rCCA is that it treats inflammation and neurodegeneration as an integrated system, capturing complex multimodal crosstalk within a unified statistical framework.

The atrophy-related inflammation CSF pattern, led by CXCL9, identified by our datadriven analysis was elevated in symptomatic patients. Previous studies focusing on single inflammation markers did not find significant increase in CXCL9 levels in blood and CSF of patients with PPA 52 or bvFTD 29 . Mechanistically, CXCL9 is an IFN-γ inducible chemokine that signals through the CXCR3 receptor 53 54 , a pathway implicated in T-cell recruitment to the CNS and to sites of inflammation 55 , that potentially contributes to neurodegeneration. On the other hand, multiple studies have shown increased levels of MCP-1 in CSF of people with FTD compared with controls 56 21.

MCP1 (also known as CCL2) is implicated in the pathogenesis of a range of human diseases 57 . MCP1 plays an important role in the inflammatory response, acting as a modulator of leukocytes, and its levels have been linked to AD disease severity 58 59.

MCP1 is a well-established biomarker that captures aspects of the inflammatory response. Similarly, IL18, which is a pro-inflammatory cytokine involved in a range of inflammatory responses including pyroptosis 60 , has been found to be increased in both blood serum and the superior frontal cortex at postmortem in people with FTD 30.

Higher CSF levels of IL18 were also detected in fast-progressing ALS with a C9orf72 mutation 61 . Several proteins with high loadings onto the protein canonical variate, including MMP10, CCL25, LAP-TGF-β1, OPG, and SIRT2, have received little to no attention in FTD fluid biomarkers research. The convergence of these novel biomarkers onto the canonical variate implicates extracellular matrix remodelling, immune cell trafficking, and osteoimmune signalling as underexplored pathological processes in FTD pathogenesis, warranting further investigation.

Although TNF-and IL-6 were not among the top-loading CSF proteins in our rCCA, this may reflect cohort, tissue or platform differences rather than a lack of biological relevance. Previous research has linked increased plasma levels of TNF-and IL-6 to accelerated longitudinal atrophy in the functional and temporal lobes in MAPT mu-tation carriers, while in C9orf72 mutation carriers higher TNF-abundance was associated with faster functional and cognitive deterioration 31 . Given that survival provides a more objective quantification of disease progression than certain clinical scales, Malpetti et al ( 2024) 23 implemented a data-driven approach to capture a proinflammatory signature driven primarily by TNF-, TNF-R1, M-CSF, IL-17A, IL-12, IP-10 and IL-6. This pro-inflammatory pattern was significantly associated with a higher probability of shorter survival in sporadic FTD, as well as higher levels of brain inflammation 23 . Linking peripheral immune signalling to in-vivo molecular brain imaging, utilising the [ 11 C]-PK11195 radiotracer (a proxy measure for neuroinflammation, binding TSPO 62 63 ), previous PET studied showed elevated neuroinflammation in frontotemporal regions of symptomatic carriers of FTD-related gene mutations as compared to controls 64 . However, the pattern of increased [ 11 C]-PK11195 signal was heterogeneous within the symptomatic FTD mutation-carrier group, closely matching brain regions that relate to their clinical syndrome; for example, participants with a MAPT mutation with a clinical diagnosis of bvFTD had elevated binding in frontostriatal regions, whereas a participant with PPA exhibited elevated signal in temporal regions. A single case study has also described elevated [ 11 C]-PK11195 signal in a presymptomatic MAPT carriers, in absence of detectable regional atrophy 65 . However, capturing the complex and intertwined links between inflammatory signalling and localised atrophy patterns requires robust multimodal statistical integration. Our implemented rCCA model addresses this complexity.

We deployed an rCCA, which is a model that captures shared variances between our two data sets (protein and MRI). To examine whether a non-brain-related inflammatory pattern is also clinically relevant we residualised our proteins against protein-CV and extracted the residuals. This effectively removed any variance that is captured within the inflammation-atrophy axis. Applying a PCA to the extracted residuals we derived an inflammation pattern that was completely decoupled from the atrophy pattern. Interestingly, this inflammation signature was not linked to any of the clinical outcomes within the symptomatic group. This suggests that a generalised immune pattern was not sufficient to explain clinical decline in our cohort, whereas the inflammatory protein-brain axis was able to predict clinical decline. Hence, the shared variance between the protein and MRI data is clinically relevant and intertwined. However, CXCL9 levels (the most highly loaded protein derived from the rCCA) alone were associated with clinical progression in participants who phenoconverted. This supplements the findings from Asken et al. (2023) 31 , which identified TNF-and IL6 as clinically relevant inflammatory markers in genetic FTD. Further research is needed to investigate whether stepwise therapeutic strategies utilising compounds targeting different parts of the immune system could be efficient diseasemodifying interventions in people with FTD.

The inflammation-atrophy axis identified in symptomatic participants has also translational relevance both as a therapeutic target and as a multivariate biomarker component for trial design. Three top-loading proteins map onto pathways with existing pharmacological tool compounds: MCP1/CCL2, IL-18 and CCL3. These can be considered in terms of translational and repurposing readiness from other fields into FTD trials. MCP1 has been implicated in HIV-associated neurocognitive impairment, which affects around 30-50% of people living with HIV. 88 89 In a small single-arm study, the dual CCR2/CCR5 antagonist cenicriviroc was associated with improved cognitive performance and reduced inflammation over 24 weeks, although it has not yet been tested in FTD. 90 The NLRP3 inflammasome-caspase-1 IL18 axis is a key mediator of innate immune activation across multiple diseases and can be targeted via IL-18 neutralisation or NLRP3/caspase-1 inhibition; notably, the oral NLRP3 inhibitor dapansutrile is in Phase 2 testing in early Parkinson's disease (DAPA-PD; NCT07157735) 91 92 93 94 95 . CCL3 is a chemotactic cytokine signalling through CCR1/CCR5. 69 Maraviroc, a CCR5 antagonist approved for HIV, has been shown by Festa et al (2023) to rescue autophagic and neurodegenerative phenotypes in mouse models 96 97 and can cross the blood-brain barrier in people with HIV 66 . Collectively, these observations suggest that targeting MCP1/CCL2, IL-18 and CCL3 biology may hold therapeutic promise in FTD and related dementias. Because the atrophy-related inflammatory pattern we identified was transdiagnostic, CSF inflammatory panels are unlikely to offer strong differential-diagnostic value across the FTD continuum. However, this same transdiagnostic quality suggests an integrated immunotherapeutic strategy may prove beneficial across individual FTD-spectrum diseases, rather than requiring disease-specific approaches. This is further supported by a growing body of clinical evidence linking inflammatory profiles to structural brain changes and shorter survival.

Several studies have demonstrated early brain changes in genetic FTD occurring within the presymptomatic window 67 14 . However, in the present study, the CCAdefined inflammatory protein component and the inflammation-related atrophy profiles revealed no statistically significant differences between healthy controls and presymptomatic mutation carriers. This is consistent with De Houwer et al. (2025) 28 , who employed proximity extension assay Olink technology to quantify over 2,900 proteins in CSF samples of people with genetic FTD and similarly identified no differentially abundant proteins between presymptomatic participants and controls. One explanation is that CSF sampling in our cohort occurred early in the disease trajectory, at a point when pathological processes remain below the detection threshold of current proteomic tools. Had samples been collected closer to phenoconversion, differences in both inflammatory proteins and inflammation-related MRI patterns relative to controls would more likely be apparent. To address this, we ran sensitivity analyses re-stratifying our participants by CDR-SB scores, which more sensitively capture granular clinical changes than the simple absence of a formal clinical diagnosis. Although proximity extension assay technology robustly quantifies a pre-specified set of proteins, the human proteome encompasses tens of thousands of distinct proteins, the majority of which remain unmeasured 68 69 70 . Crucially, this platform requires intact proteins with accessible epitopes for dual-antibody binding, and therefore cannot reliably detect short peptides, protein fragments, or heavily modified proteoformsspecies that may undergo early changes in FTD and carry prognostic or mechanistic significance. Unbiased, mass spectrometry-based proteomics approaches therefore offer a complementary and potentially more sensitive strategy for biomarker discovery in this context. In line with this, a recent GENFI study 16 , employing mass spectrometry in CSF of participants with genetic FTD, found that the immune response co-expression module did not significantly differentiate presymptomatic carriers from controls, though other proteomic clusters showed presymptomatic changes, providing further evidence that immune dysregulation may not be detectable in CSF during the presymptomatic phase. Given that neither CSF inflammation proteomics nor the CCA-derived profiles detected significant immune dysregulation in presymptomatic carriers, it is possible that neuroinflammatory activation and immunological changes may be spatially restricted to the brain parenchyma at this disease stage and not yet reflected in the CSF compartment. Future studies incorporating positron emission tomography with translocator protein (TSPO) radioligands could directly visualise microglial-driven neuroinflammation in presymptomatic mutation carriers 71 , offering a more sensitive and spatially resolved window into the temporal dynamics of neuroinflammation in presymptomatic FTD.

Several limitations of this study should be considered when interpreting our findings.

First, whilst the Olink Target 96 Inflammation platform is scalable and widely accessible, it quantifies 92 pre-selected inflammatory proteins, but does not capture the whole complexity of inflammatory cascades and other disease-relevant pathways, including synaptic and metabolic changes. Second, medical history data on past or current infections and inflammatory conditions were not available. However, our study focussed on a atrophy-related inflammatory protein pattern in CSF, which may reduce capturing signals related to peripheral conditions. Third, our study was insufficiently powered to investigate group differences in the inflammation-atrophy axis between gene mutation cohorts (C9orf72, GRN, or MAPT). Pooling the genetic subgroups in the rCCA may mask mutation-specific inflammation-atrophy associations, as previous studies identified mutation-specific differences in protein abundance 28 27 . Finally, CSF proteomic data were available cross-sectionally only and the rCCA deployed is a linear statistical model that assumes linear patterns in the protein-brain covariance matrix; hence, non-linear associations are not captured. This is particularly relevant for inflammation, which is not a static process but rather a highly complex, dynamic mechanism that may change over time. Future research incorporating longitudinal data is needed to capture non-linear trajectories of inflammatory processes across the pre-symptomatic and symptomatic windows of FTD, as well as multimodal and sensitive approaches that can capture changes in brain versus peripheral inflammation early in FTD, even before symptoms.

Conclusion

In conclusion, our study identified a robust data-driven association between CSF inflammatory proteins and brain atrophy in genetic FTD, that is driven predominantly by older symptomatic participants. The atrophy-related inflammatory protein pattern identified in this study is clinically relevant, predicting both disease progression and cross-sectional executive dysfunction in symptomatic individuals. These findings support the use of multivariate approaches to examine complex relationships and dynamics between brain atrophy, inflammation and clinical outcomes in FTD.
