How StatCheck works

Check consistency of p-values and test statistics

The Statcheck module runs Statcheck. Statcheck searches for regular expressions that match a predefined pattern, and identifies APA reported statistical tests. More information on the package can be found at https://github.com/cran/statcheck. The module only returns Statcheck results for t-tests and F-tests, as these are the only tests which have been validated, see https://osf.io/preprints/psyarxiv/tcxaj_v1/.

Statcheck was developed by Michèle Nuijten and Sascha Epskamp.

Statcheck considers p = 0.000 an error, as you should report p < 0.001. Furthermore, p < 0.03 is an error if the p-value was 0.031, and one should simply report exact p-values (p = 0.031). When the sentence of a test says it is one-sided (“one-tailed”, “one-sided” or “directional”), a p-value that fits a one-sided test counts as consistent (statcheck’s OneTailedTxt setting; #695). When the paper says anywhere that its tests are one-sided, a p-value that fits a one-sided test in either direction counts as consistent too: half the two-sided p, or 1 minus that half for an effect against the predicted direction. Equivalence tests (TOST) are left out, as their p-values do not test the difference. A statistic written with “<” or “>” is read as a bound, and in a sentence about equal variances an F-test’s two-sided p (twice the one-tailed p) counts as consistent. For more information, see StatCheck.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.), reported as exactly zero (e.g., p = .000), or impossible (below 0 or above 1, e.g., p = -.22).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold”, “legend” or “named”).

A p-value with the name of a correction or a test after the p (“pFWE < .05”, “padj < 0.05”, “p Wilcoxon = .02”) is flagged only when a test statistic comes before it in its clause (“t(37) = 7.17, p FWE < .05”). Without one it is mostly the rule that decided what was significant (“genes with padj < 0.05 were selected”); such a p-value is “named” in not_a_test. Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

A p-value below 0 or above 1 is impossible; it is listed apart and not also as imprecise. Often the statistic before it, or its minus sign, was copied into it (“t(134) = -2.32, p = -.13”, “Z = 3.091, P = 3.091”). A value above 1 is listed only after a test statistic in its clause: without one, a “P” above 1 was nearly always another quantity (a proportion, pH, a group’s mean, a model parameter). A number in scientific notation whose power of ten was lost when the PDF was read (“p = 2.4 x 10 -9” read as 2.4) is not listed. A “p” that is the subscript of another symbol (“r p = .64”, “²p = .02” for partial eta squared, “Δp = .33”), or a quantity with a unit, a logarithm or a ratio (“P = 2.9 µm”, “-log10 P = 7.5”, “Ca/P = 1.67”), is not read as a p-value at all (see extract_p_values()). Each p-value has its own row, also when the same one is written twice in a sentence.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. Abstract

Tuberculosis (TB) transmission is sustained in part by asymptomatic disease(aTB). This limits the effectiveness of passive case finding interventions that rely on symptom-based diagnosis. Compartmental transmission models commonly represent the time spent with aTB as a single disease state, thereby imposing an exponentially distributed waiting time and a constant hazard of leaving that state. We evaluated how differences in the shape of the aTB waiting-time distribution affect the fit to observed disease progression data and subsequent projections of TB incidence and active case finding (ACF) impact. We fitted exponential and chained-state gamma formulations to cohort data on aTB progression and incorporated them into transmission models. We found the gamma-distributed model to fit the data at least as well the exponential model, indicating that the alternative model structures can also capture changes of aTB dynamics. Comparing the fitted gamma-distributed model and the exponential model, we quantify how assumptions about aTB dynamics affect future disease trajectories and the expected impact of ACF interventions. Using India as a case study, we found that the gamma-distributed model projects a slower decline in TB incidence under the status quo, but a substantially larger reduction in the projected incidence of TB when ACF is employed, compared with the exponential model. These results suggest that estimates of ACF impact, and consequently assessments of its cost-effectiveness, may be sensitive to assumptions regarding the shape of waiting-time distribution for asymptomatic disease, indicating the importance of better evidence on the natural history of asymptomatic disease for projecting of intervention effects.

1 Introduction

Population-based tuberculosis (TB) prevalence surveys conducted over the past three decades have revealed that a substantial fraction of individuals with prevalent, bacteriologically-positive TB do not report the presence of typical symptoms of TB, such as persistent cough or weight loss [1, 2].

Here, we refer to this disease state as "asymptomatic" TB (aTB, consistent with the most recent WHO guidance [3]), but terms such as "sub-clinical" or "early" have also been used [4, 5]. A metaregression using data from all available surveys (23 national and 5 subnational surveys) concluded that 50.4% (interquartile range, IQR, 39.8%-62.3%) of all prevalent TB was asymptomatic [5].

The clinical and public health implications of the finding that approximately half of all prevalent bacteriologically-positive TB is found among individuals who do not report typical symptoms are potentially profound [5]. Because most tuberculosis control programs rely on passive case finding (i.e., individuals must self present to health services for diagnosis) [6], individuals are unlikely to be diagnosed or treated while in an asymptomatic disease state. This results in negative individuallevel and community-level consequences: delayed diagnosis of individuals may lead to worse shortand long-term health outcomes [7] and may allow longer periods of disease transmission in communities. The magnitude of these negative health outcomes depends on both the natural history of aTB (i.e., how long does this disease state last, and how many progress to symptomatic disease or self-cure?) and the infectiousness of individuals with aTB [8]. Recent research has focused on both of these areas of uncertainty, providing evidence that those with aTB can self-cure or progress to symptomatic TB [9], but may also remain in this disease state for years [10] [11] [12] [13]. Further, individuals with aTB can have smear-positive TB [14] and may generate as many secondary cases as individuals with symptomatic disease [15] [16] [17]. A recent modeling analysis estimated that more than two-thirds of transmission in Asia and Africa may be attributable to those with aTB [2, 16].

Transmission dynamic models designed to incorporate this growing understanding of the complex natural history of infection have typically included aTB as a single health state [9, 11, 18, 19], encoding the implicit assumption that there is a constant hazard of progression from this state and exponentially distributed durations of aTB. In this paper, we examine how the distribution of time individuals spend in an asymptomatic infectious state influences future incidence trends and the effectiveness of ACF interventions. First, we test whether models that allow for non-exponentially 2 distributed durations of aTB provide a comparable fit to observed natural history data, by fitting a range of model structures to an empirical dataset on TB incidence rates for individuals with aTB.

Second, we examine the consequences of incorporating these different structures into transmission models to project epidemic trajectories and to estimate the effect of case finding interventions. We use India as our motivating example, since India bears the world's largest TB burden [20, 21]. We use epidemiological data, including national incidence estimates and findings from an Indian cohort study [22], to ground our assumptions and model parameters in real-world observations [19, 20, 22].

By explicitly linking assumptions about the duration and progression dynamics of aTB to epidemic projections and intervention impact, we find that the details of the natural history of infection have important consequences for epidemic projections and anticipated effects of interventions [2].

2 Methods

2.1 Model Structure

Figure 1 illustrates the structure of the model. Individuals progress from minimal disease to asymptomatic tuberculosis (aTB), and subsequently to symptomatic disease. Minimal disease is defined here as pathological evidence of disease prior to bacteriological confirmation of TB, regardless of the presence of symptoms [11, 23]. In the exponential model, aTB is represented as a single compartment. In the gamma-distributed formulation, the asymptomatic stage is divided into k sequential sub-states [24, 25].

Let η denote the progression rate from aTB to symptomatic disease in the exponential model. To preserve the same mean duration of the asymptomatic stage in the gamma-distributed formulation, each of the k sequential sub-states is assigned the same transition rate, κ = kη. The total time spent across the k sub-states therefore follows an gamma distribution with shape k and rate κ, yielding a mean duration of k/κ = 1/η, identical to that of the exponential model. This parameterization ensures that the differences between the model outputs reflect the differences in the shape of the waiting time distribution rather than the differences in its mean. In particular, the gamma-distributed formulation relaxes the memoryless assumption of the exponential model and reduces the probability of extremely short asymptomatic durations.

2.2 Do cohort data support adoption of a model with non-exponentially distributed durations of aTB?

To evaluate whether the exponential distribution of aTB durations adopted in previous modeling studies adequately reflects empirical observations, we conducted a model-fitting analysis using cohort data that captured progression from aTB to symptomatic TB. We implemented a series of gamma-distributed models with increasing shape parameters (k = 1 (e.g., a exponential model assuming constant hazard) to k=100 (a model with a sharply peaked distribution of waiting times), holding the expected duration constant, to assess the performance of alternative gamma-distributed models. Model fits were compared using the widely applicable information criterion (WAIC) [26, 27] and leave-one-out information criterion (LOOIC) [28].

2.3 Does the distributional assumption of the duration of aTB affect projected TB trajectories?

To assess whether the distribution of aTB duration affects projected TB trends, we extended the natural history framework to a population-level transmission model. Two models were calibrated to match India's TB epidemic in 2022: one assuming constant progression (i.e., an exponential model (k = 1)) and the other using the gamma-distributed structure (k > 1). We calibrated each model to WHO estimated TB incidence and mortality using a Bayesian framework [12, 29, 30].

We then projected TB incidence under the status quo from 2024 to 2033 and compared the two models' predictions to examine differences in the trajectory of TB burden over time.

2.4 Does it matter for the estimated health impact of ACF interventions?

To assess whether assumptions about the distribution of aTB disease duration affect the estimated health impact of ACF, we conducted counterfactual intervention simulations under alternative natural history models. Here, ACF is conceptualized as an intervention that does not rely on symptom-based pre-screening, thereby allowing detection of aTB. We assume that individuals in the aTB state are not routinely identified through passive symptom-based healthcare seeking and, therefore, remain eligible for detection through ACF. ACF was implemented as a temporary increase during 2024-2026 in two state transitions: movement from aTB to minimal disease (reflecting earlier detection and entry into the interim recovery pathway) and from minimal disease to recovery (reflecting treatment initiation and completion). In the model, this was represented as a proportional increase in both transition rates over the intervention period. Again, we compared an exponential aTB duration model with the best fitting gamma-distributed model. For each model, an ACF intervention lasting three years was simulated and epidemic trajectories were compared to evaluate the sensitivity of the projected ACF impact to our distributional assumptions for the duration of aTB.

4 Discussion

Recent empirical and modeling work has emphasized the clinical and epidemiological importance of aTB. In this work, we investigated whether more complex models of progression from aTB than have typically been adopted are appropriate, and whether these models produce meaningful differences in disease projections and the expected impact of interventions. We evaluated assumptions governing the distribution of the duration of aTB by fitting alternative (i.e., exponential and gamma-distributed) model structures to individual-level data from the NTI Bangalore cohort.

We then constructed and fit each transmission model to a common population-level baseline using national TB incidence estimates from WHO, enabling a comparison of how these alternative subclinical progression assumptions influence long-term projections and intervention effects.

We found that the gamma-distributed and exponential formulations provided broadly comparable fits to the observed progression data. In projections without ACF, the two model structures produced broadly similar incidence trajectories, although gamma-distributed model consistently projected modestly higher incidence than the exponential model. When projecting the impact of ACF interventions, differences between model structures were substantially more pronounced.

Relative to their respective baselines, the gamma-distributed model predicted a larger percentage reduction in incidence than the exponential model, reflecting the sensitivity of case finding interventions to the distribution of waiting times in the aTB state.

In state-transition models for infectious diseases, assumptions about the distribution of time spent in each disease state are often made for mathematical convenience rather than empirical realism [34]. These models typically adopt a single compartment for each relevant natural history state, from which there is a constant hazard of transition and therefore exponentially-distributed waiting times. Others have demonstrated that even when expected durations of time spent in a state are held constant, the shape of the waiting-time distribution can substantially alter epidemic dynamics [35]. Non-exponential formulations, such as gamma-distributed or more general phasetype representations, introduce time-varying hazards and reduce the probability of early transitions.

These different assumptions lead to different patterns of state occupancy, which have been shown to influence persistence and oscillatory behavior in epidemic systems [36], as well as the sensitivity of model outputs to parameter perturbations [37].

These considerations may be particularly important for TB, where long and heterogeneous disease courses may challenge the validity of constant-hazard assumptions [4]. Previous work has demonstrated that replacing commonly used exponential assumptions about demographic processes such as survivorship, with more realistic distributions can alter TB transmission dynamics and intervention effects [38]. Our findings are consistent with this broader insight, suggesting that assumptions about subclinical progression distributions may influence estimates of ACF intervention impact, which may have important implications for the cost-effectiveness of such strategies [39]. More broadly, these results highlight the importance of treating distributional assumptions as a source of uncertainty in state-transition models, especially when evaluating interventions that depend on the distribution of waiting times in disease states.

A central finding of this study is that relatively modest changes in model structure can lead to substantial differences in epidemic dynamics and projected intervention impacts over time.

Although the two formulations share similar compartmental representations and identical mean asymptomatic disease durations, they differ fundamentally in how progression risk is distributed over time.

In the absence of intervention, baseline projections of incidence remain similar over shortl time horizons, but systematic differences emerge over longer periods. In the Indian context, the exponential model projects lower longer-term TB incidence relative to models with a more realistic temporal structure of aTB progression. While these differences are relatively small compared with the overall similarity in model fit and baseline projections, they illustrate how alternative assumptions regarding aTB progression can influence long-term epidemic forecasts.

While there are modest effects on long-term epidemic behavior, the most notable implication of the difference in the distribution of aTB waiting times is on the estimated impact of ACF interventions. Because an ACF intervention can allow for identification and and treatment individuals with aTB, its estimated effectiveness depends in part on how long individuals remain in the aTB state. Exponential models that suggest substantial rapid progression from aTB inherently limit the opportunity for earlier detection, while more complex models which concentrate the distribution of waiting times closer to the mean may provide more opportunity for detection of individuals in the 10 aTB state.

These structural differences also have implications for cost-effectiveness analyses. Economic evaluations of detection-based interventions typically depend on projected cases averted and the scale of screening required. If simpler models systematically underestimate the epidemiological impact of ACF, they will likewise underestimate its cost-effectiveness, even when intervention costs are held constant. While we do not conduct a formal economic evaluation here, these findings suggest that structural assumptions about disease progression can influence not only epidemiological conclusions, but also policy-relevant economic assessments.
