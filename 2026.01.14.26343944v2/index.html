How Power Analysis Check works

This module uses regular expressions to identify sentences that contain a statistical power analysis. If specified by the user, it also uses a large language model (LLM) to extract information reported in power analyses, including the statistical test, sample size, alpha level, desired level of power, and magnitude and type of effect size.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. With the use of an LLM, it checks if the power analysis is reported with all required information.

The regular expressions can miss power analyses, or fail to classify them correctly. The type of power analysis is often difficult to classify, which can easily be solved by explicitly specifying the type of power analysis as ‘a-priori’, ‘sensitivity’, or ‘post-hoc’. Note that ‘post-hoc’ or ‘observed’ power is rarely useful. The LLM can fail to identify information in the paper, and will not have access to information in paragraphs in the paper other than those that contain the word ‘power’. This package was validated by the Metacheck team on articles in Psychological Science.

How Preregistration Check works

Retrieve information from preregistrations in a standardised way, and make them easier to check.

The Preregistration Check module identifies preregistrations on the OSF and AsPredicted based on links in the manuscript, retrieves the preregistration text, and organizes the information into a template. The module retrieves text from the OSF with its API, and from AsPredicted with ResearchBox’s API when a ResearchBox key is set (see rbox_token()), or else from the preregistration’s web page. How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.), reported as exactly zero (e.g., p = .000), or impossible (below 0 or above 1, e.g., p = -.22).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold”, “legend” or “named”).

A p-value with the name of a correction or a test after the p (“pFWE < .05”, “padj < 0.05”, “p Wilcoxon = .02”) is flagged only when a test statistic comes before it in its clause (“t(37) = 7.17, p FWE < .05”). Without one it is mostly the rule that decided what was significant (“genes with padj < 0.05 were selected”); such a p-value is “named” in not_a_test. Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

A p-value below 0 or above 1 is impossible; it is listed apart and not also as imprecise. Often the statistic before it, or its minus sign, was copied into it (“t(134) = -2.32, p = -.13”, “Z = 3.091, P = 3.091”). A value above 1 is listed only after a test statistic in its clause: without one, a “P” above 1 was nearly always another quantity (a proportion, pH, a group’s mean, a model parameter). A number in scientific notation whose power of ten was lost when the PDF was read (“p = 2.4 x 10 -9” read as 2.4) is not listed. A “p” that is the subscript of another symbol (“r p = .64”, “²p = .02” for partial eta squared, “Δp = .33”), or a quantity with a unit, a logarithm or a ratio (“P = 2.9 µm”, “-log10 P = 7.5”, “Ca/P = 1.67”), is not read as a p-value at all (see extract_p_values()). Each p-value has its own row, also when the same one is written twice in a sentence.

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

The module also checks whether the repository pins the R/package versions the analysis actually depended on: an renv.lock file (parsed for the R version and every locked package + its version/source), a sessionInfo()/sessioninfo::session_info() text dump (matched by filename — sessionInfo.txt/session_info.txt and similar, or embedded in a README), or a groundhog::groundhog.library()/checkpoint::checkpoint() date-pin call in the code (a bare library(groundhog)/library(checkpoint) does not count — the pinning call itself must be present). When none of these is found, the report flags it as a reproducibility gap: package versions may drift between when the analysis was run and any later reproduction attempt.

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Column extraction requires files to be readable from disk. Files fetched by repo_check from OSF/GitHub/etc. without a local copy (file_location is NA) are classified but not column-extracted; pass local_path to point at a downloaded copy of the repository.

For a paper whose repository is on Dryad, this means column extraction never happens unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (dataset listing and metadata do not need one). Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

Every downloaded text file the authors wrote (code, settings, survey definitions such as Qualtrics .qsf files, documentation, outputs) is searched for keys: API keys, access tokens and private keys, which let anyone who downloads the file use a paid service at the authors’ cost. Of a tabular data file only the column names and first 3 rows of the table as read are searched: its values come from participants, but a key the authors set for a whole survey (as embedded data in a Qualtrics survey flow) is exported in every response. The search uses the rules of the secret scanner betterleaks (https://github.com/betterleaks/betterleaks, MIT licence) of high and medium confidence. A key found turns the traffic light red; the report and the keys table give its file, line and type, and only its beginning. Other files over 25 MB and binary files are not searched. A key is never tested with its provider. Every module’s result has any whole key replaced by “keyremoved” (see module_run()).

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability).

run_results$checked says what the run of each script shows about the code, in five groups, so that a script that does not reproduce is kept apart from one the check could not test: ran (it ran to the end); code_error (it did not reproduce: it stopped with an error of the code or the deposit, could not be read, or needs a file the deposit does not hold); dependency (a package or program was not available: a package that could not be installed or was not loaded, a program outside R and Python, a system library, or R crashing in a package’s compiled code); time (it did not finish within the time limit for one script, or was not started because the time for all scripts had run out); and not_checkable (it could not be checked automatically: it needs a person, the internet, a key or another setting of the authors’ computer, one platform such as Google Colab, Windows or OpenSAFELY, more memory than the run allows, a file that was not downloaded, a screen, or a program that runs it, or it is a file of a package of the code that Python runs only as a module of that package). It is NA for files run inside another script, files that are not an analysis, files not read, and a Docker failure. summary_table counts each group (repro_ran_n, repro_code_error_n, repro_dependency_n, repro_time_n, repro_not_checkable_n), and the report’s first sentence gives them. The traffic light reflects the static readiness signals by default; a script in code_error that stopped with an error makes it red, as a script that crashes on its own analysis is a genuine reproduction failure, and a script in one of the other three groups keeps it from being green. Calls that need a screen, which the run does not have (dev.print(), dev.copy2pdf(), dev.copy2eps(), savePlot(), windows(), win.graph(), x11(), quartz(), View()), are replaced before the run by calls that need none, which modifications records as screen_call_replaced. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Abstract

Objective: Because hearing difficulties contribute significantly to years lived with disability and global economic burdens, finding ways to support hearing health is crucial. A key challenge is understanding how to improve speech perception in the presence of background noise, which is a significant complaint among listeners with and without hearing loss. Understanding speech in noise requires more than simply hearing the conversation but rather also demands cognitive processes such as memory for what was said and selective attention to the target speech instead of competing noise. Because physical activity has been shown to benefit cognitive health more broadly, we surmised it may have a positive relationship with hearing health. We aimed to investigate the association between time spent in moderate-to-vigorous physical activity and selfreported hearing problems in a comprehensive population dataset.

Design: This was a prospective cohort study where participants (N= 79,286 ; 54.57% female) in the UK Biobank dataset wore an accelerometer for 7 days and completed questionnaires about self-reported hearing problems. After dividing participants into two groups based on their answers to hearing health questions, we ran a logistic regression to determine if time spent in moderate-to-vigorous physical activity decreases the likelihood of reporting hearing difficulties generally, or specifically in the presence of background noise. In addition, we investigated whether spending at least 150 minutes in moderate-to-vigorous physical activity, corresponding to the World Health Organization physical activity guidelines, was associated with hearing outcomes.

Introduction

Hearing loss has often been characterized as an "invisible disability" leading to miscommunications, exclusion, and barriers to treatment (Aldè et al., 2025). As the world's population ages, by 2050 close to 2.5 billion people will experience some form of hearing loss (World Health Organization, 2021). In addition to adversely affecting social interactions (Shukla et al., 2020), cognitive performance (Lin et al., 2011; Loughrey et al., 2018; Powell et al., 2022; Taljaard et al., 2016) and mental health (Golub et al., 2020; McClannahan et al., 2025), unaddressed hearing issues cost around $1 trillion globally each year (Ghebreyesus, 2024). Thus, there is a critical need to support hearing health throughout the lifespan and investigate how it affects healthy aging. In the current study we focus on two complementary aspects of hearing health. The first is overall hearing difficulties, primarily reflecting the integrity of the peripheral auditory system highlighting cochlear integrity. The second is the ability to understand speech amid background noise, which also relies on the central auditory system and requires higherlevel cognitive resources beyond just detecting sound.

Outside the realm of hearing health, there is a long history of research highlighting the benefits of physical activity on multiple facets of healthy aging (Blair & Morris, 2009). Being active reduces the risk of several chronic diseases such as cardiovascular disease and obesity and increases longevity (Miller et al., 2016). More physical activity also results in better overall wellbeing and mental health (Kim et al., 2012), moderates stress systems (Anderson et al., 2013; De Nys et al., 2022; Duclos & Tabarin, 2016; Fragala et al., 2011), is correlated with improved sleep quality (De Nys et al., 2022; Kredlow et al., 2015; Vanderlinden et al., 2020; Wang & Boros, 2021), and is positively associated with overall general health factors (Dhuli et al., 2022).

Although the mechanisms underlying these beneficial relationships are not fully understood, they likely encompass changes at molecular, cellular, and systems levels such as protecting musculoskeletal function during aging (Neufer et al., 2015). These same constellation of effects may extend to hearing health.

There is some evidence regarding the association between physical activity, specifically moderate-to-vigorous physical activity (MVPA), and hearing difficulties. Older adults with hearing loss are less physically active (Assi et al., 2024) and decrease physical activity levels faster than those without hearing loss (Goodwin et al., 2023). Specifically, older adults with hearing loss spend less time in MVPA than those with normal hearing (Kuo et al., 2021). Other researchers have investigated this relationship in the opposite direction such that more time in exercise leads to reduced risk of hearing loss and improved pure-tone thresholds (Li et al., 2025).

Some have found that being more active or spending more time in MVPA is associated with better pure-tone audiometry thresholds (Haas et al., 2016; Kolkhorst et al., 1998; Loprinzi et al., 2014) and lower odds of having a hearing impairment (Gispen et al., 2014).

In a more causal manner, longitudinal studies have shown that being more physically active may be a potential protective factor for mitigating the risk of developing future hearing loss where higher levels of physical activity are shown to lower incidences of developing hearing loss as one ages (Curhan et al., 2013; Kawakami et al., 2022). Those who meet physical activity guidelines, and therefore spend more time in MVPA, report better hearing thresholds than those who do not (Martinez-Amezcua et al., 2023). While further longitudinal work is needed to confirm the directionality of this relationship, the current study expands upon these findings.

A second facet of hearing health addressed in this study is the ability to understand speech in noisy environments. To understand speech in noise, a listener must be able to hear the words spoken, hold in memory what was said, and process the meaning behind words in the context of sentences (Pichora Fuller et al., 1995). Collectively, these actions tap into cognitive processes such as working memory and selective attention, often called executive functions (Miyake et al., 2000). The additional challenge associated with understanding speech in noise suggests that understanding speech in noise increases cognitive load which forces listeners to rely on resources outside the peripheral auditory network (Mattys et al., 2025; Peelle, 2018; Wingfield et al., 2005). Consistent with this hypothesis, understanding acoustically challenging speech consistently requires an upregulation of executive functions and increased activity in the frontal cortex (Davis & Johnsrude, 2003a; Gosselin & Gagné, 2011; Sherafati et al., 2022; Wild et al., 2012; Wong et al., 2009). If understanding speech in noise relies on executive functions, practices that have been validated to boost executive function and the associated brain networks that support them might improve listeners' understanding of speech in noise.

To our knowledge there are no studies directly examining the relationship between MVPA and speech-in-noise understanding. However, there is a rich history of research elucidating the benefits of physical activity on executive function. Compared to sedentary older adults, meeting MVPA guidelines presented by the World Health Organization of at least 150 minutes per week (World Health Organization, 2026) is associated with improved performance on executive function tasks (O'Brien et al., 2021). There is also moderate evidence of an association between MVPA and improvements in cognition, neuropsychological assessments, executive function, processing speed, and memory (Erickson et al., 2019; Van Praag, 2009).

Additionally, greater amounts of physical activity are associated with increased neural efficiency during cognitively challenging tasks (Erickson et al., 2015) and following exercise there is increased activity in frontal and parietal regions (Won et al., 2019). Beyond proximal effects there may also be protective effects present in older age related to a lifetime of physical activity habits such as prevention or delayed loss of cognitive decline and neurodegenerative diseases (Dik et al., 2003; Van Praag, 2009).

In summary, while the most common complaint from those who are treated for hearing loss comes from difficulty understanding speech in background noise (Billings et al., 2024; Kochkin, 2010), no comprehensive study has directly explored its association with MVPA.

Given that speech-in-noise understanding relies on these same processes that are positively correlated with physical activity, we aimed to examine whether time spent in MVPA would be associated with speech-in-noise problems. The current study also aims to add to the literature investigating the relationship between hearing problems and MVPA using objective accelerometer data in a population-based cohort. Understanding these gaps is critical to managing the myriad burdens that come with hearing impairments in the general population.

Thus, we evaluated whether spending more time in MVPA was associated with lower odds of reporting hearing difficulties and speech-in-noise problems in a sample of 79,286 participants from the UK Biobank.

Materials and Methods

Access to UK Biobank data is restricted to those with an approved project. Analysis code for the current project is available at https://osf.io/djn5m/files.

Design and Participants

The UK Biobank is on ongoing prospective cohort study of approximately half a million volunteer participants across the United Kingdom. Baseline recruitment occurred from 2006-2010 when participants (n=503,317) were between 40 and 69 years old (Sudlow et al., 2015).

Participants were tested at 22 different assessment centers and covered diverse socioeconomic and ethnic backgrounds. Initial recruitment occurred through the mail from the National Health Service (NHS) central registers. Detailed information was collected at baseline assessment including lifestyle measures, physical measures, and biological specimens. Selection criteria for the current study are shown in Figure 1. Of the total participants, 502,128 had complete baseline data and 469,592 had complete hearing data. Between February 2013 and December 2015, a subset of participants (n=103,648) was randomly invited and subsequently wore an accelerometer for 7 days to objectively measure physical activity. Of the people with valid hearing data, 79,286 also had valid accelerometer and covariate data and comprised our final sample. Data were obtained through a UK Biobank application (ID 140089). Participants provided signed informed consent and the research was approved by the North West Multi-Centre Research Ethics Committee (Sudlow et al., 2015).

Hearing and Speech-in-Noise Outcomes

Hearing outcome came from the touchscreen questionnaire question, "Do you have any difficulty with your hearing?" (Data-Field 2247). The speech-in-noise outcome came from the touchscreen questionnaire question, "Do you find it difficult to follow a conversation if there is background noise (such as TV, radio, children playing?" (Data-Field 2257). Only "Yes" or "No" answers to these questions were included in the analyses. Other options included "I am completely deaf", "Do not know", and "Prefer not to answer." Participants were also excluded if they answered "Yes" to a question at baseline assessment but answered "No" in follow-up sessions.

Physical Activity

Between February 2013 and December 2015, participants who had provided a valid email address were randomly selected and sent an email invitation to wear an accelerometer (Axivity AX3 wrist-worn triaxial accelerometer) for 7 days (Doherty et al., 2017).

Participants were told to wear the accelerometer continuously on their dominant wrist while conducting their normal activities. Processed physical activity data is provided by the UK Biobank (Walmsley et al., 2022), which uses a machine learning model to estimate time in MVPA (Data-Field 40049). As per previous work with this dataset, we excluded participants if they did not have at least 3 days of data and data in each 1-hour period of the 24-hour cycle (Data-Field 90015).

Covariates

We chose covariates based on current knowledge of possible confounders and included age at baseline (Data-Field 21022), sex (Data-Field 31), education level (Data-Field 6138), income (Data-Field 738), ethnicity (Data-Field 21000), alcohol use (Data-Field 20117), smoking (Data-Field 20116), diabetes (Data-Field 2443), vascular/heart problems (Data-Field 6150), and body mass index (BMI) (Data-Field 21001). Education was divided into higher and lower education based on if the participant had at least a college/university degree or another professional qualification. Income was dichotomized as high or low (< £51,999 and > £52,000). As the vast majority of the UK Biobank sample is White, ethnicity was dichotomized as White and Non-White. Alcohol use and smoking were categorized as never, current, previous use, or prefer not to answer. Diabetes answers included, yes, no, don't know, and prefer not to answer.

Vascular/heart problems were dichotomized as yes or no (if they had a heart attack, angina, stroke, or high blood pressure). We also created a time difference covariate to account for the time between the baseline visit and accelerometer wear period.

Statistical Analyses

To characterize baseline measurements, we summarize continuous variables as means with standard deviations (SDs), and categorical variables by count (percentages). We used multivariable logistic regressions to examine the association between MVPA and hearing and speech-in-noise outcomes. To make the results more interpretable, we also scaled accelerometerbased MVPA data by 100 so that a 1-unit increase was equivalent to a 1% increase in time spent in MVPA. All models controlled for age at baseline, sex, education level, income, ethnicity, alcohol use, smoking, diabetes, vascular/heart problems, and BMI. Age was mean-centered.

Model 1 examined the odds of reporting a hearing problem given the percentage of time participants spent in MVPA accounting for the covariates. Model 2 was similar except the outcome variable was reported speech-in-noise problems instead of hearing problems.

In Models 3 and 4, we wanted to investigate whether meeting World Health Organization guidelines of 150 minutes per week in MVPA affected the odds of reporting a hearing or speechin-noise problem, respectively, while accounting for covariates. All models passed assumption checks except for linearity of logit odds assumption. Models with hearing as the outcome variable (Models 1 and 3) had BMI as a predictor violating this assumption and models with a speech-in-noise problem as an outcome variable (Models 2 and 4) had BMI and age violating this assumption. We modeled these predictors using restricted cubic splines (df = 4) to include nonlinear relationships, but the results did not change. For simplicity, we report the results for the models without restricted cubic splines but include the spline models in Supplemental Material (Supplemental Tables 1 2 3 4). All statistical analyses were performed using RStudio 4.4.0 (R Core Team, 2024) on UK Biobank's DNAnexus platform. Values of p <.05 were considered significant. Data analysis was performed from November 2023 to September 2025.

Results

Participant Baseline Characteristics

The mean (SD) age of participants was 55.95 (7.86). Out of the total 79,286 participants, 54.57% of the participants were female, 96.88% were White, 24.26% reported having hearing problems, and 34.50% reported having speech-in-noise problems. Compared to those that said they did not have hearing problems (M = 2.94%, SD = 2.43%), those who reported hearing problems spent less time in MVPA (M = 2.87%, SD = 2.45%) by 7.05 minutes per week (296.35 minutes per week versus 289.30 minutes). The difference was found to be statistically significant, t(32,194) = 2.41, p < .01 but the effect size was negligible (d = 0.028). There was also a significant difference in time spent in MVPA for those who reported a speech-in-noise problem (M=2.90%, SD=2.45%) versus those who did not (M=2.93%, SD=2.43%), t(55,254) = 1.76, p = .040 (292.32 minutes versus 295.34 minutes) but the effect size was negligible (d = 0.013).

Associations of Hearing and Speech-in-Noise Outcomes with Time Spent in MVPA

After adjusting for covariates in the Model 1, spending more time in MVPA was significantly associated with lower odds of reporting a hearing problem (OR=0.990, 95% CI [0.983, 0.997], p=0.005) as shown in Table 1. This means that for every 14.4 minutes more a person spends in MVPA per day (or 100.80 minutes per week), the odds of reporting a hearing problem decrease by 1.00%. Increasing time spent in MVPA to 72 minutes a day (or 504 minutes per week) decreases the odds of reporting a hearing problem by 4.90%. In Model 2, after adjusting for these covariates, spending more time in MVPA was also significantly associated with lower odds of reporting a speech-in-noise problem (OR= 0.991, 95% CI [0.985, 0.998], p= 0.007) as shown in Table 1. This means that for every 14.4 minutes more a person spends in MVPA per day (or 100.80 minutes per week), the odds of reporting a hearing problem decrease by 0.90%.

Discussion

In a sample of 79,286 participants from UK Biobank, we investigated the association between time spent in MVPA and self-reported problems with hearing and understanding speech in noise. We found that spending more time in MVPA was associated with significantly lower odds of both reporting a hearing problem and reporting a speech-in-noise problem. We also found that meeting the World Health Organization guidelines of 150 minutes per week of MVPA was associated with significantly lower odds of both reporting a hearing problem and reporting a speech-in-noise problem. Below we discuss the implications of these findings and contextualize them within the broader research and clinical landscape.

While most of the work in this topic has been done investigating the relationship between hearing and physical activity, struggling to understand speech in noise remains the most common issue reported by those being treated for hearing loss (Billings et al., 2024; Kochkin, 2010). Yet, there has been insufficient prior work examining how physical activity is associated with speechin-noise perception (Martinez-Amezcua et al., 2023). Given that speech-in-noise has been shown to rely on executive functions and physical activity have been proven to improve these functions, we aimed to investigate whether speech-in-noise problems were associated with physical activity.

While cognition was not directly evaluated in the current study, previous research highlighting how speech-in-noise relies on executive functions and physical activity improves these same processes strengthens our findings. Long-term exercise improves connectivity and neural efficiency in the prefrontal cortex and leads to improved executive function driven by an improvement in cardiovascular fitness (Cabral et al., 2019; Voelcker-Rehage et al., 2011).

Engaging in physical activity throughout the lifespan has positive effects on maintaining cognitive health and improving brain function, with the largest effects seen in executive function (Erickson et al., 2015). Similarly, prior research also highlights the role of the frontal lobes when understanding acoustically challenging speech (Davis & Johnsrude, 2003b) as it requires increased listening effort, attention, and cognitive processes (Gosselin & Gagné, 2011; Peelle, 2018; Vaden et al., 2013; Wong et al., 2009). Specifically, performance on executive function tasks often correlates with performance on speech-in-noise tasks (Can et al., 2026; Dryden et al., 2017; Ward et al., 2016). Given that physical activity has moderate positive effects on executive functions (Singh et al., 2025) and speech-in-noise tasks rely on executive resources, we speculated that physical activity may help support speech-in-noise comprehension.

Our findings also corroborate previous research suggesting that there is a relationship between the odds of reporting a hearing problem and time spent being physically active such that those who are less physically active are more likely to report hearing problems (Gispen et al., 2014; Li et al., 2025; Martinez-Amezcua et al., 2023). Moderate hearing loss is associated with greater odds of spending less time being active (Choi et al., 2016; Gispen et al., 2014) and those who engage in MVPA compared to those who do not are at lower risk for developing hearing issues in later years (Kawakami et al., 2022; Kuo et al., 2021). Yet, it is also important to acknowledge that these are observational findings and others have found the opposite directionality of the relationship where hearing loss results in less physical activity (Martinez-Amezcua et al., 2021). Some researchers have found that those with moderate or greater hearing loss were more likely to be insufficiently active (Assi et al., 2024). While more work is needed to tease out the causal effects of the relationship, the current study expands on these findings using a larger population-based sample and objective accelerometer data illustrating that more time spent in MVPA is associated with an outcome of lower odds of reporting a hearing problem.

While the effect sizes for our models were modest, they represent an important step in identifying a meaningful relationship between hearing outcomes and accelerometer-derived MVPA in a large population-based cohort. Most novelly, they are the first to establish an association between time spent in MVPA and understanding speech in noise. This also aligns with previous work with physical activity's effect on cognition. Physical activity has small but meaningful selective effects on cognition, with the most significant benefits on executive processes (Etnier et al., 1997). We would expect that our effect sizes would be larger given objective measures of hearing as other researchers have only seen a relationship between cognition and speech-in-noise performance for objective not self-report measures (Hoff et al., 2023). The fact that a relationship was found with subjective hearing measures is a promising and meaningful start. Our current findings open the door to future research investigating the association between speech-in-noise outcomes and physical activity with more comprehensive assessments of hearing as well as targeted interventions.

Beginning to understand how physical activity relates to speech-in-noise comprehension in the general population is an important step towards mitigating the social, cognitive, mental, and economic burdens that stem from hearing health issues. Our study was the first to directly investigate the relationship between spending time in physical activity and reporting speech-innoise problems in a comprehensive population dataset. We found that spending more time in MVPA was significantly associated with lower odds of reporting a speech-in-noise and hearing problem which novelly advances our understanding of the association of physical activity with overall hearing health.

Implications

The World Health Organization embraces the idea that how we hear in the future depends highly on the practices we currently take to protect our ears (Ghebreyesus, 2024; World Health Organization, 2021) However, the current focus of audiological care is on finding ways to improve audibility by amplifying sound or bypassing cochlear damage with innovative technology. Hearing aids, cochlear implants, and other auditory rehabilitation devices address structural and functional decline of auditory processes but cannot fix all the hardships that come with hearing loss. We show that a modifiable lifestyle behavior, physical activity, is associated with whether someone reports hearing issues. Not only has our study confirmed previous research on physical activity being associated with better hearing in a large population-based cohort, but it also uniquely highlights its association with speech-in-noise understanding. As there is currently a lack of widespread interventions that directly target speech-in-noise ability, our findings can lead to improving a common, yet undertreated issue.

It is important to note that despite the evidence for the importance of physical activity, 31% of adults worldwide-and some 53.1% of Americans (Elgaddal et al., 2022)-fail to meet the recommended guidelines for aerobic activity (World Health Organization, 2024). Filling this gap by promoting physical activity's benefits may not just help the obvious such as cardiovascular health or metabolic health, but it may also simultaneously improve hearing health.

Limitations

While the findings of this study have important implications for hearing health, there are a few limitations that must be addressed. First, this work is only based on associations and observations from a single week instance of MVPA as well as answers to just 2 simple questions. Further research should investigate longer periods of MVPA and more objective measures of both hearing outcomes. These findings would also be aided by longitudinal or interventional studies examining how increases in MVPA may be linked to hearing health. Second, there was a variable period of time between the baseline visits and accelerometer data. We controlled for this variability by adding a covariate for the time between visits, but further work should collect these variables within a closer timeframe. It is also important to acknowledge that although we found that spending more time in MVPA was associated with lower odds of reporting hearing issues, those who have better hearing may just be more active or social in general. Future studies should disentangle the directionality of this relationship.

There are other factors that may relate to both physical activity and hearing health that we did not control for in the statistical analysis, providing opportunities for future studies that can more clearly separate out the influence of various lifestyle factors and variables like cognition.

Ideally, this could be done with more granular assessments of hearing health, which we anticipate would be more sensitive than the self-report measures we used here.

Another issue worth considering in future research relates to the language background of the participants. Although all participants in the current data are from the UK, individual language backgrounds (for example, English as a first or second language) may influence daily communication function, and is important to consider when interpreting the results. However, the degree to which this issue would impact self-report measures, as used here, is unclear.

A final caveat relates to reconciling accelerometer data with World Health Organization guidelines as using accelerometer data is not necessarily compatible with current physical activity guidelines. These recommendations were designed for activity on top of "normal" activity. Using accelerometry may lead people to believe they are exceeding guidelines as accelerometers detect all activities, including daily movement that was already factored in when creating the World Health Organizations guidelines (Thompson et al., 2016). Nonetheless, our study shows that spending at least 150 minutes per week in MVPA is associated with better hearing health.

Conclusion

Overall, this study found that more time spent in MVPA is significantly associated with lower odds of reporting a hearing problem and reporting trouble with speech in noise. It also found that spending at least 150 minutes per week in MVPA was associated with lower odds of reporting both a hearing and speech-in-noise problem. Together, these findings suggest that MVPA may be beneficial to understanding speech in noise and hearing.
