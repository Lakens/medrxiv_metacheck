How Power Analysis Check works

This module uses regular expressions to identify sentences that contain a statistical power analysis. If specified by the user, it also uses a large language model (LLM) to extract information reported in power analyses, including the statistical test, sample size, alpha level, desired level of power, and magnitude and type of effect size.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. With the use of an LLM, it checks if the power analysis is reported with all required information.

The regular expressions can miss power analyses, or fail to classify them correctly. How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.), reported as exactly zero (e.g., p = .000), or impossible (below 0 or above 1, e.g., p = -.22).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold”, “legend” or “named”).

A p-value with the name of a correction or a test after the p (“pFWE < .05”, “padj < 0.05”, “p Wilcoxon = .02”) is flagged only when a test statistic comes before it in its clause (“t(37) = 7.17, p FWE < .05”). Without one it is mostly the rule that decided what was significant (“genes with padj < 0.05 were selected”); such a p-value is “named” in not_a_test. Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

A p-value below 0 or above 1 is impossible; it is listed apart and not also as imprecise. Often the statistic before it, or its minus sign, was copied into it (“t(134) = -2.32, p = -.13”, “Z = 3.091, P = 3.091”). A value above 1 is listed only after a test statistic in its clause: without one, a “P” above 1 was nearly always another quantity (a proportion, pH, a group’s mean, a model parameter). A number in scientific notation whose power of ten was lost when the PDF was read (“p = 2.4 x 10 -9” read as 2.4) is not listed. A “p” that is the subscript of another symbol (“r p = .64”, “²p = .02” for partial eta squared, “Δp = .33”), or a quantity with a unit, a logarithm or a ratio (“P = 2.9 µm”, “-log10 P = 7.5”, “Ca/P = 1.67”), is not read as a p-value at all (see extract_p_values()). Each p-value has its own row, also when the same one is written twice in a sentence.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

In the future, the Metacheck team aims to incorporate a machine learning classifier to only return sentences likely to contain misinterpretations. If you want to help to improve the module, reach out to the Metacheck development team.

A p-value in a table note (“† p < .10, * p < .05”) or a figure legend (“dashed lines indicate non-significant paths (p > .05)”) is left out, as in stat_p_exact; the column not_a_test says why. A p-value next to words that state a threshold is kept, because such sentences often report a result against that level (“not significant at the conventional threshold (p = .054)”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables.

How Codebook Check works

This module checks whether the data columns in a repository are documented in a codebook or README. It locates codebook/readme files, extracts the variable definitions they contain, matches those definitions against the data columns extracted by data_check, and reports documentation coverage: how many data columns are documented, and which documented variables are never used.

The Codebook Check module consumes the columns and file classification produced by data_check (and, transitively, repo_check). Files classified as codebook or readme are parsed with parse_codebook(), which reads structured tables (CSV/TSV/Excel with a variable-name column and a label column), embedded labels in haven files (SPSS/Stata/SAS), and plain text from rich-text formats (docx/pdf/rtf/odt). Embedded haven labels from data files are also harvested directly.

The module defaults to rules-only when llm_use(FALSE). When llm_use(TRUE), three optional LLM tiers run: parsing unstructured codebook text that the rules could not handle, fuzzy-matching still-unlabelled columns to still-unmatched codebook variables, and merging conflicting label definitions into a single canonical label.

How Repository Check works

This module retrieves information from repositories.

The Repository Check module lists files on the OSF, GitHub, ResearchBox, DSpace (PsychArchives and other legacy- and DSpace 7-based installations), Zenodo, Dataverse, Figshare, Dryad, ReShare, 4TU.ResearchData, Mendeley Data, DataONE (Arctic Data Center, KNB, and other member nodes), and LDbase based on links in the manuscript.

A link to a file-sharing service (Google Drive, Dropbox, OneDrive, Box, WeTransfer, MEGA, iCloud Drive, Baidu Netdisk, SURFdrive; see [file_share_links()]) gets a warning and makes the light yellow: such services are not repositories, as files can be changed or deleted at any time, get no DOI, and the link stops working when the account is closed. The report advises a stable repository such as Zenodo instead. Their files are not read, and summary_table$file_share_n counts the links.

Deposits in archives for sequence and expression data (GEO, the INSDC archives BioProject, SRA, ENA and DDBJ, and ArrayExpress; see [seq_archive_links()]), mostly named by accession number, are read for whose deposit they are. The authors’ own are listed with what they hold ([seq_archive_size()]) and are not downloaded or checked as data and code; summary_table$archive_own_n counts them.

R packages on CRAN ([cran_links()], [cran_info()]) are the paper’s own when a paper author is a package author and the paper presents the package; the paper’s own are listed with their version and not checked (summary_table$cran_own_n). A Handle link (hdl.handle.net/...) that leads to a repository read here is checked as a link to that repository ([handle_links()]).

Listing a repository’s files never requires an API key, but some hosts answer faster or more completely with one: OSF allows 100 requests/hour unauthenticated versus 10,000/day with a token (see [osf_pat()]), and Dryad enforces a strict per-IP daily quota on repeated listing (see cache below). Dryad is a special case beyond rate limits: listing a Dryad dataset’s files works without a key, but actually downloading file CONTENTS from Dryad fails with HTTP 401 unless a key is set, even for a fully public dataset (see [dryad_pat()] or [dryad_auth()]). Since this module only lists files and never downloads their contents itself, that limitation applies to data_check and code_check (which do download content), not here – see their own documentation.

When a linked OSF page is a registration, its registered_from project (the one it was registered from, which the manuscript itself may never link directly) is also checked: if that project is public its files are listed under its own URL, and if it is closed or otherwise inaccessible the report flags it explicitly, since some registrations only describe their content rather than mirroring it.

Whose deposit is each link? The ownership table gives, for every repository linked in the text and (with references = TRUE) every deposit cited in the reference list, one of six labels: own_this (made by the authors for this paper), own_earlier_data or own_earlier_code (the authors’ own, from earlier work), others_data or others_code (made by other people, reused here), or not_data (a publication such as a preprint, not a deposit), with ownership_group (“own”, “others”, “not_data”) and the reason. It is decided without a language model, from the sentence or reference that cites the link, the paper’s authors (names, ORCID iDs, affiliations), and what the deposit’s own record and files say (who made it, what it names, when, whether it is a software package; for an OSF project cited only in the reference list, its record alone). On a round of labelled links the rules had not been written from, the three groups were right for 98% of links in the main text (93 of 95) and 90% in reference lists (74 of 82); the labels were made by Claude agents from each link’s evidence, and disputed ones checked against the deposits. Telling this paper’s own deposit from the authors’ earlier one is less certain.

Only the deposits that are this paper’s own are checked. A deposit linked in the text that holds other people’s work (others_data, others_code) or the authors’ earlier work (own_earlier_data, own_earlier_code) is listed in the report, with the reason, but its files are left out of table and kept in table_not_checked: they count toward nothing here (files that do not belong in a repository, naming, READMEs, studies, the traffic light), and code_check, data_check and reproducibility_check, which read table, do not check them either. reproducibility_check still puts the files of theirs that the paper’s code names in the folder the code runs in, as a re-analysis needs the data it re-analyses. When every linked deposit is set aside, the traffic light is “na”. A deposit that is the paper’s own is counted as such when its README, title or description names the paper (its title or DOI).

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

The module also checks whether the repository pins the R/package versions the analysis actually depended on: an renv.lock file (parsed for the R version and every locked package + its version/source), a sessionInfo()/sessioninfo::session_info() text dump (matched by filename — sessionInfo.txt/session_info.txt and similar, or embedded in a README), or a groundhog::groundhog.library()/checkpoint::checkpoint() date-pin call in the code (a bare library(groundhog)/library(checkpoint) does not count — the pinning call itself must be present). When none of these is found, the report flags it as a reproducibility gap: package versions may drift between when the analysis was run and any later reproduction attempt.

If you want to extend the package to perform additional checks on code files, or make the checks work on other types of code files, reach out to the Metacheck development team.

Checking code requires downloading its file contents. For a paper whose repository is on Dryad, this never succeeds unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (listing the repository’s files does not need one). Without a key, every Dryad-hosted code file is listed but unchecked, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures recorded in the manifest.

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Column extraction requires files to be readable from disk. Files fetched by repo_check from OSF/GitHub/etc. without a local copy (file_location is NA) are classified but not column-extracted; pass local_path to point at a downloaded copy of the repository.

For a paper whose repository is on Dryad, this means column extraction never happens unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (dataset listing and metadata do not need one). Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

Every downloaded text file the authors wrote (code, settings, survey definitions such as Qualtrics .qsf files, documentation, outputs) is searched for keys: API keys, access tokens and private keys, which let anyone who downloads the file use a paid service at the authors’ cost. Of a tabular data file only the column names and first 3 rows of the table as read are searched: its values come from participants, but a key the authors set for a whole survey (as embedded data in a Qualtrics survey flow) is exported in every response. The search uses the rules of the secret scanner betterleaks (https://github.com/betterleaks/betterleaks, MIT licence) of high and medium confidence. A key found turns the traffic light red; the report and the keys table give its file, line and type, and only its beginning. Other files over 25 MB and binary files are not searched. A key is never tested with its provider. Every module’s result has any whole key replaced by “keyremoved” (see module_run()).

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability).

Provenance, kept so that a TRACE Research Object (TRO) declaration of the run can be written later from a stored result (metacheck #404; the helpers are in R/provenance.R). Only when code was run (execute = TRUE): * run_results$started_at, run_results$ended_at: when each run of a script started and ended (ISO 8601, UTC, milliseconds); NA for a script that was not started. A script run again in a later pass has the times of its last run. A TRO uses them for each trov:TransparentResearchPerformance. * run_results$exit_status: the exit status of the process that ran the script (0 = ended normally); NA when the process did not report one (a time limit, or Docker failing to start the container). * artifacts: one row per file, with stage (deposit: as downloaded from the repository, hashed from the downloaded file; before_run: the run folder just before the first script ran, after metacheck’s own changes, such as rewritten paths and unpacked archives; after_run: only the files the scripts made (status new), changed (changed) or removed (removed), as an unchanged file is the one listed before the run), path (relative to the run folder, as valid UTF-8, a byte of another encoding written as <xx>), size (bytes), sha256, mime_type (by extension, NA when unknown), source (the file’s address in the repository, for deposit). The package libraries metacheck installs in the run folder are left out, as are metacheck’s own files there (a script’s runner, and the statistical output it writes in statistical_output/). Files metacheck itself copied or made between passes (see modifications, output_copied, file_placed) show in after_run too. A TRO uses the rows as trov:ResearchArtifacts and each stage as a trov:ArtifactArrangement. * modifications$sha256_before, modifications$sha256_after: the hash of the changed script as downloaded and as it ran; NA when the script is not at the same path in both (a script made from an R Markdown file). * environment: the system that ran the code (trov:TransparentResearchSystem in a TRO): metacheck_version, started_at, ended_at, host (R version, platform, operating system), sandbox, network_isolated (TRUE only when every Docker run had --network none; the process sandbox does not stop the network), internet, timeout_per_script, total_timeout, python_local (the Python run outside Docker and its version), and docker: runs (for each kind of run, r_run, r_install, python_run, python_install, the image and the docker run arguments, such as --network none, --read-only, --cap-drop ALL, no-new-privileges, the process limit and the memory and processor limits) and images (for each image, its ID and digests from docker image inspect, its creation time and the R and Python versions its environment declares).

run_results$checked says what the run of each script shows about the code, in five groups, so that a script that does not reproduce is kept apart from one the check could not test: ran (it ran to the end); code_error (it did not reproduce: it stopped with an error of the code or the deposit, could not be read, or needs a file the deposit does not hold); dependency (a package or program was not available: a package that could not be installed or was not loaded, a program outside R and Python, a system library, or R crashing in a package’s compiled code); time (it did not finish within the time limit for one script, or was not started because the time for all scripts had run out); and not_checkable (it could not be checked automatically: it needs a person, the internet, a key or another setting of the authors’ computer, one platform such as Google Colab, Windows or OpenSAFELY, more memory than the run allows, a file that was not downloaded, a screen, or a program that runs it, or it is a file of a package of the code that Python runs only as a module of that package). It is NA for files run inside another script, files that are not an analysis, files not read, and a Docker failure. summary_table counts each group (repro_ran_n, repro_code_error_n, repro_dependency_n, repro_time_n, repro_not_checkable_n), and the report’s first sentence gives them. The traffic light reflects the static readiness signals by default; a script in code_error that stopped with an error makes it red, as a script that crashes on its own analysis is a genuine reproduction failure, and a script in one of the other three groups keeps it from being green. Calls that need a screen, which the run does not have (dev.print(), dev.copy2pdf(), dev.copy2eps(), savePlot(), windows(), win.graph(), x11(), quartz(), View()), are replaced before the run by calls that need none, which modifications records as screen_call_replaced. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Abstract

The biological mechanisms governing recovery versus chronicity of adverse posttraumatic neuropsychiatric sequelae (APNS) remain poorly understood. Here, we characterized longitudinal molecular changes among trauma survivors across ten APNS domains, including pain, anxiety, and depression. Recovery across these diverse clinical outcomes was associated with a shared, temporally coordinated transcriptional signature, characterized by early innate immune activation, subsequent homeostatic and wound-healing processes, and later adaptive immune responses. In contrast, chronic APNS trajectories exhibited limited transcriptional remodeling. We derived and externally validated an RNA-based Recovery Score (RRS) capturing the shared molecular response underlying recovery. Higher RRS was associated with greater clinical recovery, elevated peritraumatic cortisol, and lower cumulative stress exposure. Drug-response profiling identified candidate compounds predicted to mimic recoveryassociated transcriptional changes. Together, these findings support posttraumatic recovery as an active biological process and identify shared molecular pathways that may be harnessed to prevent multiple adverse posttraumatic outcomes.

Traumatic stress exposures (TSEs) are a nearly universal human experience and include assaults, military combat, natural disasters, motor vehicle collisions and other life-threatening experiences. Although most individuals recover following TSEs, a substantial subset develop adverse posttraumatic neuropsychiatric sequelae (APNS), such as posttraumatic stress, chronic pain, depressive symptoms, anxiety, sleep disturbance, and cognitive impairment. 1,2 Collectively, these APNS contribute substantially to disability, diminished quality of life, increased comorbidity and suicide risk, and considerable societal burden worldwide. 3, 4 Traditionally, APNS have been investigated as distinct clinical entities. However, growing evidence demonstrates that these outcomes frequently co-occur 2 and may arise, at least in part, from shared molecular processes initiated in response to TSE. 5, 6 Defining shared molecular programs that promote recovery across APNS could reveal therapeutic targets with the potential to improve multiple trauma-related outcomes simultaneously.

Although substantial research has focused on the biological mechanisms contributing to APNS chronicity, comparatively less attention has been directed toward understanding recovery as an active biological process. One approach to addressing this gap is to identify molecular processes that differentiate individuals who recover from those who develop chronic APNS. 7, 8 The potential value of this approach is supported by evidence that recovery following TSE involves coordinated biological responses 9-13 (e.g., glucocorticoid signaling, inflammatory pathways) rather than isolated molecular events. However, whether recovery involves a shared, coordinated molecular program across diverse APNS remains unclear. Moreover, most prior studies have examined biological signals at single timepoints after TSE, and/or have focused on individual APNS, rather than evaluating how molecular processes dynamically evolve from the immediate aftermath of TSE through longer-term recovery. Characterizing these dynamic molecular programs beginning in the hours after TSE is particularly important, as available evidence suggests that the initial biological response may shape subsequent trajectories of recovery and chronicity. 14, 15 In this study, we leveraged longitudinal molecular and APNS outcome data from trauma survivors enrolled in the AURORA cohort to identify shared molecular processes associated with recovery versus chronicity across ten APNS domains. AURORA enrolled participants in the emergency department (ED) within 72 hours of TSE and assessed ten APNS outcomes over six months post-TSE. 1 By integrating longitudinal transcriptomic data with inferred transcription factor activity, estimated immune cell fractions, circulating cytokines, and peritraumatic steroid hormone measurements, we characterized molecular programs associated with recovery, developed an individualized RNA-based Recovery Scores (RRS) to quantify recovery-associated transcriptional remodeling, identified biological factors associated with the RRS, and used drug-response signature analysis to identify compounds predicted to mimic recovery-associated transcriptional changes.

Recovery following TSE is characterized by extensive longitudinal transcriptomic changes

To identify molecular processes associated with recovery following TSE, we first examined longitudinal changes in gene expression between ED and 6M timepoints across trajectories for each of the ten APNS domains (Fig 1). Across all ten domains, Recovery trajectories exhibited extensive gene expression changes with 4,360-7,319 of 12,513 tested transcripts (35-58%) differentially expressed between ED and 6M (FDR<0.01), Fig 1a-j; teal outlined volcano plots). In contrast, Chronic trajectories consistently exhibited substantially fewer longitudinal gene expression changes (Fig 1a-j; burgundy outlined volcano plots). To account for differences in trajectory sample sizes, we performed sensitivity analyses involving repeated downsampling to 20 participants per trajectory. Recovery trajectories continued to exhibit substantially more differentially expressed transcripts than Chronic trajectories across all ten APNS domains (Ext. Data Fig 2). Given the frequent co-occurrence of APNS following TSE, both in prior literature (e.g. [19] [20] [21] [22] ) and within AURORA (Ext. Data Fig 3), we next examined the extent to which recoveryassociated transcriptional changes were shared across APNS domains. Strikingly, 3,574 genes exhibited concordant longitudinal expression changes across all Recovery trajectories, including 1,829 with higher expression at the ED and 1,745 with higher expression at 6M (Fig. 1a-j; Supplementary Tables 2 3). These findings identify a shared longitudinal transcriptional program associated with recovery across diverse posttraumatic outcomes.

Molecular processes characterizing recovery include robust peritraumatic neutrophil and IL-6 responses and a coordinated immune response over time

We next examined the 3,574 shared recovery-associated differentially expressed genes (DEGs) to characterize the biological processes underlying longitudinal recovery. Across recovery trajectories, longitudinal gene expression patterns revealed an early predominance of innate immune and inflammatory pathways followed by a shift toward cellular maintenance and adaptive immune processes (Fig 2a-e). Transcripts with higher expression at the ED visit were enriched for neutrophil and innate immune functions (Fig 2a, blue circles), consistent with Gene Ontology Biological Process (GO-BP) and Reactome enrichment analyses. GO-BPs enriched at the ED in the Recovery trajectory included neutrophil and granulocyte migration, myeloid leukocyte activation and migration, and regulation of innate and inflammatory immune responses (Fig 2b, blue circles). In contrast, fewer GO-BPs were enriched among transcripts with higher expression at 6M, primarily involving rRNA and tRNA metabolism, consistent with a transition toward cellular maintenance (Fig 2b, teal circles). Reactome analyses identified ED enrichment of neutrophil degranulation, Toll-like receptor signaling, interleukin signaling, and programmed cell death, while transcripts with higher expression at 6M were enriched for antigen receptor signaling, suggesting a shift toward adaptive immunity (Supplementary Table 4).

To determine whether these pathway-level changes reflected broader longitudinal changes in immune regulatory networks, we examined inferred transcription factor (TF) activity. Recovery trajectories exhibited coordinated longitudinal changes in TF activity across APNS, with an average of 82 differentially active TFs per APNS domain. TFs associated with inflammatory and myeloid biology 23 , including SPI1, NFKB1, JUN, FOS, and AR (androgen receptor), were consistently more active at the ED visit (Fig 2c, blue circles), whereas TFs associated with hematopoietic and immune-cell programming, including TBX21 24 (T-bet), and MAF 25 , were more active at 6M (Fig 2c, teal circles). In contrast, Chronic trajectories exhibited comparatively limited changes in TF activity over time (Supplementary Table 5).

Longitudinal immune cell deconvolution analyses further supported coordinated changes in immune cell composition during recovery (Fig 2d). Across Recovery trajectories, estimated neutrophil abundance was elevated at the ED visit and declined significantly by 6M, whereas CD8+ T cells, regulatory T cells, activated natural killer (NK) cells and monocytes increased over time (Supplementary Table 6). Notably, 1,607 of the 3,574 shared recoveryassociated genes (45%) were uniquely associated with neutrophil abundance, identifying neutrophils as the dominant immune cell correlate of early recovery-associated transcriptional changes (Ext. Data Fig 4). Consistent with these findings, circulating IL-6 concentrations were elevated at the ED visit and decreased over time, representing the most robust cytokine associated with recovery (Fig 2e; additional cytokines tested included IL-8, IL-10, TNF-α, IFN-γ; Supplementary Table 7). Together, these findings define a coordinated molecular recovery program characterized by the progressive resolution of an early neutrophil-and IL-6-associated innate immune response and an accompanying shift toward adaptive immune signaling over the subsequent six months.

Drug-response profiling identifies candidate compounds predicted to mimic molecular recovery

Having identified coordinated transcriptional, immune cell, and cytokine changes associated with recovery, we next investigated whether pharmacologic perturbations could reproduce the recovery-associated transcriptional program. We queried Connectivity Map (CMap) using differential expression signatures derived from Recovery trajectories across multiple query sizes (Ext. Data Fig 5). These analyses identified compounds and mechanism of action (MOA) classes predicted to either mimic (Fig 3a and c) or oppose (Fig 3b and d) recovery-associated longitudinal transcriptional changes (Supplementary Table 8).

Recovery-mimicking compounds, defined by transcriptional signatures positively associated with the recovery-associated expression program, converged on several shared MOAs. Glucocorticoid receptor agonists were among the strongest and most consistent recovery-mimicking classes and included dexamethasone and methylprednisolone (Fig 3a and c). Additional recovery-mimicking perturbations included protein kinase C (PKC) activators (e.g., prostratin) and the sex steroids estradiol and testosterone.

Conversely, recovery-opposing compounds, whose transcriptional signatures were negatively correlated with the recovery-associated expression program, were predominantly represented by inhibitors of mTOR and PI3K signaling (Fig 3b and d). Notably, several signaling pathways were represented among both recovery-mimicking and recovery-opposing perturbations; however, the specific compounds identified within each pathway were largely distinct. These findings identify pharmacologic pathways and compounds that may be leveraged to modulate shared molecular processes associated with recovery across multiple APNS domains.

A recovery score derived from longitudinal gene expression data quantifies molecular recovery

To quantify the magnitude of the recovery-associated molecular response at the individual level, we used the 3,574 gene transcripts differentially expressed across all Recovery trajectories to derive an RNA Recovery Score (RRS) (Fig 4a, panels 1 and 2). Participants were classified according to recovery across the 10 APNS (Ext. Data Fig 6a-b) and randomly divided into training and held-out test cohorts, with an additional intermediate phenotype group retained as a separate comparison set. Elastic net modeling with bootstrap stability selection in the training cohort identified a stable 46-gene recovery signature from the shared recovery-associated transcriptome (Ext. Data Fig 6c-d), comprising 20 transcripts with higher expression at the ED visit and 26 with higher expression at 6M, combined into a weighted longitudinal expression score (RRS; Fig 4a , panels 3 and 4).

RRS values varied continuously, with higher scores reflecting greater alignment with the recoveryassociated molecular response. In the training cohort, participants with greater clinical recovery exhibited higher RRS values (Fig 4b), and this association persisted, although attenuated, in the held-out test cohort (Fig 4c). RRS values in the intermediate phenotype group fell between these extremes (Fig 4c), consistent with the RRS as a continuous measure of molecular recovery. The RRS also differentiated Chronic versus non-Chronic trajectories across all ten APNS (Fig 4e). We further evaluated the RRS in the independent longitudinal PainOMICs RNAsequencing cohort 26 . Of the 46 genes comprising the score, 43 were present in the PainOMICs dataset, where higher RRS values were associated with pain recovery (Fig 4d). Participant-level RRS values are provided in Supplementary Table 9.

Pre-and peritraumatic factors are associated with the molecular recovery response

Having established the RRS as a generalizable molecular measure of recovery, we next examined whether pre-TSE clinical characteristics, prior stress burden, and acute endocrine responses were associated with RRS values (Fig 4f and g). Lower RRS values were consistently associated with indicators of chronic stress burden and prior adversity, including greater childhood trauma and lifetime trauma exposure, and were modestly lower among Black compared with White participants (Fig 4f). Conversely, higher RRS values were associated with greater psychological resilience, relational support, emotional coping capacity, and overall physical health prior to trauma exposure (Fig 4f).

Notably, higher peritraumatic plasma concentrations of glucocorticoids, including cortisol and other corticosteroids, were associated with higher RRS values (Fig 4g). None of the five medication classes examined (NSAIDs, opioids, hormonal contraceptives, benzodiazepines, and SNRIs/SSRIs) across the pre-TSE, ED, and discharge assessment periods were significantly associated with RRS values. Together, these findings suggest that greater prior stress burden is associated with an attenuated molecular recovery response, whereas stronger peritraumatic glucocorticoid responses are associated with more robust molecular recovery (Supplementary Table 10).

Recovery-associated molecular responses occur predominantly within the first two weeks following TSE

As described above, substantial molecular changes were identified between the initial ED visit and 6M post-TSE. To better understand the timing of these changes, we examined molecular data from an exploratory subset of participants (n=40) with additional blood samples collected at 2 weeks (2WK), stratified into high and low RRS groups using a median split (Fig 5a-e). The summed expression of the 20 RRS transcripts with higher expression at the ED decreased significantly from ED to 2WK in both groups, whereas the summed expression of the 26 transcripts with higher expression at 6M increased significantly over the same interval. In both cases, the magnitude of change in expression between ED and 2WK was greater in the high RRS group (Fig 5a; Supplementary Table 11). Overall, most transcriptional changes occurred during the ED-to-2WK interval (Fig 5b). Gene set enrichment analysis of EDto-2WK changes in high RRS participants identified enrichment of myeloid cell development, homeostasis, and wound-healing pathways at the 2WK timepoint (Fig 5c, Supplementary Table 12).

High RRS participants also exhibited coordinated immune cell changes over this early period (Fig 5d, Supplementary Table 13). Estimated neutrophil fractions were highest at the ED, declined significantly by 2WK, and continued to decrease through 6M. In contrast, regulatory T cells and activated NK cells increased substantially by 2WK, whereas CD8+ T cells and monocytes increased more gradually over six months. Among low RRS participants, immune cell populations exhibited attenuated or divergent longitudinal changes compared with high RRS participants. Transcription factor activity showed a similar pattern: ETS1, GATA2, KLF1, and ESRRA increased predominantly by 2WK before plateauing in high RRS participants, whereas changes were attenuated and discordant in low RRS participants (Fig 5e, Supplementary Table 14).

Circulating cytokines showed similar, although not statistically significant, temporal differences (Fig 5f, Supplementary Table 15). High RRS participants exhibited elevated early IL-6 levels that declined by 2WK, whereas low RRS participants showed minimal early decline followed by increasing IL-6 between 2WK and 6M. TNF-α increased by 2WK among high RRS participants before plateauing, whereas IFN-γ remained stable during the first two weeks and subsequently increased through 6M among low RRS participants.

Together, these findings suggest that much of the molecular remodeling associated with recovery occurs within the first two weeks following TSE, highlighting the early posttraumatic period as a potentially important window for influencing subsequent recovery trajectories.

Discussion

Here, we demonstrate that recovery over six months following TSE is characterized by coordinated time-dependent transcriptomic, immune cell, and cytokine changes linked to peritraumatic hormone levels. Consistent with the frequent co-occurrence of APNS (e.g., pain, posttraumatic stress, depressive symptoms) and their hypothesized shared evolutionary role in promoting survival following life threat, 27, 28 individuals who recovered exhibited remarkably similar longitudinal molecular trajectories across outcomes. As summarized in our proposed heuristic model of trauma recovery (Fig 6), recovery was characterized by extensive transcriptional changes, with an early neutrophil-and IL-6-associated innate immune response followed by a shift toward cellular maintenance and adaptive immune processes. In contrast, Chronic APNS trajectories exhibited comparatively limited longitudinal molecular remodeling. These findings converge with recent rodent work in which resilient animals showed a distinct hippocampal signature consistent with active molecular adaptation, suggesting that recovery across species may reflect coordinated and tissue-specific remodeling following trauma, expressed peripherally through immune and endocrine dynamics and centrally through hormone-responsive and neural-plasticity pathways. 29 Drug-response profiling identified glucocorticoid receptor agonists and sex steroids among compounds predicted to mimic the molecular recovery response. An RRS derived from ED and 6-month transcriptomic data quantified recoveryassociated molecular remodeling and generalized to an independent cohort. Higher recovery scores were associated with lower prior trauma burden and greater peritraumatic cortisol levels, while exploratory two-week data suggested that much of the recovery-associated transcriptional changes occur within this early period.

As highlighted above, a central finding of these analyses is that recovery after TSE is associated with a coordinated molecular response that is evident in the immediate aftermath of TSE and evolves over time. Individuals who recovered after TSE exhibited a prominent early innate immune and inflammatory signature, including elevated neutrophil-associated transcriptional programs and circulating IL-6 levels. These early responses subsequently declined, accompanied by increasing homeostatic, tissue-repair, cellular maintenance, and adaptive immune programs over time. Together, these findings support a model in which successful recovery involves a robust early stress-immune response followed by coordinated resolution and restoration of physiological homeostasis. In contrast, Chronic trajectories were characterized by a comparatively attenuated early recovery-associated response and limited subsequent molecular remodeling, raising the possibility that persistent APNS reflect insufficient engagement and/or impaired resolution of these recovery-associated processes.

Persistent inflammatory activation is a well-established correlate of chronic pain, PTSD, depression, and other adverse posttraumatic outcomes 30, 31 , and inflammation following trauma has often been framed as pathogenic. 32 Yet, consistent with the evolutionary framework outlined above, acute innate immune activation is increasingly recognized as an adaptive, host-protective response 33 , one whose survival benefit depends on timely resolution rather than sustained activation. Emerging evidence from longitudinal human cohorts and experimental models suggests that transient early inflammatory responses may serve adaptive functions during recovery from stress and injury. 14, 26, [34] [35] [36] Our findings extend this framework by demonstrating that individuals who recovered exhibited a stronger early innate immune signature than those who developed persistent APNS, followed by coordinated changes consistent with active inflammatory resolution. [37] [38] [39] Thus, rather than supporting either sustained inflammation or broad immune suppression, our findings suggest that the timing and coordination of immune activation and resolution may be critical determinants of posttraumatic recovery. 40 Our exploratory two-week analyses further provide insight into the timing of these recovery-associated processes. Much of the observed gene expression changes occurred within the first two weeks following TSE, with high and low RRS participants subsequently exhibiting divergent patterns of inflammatory transcription factors, cytokines, and immune cell populations. These findings suggest that recovery may depend not only on the magnitude of the early response, but also on successful transition of early stress-immune programs toward coordinated resolution. Since a substantial proportion of these gene expression changes occur within the first two weeks after trauma, this early period may represent a potentially important window during which interventions could influence long-term outcomes. 14, [41] [42] [43] Further human studies are needed to refine the timing and sequence of molecular events occurring in the initial hours, days, and weeks after trauma, and further animal-model studies are needed to test the efficacy of candidate secondary preventive interventions based on both the treatment itself and its timing of administration. 44 Given that recovery reflects a coordinated sequence of biological processes rather than a single response, effective secondary prevention may require interventions tailored to distinct phases of the recovery process.

The observation that recovery-associated molecular trajectories diverged within the first two weeks following trauma raises an important mechanistic question: what biological systems coordinate the timing and magnitude of this early recovery program? Our findings provide convergent evidence implicating glucocorticoid signaling as a potential regulator. Multiple corticosteroid hormones measured in the ED were positively associated with molecular recovery, and glucocorticoid receptor agonists emerged from drug-response profiling as candidate modulators of the recovery-associated transcriptional program. These observations are consistent with prior studies linking blunted cortisol responses to TSE to poorer posttraumatic outcomes [45] [46] [47] [48] [49] and with a broader model in which inadequate activation of the hypothalamic-pituitary-adrenal (HPA) axis contributes to posttraumatic vulnerability 50 . Although glucocorticoids are often viewed primarily as immunosuppressive hormones, they also regulate leukocyte trafficking, innate immune activation, inflammatory resolution, and transcriptional remodeling. 51, 52 Importantly, interventional studies provide additional, although mixed, support for a role of early glucocorticoid signaling in posttraumatic recovery: hydrocortisone administered shortly after TSE has reduced subsequent posttraumatic stress symptoms in some randomized trials [53] [54] [55] , whereas another randomized trial found no overall benefit. 56 Thus, it is likely that only a subset of patients experiencing trauma would benefit from acute glucocorticoid administration, and understanding post-trauma predictive biomarkers may be critical in precision patient stratification.

In addition to glucocorticoid agonists, drug-response profiling also identified compounds predicted to induce recovery-associated transcriptional changes, including protein kinase C (PKC) activators and sex steroid hormones. These two candidate classes have some supporting evidence for potential roles in trauma recovery, including PKC activators in preclinical models 57 , and associations of peritraumatic estradiol 58, 59 and testosterone 60 with APNS outcomes. The present study adds to this evidence, characterizing the time-dependent molecular features that distinguish recovery from APNS development and highlighting the exciting potential this holds for intervention development.

A second important translational implication of the present work is that the shared recovery program can be quantified along a continuum at the individual level. This quantification (RRS) generalized across APNS in the discovery cohort and an independent cohort. Capturing recovery through a quantitative molecular score such as the RRS, rather than through symptom-based classification alone, is a step toward closing the gap between posttraumatic outcomes whose pathogenesis is relatively well understood (e.g., wound healing) and the relative "black box" of APNS pathogenesis. Biological scores such as the RRS have several potential uses in advancing understanding of trauma-related outcomes, including identifying biological subgroups of recovery and chronicity, characterizing exposures that shape APNS vulnerability, and integrating with neuroimaging and other measures of recovery to more comprehensively characterize recovery phenotypes.

Although these findings suggest that recovery-associated biology may be therapeutically enhanced, an equally important question is why some individuals fail to exhibit a robust molecular recovery response in the first place. Individuals with lower molecular recovery had greater lifetime trauma exposure, childhood adversity, and mental health-related symptoms. Molecular recovery was also modestly lower among Black participants. Given that race is a social rather than biological construct, this association may reflect differences in cumulative trauma, adversity, structural exposures, or other social and environmental factors rather than intrinsic biological differences. 61 Notably, low-RRS individuals did not simply show attenuated recovery-associated changes; several transcriptional, immune-cell, and transcription factor trajectories diverged or reversed direction between two weeks and six months. This pattern raises the possibility that persistent APNS may involve dysregulated temporal coordination of recovery biology rather than simply a weaker initial response. 62 One possible explanation is that chronic stress burden alters stress-responsive endocrine systems, impairing glucocorticoid-responsive recovery programs after subsequent trauma exposure, consistent with literature implicating HPA axis dysregulation and genetic variation in FKBP5 and CRHR1 in APNS vulnerability. [63] [64] [65] [66] Future studies are needed to determine whether impaired glucocorticoid signaling represents a causal mechanism linking chronic stress burden to reduced molecular recovery.

This study has several strengths, including its longitudinal design, paired within-subject analyses, integration of transcriptomic, immune, endocrine, and cytokine data, inclusion of both men and women from diverse racial and ethnic backgrounds, and examination of ten APNS outcomes. Limitations should also be considered. Because AURORA is observational, the molecular associations identified here cannot establish whether these biological programs causally promote recovery. In addition, molecular data were available for most participants at only two timepoints (the ED and 6 months), and the sample size available for two-week analyses was modest. Immune cell fractions were estimated through computational deconvolution and transcription factor activity was inferred rather than directly measured. All molecular analyses were performed in peripheral blood, limiting inference regarding the contribution of central nervous system processes. In addition, although our findings differ from a recent AURORA analysis linking higher ED cytokines to greater PTSD severity 67 , this discrepancy likely reflects differences in analytic approach, as we examined within-person longitudinal remodeling across multiple APNS whereas Nishimi et al. modeled baseline cytokines as predictors of PTSD. Finally, although the RRS was externally validated, replication of the broader molecular findings in independent longitudinal trauma cohorts will be important.

Together, these findings provide a time-resolved molecular framework for understanding recovery following TSE. Rather than reflecting passive symptom resolution, recovery appears to involve coordinated endocrine, immune, and transcriptional programs that unfold over time and are shared across diverse posttraumatic outcomes. Although some individuals may enter the post-TSE period with biological vulnerabilities that limit engagement of these recovery-associated pathways, our findings identify recovery as an active biological process with potentially modifiable molecular components. Defining and therapeutically harnessing these endogenous recovery mechanisms may ultimately provide new opportunities to simultaneously prevent multiple APNS and reduce their substantial global burden.

Methods

Study design and participant cohort AURORA cohort

Participants were drawn from the AURORA Study, a longitudinal observational multisite cohort study designed to investigate pain and neuropsychiatric recovery following traumatic stress exposure (TSE) 1 . Qualifying TSEs were consistent with DSM-5 Criterion A and included motor vehicle collision (MVC)s, physical or sexual assault, falls greater than 10 feet, and mass casualty incidents. Other events involving actual or threatened death, serious injury, or sexual violence were also eligible when confirmed as plausible qualifying exposures by trained research staff. Between September 2017 and July 2020, n=2,626 individuals were enrolled from 33 Emergency Departments (ED)s across the United States within 72 hours of a TSE. Participants were eligible if they had no major physical injuries (e.g., no solid organ injury Grade >1 based on the American Association for the Surgery of Trauma criteria, no significant hemorrhage, no need for a chest tube or operation with general anesthesia), were alert and oriented, fluent in English, between the ages of 18-75, and unlikely to be admitted to the hospital for >72 hours. Enrolled participants completed questionnaires and provided blood samples in the ED and were followed longitudinally for 12 months with repeated pain and neuropsychiatric assessments over that time and blood collection at two followup timepoints (2 weeks (2WK) and 6 months (6M)). All participants provided written informed consent under protocols approved by the institutional review boards of each participating site.

The present analysis focused on a nested longitudinal sub-cohort of 245 participants with paired wholeblood and plasma samples collected at the ED and 6M timepoints following TSE (n=490 samples). Of these participants, 40 also had blood sample available from the 2WK timepoint, enabling additional analyses of molecular changes across all three timepoints (ED, 2WK, and 6M). Demographics and clinical characteristics of the full AURORA cohort (n=2,626), the ED-to-6M nested cohort (n=245), and the ED-2WK-6M nested cohort (n=40), along with statistical comparisons across groups, are presented in Supplementary Table 1.

APNS trajectory classification

Symptom trajectories following TSE were previously defined and published across ten adverse post-traumatic neuropsychiatric sequelae (APNS): pain, avoidance, reexperiencing, hyperarousal, anxiety, depression, somatic symptoms, mental fatigue, nightmares and sleep disturbance 2, 16 . Briefly, longitudinal symptom assessments collected via smartphone-based flash surveys administered during the post-TSE period were used to derive APNSspecific latent trajectory classes representing distinct symptom severity and recovery patterns of symptom severity and recovery over time. For each APNS, longitudinal symptom trajectories were modeled using latent growth curves, followed by growth mixture modeling to identify distinct classes based on differences in symptom intercepts and slopes. Between two and four trajectory classes were identified for each APNS, reflecting differences in symptom burden and recovery patterns following TSE.

For example, four trajectory classes were identified for pain: low (low symptom burden throughout followup), moderate recovery (high symptom burden in the ED with substantial recovery), moderate (high symptom burden in the ED with some recovery), and high (high symptom burden throughout follow-up). In contrast, two trajectory classes were identified for sleep disturbance: low (moderate symptom burden in the ED with substantial recovery) and high (high symptom burden throughout follow-up).

For the present analysis, trajectory classes comprising fewer than 20 participants were merged with the most phenotypically similar class within the same APNS, based on changes in symptom severity from the ED to 6 months) (calculated as Ed minus 6M symptom scores). This resulted in the merging of the following trajectory classes: the moderate recovery class with the low class for mental fatigue, and the moderate class with the high class for nightmares. For each APNS, the trajectory exhibiting the greatest reduction in symptom severity over time was designated the "Recovery" trajectory, whereas the trajectory characterized by the highest and most persistent symptom burden was designated the "Chronic" trajectory. All resulting trajectory classes (2-4 per APNS) were included in the initial longitudinal transcriptomic analyses, while downstream molecular analyses focused specifically on comparisons between the Recovery and Chronic trajectories.

Cross-APNS symptom comorbidity analyses

To quantify cross-APNS comorbidity, pairwise odds ratios were calculated to assess the co-occurrence of Recovery or Chronic trajectories across APNS. Odds ratios and corresponding confidence intervals were estimated from 2 x 2 contingency tables using Wald or Fisher methods, as appropriate, implemented in the epitools 68 R package (v0.5.10.1). Multiple testing correction was performed using the Benjamini-Hochberg false discovery rate (FDR) procedure 69.

Demographic, clinical, and medication variables

Demographic and clinical characteristics presented in Supplementary Table 1 were derived from AURORA baseline and follow-up survey data. Body mass index (BMI) was calculated from self-reported height and weight collected at the 2-week follow-up as part of the Berlin Questionnaire 70 . Sex assigned at birth was self-reported at the ED baseline visit. Age at enrollment was calculated from participants' date of birth and ED presentation date. Educational attainment, marital status, and race/ethnicity were self-reported at the initial ED visit using standardized items from the PhenX Toolkit 71 . Peritraumatic distress was assessed at the initial ED visit using an 8-item AURORA-modified version of the Peritraumatic Distress Inventory (PDI) 72 , with item scores summed to yield a total score ranging from 0 to 32. The Area Deprivation Index (ADI), a census block group-level measure of socioeconomic disadvantage 73 , was assigned by geocoding participants' addresses and reported as national percentile rank. Childhood trauma was assessed at the 2-week follow-up using an AURORA-modified version of the Childhood Trauma Questionnaire-Short Form (CTQ-SF) 74 (total score range: 0-44). Lifetime traumatic event exposure was assessed at the 8-week follow-up using the Life Events Checklist for DSM-5 (LEC-5) 75 . Trauma type was classified at ED enrollment based on participant self-report and medical record review. The nested RNA-sequencing cohort included a higher proportion of participants exposed to MVCs, consistent with the study's focus on posttraumatic recovery following events involving relatively minor physical injury. Enrollment sites were grouped into Midwest, Northeast, and Southeast geographic regions based on the location of the enrolling ED.

Pain severity during the 30 days preceding TSE and at the initial ED visit was assessed using an 11-point (0-10) Numeric Rating Scale 76 . Physical and mental health status were assessed using the SF-12 Physical and Mental Component Summary scores 77 , with norm-based scoring (population mean = 50, SD = 10). Pain interference was assessed using the PROMIS Pain Interference Short Form 4a 78 , and reported as a T-score. Anxiety was assessed using a 4-item AURORA scale adapted from items in the PROMIS Anxiety Short Form 7a 79 and the Generalized Anxiety Disorder screener 80 , with scores reported as raw totals. Emotional capacity was assessed using the PROMIS Self-Efficacy for Managing Emotions Short Form 4a 81 and reported as a T-score. PTSD symptom severity was assessed using the PTSD checklist for DSM-5 (PCL-5) 82 and reported as a raw score (range 0-80); binary PTSD status was defined using a validated cutoff score greater than 30 83 . Pre-TSE depressive symptoms were assessed using the PROMIS Depression Short Form 8b 84 and reported as a T-score; binary depression status was defined as a Tscore greater than 59. Pre-TSE perceived stress was assessed using the 10-item Perceived Stress Scale (PSS-10) 85 , with scores reported as raw totals. Resilience was assessed using the 10-item Connor-Davidson Resilience Scale (CD-RISC-10) 86 and reported as a total score.

Medication use was categorized into five classes: nonsteroidal anti-inflammatory drugs (NSAIDs), opioids, hormonal contraceptives, benzodiazepines, and serotonin-norepinephrine or selective serotonin reuptake inhibitors (SNRIs/SSRIs). For each class, binary indicators of use (yes/no) were generated for the relevant assessment periods (pre-TSE, ED presentation, and discharge prescriptions, as applicable). Medication names obtained from participant reports and medical records were mapped to World Health Organization Anatomical Therapeutic Chemical (ATC) classification codes.

Molecular profiling and data pre-processing

Whole-blood and plasma collection Whole blood was collected at the ED, 2WK, and 6M study visits using PAXgene RNA and EDTA tubes. Immediately following blood collection, PAXgene RNA tubes were mixed via inversion, incubated at room temperature for four hours, then frozen at either -20˚C or -80˚C at the study sites. Plasma was separated from EDTA-anticoagulated whole blood by centrifugation at 1,500 x g for 10 minutes, aliquoted into separate storage tubes, and frozen at -20˚C or -80˚C at the study sites. All samples were shipped in batches on dry ice to the University of North Carolina at Chapel Hill Bio-specimen Processing facility, where they were stored at -80˚C until use.

RNA sequencing, alignment and gene quantification

Total RNA was extracted from whole-blood samples using the PAXgene Blood miRNA Kit (Qiagen, Hilden Germany) according to the manufacturer's instructions. RNA concentration and quality were assessed using Qubit RNA Assay Kits (Thermo Fisher Scientific, Waltham, MA) and the 4200 TapeStation System (Agilent Technologies, Santa Clara, CA), respectively. Only RNA samples meeting predefined quality-control thresholds for concentration and integrity (RNA integrity number; RIN ≥ 7.0) were advanced to library preparation. Sequencing libraries were prepped from 600ng of total RNA using the Universal Plus Total RNA-Seq Library Preparation Kit with rRNA and globin depletion (TECAN, Morrisville, NC) according to the manufacturer's specifications. Libraries were multiplexed in batches of 96, with all longitudinal samples from each participant assigned to the same sequencing batch to minimize batchrelated variability in within-participant comparisons. Libraries were sequenced using 100-bp paired-end reads on an Illumina NovaSeq platform with an S4 200-cycle kit (Illumina, San Diego, CA) at the University of North Carolina at Chapel Hill High Throughput Sequencing Facility. Samples from each participant's longitudinal timepoints were multiplexed within the same batch, precluding confounding between sequencing batch and within-participant change over time.

Raw sequencing reads were aligned to the GRCh38 human reference genome using STAR (v2.7.6a) 87 with GENCODE v47 gene annotations. Transcript-level quantification was performed using Salmon (v1.4.0) 88 . Genes were retained for analysis if they had a mean read count of at least 5, nonzero expression in at least 90% of samples, and at least 10 reads in one or more libraries. Sample outliers were identified and removed based on principal component analysis and relative log expression quality-control metrics. Concordance between reported sex at birth and molecular sex estimates was assessed using XIST expression and SNP-based genetic sex, with discordant samples excluded. Following quality control, 530 RNA-sequencing samples across the three collection timepoints were retained for analysis. Transcription factor activity inference and differential expression analyses (described below) subsequently applied a gene-level expression filter of a minimum of three reads in at least one sample.

Inference of transcription factor activity

Transcription factor (TF) activity was inferred from whole-blood RNA-sequencing data using the viper package (v1.38.0) 89 and human DoRothEA regulons 90 (v1.16.0), which represent curated TF-target gene interactions assigned confidence levels based on the strength of supporting evidence. The viper algorithm infers TF regulatory activity from coordinated expression patterns among downstream target genes rather than relying solely on TF transcript abundance. Only high confidence regulons (levels A-C) containing more than 25 target genes were retained. For TF activity inference, genes with a minimum of three reads in at least one sample were retained using filterByExpr in edgeR 91 (v4.2.2). Library sizes were normalized using trimmed mean of M values (TMM) method 92 , and normalized counts were transformed to log2 counts per million (CPM) using the voom-limma framework (v3.60.6) 93, 94 . TF activity scores were then calculated for each sample and used to evaluate longitudinal changes in inferred TF regulatory activity.

Immune cell-type deconvolution

Relative immune cell-type fractions were estimated from counts per million (CPM) normalized bulk RNAsequencing data using CIBERSORTx 95 and the LM22 leukocyte signature matrix, which contains reference expression profiles for 22 immune cell subsets. Cell types with a median estimated fraction of zero across the cohort were excluded, yielding 14 consistently detected immune cell populations for downstream analyses: neutrophils, resting mast cells, activated dendritic cells, M2 macrophages, monocytes, activated NK cells, resting NK cells, regulatory T cells, CD8+ T cells, resting memory CD4+ T cells, naive CD4+ T cells, plasma cells, memory B cells, and naive B cells. Estimated cell-type fractions were arcsine square root-transformed to stabilize variance and improve approximation to normality for downstream statistical analyses.

Cytokine quantification and data preprocessing

Cytokines (IL-10, IL-6, IL-8, TNF-α, and IFN-γ) were measured in multiplex as previously described 96 . Briefly, plasma samples were diluted and quantified using Meso Scale Discovery (MSD)'s V-PLEX Proinflammatory Panel 1 Human chemiluminescence-based assay (Gaithersburg, MD, USA, catalog # K15049D-1) based on manufacturer's specifications at The University of North Carolina at Chapel Hill. Assay panel plates were read and analyzed immediately following preparation using a QuickPlex SQ 120 instrument (MSD) and the DISCOVERY WORKBENCH® 4.0 software. The intra-and inter-assay coefficient of variation between samples and plates was ≤ 15%. The few samples with higher coefficients of variation were repeated or excluded from the analysis.

Cytokine concentrations were log-transformed before analysis. Potential plate and batch effects were evaluated separately for each cytokine using linear models that included assay plate, batch, and collection timepoint, allowing technical effects to be evaluated while accounting for biological changes over time. Significant batch effects were observed for TNF-α and IL-8, whereas plate effects were observed across all cytokines. To preserve longitudinal biological variation, only technical effects (plate and/or batch), and not collection timepoint, were removed during adjustment. Log-transformed TNF-α and IL-8 values were adjusted for both plate and batch, while IL-10, IL-6, and IFN-γ values were adjusted for plate only. Adjusted cytokine values were calculated as the logtransformed concentrations minus the estimated contributions of the relevant technical effects, preserving variation associated with collection timepoint.

For longitudinal analyses, cytokine data were restricted to participants in the RNA-sequencing cohorts with complete measurements at the relevant timepoints. ED-to-6M analyses included participants with cytokines measurements at both ED and 6M, while ED-2WK-6M analyses included participants with measurements at all three timepoints.

Hormone measurement

Plasma samples were shipped on dry ice to Biocrates Life Sciences (Innsbruck, Austria) for quantification of seventeen steroid hormones including cortisol, corticosterone, and dehydroepiandrosterone DHEA), using the AbsoluteIDQ® Stero17 assay. Hormones were quantified using ultra-performance liquid chromatography-tandem mass spectrometry (UPLC-MS/MS) in multiple reaction monitoring mode on a Waters XEVO TQ-S micro instrument (Waters, Vienna, Austria). Prior to analysis, samples underwent solid-phase extraction (SPE) in a 96-well plate format to isolate and concentrate steroid hormones. Plasma samples, calibrators, and quality control samples were spiked with internal standards and applied to a preconditioned SPE plate. After drying, analytes were eluted twice with dichloromethane into a capture plate and subsequently evaporated under nitrogen gas. Samples were then reconstituted in 25% methanol in water for UPLC-MS/MS analysis. Quantification was performed using sevenpoint external calibration curves and 15 stable isotope-labeled internal standards. Quality control samples at three concentration levels were included to assess assay performance. Steroid hormone concentrations were calculated using Biocrates' WebIDQ software 97.

Samples identified as hemolytic or turbid were excluded. Hormone analyses focused on ED plasma concentrations among 184 participants with paired ED-6M RNA-sequencing data. Values below the analyte-specific limit of detection (LOD) were imputed as LOD/√2. Hormone concentrations were subsequently log2 transformed to reduce right skewness. Potential variation associated with sample preparation plates was evaluated separately for each hormone using linear models, and no significant plate effects were detected.

Longitudinal analysis of molecular recovery

Longitudinal analyses were performed using paired within-participant designs to quantify molecular changes between the ED and 6M timepoints. Analyses were performed separately for each trajectory across the ten APNS.

Longitudinal differential expression analyses were performed using the dream framework from the variancePartition package (v1.34.0) 98 , in conjunction with the voom-limma framework (v 3.60.6) 93, 94 , with participant included as a random effect to account for repeated measures. Gene-level read counts were filtered to retain genes with a minimum of three reads in at least one sample. Library sizes were normalized using the trimmed mean of Mvalues (TMM) method, and expression values were transformed to log2 counts per million (CPM) using voom. The dream framework incorporates voom-derived observational precision weights to account for the mean-variance relationship inherent to RNA-sequencing data. Differential expression statistics were subsequently moderated using empirical Bayes methods 99 . Because all longitudinal samples from a given participant were sequenced within the same batch, the paired design also minimized potential confounding from between-batch technical variation.

To assess whether differences in longitudinal differential expression were attributable to trajectory sample size, sensitivity analyses were conducted using repeated random downsampling. For each trajectory across all APNS, 20 participants with paired ED and 6M samples were randomly selected without replacement, and differential expression was reassessed using the same filtered, TMM-normalized gene set and dream analysis pipeline described above. This procedure was repeated for 10 independent iterations per APNS trajectory, and the median number of differentially expressed genes with FDR<0.05 across iterations was used to summarize the longitudinal transcriptional signature for each trajectory.

For inferred TF activity, estimated immune cell fractions, and circulating cytokine measurements, withinindividual longitudinal change scores were computed as Δ = 6M -ED. Longitudinal changes within each APNS trajectory were evaluated using two-sided paired T-tests. P-values were adjusted for multiple comparisons within each molecular modality using the Benjamini-Hochberg procedure.

Gene set enrichment analyses

Gene set enrichment analyses were performed using the FGSEA algorithm (v1.30.0) 100 to identify biological pathways associated with longitudinal transcriptional changes associated with clinical recovery following TSE across all APNS. For each APNS, gene-level statistics were obtained from paired differential expression analyses comparing ED and 6M timepoints within the Recovery trajectory. For each APNS, gene-level statistics were obtained from paired differential expression analyses comparing ED and 6M timepoints within the Recovery trajectory. Genes were ranked by a weighted score reflecting the magnitude, direction of effect, and significance calculated as log₂ fold change × -log₁₀(p-value). Gene set enrichment analyses were performed on the single ranked list for each APNS, with pathways enriched at the ED visit indicated by a negative normalized enrichment score (NES) and 6M enrichment pathways represented by a positive NES. Enrichment analyses were performed using two pathway collections: Gene Ontology Biological Process (GO:BP) and Reactome pathways, both obtained from the Molecular Signatures Database (MSigDB; v7.5.1; C5:GO:BP and C2:CP:REACTOME, respectively) 101 . Gene sets containing 50-500 genes were included in the analyses. Significant pathway enrichment was defined as a Benjamini-Hochberg FDR<0.01.

Associations between transcriptional and immune cell changes

Associations between longitudinal changes in gene expression and estimated circulating immune cell fractions were evaluated using within-participant change scores (Δ = 6M -ED). Gene expression changes were calculated for genes exhibiting concordant differential expression across the Recovery trajectories of all ten APNS, and corresponding changes in estimated immune cell fractions were calculated for each participant over the same interval.

For each immune cell population, separate univariable linear regression models were fitted for each gene to assess associations between changes in gene expression and changes in estimated immune cell fractions. Associations were evaluated using two-sided tests, and p-values were adjusted for multiple testing using the Benjamini-Hochberg procedure separately across genes for each immune cell population.

Pharmacologic perturbation analyses

Connectivity Map (CMap) analyses were performed using the LINCS CLUE platform 17, 102 to identify pharmacologic perturbations whose transcriptional signatures were concordant or discordant with recovery-associated geneexpression changes. CMap is a large-scale reference resource comprising gene expression signatures induced by small-molecule and genetic perturbations across diverse human cell lines. Transcriptional profiling in LINCS is performed using the L1000 platform, which measures expression of approximately 1,000 landmark genes and computationally infers the expression of additional genes, enabling high-throughput screening of perturbational responses 103 . Three recovery-associated query signatures were generated from ED-to-6M longitudinal differential expression analyses using the top 50, 75, and 100 upregulated and downregulated genes exhibiting concordant differential expression across the Recovery trajectories of all ten APNS overlapping the LINCS BING space. Each signature was submitted independently to CLUE, and the corresponding gene lists are provided in Ext. Data Fig 5.

CLUE query results were annotated with cell-line metadata and restricted to small-molecule perturbations. Signatures from central nervous system, autonomic ganglia, placenta, and unknown cell lineages were excluded. Downstream analyses retained signatures meeting LINCS quality-control criteria, including CLUE high-confidence connectivity designation and a transcriptional activity score (TAS) ≥ 0.2. Positive normalized connectivity scores (NCS) were interpreted as indicating transcriptional concordance with recovery-associated signatures (recovery mimickers), whereas negative NCS values indicated opposing transcriptional patterns (recovery opposers). Signatures meeting these criteria were considered qualifying signatures for downstream compound-level analysis.

For compound-level aggregation, perturbation signatures were stratified by NCS direction and summarized separately as mimickers or opposers. Compounds were required to have at least four qualifying signatures in the corresponding direction. Compound-level summaries included median NCS, NCS variability, median TAS, number of qualifying signatures, number of cell lines, annotated mechanisms of action, and predicted targets.

Derivation of the RNA-based Recovery Score (RRS) Extreme phenotype definition

To define extreme recovery phenotypes across APNS, the number of Recovery and Chronic trajectory assignments was calculated for each participant across the ten APNS. Because Recovery and Chronic trajectory assignments differed in their frequency and patterns of co-occurrence across APNS (Ext. Data Fig 3), asymmetric thresholds were evaluated to identify distinct extreme phenotypes while preserving adequate sample sizes. Multiple combinations of Recovery and Chronic APNS trajectory thresholds were evaluated to assess group size and overlap between extreme phenotype groups (Ext. Data Fig 6a). Thresholds were selected based on clinical trajectory distributions and group sizes, independently of gene-expression data.

Participants assigned to Recovery trajectories in at least seven APNS and Chronic trajectories in fewer than two APNS were classified as "Most-Recovered" (n = 96). Participants assigned to Chronic trajectories in at least two APNS and Recovery trajectories in fewer than seven APNS were classified as "Most-Chronic" (n = 82). These thresholds eliminated overlap between the Most-Recovered and Most-Chronic groups while retaining sufficient participants for model development and evaluation. All remaining participants were classified as "Intermediate" (n = 67) and were excluded from model training and feature selection.

RRS derivation

Participant-level longitudinal transcriptional changes were quantified as ED-to-6M log2 fold-changes for recoveryassociated genes expressed across all ten APNS Recovery trajectories. These longitudinal gene expression changes served as input features for development of the RNA-based Recovery Score (RRS), a quantitative measure of recovery-associated transcriptional remodeling following TSE.

Elastic net regularized logistic regression was performed to identify longitudinal transcriptional features distinguishing Most-Recovered and Most-Chronic phenotypes. Analyses were restricted to the extreme phenotype cohort, which was randomly partitioned into stratified training (80%) and independent heldout test (20%) cohorts, preserving the balance between Most-Recovered and Most-Chronic participants. Intermediate participants were retained as an additional heldout group and were not included in model fitting or feature selection. Sex and race distributions were compared across the AURORA training, heldout test, and Intermediate cohorts to assess demographic comparability (Ext. Data Fig 6b).

Within the training cohort, repeated Monte Carlo subsampling with bootstrap-based stability selection was performed. Across 20 Monte Carlo outer splits, a stratified random 80% subsample of the training cohort was selected for model fitting. Within each outer split, 50 balanced bootstrap samples were generated by resampling equal numbers of Most-Recovered and Most-Chronic participants with replacement. For each bootstrap iteration, elastic net models were fit using the glmnet package (v4.1-8) with α = 0.1 and λ selected using 10-fold crossvalidation via the one-standard-error rule, favoring a more parsimonious model over the model with the minimum cross-validation error. Genes with nonzero coefficients were retained from each bootstrap model.

Gene stability was evaluated across bootstrap iterations and Monte Carlo outer splits. Threshold sensitivity analyses were performed to evaluate the effect of varying within-split and outer-split stability thresholds on final signature size. Lower thresholds produced substantially larger gene sets, whereas increasingly stringent thresholds rapidly reduced the number of retained genes (Ext. Data Fig 6c). Final thresholds of ≥50% within-split stability and ≥40% outer-split stability were selected to balance signature size and feature stability, retaining sufficient genes to capture interindividual variability and facilitate overlap with external transcriptomic datasets while limiting inclusion of unstable features.

For each gene retained following stability selection, elastic net coefficients were first averaged across the 50 bootstrap models within each Monte Carlo outer split. The resulting split-specific coefficients were then averaged across the 20 Monte Carlo splits to generate the final weight for each gene (Ext. Data Fig 6d). Participantlevel RRS values were calculated as the weighted sum of each participant's longitudinal ED-to-6M log2 fold-changes using these final gene weights. The same gene weights were applied without modification to the training cohort, heldout test cohort, Intermediate participants, and external validation cohort.

Internal and external evaluation RRS performance was evaluated in both the training and independent heldout cohorts by comparing Most-Recovered and Most-Chronic participants using two-sided Welch's t-tests. Discrimination between these phenotypes was additionally assessed using receiver operating characteristic (ROC) curve analysis and the area under the curve (AUC).

To evaluate associations between the RRS and individual APNS outcomes, RRS values were merged with latent trajectory classifications for each APNS. For each APNS, participants assigned to Chronic trajectories were compared with those assigned to all other trajectories using ROC analyses and AUC estimates. Associations between RRS and APNS latent trajectory classifications were additionally evaluated using Welch's t-tests for binary outcomes and one-way ANOVA for APNS with more than two trajectory classes. For APNS with more than two trajectories, post-hoc pairwise comparisons were performed using estimated marginal means from the emmeans package (v1.11.1). P-values were adjusted for multiple testing across APNS using the Benjamini-Hochberg FDR procedure.

External validation was performed using an independent longitudinal whole-blood RNA-sequencing cohort of individuals with acute low back pain who provided blood samples at an early assessment and approximately six months later (PainOMICs, GEO accession GSE177034). Raw count data were imported, mapped from Entrez gene identifiers to HGNC gene symbols, and log2 transformed after addition of a pseudocount. Participants with paired baseline (t0) and follow-up (t1) RNA-sequencing samples were retained for analysis.

The final gene weights derived from the AURORA training cohort were applied directly to the external cohort without retraining or coefficient modification. Participant-level longitudinal transcriptional changes were calculated as log2 expression differences between t1 and t0 for genes overlapping with the final RRS signature. These transcriptional changes were multiplied by their corresponding gene weights and summed to calculate participantlevel RRS values. Associations between RRS values and persistent versus resolved pain outcomes were evaluated using two-sided Welch's t-tests.

Correlates of the RNA-based Recovery Score

To identify participant characteristics associated with the RRS, univariate linear regression analyses were performed across four pre-specified categories of predictors: (1) demographic and baseline physical health measures, (2) baseline mental health, stress and adversity exposures, (3) pre-and peritraumatic medication use, and (4) peritraumatic steroid hormone levels measured in plasma collected at the ED visit. Definitions, measurement scales, and coding procedures for all evaluated variables are provided in Supplementary Table 10.

Separate linear regression models were fitted for each predictor, with RRS as the outcome. Continuous predictors were standardized to a mean of zero and standard deviation of one before analysis, allowing regression coefficients (β) to represent the difference in RRS associated with a one-standard-deviation increase in the predictor. Regression coefficients were reported with corresponding 95% confidence intervals, and p-values were adjusted for multiple testing within each predictor category using the Benjamini-Hochberg FDR procedure.

Acute and delayed longitudinal molecular changes

Additional longitudinal analyses were conducted in the subset of 40 participants with available whole-blood samples collected at 2WK following TSE, in addition to paired ED and 6M samples. Participants were stratified into high and low RRS groups using the median RRS value from the full cohort of 245 participants as the cutoff. Longitudinal molecular changes were evaluated across the ED-to-2WK, 2WK-to-6M, and ED-to-6M intervals using gene-expression profiles, inferred TF activity, estimated immune cell fractions, and circulating cytokine measurements.

Within-group longitudinal changes across each interval were evaluated using two-sided paired t-tests within the high-and low-RRS groups. Each molecular modality was processed and analyzed using the corresponding preprocessing and longitudinal analysis procedures described above. Gene set enrichment analyses for the 2WK subset were performed using the same FGSEA workflow, pathway collections, gene-set size filters, and generanking approach described above. These enrichment analyses were restricted to the high-RRS group and evaluated the ED-to-2WK and ED-to-6M intervals, in which differential expression was observed. For these analyses, pathways with Benjamini-Hochberg FDR<0.05 were considered significant. The model integrates longitudinal transcriptomic, immune cell, transcription factor, cytokine, endocrine, and clinical findings. Individuals who recover exhibit robust early stress-immune activation at the initial emergency department (ED) visit, associated with higher peritraumatic cortisol levels and innate immune and inflammatory activation, followed by changes consistent with immune resolution and restoration of homeostasis within the first two weeks and greater adaptive immune activity and cellular maintenance by six months. Individuals with chronic APNS exhibit comparatively limited longitudinal molecular changes, potentially reflecting reduced engagement or altered coordination of recovery-associated processes. Pre-trauma risk factors (chronic stress, history of trauma and adversity, and anxiety/depression) and resilience factors (physical health, emotional coping capacity, and relational support) may contribute to this divergence. The early post-trauma period may represent an important window for preventative intervention.
