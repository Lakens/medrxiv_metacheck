To fix Exact P-Values

What we found

We found 5 imprecise p values out of 95 detected p values.

Show details

Reporting p values imprecisely (e.g., p < .05) reduces transparency, reproducibility, and re-use (e.g., in p value meta-analyses). Best practice is to report exact p-values with three decimal places (e.g., p = .032) unless p values are smaller than 0.001, in which case you can use p < .001.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (e.g., “decreased at the p < .05 significance threshold”).

To check Non-Significant P Value Check

What we found

We found 35 non-significant p values that should be checked for appropriate interpretation.

Show details

Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

How StatCheck works

Check consistency of p-values and test statistics

The Statcheck module runs Statcheck. Statcheck searches for regular expressions that match a predefined pattern, and identifies APA reported statistical tests. More information on the package can be found at https://github.com/cran/statcheck. The module only returns Statcheck results for t-tests and F-tests, as these are the only tests which have been validated, see https://osf.io/preprints/psyarxiv/tcxaj_v1/.

Statcheck was developed by Michèle Nuijten and Sascha Epskamp.

Statcheck considers p = 0.000 an error, as you should report p < 0.001. Furthermore, p < 0.03 is an error if the p-value was 0.031, and one should simply report exact p-values (p = 0.031). When the sentence of a test says it is one-sided (“one-tailed”, “one-sided” or “directional”), a p-value that fits a one-sided test counts as consistent (statcheck’s OneTailedTxt setting; #695). When the paper says anywhere that its tests are one-sided, a p-value that fits a one-sided test in either direction counts as consistent too: half the two-sided p, or 1 minus that half for an effect against the predicted direction. Equivalence tests (TOST) are left out, as their p-values do not test the difference. A statistic written with “<” or “>” is read as a bound, and in a sentence about equal variances an F-test’s two-sided p (twice the one-tailed p) counts as consistent. For more information, see StatCheck.

This module only checks statistical results reported in the running text of the manuscript. It cannot (yet) process statistics reported only in tables.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.), reported as exactly zero (e.g., p = .000), or impossible (below 0 or above 1, e.g., p = -.22).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold”, “legend” or “named”).

A p-value with the name of a correction or a test after the p (“pFWE < .05”, “padj < 0.05”, “p Wilcoxon = .02”) is flagged only when a test statistic comes before it in its clause (“t(37) = 7.17, p FWE < .05”). Without one it is mostly the rule that decided what was significant (“genes with padj < 0.05 were selected”); such a p-value is “named” in not_a_test. Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

A p-value below 0 or above 1 is impossible; it is listed apart and not also as imprecise. Often the statistic before it, or its minus sign, was copied into it (“t(134) = -2.32, p = -.13”, “Z = 3.091, P = 3.091”). A value above 1 is listed only after a test statistic in its clause: without one, a “P” above 1 was nearly always another quantity (a proportion, pH, a group’s mean, a model parameter). A number in scientific notation whose power of ten was lost when the PDF was read (“p = 2.4 x 10 -9” read as 2.4) is not listed. A “p” that is the subscript of another symbol (“r p = .64”, “²p = .02” for partial eta squared, “Δp = .33”), or a quantity with a unit, a logarithm or a ratio (“P = 2.9 µm”, “-log10 P = 7.5”, “Ca/P = 1.67”), is not read as a p-value at all (see extract_p_values()). Each p-value has its own row, also when the same one is written twice in a sentence.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

This module retrieves information from repositories.

The Repository Check module lists files on the OSF, GitHub, ResearchBox, DSpace (PsychArchives and other legacy- and DSpace 7-based installations), Zenodo, Dataverse, Figshare, Dryad, ReShare, 4TU.ResearchData, Mendeley Data, DataONE (Arctic Data Center, KNB, and other member nodes), and LDbase based on links in the manuscript.

A Handle link (hdl.handle.net/...) that leads to a repository read here is checked as a link to that repository ([handle_links()]).

Listing a repository’s files never requires an API key, but some hosts answer faster or more completely with one: OSF allows 100 requests/hour unauthenticated versus 10,000/day with a token (see [osf_pat()]), and Dryad enforces a strict per-IP daily quota on repeated listing (see cache below). Dryad is a special case beyond rate limits: listing a Dryad dataset’s files works without a key, but actually downloading file CONTENTS from Dryad fails with HTTP 401 unless a key is set, even for a fully public dataset (see [dryad_pat()] or [dryad_auth()]). When a linked OSF page is a registration, its registered_from project (the one it was registered from, which the manuscript itself may never link directly) is also checked: if that project is public its files are listed under its own URL, and if it is closed or otherwise inaccessible the report flags it explicitly, since some registrations only describe their content rather than mirroring it.

Whose deposit is each link? The ownership table gives, for every repository linked in the text and (with references = TRUE) every deposit cited in the reference list, one of six labels: own_this (made by the authors for this paper), own_earlier_data or own_earlier_code (the authors’ own, from earlier work), others_data or others_code (made by other people, reused here), or not_data (a publication such as a preprint, not a deposit), with ownership_group (“own”, “others”, “not_data”) and the reason. It is decided without a language model, from the sentence or reference that cites the link, the paper’s authors (names, ORCID iDs, affiliations), and what the deposit’s own record and files say (who made it, what it names, when, whether it is a software package; for an OSF project cited only in the reference list, its record alone). Telling this paper’s own deposit from the authors’ earlier one is less certain.

Only the deposits that are this paper’s own are checked. A deposit linked in the text that holds other people’s work (others_data, others_code) or the authors’ earlier work (own_earlier_data, own_earlier_code) is listed in the report, with the reason, but its files are left out of table and kept in table_not_checked: they count toward nothing here (files that do not belong in a repository, naming, READMEs, studies, the traffic light), and code_check, data_check and reproducibility_check, which read table, do not check them either. reproducibility_check still puts the files of theirs that the paper’s code names in the folder the code runs in, as a re-analysis needs the data it re-analyses. How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability).

Provenance, kept so that a TRACE Research Object (TRO) declaration of the run can be written later from a stored result (metacheck #404; the helpers are in R/provenance.R). Only when code was run (execute = TRUE): * run_results$started_at, run_results$ended_at: when each run of a script started and ended (ISO 8601, UTC, milliseconds); NA for a script that was not started. A script run again in a later pass has the times of its last run. The package libraries metacheck installs in the run folder are left out, as are metacheck’s own files there (a script’s runner, and the statistical output it writes in statistical_output/). Files metacheck itself copied or made between passes (see modifications, output_copied, file_placed) show in after_run too. Abstract

Post-stroke aphasia recovery has been proposed to be supported by two broad mechanisms: i) reorganization within the remaining components of the language network; and ii) recruitment of brain areas outside of the premorbid language network to assume language function post stroke. A key candidate for such network reorganization is the multiple demand (MD) network, which supports executive functions and is recruited for a wide range of cognitive tasks. A prominent hypothesis suggests that, when specialized language resources are no longer sufficient, this network supports linguistic processing while retaining its domain-general role.

In this cross-sectional study, we used precision functional MRI to evaluate these two hypotheses in 37 individuals with chronic post-stroke aphasia, along with 38 age-matched controls. Language and MD networks were identified within individuals using functional localizer tasks. Participants with aphasia completed extensive behavioral assessments that evaluated linguistic and general cognitive skills. We examined responses during language processing in each of the two networks and related activity and functional connectivity measures from the two networks to linguistic ability.

Our results do not support the hypothesis that language comprehension in chronic aphasia recruits parts of the MD network. First, the language and the MD networks remain robustly dissociated: the language network responds selectively to language across modalities, and no MD region shows increased responses to language comprehension in aphasia relative to controls. Second, functional connectivity analyses reveal no increased integration between the two networks during language comprehension. Third, linguistic ability is associated with the strength of activity within the language network, but not the MD network.

Although we cannot rule out a role for the MD network in aphasia recovery during the acute or subacute phases, or in more severely impaired patients, it appears that during the chronic phase, language comprehension relies on the same specialized network as in healthy controls.

Introduction

Aphasia affects over a third of stroke survivors 1 , and the incidence of stroke continues to rise as the aging population increases 2 . Aphasia severely affects patients' quality of life [3] [4] [5] and up to 90% of persons with aphasia (PWA) do not fully recover their linguistic abilities one year after stroke 6 . As a result, developing effective treatments remains a core goal in aphasia research 7, 8 . The degree of language recovery varies substantially across PWA [9] [10] [11] [12] [13] and depends on a multitude of factors. In particular, the neuroplasticity mechanisms that underlie this variability remain poorly understood (for reviews, see [14] [15] [16] [17] [18] [19] ). The nature of the neural mechanisms supporting language in the chronic stage of recovery remains debated, yet it is critical both for understanding the fundamental principles of neuroplasticity [20] [21] [22] [23] and for informing targeted rehabilitation strategies.

One central unresolved question concerns the degree to which language function following stroke relies on the residual specialized language system or requires broader cortical reorganization of function, including recruitment of other brain networks. The most common approach to probing the neural infrastructure of language processing in aphasia is to examine brain responses (e.g., with functional MRI, fMRI) while PWA perform language tasks. In most neurologically healthy individuals, linguistic processing relies on a left-lateralized fronto-temporal network [24] [25] [26] [27] [28] [29] . This network is strongly selective for linguistic inputs (for a review, see 30 ) and supports computations related to word recognition and combinatorial syntactic and semantic processing during both comprehension and production (e.g., [31] [32] [33] ).

These language regions emerge in early childhood [34] [35] [36] [37] [38] [39] [40] and continue to support language processing across the adult lifespan (e.g., [41] [42] [43] [44] ; for reviews, see 45, 46 ).

The prevailing hypothesis about aphasia recovery has been that the spared regions of this specialized language network continue to support language processing after stroke (e.g., 15, 17, [47] [48] [49] [50] ), and that recovery occurs either through homeostatic plasticity or within-network reconfiguration (see e.g., 14 for discussion). Indeed, many studies have observed neural responses within this canonical language network in PWA performing language tasks 19,48,50- 57 ; see review by 15 . Whether, and to what extent, stroke-induced damage to this network also triggers functional reorganization that involves other brain networks-such as homotopic contralesional language regions 15, 18, 50, 53, [58] [59] [60] or the domain-general multiple demand (MD) network 15, 18, 54, 55, [61] [62] [63] [64] [65] [66] [67] [68] [69] -remains debated.

Activation in the right-hemisphere homotopic language regions is perhaps expected given that a) in neurotypical adults, these areas show some engagement during language processing, although the responses are weaker and less selective than in the core left-hemisphere language regions (e.g., 28, [70] [71] [72] [73] [74] [75] ), and b) in cases of early left hemisphere damage, the right hemisphere language network can successfully support language function [76] [77] [78] . Further, in neurologically healthy individuals, perturbation of activity in the left-hemisphere language regions using brain stimulation leads to increased activity in the right-hemisphere homotopic regions 79, 80 . Evidence from aphasia suggests that right hemisphere recruitment is prominent in the acute and subacute phases, but in PWA who recover linguistic abilities well, activity shifts back to the spared left-hemisphere regions over time, with persistent right hemisphere reliance associated with poorer long-term outcomes 50, 51, 55, 81, 82.

The role of the domain-general MD regions in aphasia recovery is more controversial. The MD network-a bilateral network with prominent components in the frontal and parietal cortex-is engaged during diverse demanding cognitive tasks and has been associated with psychological constructs such as working memory, attention, and cognitive control 63, 64, [83] [84] [85] [86].

Individual differences in activation within this network in neurotypical adults have been linked with differences in general fluid intelligence 87, 88 , and damage to the MD brain regions is associated with loss of fluid reasoning and executive control abilities [89] [90] [91] [92] [93] [94] . Importantly, in healthy brains, this network is distinct from the language network with no response during language processing and strong responses during diverse executive function tasks, and nearzero functional connectivity with the language regions (e.g., [95] [96] [97] [98] [99] [100] ; see 101, 102 for reviews).

Even when language processing gets complex, in the presence of rare words or constructions, or when non-local syntactic dependencies need to be formed, the left-hemisphere language regions, but not the MD network, show a strong response and modulation by linguistic complexity [103] [104] [105] (see 106 for review). The MD regions only show engagement-in addition to the language areas-during language tasks where language processing is accompanied by extraneous task demands, such as semantic judgments or comprehension questions about the sentences 99, 107, 108 . Thus, this body of evidence from neurotypical adults suggests that the MD network does not contribute to linguistic processing beyond being engaged by general task demands in paradigms that include tasks.

However, another important property of the MD network is its functional flexibility; these brain regions have long been implicated in learning new skills and solving new problems 64, 109, 110 . This flexibility gave rise to the hypothesis that the MD network can take on new functions-including aspects of language-when specialized processing mechanisms get damaged 17, 111, 112 . This hypothesis has received support in the form of activation in the PWA's putative MD areas during language tasks, including in the dorsal anterior cingulate cortex or the inferior and middle frontal gyri 18, 54, 55, 61, [65] [66] [67] 69 . Additional support has come from brainbehavior association studies, including those that rely on lesion-symptom mapping 113 , or static and dynamic functional connectivity 61, 65, 68, 114, 115.

However, the evidence for the role of the MD network in aphasia recovery has been challenged. For example, based on a meta-analysis of past studies, Wilson & Schneck 19 have argued that the reported upregulation of frontal and parietal regions can be explained in terms of the task demands that accompany most language paradigms used in studies of PWA, in line with fMRI evidence from healthy participants discussed above. Another limitation of prior fMRI studies of PWA is that most have relied on group-level analyses where individual brains are averaged in the common space. Because of the well-established inter-individual differences in functional topography [116] [117] [118] [119] [120] [121] , this averaging leads to the blurring of functional network boundaries, which is especially problematic when trying to differentiate between adjacent brain networks, such as the language and the MD networks that lie side by side within the frontal lobe 96, 97, 102, 122 . Indeed, one prior fMRI study that has relied on individualsubject analyses 123 did not find evidence of the MD network's engagement during language processing in chronic aphasia.

Here, we adopt the individual-subject precision fMRI approach, relying on previously validated 'localizers' for the language and MD networks 85, 116, 124, 125 , to test whether the MD regions, defined functionally within individuals, show greater engagement during language comprehension in individuals with chronic aphasia, relative to age-matched controls. We complement these analyses of the two networks' activation profiles with a detailed cognitivebehavioral assessment of linguistic and cognitive abilities in PWA to ask which aspects of neural activity best predict linguistic competence (preregistration for this component of the study: https://osf.io/xcfpz/). If the MD network supports linguistic processing in chronic aphasia, we should observe i) MD network engagement during language comprehension tasks, ii) increased integration between the language and the MD networks, as reflected in functional connectivity, and iii) associations between MD network activity or connectivity and linguistic competence. If, instead, the residual language network remains the neural substrate for linguistic processing in PWA, we should observe selective engagement of the language regions during language comprehension tasks, persistent segregation between the two networks in their functional connectivity patterns, and associations between the language network activity/connectivity and linguistic ability. In exploratory analyses, we evaluated whether aphasia severity and lesion location affect the engagement of the two networks during language processing, to test whether greater aphasia severity may be associated with reduced language-network engagement and increased recruitment of the MD network. PWA and controls did not differ significantly in age (p = 0.102) but controls had significantly more years of education (p <0.001). Participants with aphasia (PWA) were all in the chronic phase of stroke recovery (> six months post-stroke). Participants were native English speakers (including three bilingual individuals with aphasia; for all three, all the testing was done in English), had normal or corrected-to-normal hearing and vision, and were medically and neurologically stable. Four additional PWA and four controls were excluded from the fMRI analyses for inability to complete tasks in the MRI or because their age fell substantially outside the range of the rest of the cohort. Among the 37 PWA, four completed the behavioral battery more than 9 months from their MRI session because of COVID-19 restrictions and were therefore excluded from the brain-behavior analyses. For the remaining 33 PWA, the mean interval between scanning and behavioral testing was 59 days (SD = 70 days). Three of the four excluded PWA were retained in the analyses of aphasia severity (n = 36), as their WAB-AQ was collected within two months of scanning. Detailed demographic information is available in Supplementary Table 1. The mean Western Aphasia Battery-Revised (WAB-R) 126 aphasia quotient (AQ) across all 37 PWA was 80.6 (SD = 22.1, min = 12.4, max=100). All PWA reported persistent language difficulties in their daily life at the time of the study, although fifteen PWA scored at or above the WAB-R cut-off for recovery (AQ ≥ 93.8), indicating they no longer met diagnostic criteria for aphasia at the time of testing (see Supplementary Figs. 1 and 2 for evidence that the data are similar when this subset is excluded). All participants gave written informed consent in accordance with the requirements of MIT's Committee on the Use of Humans as Experimental Subjects (COUHES), the Declaration of Helsinki, and the Institutional Review Board of Boston University. Participants were paid for their participation.

Participants completed three tasks while undergoing fMRI (Fig. 1B): two language 'localizer' paradigms (an audio-visual version and a reading-based version) designed and previously validated to identify the language network within individual participants and measure its response properties (e.g., 30, 97, 116, 128 ); and an MD network 'localizer' paradigm (an arithmetic addition task) designed and previously validated to identify and measure response properties of the MD network 85, 129, 130 . We included two versions of the language localizer for two reasons: to maximize our chances of reliably identifying language areas in each individual, given that different versions may work better for different participants; and to generalize our findings across the listening and reading modalities. We had attempted to include an alternative version of the MD localizer as well (a spatial working memory task; e.g., 95 ), but the task proved too difficult for PWA (with accuracies of ~60% on both the harder and easier conditions), so we chose not to include the data from this task. All paradigms used a blocked design, and each participant completed two runs of each task, with condition order counterbalanced across runs. The scanning session lasted approximately two hours including breaks. Prior to the scanning session, participants practiced the tasks on a laptop.

In the audio-visual language localizer, participants watched short videos. The videos for the critical condition consisted of a woman producing sentences (all 12 words long and varying in structure and meaning; the sentences were extracted from language corpora and recorded with the help of a trained actress and a professional videographer). For the control condition, the video was blurred and the audio distorted to render speech incomprehensible 124 . In the reading-based language localizer task, participants read eight-word-long sentences (critical condition) and sequences of eight nonwords (control condition), presented one word/nonword at a time 75, 116 . At the end of each trial, a word/nonword was presented, and participants had to decide whether it was the same as the last word/nonword of the trial. The task was designed to be easy and was included to help participants stay alert (see 108 for evidence that the language network's topography and responses are the same for passive reading vs. this, and other, tasks).

In the MD localizer task, participants solved two-operand addition problems that were either harder (critical condition, involving double-digit addends: e.g., 36+45 = 81) or easier (control condition, involving single-digit addends: e.g., 2+4 = 6). The problems were shown with the sum, and the sum was correct on half of the trials. Participants responded with a button press to indicate whether the sum was correct or incorrect. Slightly different versions of the reading-based language localizer task and the MD task were used by PWA and controls to adjust for differences in processing speed and task performance (see Supplementary Tables 2 3 4 5for details of the procedure and timing; Supplementary Tables 6-7 for behavioral performance).

In addition, two naturalistic-cognition paradigms were included (and used in the current study for the functional connectivity analyses): a resting-state run (participants were instructed to close their eyes but stay awake and allow their minds to wander) and a ~five-minute-long story from the Natural Stories corpus ( 131 ; an edited version of the publicly available story "Elvis Died at the Florida Barber College" by Roger Dean Kiser; unedited version: http://www.eastoftheweb.com/short-stories/UBooks/ElvDies.html). The story was edited to incorporate various linguistic features known to increase processing difficulty based on behavioral investigations of incremental sentence processing and has been used in numerous prior fMRI studies 95, [103] [104] [105] . The story was played twice during the scanning session, and the results were averaged across the repetitions in the analyses. The story was followed by seven yes/no content-related questions, included to assess comprehension levels (PWA mean accuracy = 78% ± 22, Controls mean accuracy = 97% ± 11).

MRI Acquisition

Images were acquired on two identical scanners with identical sequences at Boston University and Massachusetts Institute of Technology (a Siemens 3.0T Prisma-upgraded scanner with a 32-channel head coil). Structural T1-weighted and functional BOLD data were collected for all participants. In particular, anatomical (T1-weighted) data were acquired using a T1 MEMPRAGE sequence (176 sagittal slices, 1mm×1mm×1mm voxel size, TR = 2530ms, TE1 = 1.69ms, TE2 = 3.55ms, TE3 = 5.41ms, TE4 = 7.27ms, TI = 1100ms, flip angle = 7.0 degrees). Functional data were acquired using an SMS EPI sequence (2.4 × 2.4 × 1.8 mm voxels, TR = 2,000 ms, TE = 32 ms, 81 slices). See Supplementary Methods for additional details on the sequences. fMRI Preprocessing fMRI data were preprocessed using SPM12 (release 7487), the CONN EvLab module (release 19b), and custom MATLAB scripts. For each PWA, a lesion mask was generated using semi-automated segmentation in ITK-SNAP 132 . Functional scans were coregistered to the first scan of the first run, and potential outlier scans were identified based on motion estimates and BOLD signal indicators using default CONN thresholds. Functional and structural data were normalized to the MNI space (IXI549Space template) using SPM12 unified segmentation with the lesion masked out, resampled to 2 mm isotropic voxels, and smoothed with a 4 mm FWHM Gaussian kernel (excluding voxels within the lesion mask).

The data from the naturalistic paradigms underwent additional denoising: nuisance regression of motion parameters and white matter/CSF signals, followed by bandpass filtering (0.01-0.25 Hz).

First-level Analysis

Voxel-level responses were estimated using a General Linear Model (GLM) in which each experimental condition was modeled with a boxcar regressor convolved with the canonical hemodynamic response function (HRF) (fixation was modeled implicitly, such that all timepoints that did not correspond to one of the conditions were assumed to correspond to a fixation period). Temporal autocorrelations in the BOLD signal timeseries were accounted for by a combination of high-pass filtering with a 128-second cutoff, and whitening using an AR(0.2) model (first-order autoregressive model linearized around the coefficient a=0.2) to approximate the observed covariance of the functional data in the context of Restricted Maximum Likelihood estimation (ReML). In addition to experimental condition effects, the GLM design included first-order temporal derivatives for each condition (included to model variability in the HRF delays), as well as nuisance regressors to control for the effect of slow linear drifts, subject-specific motion parameters (6 parameters), and potential outlier scans (identified during preprocessing as described above) on the BOLD signal.

Functional Localization of Networks and Response Estimation

For each participant, functional regions of interest (fROIs) were defined using the Groupconstrained Subject-Specific (GSS) approach 116, 133 , whereby a set of parcels or "search spaces" (i.e., brain areas within which most healthy individuals in prior studies showed activity for the corresponding contrast) was intersected with each participant's activation map for the respective localizer contrast. To define the language fROIs, we used five parcels derived from a group-level probabilistic activation overlap map for the sentences > nonwords contrast in 220 independent participants 98, 125, [134] [135] [136] . These parcels include three regions in the left frontal cortex: two located in the inferior frontal gyrus (LH IFG and LH IFGorb), and one located in the middle frontal gyrus (LH MFG); and two regions in the left temporal cortex spanning the extent of the lateral temporal lobe (LH AntTemp and LH PostTemp).

Additionally, we examined activations in the right hemisphere (RH) homotopes of the language regions. To define the RH fROIs, the LH parcels were mirror-projected onto the right hemisphere to create five homotopic parcels. By design, the parcels cover relatively large swaths of cortex to accommodate inter-individual variability, making their mirrored versions likely to encompass right-hemisphere language regions despite potential hemispheric asymmetries in the precise locations of activations 75, 137 . Individual language fROIs were defined by selecting within each parcel the 10% of most localizer-responsive voxels based on the t-values for the intact > degraded speech contrast of the audio-visual language task or the sentences > nonwords contrast of the reading-based task (see Fig. 1C).

Analyses were performed using each set of language fROIs for each individual (audio-visual and reading-based). To define the MD fROIs, we used a set of 20 parcels (10 in each hemisphere) derived from a group-level probabilistic activation overlap map for the hard > easy spatial working memory contrast in 197 participants, which have been used in numerous prior studies 85, 95, 105, 107 inter alia. These parcels include regions in the parietal cortex (PostParietal, MidParietal, AntParietal), superior frontal gyrus (SFG), precentral gyrus (PCG), IFG pars opercularis (IFGop), middle frontal gyrus and its orbital part (MFG, MFGorb), insula, and medial frontal cortex (Medial Front). Individual MD fROIs were defined by selecting within each parcel the top 10% of most localizer-responsive voxels based on the t-values for the hard > easy contrast of the MD localizer task.

The language and MD parcels are available at https://www.evlab.mit.edu/resources-all/download-parcels. In PWA, an fROI was excluded when ≥ 90% of the corresponding parcel overlapped with the participant's lesion mask. Overlap was calculated as the intersection between the lesion mask and the parcel (see Supplementary Table 8 for the number of PWA included per fROI and task).

For both the language and the MD networks, we estimated the responses in the individually defined fROIs to the intact and degraded speech conditions of the audio-visual language task, to the sentences and nonwords conditions of the reading task, and to the easy and hard conditions of the arithmetic addition task. For extracting the responses of the language fROIs to the same language task conditions, and for extracting the responses of the MD fROIs to the arithmetic task conditions, an across-runs cross-validation procedure was used (first, data from run 1 were used to define the fROIs and data from run 2-to estimate the responses; second, data from run 2 were used to define the fROIs and from run 1-to estimate the responses; finally, the response estimates were averaged to obtain a single value per condition per fROI per participant). This approach ensures statistical independence between the data used for fROI definition and response estimation 127, 138 . Statistical tests were performed on these estimate values.

Estimation of Inter-regional Functional Correlations during

Naturalistic Cognition Paradigms

Analyses of inter-regional functional correlations, typically referred to as functional connectivity (FC), were performed on the naturalistic paradigms data (i.e., resting state and story listening). First, for each naturalistic run, the average BOLD signal intensity timecourse was extracted from each language and MD fROI (defined as explained above). Then, for each pair of language fROIs, MD fROIs, and language-MD fROIs, the Fisher-transformed Pearson's correlation coefficient was computed between their respective time-courses using custom R scripts (R version 4.2.1). For participants with two story-listening runs, correlation coefficients were averaged across runs. These analyses resulted for each naturalistic paradigm and for each participant in a 10x10 correlation matrix of functional connectivity among the language regions, a 20x20 correlation matrix of functional connectivity among the MD regions, and a 10x20 correlation matrix of functional connectivity between the language and MD regions. Statistical tests were performed on these correlation values.

Behavioral Assessments

A battery of standardized assessments was administered to PWA to assess their language and cognitive abilities. These assessments included the Western Aphasia Battery-Revised (WAB-R) 126 to characterize aphasia severity, the Boston Naming Test (BNT) to assess naming abilities 139 , the Psycholinguistic Assessments of Language Processing in Aphasia (PALPA) to assess lexical decision and non-word repetition 140 , the three-picture version of the Pyramids and Palm Trees Test (PAPT) to evaluate non-verbal semantic abilities 141 , and the Reading Comprehension Battery for Aphasia -second edition (RCBA) 142 to assess general reading abilities at the sentence and word levels. Auditory and visual sentence comprehension were further evaluated using a computerized version of a sentence-picture matching task developed by Zimmerer and colleagues 143 . In addition, general cognitive skills including attention, memory, and visuospatial processing were evaluated with the Repeatable Battery for the Assessment of Neuropsychological Status (RBANS) 144 , the Wechsler Memory Scale fourth edition (WMS-4) 145 , and the Cognitive Linguistic Quick Test (CLQT) 146 . All assessments were administered over videoconference or in person depending on the participant's ability to use technology and COVID-19 pandemic safety protocols.

Statistical Analyses

We investigated group differences between PWA and controls across two primary neural measures: (1) responses within the language and MD fROIs during the two language tasks (audio-visual and reading-based) and the arithmetic addition task; and (2) functional connectivity (FC), defined as the Pearson's correlation of BOLD time-courses between fROI pairs during the two naturalistic paradigms (resting state and story comprehension).

Task activation analyses

Overall, group comparisons were conducted using linear mixed-effects models (LMEMs) in R fitted with the bobyqa optimizer in lme4 147 , with Satterthwaite degrees of freedom via lmerTest 148 (also used for emmeans contrasts). The random-effects structure followed the design of the data 149 : random intercepts for participants and fROIs, by-participant random slopes for the within-participant effect being tested (response condition or task), and a random intercept for each participant's fROI, since the conditions were measured within the same fROI. By-fROI random slopes were not included, as inference was made over participants for a predefined set of fROIs. When a model was singular or did not converge, correlations between random effects were first removed and, if needed, variance components estimated at zero were dropped; the by-participant slopes of the tested effects were always retained. Confidence intervals were computed by the Wald method, and marginal/conditional R² via the performance package.

Within each group, the language > control effects (intact > degraded speech for the audiovisual task, sentences > nonwords for the reading task) and the hard > easy arithmetic effect were first tested separately for each LH and RH language and MD fROI using paired t-tests when a Shapiro-Wilk test indicated normality of the pairwise differences (p ≥ 0.05) and At the fROI level, the contrasts were compared with the paired t-test/Wilcoxon procedure described above, FDR-corrected across fROIs within each localizer × group combination.

To test whether responses differed by aphasia severity, patients were stratified using the Aphasia Quotient (AQ) from the Western Aphasia Battery (AQ ≥76 = mild aphasia; AQ <76 = moderate to severe aphasia), and the hemisphere-level interaction model was refit for each localizer × task × hemisphere combination with this three-level group factor (controls, mild, moderate-severe) in place of the binary group factor. Pairwise group differences (interaction contrasts, and simple contrasts within the preferred condition) were extracted via emmeans and Holm-corrected separately within the interaction contrasts and within the simple contrasts.

The analyses of the response profiles were complemented with analyses of spatial overlap between the language and the MD network, and analyses of lateralization for the language network (see Supplementary Material).

Functional connectivity analyses

Fisher z-transformed Pearson correlations between fROI-pair BOLD time-courses were modeled with an LMEM including random intercepts for participant and fROI pair. To test for network segregation (i.e., whether within-network connectivity was stronger than between-network connectivity), an LMEM with network type (within-language-network, within-MD-network, between-network) as fixed effect, by-participant random slopes for network type (following the simplification procedure described above), and random intercepts for participant and fROI pair was fit separately for each group, task, and hemisphere (within-LH, within-RH, interhemispheric); pairwise contrasts were extracted via emmeans with Tukey correction. Group comparisons were performed separately for each naturalistic paradigm (resting state and story) and each of the network × hemisphere combinations using an LMEM (Corr ~ Group + (1|participant) + (1|fROIpair)); p-values were FDR-corrected across all tests.

Brain-Behavior Analyses

For this component of the study, we pre-registered a set of planned analyses to evaluate the relationship between a) neural measures extracted from the language and MD networks and b) behavioral measures of linguistic and cognitive abilities in PWA (https://osf.io/xcfpz/).

Prior to all analyses, variables were z-scored, and missing data were imputed using predictive mean matching (MICE, 50 iterations). To reduce the dimensionality of the behavioral dataset while retaining meaningful variance, we first carried out a Principal Component Analysis (PCA) on the behavioral assessments described above (see Supplementary Methods); the resulting components served as the dependent variables for the analyses described below.

For the neural data, we used two complementary approaches: 1) The PCA approach: We applied a PCA to reduce the dimensionality of neural features across participants (see Supplementary Methods).

We then used multiple linear regression to test relationships between these neural components and the behavioral principal components (i.e., BCi ~ NC1 + NC2 + … + NCK + lesion volume, where BCi represents the i th behavioral component and K is the number of neural components NC).

2) The Elastic Net approach: To provide more granular insights into specific neural predictors, we employed a two-stage approach. Variable selection was performed using elastic net regression with leave-one-out cross-validation, separately for three predefined neural feature sets: language network features, MD network features, and language-to-MD functional connectivity features, with lesion volume as a candidate predictor in each set. The mixing parameter was fixed at α = 0.5 (equal L1 and L2 penalization), and λ was the value minimizing the cross-validated mean squared error.

Predictors with non-zero coefficients at this λ were then entered into confirmatory linear regression models to obtain inferential statistics. Because variable selection and confirmatory regression were performed on the same data, the confirmatory R² and pvalues may be optimistic; we therefore also report the leave-one-out cross-validated R² of the elastic net (1 -cross-validated mean squared error / outcome variance).

For both approaches, residual normality (Shapiro-Wilk) and homoscedasticity (Breusch-Pagan) were tested and multicollinearity was checked (variance inflation factors); when either test was significant (p < 0.05), heteroscedasticity-consistent (HC1) robust standard errors were used, with a robust Wald F test for the overall model. FDR correction was applied to the two overall model p-values in the PCA-based analyses, and across all predictors of the confirmatory regression models.

The relationship between aphasia severity and engagement of the MD and language networks during language processing was assessed with four LMEMs (two networks [language, MD] x two language contrasts [intact > degraded speech, sentences > nonwords]), with fROI-level effect sizes as the outcome, WAB-AQ as the predictor, and participants and fROIs as random intercepts. Because model residuals were heavy-tailed, all models were fitted as robust LMEMs (robustlmm package), with p-values based on a normal approximation; standard LMEMs (lmerTest, Satterthwaite degrees of freedom) yielded the same conclusions. A secondary, exploratory analysis used the same approach for the response to each language condition (intact speech, sentence reading) relative to fixation. FDR correction was applied within each family of four tests (primary contrasts, fixation responses, hemisphere followups). All analyses were conducted in R using the lme4, lmerTest, and robustlmm packages.

Given that previous work has found distinct patterns of reorganization and recovery following frontal versus temporal lesions [150] [151] [152] [153] [154] , we examined whether lesion location modulated the relationship between neural measures and linguistic abilities. We fitted linear regression models testing two-way interactions between each neural component (NC from the PCA) and lesion location (i.e., proportion of damage in frontal / temporal language parcels) in predicting the behavioral component (BC) reflecting linguistic abilities. The models took the form: BC1 ~ NCj*(Frontal Damage + Temporal Damage), where NCj represents each neural component, Frontal Damage represents the mean proportion of damage across LH IFGorb, IFG and MFG language parcels, and Temporal Damage represents the mean proportion of damage across LH anterior and posterior temporal language parcels. Influence diagnostics applied to each model separately identified outliers based on Cook's distance > 4/n; models were refit without these cases. To assess robustness, we report results both with and without these outlier cases.

In a final exploratory analysis, we tested whether the relationship between responses to language in the MD network and linguistic abilities depended on lesion location, with models of the same form using the intact > degraded speech and sentences > nonwords effects averaged across the MD fROIs (excluding fROIs with ≥ 90% damage): BC1 ~ Mean Language > Control Effect × (Frontal Damage + Temporal Damage), with the same outlier procedure. As a follow-up, the same models were fitted with the MD network responses to sentence reading and to nonword reading relative to fixation.

Results

The response profile of the language network

The language network of PWA showed a strong and selective response to language comprehension in both audio-visual and reading modalities, but the response was weaker than in age-matched controls in the left hemisphere (Fig. 2). Here, we report the results for the language fROIs defined using the audio-visual language localizer, but the results are highly similar when the fROIs are defined with the reading-based localizer (Supplementary Fig. 3).

All left-hemisphere (LH) language fROIs responded more strongly during the language comprehension condition than the control condition in both PWA and age-matched controls in both modalities (FDR-controlled for the number of fROIs; all pfdr < 0.008, Fig. 2A,C).

Similarly, in both groups, all homotopic right-hemisphere (RH) language fROIs showed a language > control effect in both modalities (all pfdr < 0.04, Fig. 2B,C), with the exception of the RH MFG fROI's response to the reading-based contrast in control participants (pfdr = 0.105).

In the left hemisphere, at the network level, PWA showed an overall weaker response than controls to the reading contrast (t(74) = -5.08, pholm < 0.001, d = -0.57); the response to the audio-visual contrast was also weaker, but this difference did not survive correction (t(69) = -2.92, p = 0.005, pholm = 0.061, d = -0.32; Fig. 2A). At the fROI level, PWA showed a weaker language > control effect for the reading contrast in all five LH fROIs (all pfdr < 0.012, Fig. 2C). This was not the case for the audio-visual contrast, for which responses were lower in magnitude in most left fROIs but the language>control effect did not statistically differ from controls (all pfdr > 0.06).

In the right hemisphere, at the network level, there were no significant group differences in language > control effect in either modality (audio-visual: t(72) = -0.76, pholm = 1.00; reading: t(73) = -0.75, pholm = 1.00; Fig. 2B). However, at the fROI level, PWA showed a weaker language > control effect in the reading modality in the AntTemp fROI only (pfdr=0.034, see Fig. 2C), with no reliable group differences observed in the audio-visual modality (all pfdr > 0.30). For detailed results of hemisphere-level group comparisons in language responses across modalities and localizers, see Supplementary Table 9.

Consistent with these hemisphere-specific differences, the language network of PWA was less left-lateralized than that of controls during the audio-visual (PWA: LI = -0.13 ± 0.46; controls: LI = 0.11 ± 0.21; pfdr = 0.006), but not during the reading task (PWA: LI = 0.39 ± 0.58; controls: LI = 0.51 ± 0.34; pfdr = 0.90; Supplementary Fig. 4). This change reflected reduced left-hemisphere engagement rather than increased right-hemisphere recruitment: during the audio-visual task, PWA had fewer suprathreshold voxels than controls in the lefthemisphere language parcels and not more, if anything fewer, in the right-hemisphere parcels. During the reading task, suprathreshold voxel counts were reduced in both hemispheres, leaving the lateralization index unchanged.

In both groups, language network responses were strongly selective for language in both hemispheres, with significantly larger language contrasts (in both modalities) than MD contrasts (hard > easy arithmetic) (all pfdr < 0.05). In particular, in PWA the MD contrast was non-significant in the language network of each hemisphere (all pholm = 1.00). At the level of individual fROIs, a weak positive hard > easy effect was found in two frontal fROIs (LH IFG: pfdr = 0.023; RH MFG: pfdr = 0.021). However, this effect was not specific to PWA: controls showed a positive hard > easy effect in the same frontal fROIs, as well as in the LH MFG and RH IFG fROIs (all pfdr < 0.001). The effect was never significantly larger in PWA than in controls, and it was reduced in PWA in the LH MFG (pfdr < 0.001), RH IFG and RH MFG (both pfdr = 0.037) fROIs. Thus, the response of the language network to the arithmetic task did not differ qualitatively between groups, and there was no evidence of increased recruitment of the language fROIs for non-linguistic processing in PWA. The response profile of the Multiple Demand network

The bilateral MD network of PWA did not show any language-selective responses, similar to controls (Fig. 3). In particular, both PWA and controls showed close to zero or negative responses to the audio-visual language conditions (intact and degraded speech; no intact > degraded effect at the hemisphere level in either group, all pholm = 1.00) and low responses to the reading conditions. The response to nonword reading was numerically stronger than to sentence reading in both groups and hemispheres-the opposite of the language network's profile-but this effect was significant only in the right hemisphere of PWA (pholm = 0.029; controls LH: pholm = 0.12, RH: pholm = 0.075; PWA LH: pholm = 0.64). It did not differ significantly between groups in either hemisphere (both pholm = 1.00) (Fig. 3A-B). Even when restricting the analyses to the subgroup of individuals with more severe aphasia (i.e., WAB-AQ < 76), responses to the language conditions in the MD fROIs did not differ significantly from those of controls (all pholm = 1.00, see insets in Fig. 3A-B and Supplementary Table 10). In contrast, the MD network across both hemispheres, and all individual MD fROIs, showed a robust response to the hard > easy arithmetic addition contrast in both groups (all pholm/fdr < 0.001, Fig. 3C). However, similar to the language network's response to the language tasks, PWA showed an overall weaker response to the arithmetic task contrast than the controls in both hemispheres (LH: t(73) = -4.85, pholm < 0.001, d = -0.66; RH: t(73) = -3.83, pholm = 0.004, d = -0.53, Fig. 3A-B); this effect held in the individual fROIs (all pfdr < 0.02, Fig. 3C), except for the RH MFGorb fROI (pfdr = 0.063).

In the controls, several MD fROIs (bilateral IFGop and PCG fROIs, and the RH SFG fROI) showed a significant audio-visual language effect (all pfdr < 0.04, Fig. 3C). However, these effects a) did not generalize to the reading modality, which argues against their interpretation as reflecting language processing; and b) were small in size and significantly smaller in magnitude than the hard > easy arithmetic effect in the same fROIs (all pfdr < 0.001).

The language-MD network dissociation in PWA in patterns of response, spatial overlap, and functional connectivity

The dissociation between the language and MD networks in PWA is evident in three complementary measures: task activation patterns in individually defined fROIs, spatial overlap of thresholded activation maps, and inter-regional functional connectivity during naturalistic paradigms. First, language and MD fROIs showed distinct profiles even for adjacent regions within the left frontal cortex (Fig. 4A). The left frontal language fROIs showed robust responses to both language comprehension contrasts (all pfdr < 0.008), whereas the neighboring MD fROIs showed the opposite profile: strong hard > easy arithmetic effects (all pfdr < 0.001) and no language > control effect in either modality. The left IFG and MFG language fROIs also responded to the arithmetic conditions, and the hard > easy contrast reached significance in the IFG fROI only (pfdr = 0.023; MFG: pfdr = 0.061; IFGorb: pfdr = 0.80; Fig. 2C). In the IFG fROI, the audio-visual language effect was larger than the arithmetic effect (pfdr = 0.043), but the reading effect was not (pfdr = 0.75).

Second, if the MD regions take on some language function in chronic aphasia, the two networks should show an increase in spatial overlap in PWA. This is not what we observed (Supplementary Fig. 5). The Dice coefficient between the thresholded language and MD activation maps was lower in PWA than in controls across all bilateral parcels (audio-visual: pfdr = 0.003; reading: pfdr = 0.008) and within the frontal parcels (audio-visual: pfdr < 0.001), and did not differ between groups for the reading contrast maps within the frontal parcels (pfdr = 0.051).

And third, functional connectivity analyses aligned with the activation-based analyses in showing clear segregation between the two networks in PWA, similar to controls (Fig. 4B).

Within-network synchronization was consistently stronger than between-network synchronization for both the language and MD networks during both rest and story listening (for within-left-hemisphere, within-right-hemisphere, and interhemispheric connections: all Tukey-adjusted p < 0.02). Discussion

.

To adjudicate between two accounts of post-stroke language organization-reliance of language processing on the residual portions of the specialized language network versus recruitment of (parts of) the domain-general multiple demand (MD) network for linguistic processing-we carried out a precision fMRI investigation. Using robust and extensively validated fMRI localizers to map the language and MD networks within individuals, we found that in chronic post-stroke aphasia 1) language comprehension relies on the spared parts of the bilateral language network, and 2) the MD network remains functionally dissociated from the language network, showing no language-selective response during language comprehension tasks. Furthermore, 3) better language outcomes are associated with greater engagement of the bilateral language network during language comprehension, not the MD network. Together, these findings suggest that in individuals with chronic post-stroke aphasia, language processing relies on the spared bilateral language regions, whereas the MD regions maintain their role in executive functions and are not recruited for language comprehension more than in age-matched controls.

Language comprehension relies on the spared bilateral language network in chronic post-stroke aphasia

In individuals with chronic aphasia, the selectivity of the language network is preserved. Spared regions of the bilateral language network showed strong responses to language comprehension across modalities (audio-visual and reading), and little to no response to a non-linguistic demanding task (arithmetic addition), similar to age-matched controls. Both the response magnitude and inter-regional functional connectivity during language comprehension were reduced in the left-hemisphere language network in PWA compared with controls, consistent with a large body of prior work 48, 50, 51, 53, [55] [56] [57] 155 ; see review by 15 . This activity reduction may reflect physiological factors, such as residual diaschisis in regions connected to the infarcted language areas [156] [157] [158] , persistent hypoperfusion around the lesion [159] [160] [161] [162] , or vascular changes that lower signal-to-noise ratio 163 . Although most patients in this cohort had mild aphasia (WAB AQ mean = 80.6), it is possible that variable ability to process linguistic stimuli may have influenced the results (Supplementary Tables 6 7).

In contrast to the left hemisphere, we found no reliable group differences in magnitude and connectivity in the right-hemisphere language regions in PWA relative to controls, even though it should be noted that PWA show a strong response in all homotopic RH fROIs. Linguistic competence in chronic aphasia was closely linked to how strongly the bilateral language network was engaged, particularly during the reading-based comprehension task.

Although we do not find evidence for a right-hemisphere "takeover" of language function beyond activation levels observed in controls, higher right-hemisphere language network activation was consistently related to better linguistic performance across analytic approaches. The association was specific to reading (Supplementary Table 12), possibly because reading is more strongly left-lateralized than audio-visual comprehension (Supplementary Fig. 4) and therefore more vulnerable to left-hemisphere stroke, making compensatory right-hemisphere engagement particularly beneficial for reading, whereas audio-visual comprehension is already more bilaterally distributed.

Surprisingly, left-hemisphere (LH) activation did not independently predict linguistic outcomes once right-hemisphere (RH) activation and lesion volume were accounted for.

However, this pattern was attributable to collinearity between the two hemispheric measures: PWA who more strongly engage residual LH language regions tend to also more strongly engage RH homotopic regions, and the RH feature outperforms the LH feature in predicting better outcomes. This finding suggests that the functional significance of residual LH activation cannot be evaluated in isolation: what matters is not simply whether the damaged left hemisphere remains active, but whether that activity occurs in the context of a synchronously engaged bilateral language network. This construal may help reconcile an apparent contradiction in past studies, where some have reported that RH activation predicts better outcomes in chronic aphasia 60, 164 , but others have found that persistent RH reliance is associated with poorer long-term recovery 50, 51, 55 . The latter likely reflects maladaptive overrecruitment of the right hemisphere in the context of a severely damaged left-hemisphere language network, whereas the former-along with our own findings-likely reflects preserved bilateral network architecture in stroke survivors who retain sufficient LH language resources to sustain coordinated bilateral engagement. Taken together, these results suggest that the right hemisphere's contribution to language outcomes in chronic aphasia is best understood not as a replacement system, but as a marker of the overall integrity of the bilateral language network.

The Multiple Demand network maintains a domain-general support role in chronic aphasia

We found no evidence that any parts of the domain-general MD network are recruited by individuals with chronic aphasia to process language. Across our tasks, the MD network in PWA behaved similarly to what has been reported in prior literature for young adults and to what we found in our study for age-matched controls (see also 44 ). In particular, the MD network responded strongly to a cognitively demanding non-linguistic task (arithmetic addition problems), with greater activation for the more difficult problems, and showed little to no response during language processing tasks. For the audio-visual language comprehension task, responses were overall low, close to the fixation baseline; for the reading comprehension task, the MD network of PWA showed a canonical opposite effect, with stronger responses to the meaningless and unstructured nonword-list condition compared to sentences (e.g., 85, 107, 108 ). Some frontal language regions showed a weak hard > easy arithmetic effect in PWA (LH IFG and RH MFG). However, this effect was also present in controls, often more strongly, and was never larger in PWA, arguing against poststroke functional reorganization.

Functional connectivity results converged with the activation findings. We found no evidence of consistently increased integration between the language and MD networks during language processing in PWA in either hemisphere. Although the connectivity between the two networks was slightly elevated in the right hemisphere of PWA during rest, this increase was not present during naturalistic story listening, which argues against the idea that the two networks interact to a greater extent in PWA in the service of language comprehension. This dissociation between resting-state and language task-based inter-network connectivity argues against a language-specific reorganization. The MD network therefore appears to retain its domain-general role in supporting cognitively demanding tasks, rather than being repurposed for language comprehension. PWA showed weaker MD responses to the arithmetic addition task than controls, and this difference was driven by the hard condition. A similar pattern of a selective reduction in the magnitude of response to the hard condition has been reported for healthy older adults compared to younger adults 44 . The aging effect is in line with the Compensation-Related Utilization of Neural Circuits (CRUNCH) hypothesis 165 , whereby the ceiling for the engagement of the executive control network lowers with age. In PWA, however, there are likely additional contributions of direct structural damage to the MD regions or their whitematter connections. Indeed, we found reduced functional connectivity within the lefthemisphere MD network during naturalistic paradigms, including rest, but not within the right-hemisphere MD network, suggesting a stroke-related weakening of ipsilesional MD function that is not limited to tasks with high cognitive demands. Nevertheless, reduced activation for the hard condition was present in MD regions bilaterally, indicating a generalized capacity limitation rather than a purely stroke-related effect.

In line with the lack of engagement of the MD network during language processing, our brain-behavior analyses suggested that properties of the MD network are not reliably associated with linguistic abilities. However, our exploratory analyses did reveal some heterogeneity across patients in the relationship between MD network engagement and language outcomes. In particular, stronger MD responses to the reading comprehension task were associated with better linguistic abilities, but only in patients with extensive damage to the temporal language regions, and not in patients with predominantly frontal damage.

Damage to left temporal and parietal cortex has long been shown to lead to longer-lasting and more severe aphasia 151, 154 , and some studies have reported qualitatively different functional reorganization patterns following temporo-parietal vs. frontal lesions 55, 114 . These preliminary findings are also in line with the Adaptive Plasticity Control (APC) framework 14 , which proposes that domain-general regions of the MD network may be recruited to scaffold language processing when core language resources are severely compromised, enabling more efficient use of spared linguistic representations and supporting relearning. Our findings suggest that the extent of temporal damage may be a key factor in whether such recruitment occurs. Because these analyses were exploratory and uncorrected for multiple comparisons, future work should replicate them and test the causal contribution of the MD regions to language outcomes. In particular, it should examine whether this contribution changes over the course of stroke recovery and depends on the degree of language network damage. While the results of the present study are preliminary and with a relatively modest sample size of 37 PWA who were generally mild in their aphasia severity, the methodology employed in this work allows a more precise evaluation of the language and the MD networks within each individual.

Clinical implications and future directions

The current findings carry direct implications for the design of language rehabilitation strategies in aphasia. In particular, rehabilitation efforts should focus on the residual language network given that stronger responses in this network during the chronic stage are associated with better language outcomes. This implication holds for both behavioral interventions, which should focus on linguistic tasks while minimizing general cognitive demands, and for non-invasive brain stimulation. Language localizers can be used to effectively identify the language areas within each patient to guide the placement of stimulating devices. Although some approaches (e.g., transcranial direct current stimulation, tDCS 166, 167 ) target broad anatomical areas, other, more recent approaches (e.g., focused ultrasound, FUS 168 ) can be used to target particular brain areas, which makes individualized functional mapping critical (see Shain et al., under review, for discussion). If the preliminary finding that MD recruitment benefits PWA with extensive damage to the temporal component of the language network replicates in future larger-scale studies, this would suggest that a subset of PWA with severely compromised language resources may benefit from approaches that target executive resources to scaffold linguistic processing. More broadly, our findings align with the general move toward personalized medicine 169, 170 by underscoring the importance of considering individual-level neural and behavioral profiles for both predicting recovery and optimizing treatments 49, [171] [172] [173].

Limitations

Several limitations constrain the interpretation of our findings. First, by design, the language tasks used here minimize extraneous cognitive demands and approximate naturalistic comprehension. Although both the critical language conditions in the localizers and the naturalistic story listening task include linguistic features known to increase local processing difficulty, such as low-frequency and unpredictable words and constructions, non-local syntactic dependencies, and temporary ambiguity (e.g., 103, 104 ), future studies should manipulate these aspects of linguistic complexity more directly, in both comprehension and production, to test whether the MD network's engagement may increase with greater linguistic difficulty. This is not the case in young neurotypical adults (see 106 for a review), but may be observed in populations with linguistic challenges. Second, this study focuses on the chronic stage of recovery with a majority of patients with mild to moderate aphasia; in fact, 15 PWA no longer met the WAB-R criterion for aphasia (AQ ≥ 93.8) at the time of testing, although they all still reported language difficulties affecting their daily life. Whereas most PWA in our sample showed relatively mild comprehension deficits on simple syntactic structures (mean WAB-R auditory verbal comprehension accuracy: 90% ± 14), a majority showed difficulty processing more complex structures (mean accuracy for comprehension of passive sentences and object relative clefts: 65% ± 20). Nevertheless, the lack of a sufficient number of PWA with more severe linguistic impairments may have reduced our ability to detect MD network engagement (if such engagement is only observed in the most impaired PWA). However, two observations mitigate this possibility: aphasia severity did not predict MD network engagement during language processing, and post-hoc analyses restricted to the moderate-to-severe aphasia subgroup yielded the same results (Supplementary Table 10).

Furthermore, we cannot exclude the possibility that the MD network plays a role during earlier stages of recovery, before language network function normalizes 55 . Indeed, some prior evidence supports a time-limited scaffolding role for the MD network: for example, frontoparietal functional connectivity during the subacute stage predicts subsequent language recovery 115 , and MD activity during speech production at the acute stage predicts long-term outcomes 65 . Longitudinal studies that track the engagement of and functional connectivity in the language and MD networks from the acute through the chronic stages of recovery will be critical to understanding the potential changes in the MD network's contributions to language processing in aphasia.

Third, the study has a sex imbalance between the groups: PWA were predominantly male (30 men, 7 women; 19% female), whereas the control group was more balanced (17 men, 21 women; 55% female). This asymmetry reflects the higher incidence of stroke in men in the relevant age range, but potentially complicates the interpretation of group differences in the degree of language lateralization and interhemispheric connectivity, although large-scale datasets of the language responses suggest no reliable differences between sexes (e.g., 174 ; unpublished data from the Fedorenko lab).

Conclusion

Using precision fMRI, the present study shows that people with chronic post-stroke aphasia do not recruit the domain-general multiple demand (MD) network to a greater extent than neurologically healthy age-matched individuals during language comprehension. Instead, similar to control participants, language comprehension in people with aphasia relies on the spared parts of the bilateral language network. Despite weaker responses and lower withinnetwork functional connectivity following a stroke, the language-selective and the domaingeneral MD networks, identified with robust individual-level fMRI localizers, remain dissociated.
