About the personal-information flags. These are pattern matches, not confirmed disclosures, and they are tuned to over-report rather than miss something. Expect false positives:

  • Column names are matched against identifying words in English and other European languages (email, telefoonnummer, geboortedatum, …). A column called phone_number flags whether or not it holds one, and an empty or already-anonymised column flags on its name alone.
  • Values are matched against the shape of an identifier. An IP address pattern also matches a version string or a dotted numeric code; a card-number pattern requires both a real issuer prefix and a checksum, but a long numeric ID can still coincide.
  • Free text is flagged when a column holds long, mostly-distinct prose — the shape open-ended answers take. Most such columns contain no names at all.

A flag means look at this column. Where the data is already de-identified (an ip column reading Anonymized, a name column the authors emptied), no action is needed.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). 1. Introduction

In recent years, machine-learning classiers based on typing dynamics (keystroke dynamics) have been used for Parkinson's disease (PD) screening and have demonstrated promising discriminative performance [1, 5, 13, 15]. Publicly available datasets have facilitated the continued development and validation of related models over the past decade. The performance of existing machine-learning classiers based on typing dynamics for PD has been evaluated primarily in terms of discrimination, typically measured by the area under the receiver operating characteristic curve (AUC) [2, 12, 23]. However, when a model is transferred from its development dataset to a new dataset, distribution shift may arise from changes in input feature distributions, participant composition, data acquisition devices, task designs, and sources of diagnostic labels. Therefore, the evaluation of cross-dataset deployment needs to consider both model discrimination and the reliability of predictive uncertainty.

Conformal prediction (CP) provides a model-agnostic framework with growing clinical adoption [7, 9, 26] for quantifying predictive uncertainty [4]. It characterizes the reliability of uncertainty quantication by generating prediction sets and evaluating their coverage. When the calibration data and the target data satisfy exchangeability, split conformal prediction provides 20 a nite-sample guarantee for marginal coverage, with the true label being included in the prediction set with probability at least 1-α. However, crossdataset deployment may violate exchangeability [6], rendering the standard coverage guarantee inapplicable to the target data and potentially causing the empirical coverage to deviate from its nominal level. Changes in conformal coverage across publicly available PD typing datasets, and the relationship between coverage degradation and degradation in discrimination, have not yet been systematically investigated [20, 25] through cross-dataset audits.

AUC measures a model's ability to discriminate between classes, whereas conformal coverage measures the frequency with which prediction sets contain the true label. The two metrics have distinct statistical interpretations, and their changes are not necessarily coupled under distribution shift [18, 22]. This raises a direct empirical question: when PD typing classiers are deployed across datasets, do coverage degradation and discrimination degradation vary in tandem across dierent transfer directions? We hypothesize that coverage degradation and discrimination degradation exhibit dierent patterns of change under distribution shift and should therefore be treated as distinct dimensions of deployment reliability. If this hypothesis holds, external evaluation based solely on AUC cannot fully characterize changes in predictive reliability.

In this study, we conducted an audit of conformal coverage for PD typing classiers deployed across datasets, covering all 12 ordered transfer directions among four publicly available datasets. We compared AUC and marginal coverage across transfer directions to examine whether coverage degradation and discrimination degradation occurred in tandem and characterized class-specic coverage failure patterns through class-conditional coverage diagnostics. We then investigated the potential sources of coverage degradation using controlled stress tests and evaluated the amount of target-domain labeling required to restore coverage, as well as the associated costs in prediction set-eciency, under dierent calibration strategies.

2.1. Data sources

The data used in this study were obtained from four publicly available datasets: MIT-CSXPD (the neuroQWERTY project; PhysioNet, nqmitcsxpd v1.0.0 [13]), Tappy (PhysioNet, tappy v1.0.0 [1]), TyPD (i-PROGNOSIS 55 touchscreen typing data; Zenodo record 2571623 [14]), and Online English (OE; OSF repository ew34b [11]). These datasets are heterogeneous in terms of diagnostic information sources, typing platforms, devices, and task designs. MIT-CSXPD and TyPD provide clinical diagnostic labels, whereas Tappy and OE use self-reported diagnostic labels. The data collection settings span clinical environments, personal devices, and web-based platforms. The source publications report an accrual period only for Tappy (July 2016 to March 2017) [1]; MIT-CSXPD, TyPD, and OE do not report accrual dates.

2.2. Cohort construction and data cleaning

Digraphs (ordered pairs of consecutive keystrokes) were used as the basic units for feature construction. Data cleaning and ltering were performed without reference to participants' diagnostic labels, relying solely on the quality of the typing data. Digraphs were rst extracted from the raw keystroke records, retaining valid events that passed parsing and validation checks and had complete key-down and key-up timestamps. On this basis, uniform thresholds for key-hold duration and inter-keystroke interval were applied across all datasets to remove anomalous data, followed by additional taskspecic rules for the three datasets that used xed-text transcription tasks. Next, a continuous period of typing was dened as a session, and session segmentation criteria were established for each dataset. For the MIT clinical dataset, only sessions from each participant's rst visit were retained. Finally, all valid digraphs were aggregated for each participant, and participants with fewer than 300 digraphs were excluded. Detailed ltering rules, the number of samples excluded at each step, and the nal cohort composition are provided in Supplementary Tables S1 and S4. 80

2.3. Feature construction and prediction models

All features were aggregated at the participant level, with all valid digraphs from each participant used for feature calculation. Features were constructed at three levels of complexity: L1 calculated distributional statistics (mean, median, standard deviation, 10th percentile, and 90th percentile) for each of the three temporal measures, hold (key press duration), latency (time from the release of the previous keystroke to the press of the current keystroke), and ight (time interval between two consecutive keystrokes), yielding 15 features available across all datasets; L2 added mean features for left-and right-hand conditions to L1 and was supported only by MIT, Tappy, and OE; L3 aggregated mean latency and ight values according to hand transition types between adjacent digraphs and included the proportion of transitions between hands, with this level supported only by MIT and OE. For each transfer direction, the highest level supported by both the source and target datasets was used, and results stratied by feature level 95 were reported as sensitivity analyses.

The primary model was ℓ2-regularized logistic regression (feature standardization was performed only within the training set), the comparator model was LightGBM, a gradient boosting decision-tree framework [19], with a shallow-tree conguration (maximum depth of 3; minimum number of samples per leaf set to one-quarter of the training set), and the parameters were not adjusted thereafter. Both models were evaluated within the MIT source domain using internal splits with 50 random seeds, yielding mean test AUCs of 0.787 and 0.726, respectively. This evaluation did not involve target data; its results also served as the development-domain reference for ∆AUC.

2.4. Conformal prediction framework

Split conformal prediction (Split CP) was used as the coverage audit framework, with the Least Ambiguous Set-Valued Classier (LAC) score [4] as the nonconformity score, dened as one minus the model's predicted probability for the true label. The lower the predicted probability for the true 110 label, the higher the LAC score, indicating greater nonconformity between the true label and the prediction model.

The calibration set was sampled from the source cohort using classstratied sampling and accounted for 30% of the source cohort. The conformal threshold was calculated jointly using all scores in the calibration set, 115 targeting a marginal coverage of 1-α. In this study, α = 0.10, corresponding to a nominal coverage of 90%. The conformal threshold was set to the k-th smallest LAC score in the calibration set, where k = ⌈(n cal +1)(1-α)⌉ and n cal denotes the calibration set size. A candidate label was included in the prediction set if its LAC score did not exceed this threshold, and the prediction set consisted of all classes when k > n cal . The primary analysis used a single split corresponding to the rst of the 50 random seeds, and the mean results across the 50 seeds were used only for descriptive analysis. Class-conditional coverage was used as a diagnostic metric for failure modes. Under the exchangeability assumption, the theoretical guarantee of Split CP is marginal coverage of 1-α.

We evaluated three coverage recovery strategies to assess the feasibility and cost of restoring coverage. For target-domain recalibration, 5%, 10%, 20%, or 30% of labeled target-domain samples were selected using classstratied sampling to recalculate the threshold. Weighted conformal prediction (weighted CP) used density ratios between the target and source domains as calibration weights, estimated as the odds output of a logistic-regression domain classier trained on the source training samples and all target samples with class-balancing weights under an equal-domain prior. Following the weighted conformal prediction framework for covariate shift [16], the weights 135 5 were truncated at the pooled 99th percentile (p99), which forfeits the formal weighted marginal-coverage guarantee that holds without truncation. Protocol-conditional recalibration calculated calibration quantiles separately for each acquisition protocol, setting the target marginal coverage within each protocol group to 1-α, conditional on exchangeability holding within 140 each group.

2.5. Statistical analysis

All inferential analyses used the participant as the unit of analysis: each participant's session data and valid digraph events were aggregated beforehand, and each participant contributed one binary (0/1) observation to 145 target-domain coverage. The primary audit metric in this study was marginal coverage for each transfer direction, and inferential tests were conducted only for three primary transfer directions: Tappy→MIT, MIT→Tappy, and the pooled transfer direction from the clinical datasets (MIT+TyPD) to the selfreported datasets (Tappy+OE). The results for all 12 ordered transfer direc-150 tions among the four datasets formed a descriptive audit matrix. Marginal coverage in each primary direction was assessed using a one-sided binomial test, with the null hypothesis that the true coverage was ≥ 0.90 and a nominal signicance level of α = 0.10. The Holm correction was applied to control the family-wise error rate at 0.10 across this family of tests. The binomial tests evaluate coverage conditional on the xed training and calibration split; the 50-seed summaries are descriptive and do not support inference about split-averaged coverage, because the splits reuse the same participants.

Discrimination was measured using participant-level AUC, with the mean and standard deviation across 50 random seeds reported for each direction. 160 The development-domain reference was the mean AUC from the sourcedomain evaluation described above (0.787 and 0.726), and ∆AUC was dened as the dierence between each direction's mean AUC and this reference. This MIT-based benchmark was shared across all directions; ∆AUC therefore measures deviation from a xed development-domain reference rather 165 than the source-specic change in discrimination caused by transfer. The central hypothesis of this study was that coverage degradation and discrimination degradation exhibit dierent patterns of change under distribution shift. It was assessed descriptively at the direction level by jointly interpreting ∆AUC and the deviation of marginal coverage from the nominal level of 170 0.90 as continuous quantities; patterns consistent with the hypothesis were 6 those in which one dimension departed from its reference while the other did not.

The operational audit further compared unadjusted 95% ClopperPearson intervals with the 0.80 audit threshold, with the rules applied sequentially: directions with an upper condence bound below 0.90 were classied as Incompatible; otherwise, directions with a lower condence bound of at least 0.80 were classied as Compatible; all remaining directions were classied as Undetermined.

2.6. Recovery and stress-test analyses 180

The recovery-cost analysis evaluated target-domain recalibration (labeling budgets of 5/10/20/30%), weighted CP, and protocol-conditional recalibration, each against unmodied split CP, and reported the number of targetdomain labels, coverage, PD-conditional coverage (coverage among participants with PD), mean set size, singleton rate, and the full-label-set output rate (the proportion of participants receiving all labels; rejection rate). Costs were measured along two dimensions: the amount of target-domain labeling as information cost, and mean set size, singleton rate, and full-label-set output rate as prediction-set eciency costs. Recovery outcomes were assessed according to the audit thresholds and condence interval-based decision rules 190 described above.

4. Discussion

Discrimination and conformal coverage across four publicly available typing datasets and 12 ordered transfer directions showed asynchronous changes under distribution shift, and changes in one dimension could not be reliably inferred from the other. The comparator model further demonstrated the 330 same separation. LightGBM had lower AUC than logistic regression in all 12 directions, but higher marginal coverage in 11 of them. This nding was consistent with the central hypothesis, indicating that coverage degradation and discrimination degradation constitute two separable dimensions of deployment reliability, and that external validation based on AUC alone is insucient to characterize deployment reliability [25].

This decoupling reects the dierent properties [17] measured by the two metrics. AUC measures pairwise ranking quality; conformal coverage depends on the calibration-score distribution and on exchangeability between calibration and target data. Distribution shift may simultaneously alter class separability, model condence, the distribution of calibration scores, and class composition, but these changes do not necessarily have consistent eects on ranking performance and prediction set validity.

Marginal coverage provides an overall frequency guarantee but does not guarantee coverage separately for each class. Even when marginal coverage 345 passes the audit, it is still necessary to determine which class is aected by the failure. Tappy→MIT is the clearest example. The class aected by undercoverage also diered across the three target cohorts, with undercoverage occurring in the HC class in the two target cohorts with PD proportions of 77% and 59%. In Tappy→MIT, where the two classes were nearly balanced, 350 11 undercoverage occurred on the PD side. Thus, marginal coverage can detect a decline in overall validity but cannot identify its class-specic structure [4], making class-conditional coverage a necessary complementary diagnostic for deployment audits.

The stress tests indicate what the candidate mechanisms can and cannot explain. Label noise can produce one-sided, direction-dependent classconditional collapse, yet the collapse side in the actual Tappy→MIT transfer (the PD side) diers from what calibration-side HC→PD ipping produces, and none of the three manipulation scenarios reproduced the observed pattern within the practical-equivalence tolerances. BBSE approximately recovered the target prevalence in constructed label-shift scenarios but not in Tappy→MIT; the estimates did not support pure label shift as the dominant explanation for the most severe failure.

Coverage recovery showed that dierent transfer directions required different calibration resources. Target-domain labeling was the most direct strategy: the label budget required to reach the audit threshold varied across directions, and Tappy→MIT did not reach it even at the 30% budget, with the PD conditional coverage decit persisting. The eectiveness of targetdomain recalibration is therefore direction-specic, and no xed labeling budget applies across sites [10]. Weighted CP [16] restored coverage without target-domain labels but returned the full label set (Figure 4b, c). Protocolconditional calibration did not clear the audit threshold [21]. Coverage recovery is therefore not simply a matter of success or failure, but involves trade-os among coverage validity, access to target-domain information, and prediction-set eciency.

These results indicate that cross-dataset deployment audits cannot be conducted using a single performance metric [20, 25]. AUC can reveal whether discrimination is maintained, marginal coverage can assess overall validity, class-conditional and subgroup coverage can identify failure patterns, and recovery experiments can quantify the target-domain information required to achieve the target coverage and the associated eciency costs.

This study has several limitations. The stress tests examined whether candidate mechanisms could reproduce the observed patterns under controlled conditions, but they cannot establish that these mechanisms caused the patterns in the data; comparisons across transfer directions remain observational. The primary analyses relied on a single calibration split, with the results across 50 random seeds reported only descriptively. For MIT→Tappy, the upper condence bound was 0.899, close to the nominal coverage level of 0.90, so the audit classication for this direction may be sensitive to the calibration split. ∆AUC was computed against the MIT development-domain benchmark for each model; for directions from other source datasets, deviations partly reect source-domain model dierences rather than transfer eects alone. Target-domain recalibration samples were drawn with classstratied sampling; in prospective deployment, labels would be obtained for randomly selected participants rather than class-balanced samples, so the re-395 ported label budgets characterize this design rather than a deployable minimum. Sex-stratied analyses were possible only for transfer directions whose target cohorts included Tappy participants, because MIT and OE do not provide demographic data. The four datasets also diered in diagnostic label source (clinical diagnosis or self-report) and data-collection platform, both 400 of which are part of the deployment heterogeneity examined here. The extent to which the ndings apply to other typing modalities or populations [8] remains to be evaluated. The study used research-grade classiers on public datasets and did not assess their validity or utility for clinical screening.

Future studies should extend the audit to other typing modalities and col-405 lection settings and prospectively assess whether coverage-aware deployment reporting informs model selection and monitoring decisions.

5. Conclusion

The audit across four publicly available typing datasets showed that AUC and conformal coverage changed asynchronously during cross-dataset trans-410 fer. Class-conditional coverage further revealed class-asymmetric failures that were not fully captured by marginal coverage, and the aected class varied across target cohorts. The eectiveness of coverage recovery varied by transfer direction and recovery strategy, involving trade-os between targetdomain information requirements and prediction-set eciency. Therefore, 415 deployment evaluation should report marginal and class-conditional coverage by target cohort in addition to AUC and take into account the resources required for coverage recovery and associated prediction-set eciency. ests or personal relationships that could have appeared to inuence the work reported in this paper.
