To fix Exact P-Values

What we found

We found 3 imprecise p values out of 32 detected p values.

Show details

Reporting p values imprecisely (e.g., p < .05) reduces transparency, reproducibility, and re-use (e.g., in p value meta-analyses). Best practice is to report exact p-values with three decimal places (e.g., p = .032) unless p values are smaller than 0.001, in which case you can use p < .001.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (e.g., “decreased at the p < .05 significance threshold”).

The APA manual states: Report exact p values (e.g., p = .031) to two or three decimal places. However, report p values less than .001 as p < .001. However, 2 decimals is too imprecise for many use-cases (e.g., a p value meta-analysis), so report p values with three digits.

To check Non-Significant P Value Check

What we found

We found 15 non-significant p values that should be checked for appropriate interpretation.

Show details

Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Column extraction requires files to be readable from disk. Files fetched by repo_check from OSF/GitHub/etc. without a local copy (file_location is NA) are classified but not column-extracted; pass local_path to point at a downloaded copy of the repository.

For a paper whose repository is on Dryad, this means column extraction never happens unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (dataset listing and metadata do not need one). Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

Every downloaded text file the authors wrote (code, settings, survey definitions such as Qualtrics .qsf files, documentation, outputs) is searched for keys: API keys, access tokens and private keys, which let anyone who downloads the file use a paid service at the authors’ cost. Of a tabular data file only the column names and first 3 rows of the table as read are searched: its values come from participants, but a key the authors set for a whole survey (as embedded data in a Qualtrics survey flow) is exported in every response. The search uses the rules of the secret scanner betterleaks (https://github.com/betterleaks/betterleaks, MIT licence) of high and medium confidence. A key found turns the traffic light red; the report and the keys table give its file, line and type, and only its beginning. Other files over 25 MB and binary files are not searched. A key is never tested with its provider. Every module’s result has any whole key replaced by “keyremoved” (see module_run()).

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Abstract

Freezing of gait (FoG) is among the most disabling symptoms of Parkinson's disease (PD) and is associated with balance impairment and increased falls risk, yet remains challenging to understand due to its episodic and context-dependent nature. Altered supplementary motor area (SMA) function at rest and before self-initiated movements has been implicated in FoG; however, whether this extends to functionally relevant balance behavior is unknown. A loss of balance in response to support surface translations during standing elicits a perturbation-evoked N1 potential, an error assessment signal linked to SMA activity. We therefore predicted that people with FoG would have smaller and later N1 responses than people with PD without FoG and older adults. We recorded electroencephalography (EEG) during backward support-surface translations in 29 people with PD (71 ± 7 years), including 13 people with a history of FoG (FoG+) and 16 people without FoG (FoG-), and 26 older adults (OA; 67 ± 6 years). N1 amplitude and latency were quantified at a central midline electrode and defined as the largest negative peak 100-300 ms post-perturbation. N1 responses were similar between OA and FoG-(∆ = 4.0 µV and 2.8 ms, respectively). In contrast, FoG+ had smaller N1 amplitudes than FoG-(∆ = 18.1 µV, p = 0.001) and OA (∆ = 14.1 µV, p = 0.003), and both differences persisted after adjusting for age.

FoG+ also had later N1 latencies than OA (∆ = 26.5 ms, p = 0.029), with a similar but non-significant difference versus FoG-(∆ = 23.6 ms, p = 0.091); after adjusting for age, these latency differences were not retained.

These findings suggest that perturbation-evoked cortical activity is altered in FoG, potentially reflecting altered SMA function, and may provide a functionally relevant marker of FoG susceptibility.

1. INTRODUCTION

Freezing of gait (FoG) is one of the most disabling features of Parkinson's disease (PD) and is associated with increased fall risk (Okuma et al., 2018; Perez-Lloret et al., 2014), yet how neural processes for mobility differ in individuals with and without FoG remains poorly understood. FoG can occur across disease stages and becomes increasingly prevalent with disease progression, affecting up to 80% of people with PD in advanced stages (Gilat et al., 2026; Gülke and Lewis, 2026). Although FoG manifests episodically, susceptibility to freezing may also reflect differences in neural processes that are evident even outside overt freezing episodes. For instance, even outside of freezing episodes, individuals with FoG exhibit poorer gait (Barbe et al., 2014; Glover et al., 2020), balance (Bekkers et al., 2017), and cognitive function (Monaghan et al., 2023) than those without a history of freezing, although the extent of these impairments varies across individuals. Identifying objective physiological markers of FoG susceptibility could improve our mechanistic understanding and inform the development of targeted assessments and interventions.

Dysfunction across widespread cortical and subcortical networks has been implicated in FoG, with many studies implicating the supplementary motor area (SMA) as an important node within these networks.

The SMA is extensively connected with cortical and subcortical regions and contributes to internally generated movement, motor preparation, task switching, response inhibition, and balance control (de Lima-Pardini et al., 2020; Jacobs et al., 2009; Nachev et al., 2008; Rahimpour et al., 2022). Resting-state fMRI (Mi et al., 2017) and task-based fMRI using motor imagery (Peterson et al., 2014) or virtual-reality paradigms (Ehgoetz Martens et al., 2018; Gilat et al., 2018 Gilat et al., , 2015;; Matar et al., 2019) have demonstrated altered SMA activity and functional connectivity with basal ganglia, premotor, and brainstem locomotor regions in people with FoG compared with those without FoG. However, the functional relevance of this network dysfunction remains unclear since fMRI is conducted in a supine, stationary scanner environment that does not challenge balance or pose a threat of falling. Functional near-infrared spectroscopy (fNIRS) has enabled measurement of cortical activity during actual locomotion, revealing altered recruitment of SMA and other frontal motor regions during FoG-provoking tasks such as turning and doorway passage, even in the absence of overt freezing episodes (Cockx et al., 2024). However, because hemodynamic signals are inherently slow, a limitation of both fMRI and fNIRS, the time course of altered SMA activity in balance and gait in people with FoG is unclear.

Standing balance perturbations elicit a prominent cortical negative potential (N1) measured by electroencephalography (EEG), with source-localization studies implicating the SMA as a primary contributor (Marlin et al., 2014; Mirdamadi et al., 2024; Protzak et al., 2026). The N1 is thought to reflect a balance error signal shaped by bottom-up and top-down factors (Payne et al., 2019; Purohit and Bhatt, 2022; Varghese et al., 2017). For example, N1 amplitudes scale with perturbation acceleration (Payne et al., 2019) and are modulated by perturbation predictability, attention, and postural threat (Adkin et al., 2008; Mochizuki et al., 2008; Quant et al., 2004). Perturbation-evoked N1 responses also demonstrate excellent within-individual reliability for at least one year in older adults (Mirdamadi et al., 2025), supporting its potential clinical utility as a biomarker in PD. In older adults, larger N1 responses correlate with poorer cognitive set-shifting (Payne et al., 2021), suggesting that individual differences in the N1 may relate to the ability to flexibly adapt balance responses to changing task demands. Cognitive set-shifting is also impaired in people with FoG (Monaghan et al., 2023), providing a potential link between N1-related cortical processing and freezing susceptibility.

Although our prior work found similar N1 responses between older adults and people with PD (Payne et al., 2022), whether N1 responses differ by freezing status remains unknown. Given the prominent contribution of SMA activity to the perturbation-evoked N1 (Protzak et al., 2026), the N1 may provide a physiologically relevant measure of altered cortical engagement during balance control in individuals with FoG, even in the absence of an overt freezing episode. Conceptual models propose that FoG arises when motor, cognitive, and limbic deficits accumulate or interfere with one another, limiting the ability to adapt ongoing movement to changes in context (Nieuwboer and Giladi, 2013). If FoG reflects a reduced capacity of SMA-implicated networks to process and respond to such changes, then people with FoG may exhibit altered perturbationevoked cortical responses during balance control.

Here, we measured perturbation-evoked N1 responses using EEG during standing support-surface translations in people with PD with FoG (FoG+), people with PD without FoG (FoG-), and older adults. We predicted that FoG+ would have smaller N1 amplitudes than FoG-and older adults, reflecting reduced SMA engagement, and later N1 latencies, consistent with delayed N1 responses in populations with impaired balance (Duckrow, 1999; Palmer et al., 2025). As exploratory analyses, we examined whether N1 amplitude and latency were associated with freezing severity and other clinical characteristics relevant to FoG.

2. METHODS

>METHODS

2.1 Participants

The study included 29 people with PD (8 female, 70.8 ± 7.0 years old) and 26 older adults (OA; 14 female, 66.6 ± 6.5 years old). People with PD were eligible if they had a clinical diagnosis of PD, were taking dopaminergic medications, and were in Hoehn & Yahr Stage II-III. All participants with PD were Hoehn & Yahr Stage II, except for two participants who were Stage III (one FoG+, one FoG-). All participants were required to be 50-85 years of age, have no neurological conditions other than PD, have sufficient cognitive capacity to provide informed consent, be able to walk 10 m, and be able to stand for 10 minutes. The experimental protocol was approved by the Emory University Institutional Review Board, and all participants provided written informed consent. Data from a subset of OA (n = 14) were included in a previous study addressing different research questions (Mirdamadi et al., 2025).

2.2 Experimental Design

The present study included data from a single testing session in which people with PD were tested in the practically defined "OFF" state (>12 hours after dopaminergic medication intake) (McKay et al., 2019), except for two participants for whom data from the ON-medication session were used: one participant with FoG who was unable to tolerate OFF-medication testing and one participant without FoG who did not complete the OFF-medication session. These procedures were part of a larger project in which participants completed two sessions that differed in medication state ("OFF" and "ON" their typical dopaminergic medications), separated by approximately one week, with session order counterbalanced across participants; data from the ONmedication sessions will be reported separately. The present analyses were restricted to the OFF state, where available, to minimize the acute effects of dopaminergic medication and variability associated with medication dose and timing.

2.3 Freezing of Gait Assessment

FoG status was determined from clinical documentation and self-report. All participants with PD completed the New Freezing of Gait Questionnaire (NFOG-Q) (Nieuwboer et al., 2009) and item 3.11 of the MDS-UPDRS-III (Goetz et al., 2008). Participants also performed two consecutive 360° turns, one in each direction, to attempt to provoke FoG during the laboratory assessment. Participants were categorized as FoG+ (n = 13) if FoG was documented in their clinical record or self-reported on the NFOG-Q (total score > 0); all other participants with PD were classified as FoG-(n = 16). The NFOG-Q total score was used as a continuous measure of FoG severity in exploratory correlation analyses.

2.4 Clinical assessments and questionnaires

Clinical assessments were performed in the OFF-medication state, except for the Montreal Cognitive Assessment (MoCA) (Nasreddine et al., 2005), which was assessed in the ON-medication state and used as a measure of global cognitive function. Balance was assessed using the Mini-Balance Evaluation Systems Test (Mini-BESTest) (Leddy et al., 2011), and motor symptom severity was assessed using the MDS-UPDRS-III (Goetz et al., 2008). The MDS-UPDRS-III was video-recorded and scored offline by a neurologist, with the exception of rigidity, which was scored at the time of assessment. et al., 2009). Balance confidence and anxiety, additional clinical characteristics relevant to FoG, were assessed using the Activities-specific Balance Confidence (ABC) Scale (Powell and Myers, 1995) and Beck Anxiety Inventory (BAI) (Beck et al., 1988), respectively.

2.5 Standing balance perturbations

Participants underwent a series of standing balance perturbations while EEG was continuously recorded (Section 2.6). Participants stood barefoot with their feet approximately hip-width apart and wore an overhead safety harness. Before testing, participants completed a familiarization block of backward perturbations to ensure that they could recover balance without taking a step.

Participants then underwent approximately 45 pairs of backward support-surface translation perturbations (7.5 cm, 15 cm/s, 0.01 m/s 2 ) with their eyes closed. After each pair, participants verbally reported whether the second perturbation was in the same or a different direction from the first. In each pair, the first perturbation was directed directly backward and occurred at an unpredictable time. The second perturbation occurred 4 s later and was directed posterolateral to the left or right. Following the participant's response, the platform returned to its initial position without lateral displacement to avoid providing additional directional information. Intertrial intervals ranged from approximately 10 to 60 s. Seated rest breaks were taken every 15 trials or sooner if requested. Additional details of the paradigm have been reported previously (Bong et al., 2020; Mirdamadi et al., 2025 Mirdamadi et al., , 2024)). Because the angle and direction of the second perturbation varied across trials and participants based on perceptual responses, only responses to the first perturbation were included in the present analyses.

2.6 EEG Recording and Preprocessing

EEG was continuously recording during standing balance perturbations (sampling frequency 1000Hz, impedance <25kOhm) using a 64-channel active electrode cap (actiCAP) and ActiCHamp amplifier with a 24bit A/D converter and an online 20 kHz anti-aliasing low-pass filter (Brain Products, GmbH). Fz was the online reference electrode and Fpz was the ground electrode.

EEG preprocessing involved a modified version of the BeMoBIL pipeline (Klug et al., 2022) that incorporates removal of line noise (Klug and Kloosterman, 2022), removal and interpolation of bad channels, reconstruction of the online Fz reference after average re-referencing, high-pass filter with a cutoff of 1.5 Hz, and adaptive mixture component analysis algorithm (AMICA) (Palmer et al., 2008). Modifications to the original pipeline were similar to that described in our prior manuscripts involving independent component (IC) selection that used multiple approaches to distinguish brain from non-brain ICs (Mirdamadi et al., 2025; Protzak et al., 2026). We rejected ICs that were identified by ICLabel (Pion-Tonachini et al., 2019) as "eye", "heart", or "channel noise", ICs with a residual variance > 0.15, ICs in which the linear slope of the power spectrum between 2-40 Hz was >0, and any additional ICs labeled as "bad channels" using the TESA toolbox (Rogasch et al., 2017). The remaining ICs were visually inspected based on their dipole location, scalp map, power spectrum, and power-power coupling from the Powpowcat toolbox (Thammasan and Miyakoshi, 2020) and removed if applicable. The final IC solution was projected to the continuous, unfiltered dataset (but otherwise preprocessed), since high-pass filters >1 Hz used to improve the AMICA decomposition can distort the signal (de Cheveigné and Nelken, 2019; Tanner et al., 2015). Channel-level data were high pass filtered with a cutoff of 0.5 Hz, low pass filtered with a cutoff of 25 Hz, re-referenced to the mastoids, epoched -2 to 2 seconds around each perturbation, and baseline removal -150 to -50 milliseconds.

2.7 N1 Data Analysis

For each participant, the channel-based time series data were averaged across single-trial epochs for the first perturbation of each pair. The N1 response was defined as the largest negative response between 100-300 msec post-perturbation based on prior work demonstrating delays in the evoked response in older adults (Duckrow, 1999; Mirdamadi et al., 2025; Palmer et al., 2025). If more than one local minimum was identified, we chose the most negative local minimum. If no local minimum was identified, we chose the most negative value. We quantified the N1 from 3 central midline electrodes (FCz, Cz, CPz) to account for individual differences and selected the electrode that generated the largest peak response for further analysis (Protzak et al., 2026).

2.8 Statistical Analyses

Age was compared between OA, FoG+, and FoG-using a one-way ANOVA; where significant, posthoc pairwise comparisons were computed with Tukey correction. Sex was compared using Fisher's exact test, with Cohen's h as the effect size for the difference in proportions. For PD-specific variables (disease duration, UPDRS-III, MoCA, Mini-BESTest, ABC Scale, TMT B-A, and Beck Anxiety), Welch's independent samples ttests were used to compare FoG+ and FoG-only.

To test whether perturbation-evoked cortical responses differed across groups, separate one-way ANOVAs were conducted for N1 amplitude and latency, with Group (FoG+, FoG-, OA) as the betweensubjects factor. Three pairwise comparisons were specified a priori (FoG+ vs. FoG-, FoG-vs. OA, and FoG+ vs. OA), with Tukey adjustment for multiple comparisons. Effect sizes are reported as partial eta-squared for omnibus tests and Cohen's d for pairwise comparisons.

Exploratory Spearman rank correlations were used to examine associations between N1 amplitude and latency and clinical measures, given the small within-group samples and the positively skewed distribution of N1 amplitude within FoG+. Within FoG+, we examined associations with freezing severity (NFOG-Q), including Pearson partial correlations adjusting for age. Associations with Mini-BESTest, MoCA, TMT B-A, UPDRS-III, ABC Scale, and Beck Anxiety Inventory scores were examined separately within FoG+ and FoG-.

As post hoc covariate analyses, N1 group comparisons were repeated with age as a covariate and, within the PD sample, with age and disease duration as covariates. Covariate-adjusted models are reported in the Supplementary Results (Table S1). Statistical significance was set at alpha < 0.05.

4. DISCUSSION

Here, we observed differences in perturbation-evoked cortical activity between people with PD with and without FoG during a functionally relevant balance task. Although the reactive balance task did not elicit overt freezing episodes, people with FoG demonstrated smaller N1 amplitudes and tended to have later N1 latencies than both people without FoG and older adults, with amplitude differences persisting after adjusting for age. In contrast, people with PD without FoG showed N1 responses similar to older adults, suggesting that altered cortical activity in PD may be more closely associated with FoG status than with PD diagnosis alone, and highlight the value of considering FoG status when examining cortical activity in PD. Importantly, these differences were evident even in the absence of a freezing episode, suggesting that perturbation-evoked cortical activity may capture neurophysiological differences associated with susceptibility to FoG.

FoG-related alterations in cortical activity may extend beyond voluntary movement to processes involved in responding to unexpected balance disturbances. Reduced cortical potentials associated with motor preparation have been observed in people with FoG compared to older adults during voluntary lower-limb movement and gait initiation (Karimi et al., 2021; Marquez et al., 2023). During balance perturbations, people with PD demonstrate altered preparatory cortical activity (Smith et al., 2012) but similar perturbation-evoked cortical potentials compared to older adults (Payne et al., 2022). However, neither study considered FoG status. Our findings extend prior work by identifying smaller N1 responses following unexpected balance disturbances in people with FoG, which may reflect altered cortical processes involved in rapidly evaluating and responding to unexpected balance disturbances. Consistent with this interpretation, both perturbationevoked N1 responses and midfrontal theta activity (3-7 Hz), a marker of action monitoring (Luu et al., 2000), increase following a loss of balance, scaling with both the magnitude of the perturbation and need for corrective motor responses (Solis-Escalante et al., 2021). Importantly, midfrontal theta activity is reduced in people with FoG compared to those without FoG at rest and during lower-limb pedaling (Bosch et al., 2022; Singh et al., 2020), and reduced in people with PD with postural instability (Bosch et al., 2021), which frequently co-occurs with FoG (Bekkers et al., 2017). Together with smaller perturbation-evoked N1 potentials observed here, these findings suggest that people with FoG may have altered cortical processes associated with action monitoring that limits the ability to evaluate and response to balance perturbations.

Our findings support the hypothesis that FoG is associated with altered SMA and broader motornetwork function, even without overt freezing episodes. In neurotypical adults, source localization analyses indicate that the perturbation-evoked balance N1 is dominated by a central midline cortical source encompassing the SMA (Protzak et al., 2026). Although source localization is beyond the scope of the present study, our findings of altered perturbation-evoked cortical activity in people with freezing are consistent with neuroimaging evidence implicating altered SMA activity and connectivity in FoG. Altered connectivity between the SMA and cortical and subcortical locomotor regions further suggests that FoG reflects dysfunction of a distributed motor network rather than the SMA in isolation (Bardakan et al., 2022; Fling et al., 2014; Song et al., 2021). One potentially relevant circuit is the hyperdirect pathway, through which the SMA and other frontal regions project directly to the subthalamic nucleus (STN) to rapidly modify or suppress motor output (Nambu et al., 2002). Altered cortical-STN signaling and recruitment of stopping-related circuitry have been implicated in FoG, particularly during challenging gait conditions such as turning and doorway passage (Cockx et al., 2024; Gilat et al., 2015; Matar et al., 2019). Thus, smaller N1 responses in FoG+ may reflect broader SMA-centered network dysfunction rather than isolated SMA dysfunction. Future studies combining EEG source localization with measures of cortical-subcortical connectivity could clarify the neural circuits underlying these altered responses.

Later perturbation-evoked N1 latencies may reflect slower cortical processing of balance-related information. This interpretation is consistent with the broader ERP literature, in which longer component latencies have been associated with slower stimulus evaluation and information processing (Pinal et al., 2015a; Terrasa et al., 2018), whereas ERP amplitude can reflect the magnitude of neural resource allocation or engagement during stimulus processing (Pinal et al., 2015b; Sachs et al., 2004). However, the latency differences observed here should be interpreted cautiously. Although N1 latency was later in FoG+ than in older adults, the difference between FoG+ and FoG-did not reach statistical significance. Moreover, group differences in N1 latency were attenuated after adjusting for age, which was itself a significant predictor of latency, and the FoG+ group was older than OA. Thus, later N1 responses may reflect age-related slowing of cortical processing rather than a FoG-specific alteration. Interpretation of N1 latency is further complicated because many individuals in the FoG+ group had atypical perturbation-evoked morphologies, with multiple small deflections often present within the N1 time window (100-300 ms post-perturbation) rather than a single well-defined peak. Thus, it is unclear whether latency estimates in FoG+ reflect true differences in response timing or are influenced by differences in overall waveform morphology.

Because people with FoG also demonstrated poorer balance, the smaller N1 responses observed in this group could reflect greater overall impairment rather than FoG status specifically. However, FoG+ and FoG-had similar disease duration, motor symptom severity, global cognition, and set-shifting. Prior work has associated N1 amplitude with individual differences in cognitive set-shifting and balance-related function in older adults (Payne et al., 2022). However, N1 amplitude was not associated with balance or set-shifting function within either PD group in the present study. One possible explanation is that the same perturbation magnitude represented different levels of balance challenge across individuals, which can influence cortical responses to perturbations (Kerr et al., 2026; Payne and Ting, 2020). Alternatively, N1 amplitude may capture only one of several neural processes contributing to individual differences in clinical function.

In contrast to the lack of association with clinical balance function, larger N1 amplitudes were associated with greater perceived balance confidence on the ABC Scale in people with FoG. This direction is opposite to that reported in neurotypical older adults, in whom larger N1 amplitudes were associated with lower balance confidence (Payne et al., 2022). This distinction may be clinically relevant because discordance between perceived and objective balance ability has been independently associated with fall history in people with PD, suggesting that perceived balance provides information not fully captured by performance-based measures (Longhurst et al., 2025a (Longhurst et al., , 2025b)). These findings suggest that the relationships between brain activity and clinical characteristics may differ by FoG status; however, given the small sample and exploratory nature of this analysis, these findings should be replicated before drawing mechanistic conclusions.

Despite group-level differences in N1 amplitude, individual variability suggests that perturbation-evoked cortical activity does not map simply onto binary FoG status. This variability is consistent with the clinical and pathophysiological heterogeneity of FoG and the episodic nature of its presentation. In this study, one individual in the FoG-group had an N1 amplitude more than 1.5 SD below the FoG-mean, within the range observed in FoG+, whereas one FoG+ participant had an N1 amplitude nearly 3 SD above the FoG+ mean, exceeding the FoG-mean. This variability may reflect heterogeneity in freezing phenotype (e.g., levodoparesponsive versus levodopa-unresponsive FoG), the presence or absence of postural instability, cognitive status, or diagnostic classification (Bekkers et al., 2017; McKay et al., 2019; Nonnekes et al., 2015). Larger and more diverse cohorts will be needed to determine whether perturbation-evoked cortical responses can distinguish established FoG from prodromal vulnerability to freezing, or whether they are better conceptualized as markers of a broader balance-cognitive phenotype associated with freezing risk.

Taken together, perturbation-evoked cortical activity may provide a sensitive and functionally relevant neurophysiological signal for identifying freezing-related balance dysfunction and warrants further study in larger cohorts. Given the N1 is elicited during a functionally relevant balance task that engages cognitive, affective, and sensorimotor processes, it may be capable of capturing distinct mechanisms recruited during freezing in real-world settings compared to stationary laboratory paradigms. This capability is particularly relevant given that freezing categorization varies with the measure used (Duysens and Smits-Engelsman, 2026), and subjective self-reports do not always align with episodes observed in the laboratory or clinic due to the transient and context-dependent nature of freezing (Gilat et al., 2026). Combined with the reliability and clinical feasibility of the balance N1 (Mirdamadi et al., 2025), this work lays the foundation for future studies to examine whether perturbation-evoked cortical activity can track disease progression, predict clinical outcomes, or change in response to therapeutic interventions.
