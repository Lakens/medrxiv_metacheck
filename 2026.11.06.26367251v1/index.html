Reporting p values imprecisely (e.g., p < .05) reduces transparency, reproducibility, and re-use (e.g., in p value meta-analyses). Best practice is to report exact p-values with three decimal places (e.g., p = .032) unless p values are smaller than 0.001, in which case you can use p < .001.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (e.g., “decreased at the p < .05 significance threshold”).

P-Value Text
P < .01 greater probability of large slow waves in the ON versus OFF condition (all P < .01) in the post-hoc comparisons (Table S1, S2).
P < .01 The presence of a slow wave was associated with a higher probability of a spike after a stimulus (OR = 1.23, 95% CI: 1.07, 1.43, P < .01).

The APA manual states: Report exact p values (e.g., p = .031) to two or three decimal places. However, report p values less than .001 as p < .001. However, 2 decimals is too imprecise for many use-cases (e.g., a p value meta-analysis), so report p values with three digits.

What we found

We found 2 non-significant p values that should be checked for appropriate interpretation.

Show details

Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

Metacheck does not yet analyze automatically whether sentences which include non-significant p-values are correct, but we recommend manually checking the sentences below for possible misinterpreted non-significant p values.

Text Sentence
P = .056 Slow-wave probability was lower in the ON condition before the stimulus and at 2 seconds after the stimulus at trend level (P = .056) (Figure 2, right side and table S7, S8).
p < 0.1 Significance stars refer to the outcome of post hoc estimated marginal means comparisons (Holmcorrected for multiple comparisons * p < 0.05, ** p < 0.01, and *** p < 0.001 (+ p < 0.1, for significance at trend level).

How Power Analysis Check works

This module uses regular expressions to identify sentences that contain a statistical power analysis. If specified by the user, it also uses a large language model (LLM) to extract information reported in power analyses, including the statistical test, sample size, alpha level, desired level of power, and magnitude and type of effect size.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. With the use of an LLM, it checks if the power analysis is reported with all required information.

The regular expressions can miss power analyses, or fail to classify them correctly. The type of power analysis is often difficult to classify, which can easily be solved by explicitly specifying the type of power analysis as ‘a-priori’, ‘sensitivity’, or ‘post-hoc’. Note that ‘post-hoc’ or ‘observed’ power is rarely useful. The LLM can fail to identify information in the paper, and will not have access to information in paragraphs in the paper other than those that contain the word ‘power’. How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Codebook Check works

This module checks whether the data columns in a repository are documented in a codebook or README. It locates codebook/readme files, extracts the variable definitions they contain, matches those definitions against the data columns extracted by data_check, and reports documentation coverage: how many data columns are documented, and which documented variables are never used.

The Codebook Check module consumes the columns and file classification produced by data_check (and, transitively, repo_check). Files classified as codebook or readme are parsed with parse_codebook(), which reads structured tables (CSV/TSV/Excel with a variable-name column and a label column), embedded labels in haven files (SPSS/Stata/SAS), and plain text from rich-text formats (docx/pdf/rtf/odt). Embedded haven labels from data files are also harvested directly.

Each data column is then matched against the parsed variable definitions with match_column_labels(), using normalised-name matching with experiment-group scoping, haven-label priority, and rule-based label-equivalence merging.

Beyond the variable label, the module harvests the DDI-style per-variable properties a source supplies: the value labels / code list (the 1=“Strongly disagree”…5=“Strongly agree” mapping — from SPSS/Stata value labels and from a codebook “values”/“coding” column), the missing-value scheme (which codes denote missingness, from haven declared missings and labels that read as “refused”/“n/a”), and question text and columns when present. These are carried onto the matched data columns and exported into the Psych-DS variableMeasured (as a schema.org code list plus namespaced metacheck: fields).

The module defaults to rules-only when llm_use(FALSE). When llm_use(TRUE), three optional LLM tiers run: parsing unstructured codebook text that the rules could not handle, fuzzy-matching still-unlabelled columns to still-unmatched codebook variables, and merging conflicting label definitions into a single canonical label.

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module will return suggestions to improve the code if there are no comments, if libraries/imports are loaded in lines further than 4 lines apart, if files that are loaded are not in the repository, if absolute file paths, setwd() or install.packages() are found, and if R code cannot be parsed.

The regular expressions can miss information in code files, or falsely detect parts of the code as a fixed file path. Libraries/imports might be loaded in one block, even if there are more than 3 intermittent lines. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. There might be valid reasons why some loaded files can’t be shared, but the module can’t evaluate these reasons, and always gives a warning.

How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Column extraction requires files to be readable from disk. Files fetched by repo_check from OSF/GitHub/etc. without a local copy (file_location is NA) are classified but not column-extracted; pass local_path to point at a downloaded copy of the repository.

For a paper whose repository is on Dryad, this means column extraction never happens unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (dataset listing and metadata do not need one). Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

Every downloaded text file the authors wrote (code, settings, survey definitions such as Qualtrics .qsf files, documentation, outputs) is searched for keys: API keys, access tokens and private keys, which let anyone who downloads the file use a paid service at the authors’ cost. Of a tabular data file only the column names and first 3 rows of the table as read are searched: its values come from participants, but a key the authors set for a whole survey (as embedded data in a Qualtrics survey flow) is exported in every response. How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Abstract

Interictal epileptiform discharges, so called spikes, are often strongly activated during non-rapid eye movement (NREM) sleep in childhood epilepsies. In children with pronounced spike activation during NREM-sleep, spike burden can be associated with lifelong impaired cognitive functions. This spike activation is also related to alterations in sleep oscillations, specifically slow waves and spindles, which play essential roles in brain maintenance and maturation. These observations suggest that spikes may disrupt sleep-dependent brain processes that are critical for the development of cognitive functions.

Phase-targeted auditory stimulation during NREM sleep delivers brief, non-arousing tones at specific phases of ongoing slow waves to modulate sleep oscillations. Recently, our group showed that isolated, less frequent, and thus less expected, tones engage widespread thalamocortical networks, whereas repetitive, regular trains of tones promote habituation and engage more local corticocortical networks. In this study, we use these contrasting stimulation patterns for a targeted modulation of sleep oscillations and examine their interaction with epileptic spikes.

In an initial exploratory study (N = 10; age range: 7.3-16.2 years), we used a within-night block design to directly compare responses to the different stimulation patterns. Isolated tones delivered at long interstimulus intervals induced a transient increase in spike rate, whereas down-phase stimulation delivered in trains at short, regular intervals was associated with a significant reduction. We subsequently optimized the train-based paradigm and evaluated stimulation delivered throughout the night in a proof-of-concept study using a counterbalanced, between-night design (N = 5; age range: 4.4-10.7 years). Spike density decreased locally in all patients, providing convergent evidence for the effects observed in the exploratory study.

With this mechanistically guided approach, we demonstrate that repetitive down-phase auditory stimulation of slow waves results in a local reduction of epileptic spikes. This framework may provide a rational basis for targeted interventions aimed at reducing spikes and related cognitive impairments.

Introduction

Interictal epileptiform discharges (IEDs) are often most pronounced during non-rapid eye movement (NREM) sleep. They commonly appear as spikes or sharp waves and are brief, hyper-synchronized bursts of cortical neuronal activity 1, 2 . A strong activation of IEDs during NREM sleep is a shared hallmark of wide spectrum of epilepsies where the most extreme form, the (developmental) and epileptic encephalopathies with spike-wave activation during sleep ((D)EE-SWAS) is defined by developmental regression and possible lifelong cognitive deficits 3 . In this paediatric population, spike burden has been related to memory impairments 4.

Physiological NREM sleep oscillations, specifically slow waves and spindles, are linked to sleep-related memory consolidation 5, 6 and brain development 7 . In SWAS epilepsy patients, it has been reported that spindle density is decreased and inversely correlated to spike density 8 and that the precise phase-coupling of slow waves and spindles, a marker related to memory consolidation, is altered by spike density 9 . Slow waves on the other hand have been reported to facilitate spikes, specifically in their ascending phase, both in adult focal epilepsies 10 and in EE-SWAS 11 . These findings suggest that cognition, spikes and sleep oscillations are closely related; however, the causality and directionality remain unclear.

Down-phase-targeted auditory stimulation (down-PTAS) during NREM sleep allows modulating sleep oscillations noninvasively 12 . It consists of playing short, non-arousing tones, phase-locked to the down-phase of ongoing slow waves. In healthy adults, our group recently showed that depending on the stimulation parameters, tones can influence sleep oscillations in two ways, either inducing them on the global level or suppressing them on a local level 13.

Isolated stimuli, which are likely processed as novel sensory events, evoke a K-complex (KC), a high-amplitude, rather global, thalamocortically generated slow wave, typically followed by a sleep spindle. In contrast, repetitive stimulation delivered during the down-phase of the slow wave, induces local desynchronization of cortical neuronal activity once the brain has habituated to the stimulus, resulting in a reduction of slow-wave activity 13, 14.

We and others have used PTAS in paediatric patients with SWAS with different stimulation paradigms [15] [16] [17] . These studies yielded somewhat contradictory results but overall showed a potential interaction between PTAS and epileptic spikes. Based on previous literature, it therefore remains unclear which stimulation approach could be most effective in reducing epileptic spikes. One study successfully reduced epileptic spikes and proposed that isolated stimuli, by inducing K-complexes and associated sleep spindles, could reduce epileptic activity through a disruption or "hijacking" of the thalamocortical loop 16 . Alternatively, repetitive stimulation delivered during the slow-wave down-phase (down-PTAS), which is proposed to . locally desynchronize cortical activity, could counteract the hypersynchronous neuronal activity underlying epileptic spikes 2.

Here we aimed to differentiate between these two hypotheses and understand whether occupation of the thalamocortical loop or local cortical desynchronization leads to the reduction of epileptic spikes. To address this, we systematically assessed the effects of different interstimulus intervals (ISIs) and regularity of tones on epileptic spikes in paediatric patients with epilepsy. In an initial exploratory phase with a within-night block design, we found that repetitive down-PTAS with short ISI resulted in a local reduction of epileptic spikes. This effect was subsequently systematically tested in a two-night proof-of-concept study, in which application of whole night continuous stimulation led to a local reduction of spike activity compared to the Sham night. This confirmed that down-PTAS effectively reduces spikes locally, possibly through desynchronisation of cortical neuronal activity. Taken together, these findings demonstrate a mechanistically guided approach to effectively reduce epileptic spikes with PTAS.

Materials and methods

Patients and set-up

The study was approved by the local ethics committee (Kantonale Ethikkommission Zürich, KEK-ZH, BASEC 2019-02134) and was conducted in adherence to the principles outlined in the Declaration of Helsinki. Written informed consent was obtained from all patients or their guardians before their participation in the study. In this paper, we report data from two different experimental set-ups as outlined below (see also Figure 1).

For both cohorts, patients had to be between 4 and 17 years old and diagnosed with epilepsy, with the last EEG showing epileptiform discharges within 24 months prior to the recording. They were not eligible if they had an irregular sleep-wake rhythm, a hearing disorder or had travelled through 2 or more time zones in the prior month. Ongoing treatment with corticosteroids, immunosuppressants or vagus nerve stimulation, medication other than antiseizure medication and substance abuse were also exclusion criteria. Additionally for cohort B, patients with a high risk of seizures during the study night, a seizure frequency > 1/week, a seizure within 24 hours before the study night, convulsive status epilepticus since beginning of their current treatment and a history of seizure provoked by sleep deprivation were not considered eligible.

Exploration phase -cohort A

Eligible patients were approached during their clinical visit in the epilepsy monitoring unit by the research team, in accordance with their treating physician. 18 patients were recorded in the epilepsy monitoring unit of the Children's Hospital Zurich and the Swiss Epilepsy Centre between April 2024 and September 2025. Eight patients were excluded due to various technical problems. Ten patients were included in the final analysis (seven females, ages: 7 -16, see Table 1).

As part of their clinical visit, whole-night electroencephalographic (EEG) recording was performed. This was done with the Micromed Ambulatory System with 29-43 scalp electrodes, depending on clinical interest, placed according to the extended 10-20 system and sampled at . impedance was kept between 2 and 5 KΩ. In addition to this clinical diagnostic recording, we performed auditory stimulation during the night. The availability of 24/24-hour monitoring by trained staff made this an ideal setting to explore various stimulation parameters.

Proof of concept -cohort B Eligible patients were approached by their treating physician and interested patients were then contacted by the research team. Seven patients were recorded in the research sleep laboratory of the Children's Hospital Zurich between July 2024 and May 2026. One patient dropped out due to discomfort of the net and one was excluded due to technical issues. Five patients (two females, ages: 4 -10, see Table 1) were included in the final analysis.

Patients came to the sleep laboratory on two separate occasions for a whole-night EEG recording, one stimulation night (Stim) and one control night (Sham). To exclude potential carry-over effects, the two nights were at least seven days apart. Patients were asked to keep a regular sleep-wake cycle for three days before the recording. Adherence was checked on the evening of the recording through actimetry recordings and logs in a sleep diary. Sleep and wake time was based on their usual routine and kept the same for both recording nights. EEG was recorded using 128 channel high-density EEG (Net Amps 300 amplifier of the Geodesic EEG system (Electrical Geodesics, Inc.), Electrical Geodesics Sensor Net for long-term monitoring Hydrogel). EEG was sampled at 1000 Hz (analogue filter: 0.01-200 Hz) and referenced to the vertex (Cz). Electrooculogram (EOG) and submental electromyogram (EMG) were registered for visual sleep-stage scoring. After adjusting the net to the nasion, vertex, and mastoids, all electrodes were filled with an electrolyte gel. EEG electrode impedances were below 50 kΩ at the start of the recording and were re-checked in the morning.

Auditory stimulation

Auditory stimulation was performed with the TOSOO Axo device, which allowed stimulation at the patient's bedside with very minimal burden. For Cohort A, signals from an active channel, chosen to be over the epileptic focus, the respective contralateral mastoid as a reference, and the system's ground channel as ground were fed into the Axo device with a touch-proof splitter cable. For Cohort B, an additional electrode was placed in the area of the epileptic focus and signals from both earlobe channels were fed into the Axo device, the contralateral side being used as reference and the ipsilateral as ground. A phase-locked algorithm was then applied to detect slow waves in real time and trigger stimuli between the negative zero-crossing and the trough of the ongoing slow wave. If an arousal is detected, defined as an increase in beta power within the past second, stimulation is prevented.

For further information see 18 . In the ON/Stim condition, 50 ms bursts of pink noise are being played, whereas in the control (OFF/Sham) condition, stimuli are muted.

In Cohort A, stimulations were applied in an ON-OFF window design, with a length of one minute each. The minimal inter-stimulus interval (ISI) was two seconds. Because of the clinical setting, tones were delivered over headphones with a volume of ~50 dB.

In Cohort B, stimulation was applied continuously with a minimal ISI of 0.5 seconds. Tones were delivered with a volume of ~50 dB through speakers attached to the bed. During one of the nights, the 'Sham night', tones were muted. The order of the nights was random and balanced across patients.

Data processing

For cohort A, EEG data was exported to MATLAB, band-pass filtered between 0.5 and 40 Hz using digital filters (low-pass: passband edge 40.2 Hz, stopband 49.75 Hz, 60 dB attenuation; high-pass: passband edge 0.5 Hz, stopband 0.25 Hz, 30 dB attenuation), with passband ripple ≤0.02 and 0.05, respectively. The data was then downsampled to 128 Hz.

For cohort B, EEG data was exported to MATLAB and filtered using a zero-phase forwardbackward digital filter to remove DC offset. Then it was low-pass filtered at 30 Hz using the FIRfilt plugin in EEGLAB, subsequently downsampled to 128 Hz, then high-pass filtered at 0.5 Hz.

Sleep stages were visually scored using Scoring Hero 19 by a trained sleep expert for consecutive 30-s epochs according to standard criteria (American Academy of Sleep medicine (AASM)) 20 . Unclear epochs were re-evaluated with another sleep expert. After scoring, NREM sleep epochs were subjected to a semi-automatic artifact detection routine 21.

For all analyses, only artefact-free N2 and N3 epochs were considered. In cohort B channels with less than 90% artefact-free epochs were excluded. For topographical analyses channels below the ears were excluded and only N2 and N3 epochs which were artefact-free across all remaining channels were induced. Data was re-referenced to the linked mastoids. For one patient, signal of one mastoid had to be excluded due to bad signal quality. The data was therefore re-referenced to the linked earlobes instead.

.

Spike detection

All EEG analyses were done in MATLAB R2022a. For automatic spike detection we used a previously developed method 22 . With this method we were able to detect epileptic spikes for the whole night in all channels. In addition, to exclude potential detection biases of the algorithm, a trained technician, blinded to the condition, visually detected spikes for Cohort B in a bipolar montage in 10 second epochs. This was done for 10 min of NREM sleep in the first cycle. The segments for each patient were chosen to be comparable within the patient regarding number of stimulations and location within the night. To validate the findings of the automatic detection, the visual detection was done for a focus channel, chosen as the channel with the biggest automatically detected difference in spike density and closest to the detection electrode.

A spike-wave index (SWI) was then calculated by dividing the number of seconds affected by spike waves by the number of seconds analysed, multiplied by 100 23.

Spindle detection

We used an automatic spindle detector, developed by Kramer and colleagues 8 to detect spindles in EEG signal with epileptic spikes. Briefly, the spindle detector estimates a latent state (the probability of a spindle) using three features: the Fano factor (estimated for data FIR filtered between 3 and 25 Hz), normalized power in the spindle band (9-15 Hz) and normalized power in the theta band (4-8 Hz). The spindle detector estimates the probability of a spindle in 0.5 s intervals (0.4 s overlap). To be considered a spindle, the probability had to be over 0.95 and the duration of at least 0.5 s. Spindles that were less than 1 s apart were merged. A subset of the detected spindles was confirmed visually for each patient. Only spindles in artefact-free, NREM 2 and 3 epochs were considered for analysis. The spindle detector is available at https://github.com/Mark-Kramer/Spindle-Detector-Method.

Slow wave detection

Slow waves were detected using an existing algorithm 24 . Artefact-free NREM 2 and 3 sleep data was bandpass filtered (3 dB cut-offs: 0.5 Hz and 4 Hz; Chebyshev Type II IIR filter; filter order: 2, using filtfilt) and all peaks, troughs, and zero-crossings were identified. Slow waves were defined as the time between two negative zero-crossings, with a duration of 0.5 to 2 s. As we were mostly interested in high-amplitude KC-like waves, we only analysed the top 25% of slow waves of peak-to-trough amplitude in each channel and excluded the top 5% to account for potential artefacts.

.

EEG power calculation

For power calculations in cohort B, EEG data were re-referenced to the average signal across all retained channels. Power spectral density (PSD) was computed for each epoch using Welch's method, with 4-s Hanning windows, 50% overlap, and a frequency resolution of 0.25 Hz. For slow-wave activity, mean PSD was calculated across the 0.5-4 Hz frequency range, whereas spindle activity was quantified as mean PSD across the 9-14 Hz frequency range.

These epoch-wise values were then averaged across all included epochs, resulting in one mean band-specific PSD value per channel for each participant and condition.

Estimation of phase precision and definition of region of interest

We estimated the phase precision of the stimuli, like previously done by our group 14, 25 . Briefly, the pre-processed EEG data was filtered in the slow wave range (low-pass filtered at 4 Hz).

Phase values corresponding to the times of stimulation within artifact-free NREM (N2+N3) epochs were then extracted by applying the Hilbert function to the EEG data of each channel.

The extracted phase values were then clustered into one of twelve 30° bins, between the two negative zero crossings. The percentage of values falling within each specific phase bin was then calculated. Stimuli were considered in the down-phase of the slow wave when they occurred in bin 2-4, equalling the period before and around the slow wave trough.

We defined a region of interest (ROI) in cohort A for statistical comparisons across patients with different locations of the detection electrode. This was done to ensure that for each patient we analysed a region with enough stimuli in the down-phase of the slow wave and enough epileptic spikes. The ROI was therefore defined as the overlap of the channels with at least 50% of stimuli in the down phase of the slow wave and at least four spikes per minute. An example of this can be found in Supplementary Figure 1.

Statistical analysis

Statistical analyses for cohort A were done in RStudio 2026.01.2. To investigate the effect of stimuli on large-amplitude slow waves, spindles and spikes, we modelled their event probability after a stimulus (ON) compared to a muted stimulus (OFF). Generalized linear mixed-effects models (binomial logistic regression) were used to model binary event occurrence on single trial data as a function of condition (on or off stimulus), timepoint, and the interaction effects of the predictors. Participant was included as a random intercept with a random slope for condition. Because event rate was low, counts were binarized to indicate the presence versus absence of at least one event per observation window. Post hoc estimated marginal means comparisons were computed to quantify condition differences at each timepoint. All reported p-values of the post-hoc contrast tests are Holm-corrected for multiple comparisons.

Additionally, we performed a generalized linear mixed-effects model (binomial logistic regression) to predict binary spike occurrence based on slow wave occurrence, condition, and their interaction. Participant was included as a random intercept with a random slope for condition.

Due to the lower sample size in cohort B, for paired comparisons between the Stim and Sham conditions, difference scores were calculated for each participant (Stim -Sham). Effect size was quantified using Cohen's d, calculated as the mean paired difference divided by the standard deviation of the paired differences.

Results

Exploration phase -Cohort A

Recent work from our group showed that depending on regularity of the tones and the length of the ISI, auditory stimuli elicit different responses 13, 14 . More precisely, it was proposed that isolated (long ISI), therefore novel and surprising, stimuli are more likely to induce a KC followed by a spindle. Repetitive down-phase stimulation with shorter ISI, when the brain has habituated to the stimulus, induces a reduction of local slow wave activity, which might reflect a reduction of cortical neuronal synchronization. Based on these results we chose long stimulation windows (1 minute) and a medium ISI (at least 2 seconds) to ensure both types of stimulation in this cohort. Stimuli that had an ISI of at least 5 seconds to the previous stimulus were considered isolated stimuli. Stimuli with an ISI smaller than 3.5 seconds were considered part of a train. For analysis, the first five stimuli of a train were not considered, as the effect of the train stimulation emerges after the fifth stimulus 14 . We then post-hoc divided the stimuli of Cohort A into isolated stimuli (mean number of stimuli ± SD; ON 195 ± 114.9, OFF 209.9 ± 117.3) and trains of stimuli (ON 392.7 ± 343.4, OFF 393.9 ± 400.6), similarly to 13, 14 (see Supplementary Figure 2).

The comparison of spike density between ON and OFF windows showed no significant difference, therefore only the responses to the different types of stimuli are shown.

. Spikes, spindles, and slow waves were automatically detected across all channels using established algorithms (see methods for more details).

Stimulus-locked response of isolated stimuli

To investigate the stimulation effect of isolated stimuli on large-amplitude slow waves, spindles and spikes, we modelled their probability after a stimulus (ON), compared to a muted stimulus (OFF). The effect on spikes is based on counts the predefined ROI (see methods and supplementary figure 1), for spindles and slow waves it was based on averaged counts from channels Fz and Cz. The full outcome of the models can be found in the supplementary table 1-6.

As shown in Figure 2 (left part) isolated stimuli increase the probability of high amplitude slow waves. This effect was most pronounced within the first 1.5 seconds as indicated by significant.

greater probability of large slow waves in the ON versus OFF condition (all P < .01) in the post-hoc comparisons (Table S1, S2).

For spindle occurrence, post hoc comparisons showed a significantly greater spindle probability in the ON than the OFF condition at 1 second after isolated stimuli (P < .001), whereas spindle probability was lower in the ON condition during the first 500 ms and at 2 seconds after stimulation (all P < .001) (Figure 2B, and Table S3, S4).

Spike probability was increased in the ON compared to the OFF condition during the first second after an isolated stimulus (P < .001) (Figure 2B, Table S5, S6).

Since most of our patients show spike-wave complexes in their EEG we cannot fully exclude that the simultaneous stimulus-locked increase of both spikes and slow waves in cohort A is not driven by pathological spike-wave complexes. However, when excluding all slow waves that are preceded by a spike (Bölsterli Heinzle et al., 2014), to exclude spike-wave complexes, we observe the same pattern of evoked slow waves, but in reduced numbers (Supplementary Fig. 3).

As expected from previous literature and consistent with an auditory evoked KC response, the model showed an increase in the slow wave rate immediately after an isolated stimulus, followed by an increased spindle rate. In parallel, isolated stimuli were associated with a transient increase, rather than a reduction, in epileptic spike probability (Figure 2A, B).

Spike likelihood is modulated by slow wave presence

Since we observed a simultaneous increase of spike and slow wave rate time-locked to the stimulus (Figure 2A), we investigated whether the presence of an evoked slow wave modulates the probability of a spike. Previous literature interprets the stimulus-locked highamplitude slow wave as an evoked KC, equivalent to the auditory-evoked N550 component 13 . We therefore considered big KC-like slow waves to be evoked when they happened 200-800 ms after an isolated stimulus. We then modelled spike probability in the same time period based on slow wave occurrence and stimulation condition. The presence of a slow wave was associated with a higher probability of a spike after a stimulus (OR = 1.23, 95% CI: 1.07, 1.43, P < .01). A similar association was observed in the OFF condition, indicating that both evoked and spontaneous slow waves were associated with increased spike probability (Table S13,14).

Spikes preferentially occur before the slow wave trough Intracranial recordings have shown that spikes preferentially occur in the down going slope before the slow-wave trough, coinciding with maximal neuronal synchrony 10, 11 . To explore this in our data, we divided the evoked slow waves into eight bins. Consistent with these findings, our exploratory analysis showed that the majority of spikes (62.5%) occurred during the descending slope of slow waves (Supplementary Figure 4).

Stimulation in trains is associated with a reduction in spike probability

We then examined stimulus-locked responses after a train of stimuli. Slow waves, spindles and spikes were counted within the ROI (see methods and Supplementary Figure 1), as it was shown that the effects of repetitive auditory stimulation are most pronounced close to the detection electrode 14, 26 . The full outcome of the models can be found in Supplementary table 7-12.

For slow wave occurrence, post hoc comparisons indicated no significant difference at any timepoint. Slow-wave probability was lower in the ON condition before the stimulus and at 2 seconds after the stimulus at trend level (P = .056) (Figure 2, right side and table S7, S8).

Isolated stimuli and trains of stimuli elicit different responses

We observed a reduction of spindle likelihood before the stimulus for both stimulus types in cohort A. This is not visible if we only look at the first stimulus in each ON window, meaning that there was no other stimulus for at least one minute. We therefore interpret the reduction before the stimulus as the spindle refractory period 27 induced by spindles evoked by the previous stimulus.

Overall, these results point towards two distinct mechanisms of how isolated stimuli and stimuli in trains interact with the spikes (Figure 2). Isolated stimuli are likely to induce big KC-like slow waves that have been shown to increase spike-likelihood 10, 11 . Down-PTAS applied in trains on the other hand, reduce spikes locally, potentially through local cortical desynchronisation 26.

Proof of concept -Cohort B

Presumably due to the mixed effects of isolated stimuli and trains of stimuli, we did not see any effects when comparing spike rate between ON and OFF windows in cohort A. Additionally, the analysis of isolated and train stimuli separately revealed that train stimuli reduce spike rate significantly. In cohort B, we therefore used an optimized train stimulation protocol with the goal to reduce spike rate consistently.

. In this cohort, the auditory stimulation was applied continuously time-locked to the slow wave down-phase every time a slow wave was detected, meaning without ON/OFF windows and a shorter minimal ISI (0.5 seconds) allowing for longer trains of stimuli and less isolated stimuli (mean number of stimuli ± SD; all stimuli Sham: 3715.6 ± 1761.5, single stimuli Sham: 339.4 ± 206.6, all stimuli stim: 4253.6 ± 1447.6, single stimuli stim: 423.8 ± 264.9).

Spikes are reduced across the whole night

Manual spike count confirms the results

To put the results into clinical context, spikes were blindly marked by an expert manually. We then the spike wave index (SWI) in the respective focus channel (Supplementary figure 5). All five patients showed a reduction during the Stim night and spike rate was reduced during the Stim night compared with the Sham night overall (Sham: 53.60 ± 14.86%; STIM: 47.80 ± 14.45%, Cohen's d = 1.36). These results confirm that the reduction is also detectable using the clinically established manual spike count. Importantly, it also shows that the reduction cannot be attributed to a detection bias of the automatic spike detection.

Discussion

The exploratory phase of the project shows that auditory stimuli evoke different responses depending on their regularity and ISI. Specifically, isolated stimuli evoked the typically observed pattern of a global, high-amplitude KC-like slow wave followed by a spindle. This response was accompanied by a transient increase in spikes predominantly around the slow wave through (Fig 2. A-B, Supplementary figure 4). Repetitive regular stimulation targeting the down phase of slow waves on the other hand, decreases spike probability and, at trend level, spindle and slow wave probability after the stimulus (Fig 2. C-D). Applying these findings to the next phase, as a proof of concept we applied stimulation optimized for repetitive regular stimulation with short ISI for a whole night and compared the spike rate to a Sham night with muted stimuli. In all five patients we saw a clear reduction of spikes in their epileptic focus, most pronounced in the area where the slow wave phase was detected (chosen to be over the epileptic focus) (Fig 3). This method therefore offers the possibility for a non-invasive way to reduce epileptic spikes during sleep.

In the recently described dual-process model of auditory stimulation 13 , it was proposed that isolated, therefore novel, stimuli have a high likelihood of evoking a KC followed by a spindle.

In this context, the globally distributed N550 component of the KC has been interpreted as the electrophysiological signature of a highly synchronized cortical off-state resulting from a transient reduction on tonic thalamocortical excitation caused by sustained inhibitory activity of thalamic reticular nucleus neurons 28 . One previous study successfully reduced epileptic spikes with isolated stimuli and hypothesized that inducing K-complexes and associated sleep spindles, could reduce epileptic activity through a disruption or "hijacking" of the thalamocortical loop 16 . In our results however we see an increase in spike density after isolated stimuli. We therefore hypothesize that in patients with pronounced IEDs during NREM sleep, the highly synchronous neuronal states evoked by isolated stimuli might facilitate spike generation. In accordance with this hypothesis it has previously been shown in intracranial data across different epilepsy populations, in children and adults, that (high amplitude) slow waves increase spike likelihood 10 and that spikes couple to the ongoing slow wave in its down-phase 11 . In our data we show that the presence of a high-amplitude slow wave, both evoked and . spontaneous, significantly increases the likelihood of a spike. Moreover, consistent with previous studies, we show in an exploratory analysis that spikes occur most frequently during the transition from the up-phase to the down-phase of the slow wave, a period of maximal cortical synchrony during which neuronal populations collectively enter the cortical off-state 10 . Overall, our data strongly suggests that the typical evoked response from an isolated stimulus increases spike likelihood, likely through increased thalamocortical synchronisation.

In our data, in both cohorts, we observed that repetitive stimuli reduce epileptic spike likelihood significantly. In cohort A we observed a transient decrease after a stimulus, whereas in cohort B we observed this effect over a whole night. It has been proposed for decades that epileptic spikes can result from over-synchronous sleep oscillations 2, 4 . We therefore hypothesize that our stimulation reduces the synchrony of slow waves, and by that reduce the spike rate.

However, the topographical effect of the repetitive stimulation on slow waves (data not shown) is not as clear as the effect on spikes.

According to the dual-process model, repetitive downphase stimulation, once the brain has habituated to the stimulus, results in local reduction of slow waves, interpreted as local cortical desynchronisation. The locality of the effect may be explained by the spatial variability of slow-wave activity across the scalp, restricting the observable reduction to the cortical area where the tone is delivered during the slow-wave down-phase 13 . With the main goal to reduce the spikes, we chose the detection electrode based on the epileptic focus. Depending on the location, in some patients the local effects will thus not be in the area of maximal slow wave activity. This could mean that the magnitude of the induced effects is too small to detect reliably on the single subject level. In this data we therefore cannot conclude if the observed spike reduction is exclusively mediated by a reduction of slow wave activity, previously described in healthy populations 26 , or if there is an underlying mechanism directly interacting with the spikes. To answer this question definitively, recordings with simultaneous thalamic and cortical electrodes over the epileptic focus would be needed to directly observe the effect of the stimulation on spikes in the location of their generation.

In cohort A, isolated stimuli were followed by an increase in spindle likelihood, consistent with thalamus can suppress spindle generation over the following seconds, providing a potential mechanistic explanation for this relationship. Conversely, spikes have also been shown to evoke spindle activity 16 , and sigma power has been reported to positively correlate with spike activity [29] [30] [31] . Thus, whether the changes in spindle activity observed here contribute to, or result from, the modulation of spikes remains unclear. Importantly, our stimulation effects cannot be considered independently of slow waves, as stimuli were delivered during the slow-wave downphase and both stimulation paradigms interacted with slow-wave activity. Disentangling the contribution of spindles from that of slow waves will therefore require approaches that allow spindle activity to be modulated more selectively, such as spindle-targeted auditory stimulation 32 or temporal interference stimulation 33, 34 . Such approaches could help determine whether spindles play a causal role in the observed modulation of spike activity.

Both cohorts encompassed a range of diagnoses, including both focal and generalized epilepsies. If the mechanisms underlying spike generation and propagation differ between aetiologies, this heterogeneity complicates the interpretation of how stimulation interacts with epileptic activity. In particular, spikes may arise and propagate through cortical as well as thalamocortical networks 11, 35, 36 . If the stimulation in trains primarily disrupts cortical synchrony, one might therefore expect a stronger effect on cortically than on thalamocortically generated spikes. We attempted to separate cohort A based on aetiology, the interpretation however was severely limited by the small sample size. In our data we therefore cannot determine if the effects of stimulation extend beyond spike generation and also influence the propagation of epileptic activity. Disentangling these effects is further complicated by the fact that, based on scalp EEG, we cannot determine whether the slow waves during which stimulation was delivered are primarily cortical or thalamocortical in origin 37 . Thus, the observed effects could reflect modulation of cortical activity, thalamocortical interactions, or both. Larger samples allowing subgroup analyses based on diagnosis and aetiology, together with intracranial recordings, will be necessary to distinguish between these possibilities and to test the underlying mechanisms.

Our results come with certain limitations. While the location of the detection electrode in the epileptic focus area allows us to personalize the stimulation to each patient, it also makes group effects difficult to quantify and interpret. In addition, the sample size might be too small to detect subtle effects on a group level. As mentioned above, different aetiologies and scalp EEG does not allow for any mechanistic explanation of the observed stimulation effect. Finally, cognitive and clinical outcomes are missing to investigate whether the spike reduction has beneficiary effects on cognition and the overall epilepsy condition.

. Nevertheless, in this study we show that epileptic spikes can be effectively reduced with continuous down-phase auditory stimulation during sleep. In the exploratory phase of the study this effect was only visible in the time immediately after the stimulus. Applying this protocol to the whole night we see the reduction in all five patients. Overall, PTAS shows great potential as a non-invasive tool to reduce the burden of epileptic spikes in children. While our approach is mechanistically guided, we cannot exclude that different stimulation parameters would be equally effective. Therefore, more studies are needed to carefully assess the optimal stimulation parameters and the effect of the stimulation over a longer period of time. Especially in more severe forms of SWAS, such as (developmental) epileptic encephalopathy with SWAS ((D)EE-SWAS), future studies would need to assess PTAS in comparison to currently available treatment options and its effect on cognitive functions.
