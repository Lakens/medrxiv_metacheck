Reporting p values imprecisely (e.g., p < .05) reduces transparency, reproducibility, and re-use (e.g., in p value meta-analyses). Best practice is to report exact p-values with three decimal places (e.g., p = .032) unless p values are smaller than 0.001, in which case you can use p < .001.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (e.g., “decreased at the p < .05 significance threshold”).

What we found

We found 6 non-significant p values that should be checked for appropriate interpretation.

Show details

Meta-scientific research has shown nonsignificant p values are commonly misinterpreted. It is incorrect to infer that there is ‘no effect’, ‘no difference’, or that groups are ‘the same’ after p > 0.05.

It is possible that there is a true non-zero effect, but that the study did not detect it. Make sure your inference acknowledges that it is possible that there is a non-zero effect. It is correct to include the effect is ‘not significantly’ different, although this just restates that p > 0.05.

How Power Analysis Check works

This module uses regular expressions to identify sentences that contain a statistical power analysis. If specified by the user, it also uses a large language model (LLM) to extract information reported in power analyses, including the statistical test, sample size, alpha level, desired level of power, and magnitude and type of effect size.

The Power Analysis Check module uses regular expressions to identify sentences that contain a statistical power analysis. Without the use of an LLM, the module uses regular expressions to classify the power analysis as a-priori, sensitivity or post-hoc. With the use of an LLM, it checks if the power analysis is reported with all required information.

The regular expressions can miss power analyses, or fail to classify them correctly. The type of power analysis is often difficult to classify, which can easily be solved by explicitly specifying the type of power analysis as ‘a-priori’, ‘sensitivity’, or ‘post-hoc’. Note that ‘post-hoc’ or ‘observed’ power is rarely useful. The LLM can fail to identify information in the paper, and will not have access to information in paragraphs in the paper other than those that contain the word ‘power’. This package was validated by the Metacheck team on articles in Psychological Science.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.) or reported as exactly zero (e.g., p = .000).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold” or “legend”). Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

How Codebook Check works

This module checks whether the data columns in a repository are documented in a codebook or README. It locates codebook/readme files, extracts the variable definitions they contain, matches those definitions against the data columns extracted by data_check, and reports documentation coverage: how many data columns are documented, and which documented variables are never used.

The Codebook Check module consumes the columns and file classification produced by data_check (and, transitively, repo_check). How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Each script runs in an isolated subprocess so a crash cannot take down the R session; note this isolates crashes, not the filesystem or network. Installs (when install_missing = TRUE) and the throwaway run library never touch your main R library. Each script’s outcome is one of ran_ok, errored, timed_out, dependency_unavailable, not_parsed, run_by_source (an R script another script runs with source(), which is run only inside that script, since on its own it lacks the packages and objects the sourcing script sets up first), run_by_import (a Python file other files import, a module rather than a script, unless it has an if __name__ == "__main__": block), jags_model (a JAGS or BUGS model saved with an R extension, which another script reads) or not_r_content (a file that is not R at all, such as a JSON or HTML dump); these last two are not run and are not failures. python2 marks Python 2 code that was not run. With sandbox = "docker" such code runs with Python 2.7 (option metacheck.docker_image_py2; FALSE turns this off), which modifications records; it is never converted, since that can change results. defines_functions is a file that only defines functions, which is used, not run (table$used_by names the scripts that use it), and not_analysis is a file of software rather than of the analysis: a package’s code, tests, documentation or setup.py, a copy of a tool, a web application, a script a program wrote (table$not_analysis_why says which); neither is run or counted as a script. docker_failed means the container never started, which says nothing about the script, so it keeps the light from being green but does not make it red. needs_a_person is a script that stopped because it asks a person to choose a file or answer a question, or that starts an app, and needs_internet one that stopped because the network is off in a Docker run, or, with internet = TRUE, could not reach what it asked for; download_too_large is a script stopped for downloading more than the limits allow (see internet), and out_of_memory one that, or a program it started (such as a compiler), ran out of the memory each script may use. All four are treated the same way. not_downloaded is a script that stopped on a file the repository lists but that was not downloaded, such as one over max_file_size: it could not be tried, so it is not counted as a script that did not reproduce (summary_table$repro_not_downloaded_n counts them apart). not_read is a file metacheck could not read, so it was not run; the light is then not green, as the file may read and run on another computer, and table$error_message says why, naming a package that is installed but cannot be loaded on the computer that ran the check. empty is a file with nothing in it, which is not run or counted as a script. For a script that did not run through, table$error_message is its error, short (at most 300 characters): the error line of its output, which names a package that is not there, with the address it asked for when it needed the internet, or the time limit it reached; table$reason sorts it into a kind. A timeout means “still running at the cutoff”, not a failure, so raise timeout for legitimately long-running (e.g. Bayesian) scripts. dependency_unavailable means the script’s own package could not be installed from live CRAN, the CRAN Archive, or a named GitHub/URL source — an infrastructure limitation, not a defect in the paper’s code, so unlike errored/timed_out it does not force the traffic light red. The full stdout/stderr of every run is kept in the result’s run_results (the report shows it in per-script dropdowns, capped for readability). The traffic light reflects the STATIC readiness signals by default, but an execution error (errored/timed_out) does recolour it to red — a script that crashes on its own analysis is a genuine reproduction failure. A script that fails with could not find function is run once more with the library() calls the project’s other scripts make added at its top (or the one package that exports the function, or magrittr for %>%), and a script that then runs is reported as reproducible only after that repair.

Dependencies are reported name-only, with the source (CRAN, GitHub, or a base package already shipped with R) — static analysis of the code cannot know which version was used, and running against current package versions is itself informative: a break argues the authors should have pinned versions. When the repository does record versions, a run with recorded_versions = TRUE installs the packages the scripts load at those versions, but it does not change the R version, which remains a limitation of the check.

Run order is derived from read-after-write data dependencies (a script writing a file another reads must run first), source() edges, and numeric filename prefixes as a weak tie-breaker. Ambiguous orderings, dependency cycles, and inputs a script reads but that no earlier script produces (and that are not in the repository) are surfaced as warnings, since these are the situations most likely to make an otherwise-correct reproduction fail.

Python code (.py files, and notebooks and Quarto documents whose code is Python, from which the code is extracted first) goes through the same two phases, reported in its own “Python code” section. Each file is checked for syntax errors with Python’s own parser when a Python interpreter (python, or else python3) is available; dependencies are read from the import statements, with versions from a requirements.txt or pyproject.toml when there is one, and installed with pip; each script runs as its own python process (processx is required), so unlike R scripts, a name one script defines is not available to another. When no Python interpreter is available, the Python files are reported as not run and the R results are still returned. Statistics the Python scripts print are compared with the paper together with the R output and any self-reproducible output (JASP/jamovi, SPSS-Viewer, notebook outputs).

Abstract

Improved understanding of how myelin damage contributes to disability in multiple sclerosis (MS) is needed to inform targeted therapeutic strategies and improve clinical trial platforms. Magnetization transfer saturation (MTsat) and T 1 relaxometry provide in vivo quantitative MRI measures of myelin integrity, and may offer insights into disability-relevant pathology beyond inflammatory relapse. This longitudinal study explores the relationship between early demyelination and disability progression over the first five years following diagnosis. 62 people with relapsing-remitting (pwRR)MS (≤ 6 months post-diagnosis, 48 female, mean age 38 years) underwent baseline and one-year MRI and Expanded Disability Status Scale (EDSS) assessment. Introduction

Immune-mediated demyelination in relapsing-remitting multiple sclerosis (RRMS) is thought to result in axonal damage, leading to neuronal dysfunction and clinical disability. 1, 2 Modulation of neuroinflammatory pathways with current disease-modifying therapies (DMTs) reduces rates of clinical relapse and new or enlarging white matter lesions (NELs), and slows disability progression. 3 It is increasingly recognised however that disability accumulation in RRMS may also occur independently of DMT-modifiable inflammatory relapse activity, termed 'silent progression' or progression independent of relapse activity (PIRA). 4 The pathological processes underlying disability progression in early RRMS and the variable trajectories of evolving disability for individual patients, however, remain poorly understood.

Current clinical neuroimaging criteria provide only limited insights into the biological processes that may be driving disability in early RRMS: the presence of NELs on serial T 2dependent MRI is an indicator of inflammatory relapse-associated radiological interval disease activity, 5 and contrast-enhancing lesions (CELs) reflect blood-brain barrier breakdown, which is a surrogate marker of active inflammation. White matter lesion (WML) burden does not correlate well with clinical disability progression in RRMS, which has given rise to the widely-recognised notion of the 'clinico-radiological paradox'. 6, 7 Grey matter (GM) lesions appear more closely associated with disability, but are more difficult to detect and quantify reliably on MRI. 8 Emerging therapeutic strategies, focused on remyelination and neuroprotection, require more specific, objective, non-invasive in vivo measures of disability-relevant myelin and axonal damage for patient stratification, to assess target engagement, and as surrogate endpoints of clinical efficacy. Brain atrophy measured from longitudinal analysis of structural MRI has recently been proposed as an in vivo marker of neurodegeneration for clinical evaluation and therapeutic trial endpoints in MS. 9 Widespread atrophy is apparent in early MS, 10 has been shown to be reduced by DMTs, 11 and is also greater in people with RRMS with PIRA than those who are clinically stable. 12 Macrostructural atrophy however remains an indirect 'downstream' marker that may be confounded by other factors such as pseudoatrophy and brain hydration state, 9 and lacks specificity for underlying pathophysiological features in brain tissue.

Diffuse myelin and axonal damage within normal-appearing white matter (NAWM) and grey matter (NAGM) are known pathological features of RRMS, 13 and microstructural MRI allows more specific non-invasive quantification of myelin and axonal integrity than is possible with conventional structural imaging. 14 Magnetization transfer imaging (MTI) detects signal indirectly from protons bound to macromolecules, 15 which are not distinguishable on conventional MRI sequences. In healthy white matter (WM), this signal is dominated by myelin-bound protons, hence providing a degree of specificity for quantifying myelin content. The magnetization transfer ratio (MTR) has been extensively applied to the study of MS, although reported relationships between MTR and disability have varied. 16 A recent meta-analysis which included RRMS cohorts of varying disease duration showed a negative association between NAWM MTR and Expanded Disability Status Scale (EDSS) scores, 16 however many individual studies found no such relationship. [17] [18] [19] [20] [21] [22] [23] [24] [25] The smaller number of analyses of NAGM MTR in mixed disease duration cohorts showed no significant association with EDSS. 16 MTR data are confounded by T 1 relaxation and B 1 + magnetic field inhomogeneity effects, which may result in both increased variance and systematic bias in myelin estimation, and may partially account for inconsistent findings across different studies.

Magnetization transfer saturation (MTsat) signal incorporates an inherent T 1 and B1+

correction, 26 and is therefore thought to be more specific to myelin content compared with MTR. To date, MTsat has seen limited application in MS (Supplementary Table 1), although one cross-sectional study has reported associations between clinical disability and NAWM MTsat, but not MTR. 34 The variable flip angle (VFA) T 1 approximation required for MTsat calculation provides an additional quantitative measure of T 1 , which is also thought to be a proxy for myelin density. 48 More marked focal T 1 prolongation within WML provides a quantitative correlate of visible T 1 -weighted 'black hole' lesions, which are known to be associated with MS disease progression. 49 The relationships between changes in myelin integrity in visible lesions and normal-appearing brain, measured using MTsat, disability progression, and interactions with radiological interval disease activity remain unexplored in early RRMS. Associations between T 1 and minor disability worsening over one year were previously reported in the FutureMS cohort; 50 disability measures over five years were not however previously available.

The primary aims of this study are to determine the degree to which demyelination, measured longitudinally in vivo using MTsat in NAWM and WML, (a) drives clinical disability progression in the five years following diagnosis of RRMS, (b) predicts future disability progression, and c) how the relationship between myelin integrity and disability relates to interval inflammatory disease activity reflected in NELs. As exploratory aims, we explore the association between early T 1 changes and disability progression over five years in this early RRMS cohort, and re-examine previous analyses of disability evolution over one year using more stringent and widely-used definitions of disability worsening. We additionally examine associations between baseline myelin measures, diffusion-weighted imaging (dMRI)-derived metrics, blood-derived markers of neuroaxonal damage and disability progression, and we explore whether and how trajectories of five-year microstructural changes co-vary with disability progression.

Materials and methods

Participants

People with RRMS

Seventy-nine people with RRMS (pwRRMS, Figure 1) consented to take part in a singlecentre (Anne Rowling Regenerative Neurology Centre, Edinburgh, United Kingdom) substudy of FutureMS, a prospective multi-centre longitudinal inception cohort study of people recently diagnosed with RRMS in Scotland. 51, 52 For inclusion, participants had to be diagnosed with RRMS, according to 2010 McDonald criteria, 53 up to six months prior to baseline visit, be over 18 years of age, and not yet be receiving treatment with any DMTs.

Exclusion criteria included contraindication to MRI. Sample size for the wider FutureMS study was calculated based on simulation models, 54 as previously described. 52 The extended sub-study MRI protocol was pragmatically offered to all Edinburgh FutureMS participants once recruitment opened in November 2017 until recruitment ended across all centres in March 2019. 52

Healthy controls

Twelve age-and sex-matched healthy controls were additionally recruited to establish testretest agreement for each microstructural metric, as previously described. 37 Exclusion criteria were contraindication to MRI and incidental findings on MRI. Control participants received an identical MRI protocol to pwRRMS, repeated within two weeks.

Standard Protocol Approvals, Registrations, and Patient

Consents

Clinical Assessment

Clinical assessment at baseline, one-year and five-year follow-up included EDSS score. The EDSS ranges from 0 to 10, with a higher score indicating more severe disability. 55 Disability progression was defined as an increase of ≥1.5 points, ≥1.0 point or ≥0.5 points for EDSS scores of <1.0, 1.0 to 5.5, and ≥6.0, respectively, at the previous time point.

MRI Acquisition

MRI acquisition took place at baseline, one-year, and five-year follow-up, as described previously. 37, 52 All imaging was obtained on a 3 Tesla Prisma MRI system (Siemens, Erlangen, Germany) with a 32-channel head coil. MRI data included: (1) a 3D T 1 -weighted Magnetization Prepared Rapid Acquisition Gradient Echo (MPRAGE) and (2) 2D dual echo (DE) for brain tissue segmentation; (3) 2D fluid-attenuated inversion recovery (FLAIR) for WML segmentation; (4) two 3D proton density fast low-angle shot spoiled gradient echo (SPGR) images with and without a Gaussian saturation pulse (9.984 ms; 500°) at 1.2 kHz offset from the water frequency, plus an additional 3D SPGR T 1 -weighted image required for MTsat and VFA T 1 calculation; and, (4) multi-shell 2D diffusion-weighted spin-echo echoplanar imaging (151 directions; 0/200/500/1000/2000 s/mm2 b-values) with an additional three reverse phase-encoding volumes (b=0 s/mm2) to derive diffusion tensor imaging (DTI) and neurite orientation dispersion and density imaging (NODDI) parameters. Full MRI acquisition parameters are given in Supplementary Table 2.

MRI Processing

Parametric maps

Following methodology detailed elsewhere, 37, 50, 52 MTsat parametric maps (Figure 2) were calculated from MT on , MT off and MT T1w SPGR images (with echoes summed to increase signal-to-noise), and T 1 was approximated from MT off and MT T1w images, according to equations described by Helms et al. 26 in MATLAB (R2018b, software available: https://doi.org/10.7488/ds/2965). 59 DMRI data were processed with the NODDI toolbox 60 (v1.0, mig.cs.ucl.ac.uk, MATLAB R2018b) and DTIFIT after performing brain extraction, removal of bulk motion and eddycurrent induced distortions, and registration to first b0 volume with FSL (v6.0.1), as described previously. 52 [Insert Figure 2]

Brain tissue segmentation

As described in detail previously, 52 skull-stripping was performed on DE proton density brain images with FSL 61 (v6.0.1) and manually edited to obtain intracranial volumes (ICV). WML were segmented on T 2 FLAIR (Figure 2), using an adapted thresholding method. 52, 62 Segmentation of brain tissue, including NAWM, cortical GM, deep GM (thalami, basal ganglia, and amygdala), and hippocampi, was performed on T 1 -weighted MPRAGE images with FreeSurfer (v6.0, https://surfer.nmr.mgh.harvard.edu/) with edited ICV masks and DE T 2 -weighted images as additional inputs. WML were subtracted from tissue masks and all other tissue masks were eroded by one voxel. Tissue volumes were calculated and corrected for ICV. GM and WM were similarly segmented for healthy control images.

To account for the influence of additional WML voxels forming over the follow-up period, baseline WML were registered to one-and five-year follow-up parametric maps using FSL flirt.

We also calculated the number of 'prolonged T 1 voxels' in WML with T1 ≥2.00 s as detailed previously. 50 Interval disease activity, evidenced by the presence of NELs at follow-up, was assessed by visual inspection on FLAIR by an experienced neuroradiologist. 52

Blood-derived markers

Blood plasma neurofilament light chain (NfL) and glial fibrillary acidic protein (GFAP) were measured using a multiplex single molecule array (Simoa) enzyme-linked immunosorbent assay (ELISA), as described previously. 35 NfL and GFAP z-scores, adjusted for sex (GFAP only), age, and body mass index (BMI) were calculated using large reference populations. [56] [57] [58] EBV nuclear antigen 1 (EBNA1) immunoglobulin G (IgG) titres were measured by an extended-dilution indirect ELISA using recombinant whole EBNA1 protein. Serum was assayed in duplicate across serial dilutions (1:200, 1:800, 1:3,200 and 1:12,800), with platespecific normalisation using pooled control sera and on-plate controls. Quantitative titres were derived by fitting 4-or 5-parameter logistic dilution curves and calculating the reciprocal dilution corresponding to a predefined optical-density threshold; titres were log2transformed for analysis.

Statistical Analyses

Statistical analyses and extraction of regional median MTsat and T 1 were carried out in RStudio (v1.4.1717, R v3.6.1).

Test-retest agreement

As a measure of test-retest agreement, and as previously described, 37 Bland-Altman limits of agreements 63 were established from healthy control WM and GM, between which 95% of repeated measurements would be expected to fall.

Relationship with disability progression

Primary analyses

Primary analyses examined the association between change in regional MTsat between time points, and disability progression between the same and future time points was assessed with binomial logistic regression, adjusted for baseline age, sex, change in WML volume, baseline MTsat, and dichotomised DMT usage. The majority of participants were treated with lowefficacy DMTs or untreated at one-year (93.5%) and five-years (80.3%); there was thus limited scope to further interrogate the effect of high-efficacy treatment on associations.

False Discovery Rate (FDR) correction was performed. Overall goodness-of-fit was assessed with Nagelkerke's 64 (pseudo)-R² (rms package). 65 Log-Likelihood Ratios with Wald's chisquared (χ 2 ) tests and, when significant, receiver operating characteristic (ROC) curves with Akaike Information Criterion (AIC) were used to compare models against the null model and the reference model, i.e. with microstructural MRI markers removed. 66, 67 Odds ratios were calculated for coefficients of z-normalised variables. To determine the robustness of findings, analyses were repeated excluding the five observations with the largest Cook's distance per model.

For significant primary models, to determine the influence of interval disease activity, models were repeated with inclusion of an interaction term between change over time in the given metric and NEL group.

Exploratory analyses

Analyses were repeated for T 1 , prolonged T 1 voxel count in WML, NODDI, DTI, and baseline microstructural metrics to determine associations with disability progression.

Baseline models included baseline WML volume, age and sex as covariates.

As NfL and GFAP are markers of neuroaxonal damage, and EBNA1 titres are elevated in people with MS, blood-derived markers were also added to primary analyses to determine incremental value.

To determine retrospectively whether the trajectory of microstructural changes differed between those who did or did not experience disability progression in the five years following diagnosis, participants with complete MRI and EDSS data were split into disability groups: 'progressors' who experienced disability progression between baseline and one-year, and between one-year and five-years; 'early progressors' who only showed progression between baseline and one-year; 'late progressors' who only progressed between one-year and fiveyears; and, 'non-progressors' with no evidence of progression between time points. Linear mixed-effects models, with baseline age, sex, baseline WML load, and DMT usage as covariates, were used to determine whether the microstructural metric significantly depends on the interaction term between progression group and time.

Discussion

In this study, we investigate associations between quantitative microstructural MRI markers of myelin integrity and disability progression in the five years following RRMS diagnosis.

We show that longitudinal groupwise one-year change in NAWM MTsat is associated with contemporaneous disability progression, but does not predict the subsequent four years of disability progression. We also demonstrate a relationship between decreasing MTsat in WML and disability progression over the first year, but not over subsequent one-to-five-year follow-up. We find no evidence to suggest that disability progression associated with early NAWM or WML demyelination is influenced by the presence of NELs, suggesting that changes in myelin integrity may occur independently of radiological inflammatory disease activity in recently diagnosed RRMS.

We also find evidence of progressive demyelination within GM and the majority of deep GM structures, which is detectable with MTsat, but generally show only modest associations with early disability progression.

Exploratory analyses show that the trajectory of WML MTsat nominally differs between individuals with different five-year disability progression trajectories; however, this finding does not survive FDR correction. Neither T 1 nor any baseline metrics are associated with disability progression, and blood-derived NfL, GFAP and EBNA-1 markers did not provide incremental value to models.

Longitudinal microstructural metrics and disability progression

Normal-appearing white matter

Diffuse NAWM abnormalities in pwMS, detected with quantitative MR techniques including MTR are well-documented; 68 insights into the pathological drivers of disability divergence in early MS have, however, been limited by technique sensitivity and specificity. MTsat is thought to be more specific to myelin than MTR due to inherent correction for T 1 relaxation effects (and, to some degree, B 1 + inhomogeneities), 26 and is strongly associated with myelin marker Luxol-Fast Blue. 69 We previously observed a groupwise longitudinal decrease in MTsat in NAWM in our cohort of newly diagnosed pwRRMS, suggestive of widespread progressive demyelination. 37 Here, we report for the first time that greater decreases in MTsat in NAWM in the year following RRMS diagnosis are associated with a significantly increased likelihood of early disability progression over the same one-year period. Our findings suggest that early subtle demyelination beyond visible WML contributes significantly to worsening disability.

The absence of any significant interaction between change in NAWM MTsat and NELs on disability evolution suggests that progressive 'invisible' myelin loss (demyelination and/or failure of remyelination) may be one of the substrates underlying progression in early RRMS, and occurs independently of MRI-visible inflammation. This may provide a potential mechanism underlying PIRA, 70 and may have important treatment implications. The sample size of the current study, however, limits further robust interrogation of PIRA and relapseassociated worsening (RAW) phenotypes beyond the presence of NELs.

Our findings broadly support the hypothesis that disability in early MS is predominantly driven by a diffuse 'smouldering' pathological process, rather than by episodic focal inflammatory episodes. 71 While paramagnetic rims around WML are thought to be a localised manifestation of chronic inflammation, 72 widespread NAWM microglial activation, detected with PET and associated with microstructural disruption and disability, has also been reported in a mixed MS subtype cohort. 73 It is not yet clear whether the widespread disability-relevant myelin loss demonstrated here results directly from more global brain inflammation in early RRMS.

Although one-year change in NAWM MTsat was associated with one-year disability progression, it was not predictive of one-to-five-year disability progression. One-to-five-year change in NAWM MTsat was also not associated with disability progression over that same period. There are a number of possible explanations for this. The rate of disability-relevant myelin loss may vary with time in MS. Indeed, we observed that the annualised MTsat change over the first year was more pronounced than over the subsequent four years.

Trajectory over the first year following diagnosis is therefore not necessarily a predictor of disease behaviour over subsequent years. Variation in the efficacy of repair mechanisms in NAWM and treatment with DMTs during the one-to-five-year period may also mitigate longer term disability progression, and weaken any predictive relationship. Change in MTsat over five years is modest, and larger subject numbers or measurement over a longer period may be needed to identify statistically significant associations with and predictors of disability during this disease phase.

White matter lesions

Here, we demonstrate an association between changes in WML MTsat and disability progression over one year, although that change is not predictive of forward disability progression from one to five years. Within our recently diagnosed RRMS cohort, we previously noted a net increase in WML MTsat over time, 37 which we speculated could be caused either by spontaneous remyelination after an acute inflammatory episode that prompted diagnosis, or reduction in oedema following acute inflammation in lesions; this accords with other evidence that remyelination within lesions may occur to a varying extent across patients. 74 When grouped by EDSS progression trajectory however, we observe in this study that participants in our recently-diagnosed RRMS cohort with progression between time points tended to demonstrate a decrease in MTsat within WML, whilst an increase in WML MTsat was more commonly observed in those without progression. This suggests that recruitment of innate myelin repair mechanisms within focal WML may slow progression.

Myelin-sensitive MTR within lesions has previously been applied as an endpoint in a remyelinating therapy trial, 75 and MTsat may provide a more sensitive and specific end point for such studies in future.

The observation that MTsat changes in WML over a year do not predict one-to-five-year disability progression suggests that early spontaneous remyelination of already-extensivelydamaged tissue does little to mitigate long-term disability accrual. The absence of detectable association with future disability progression could additionally be explained by technical MTsat 'floor effects' due to already very low myelin density within some WML.

Cortical grey matter

Previous studies have suggested that GM damage may contribute disproportionately to early disability progression in MS, [76] [77] [78] and cortical MTR changes indicative of myelin loss and repair measured over a year in a mixed MS cohort have recently been shown to predict disability after a five-year interval. 78 In our early MS cohort, we found that cortical GM myelin changes measured with MTsat were significantly associated with one-year disability progression, which accords with previous findings. This model was, however, no better than the null (intercept-only) model, suggesting that GM may be marginally influential, but not the primary disability driver in the model. As with NAWM and WML, one-year cortical myelin change also did not predict one-to-five year disability progression and one-to-five year myelin changes were not associated with disability progression over the same period. Cortical GM is more sparsely myelinated than WM; low myelin density may reduce the accuracy of our myelin-sensitive metrics within the cortex. Poor detection of cortical GM lesions at 3 T clinical field strengths precludes reliable segmentation and therefore microstructural characterisation of focal cortical lesions. Our findings overall indicate that disability-relevant myelin changes occur within the cortex in early RRMS, but are difficult to detect without specific myelin-sensitized acquisition techniques, and may not predict longer term disability outcomes.

Deep grey matter

We observed a relationship between combined deep GM change in MTsat and one-year disability progression, in addition to individual associations with MTsat changes in the thalamus, basal ganglia and hippocampus. Histopathology has demonstrated demyelination in deep GM in MS. 79 We are not aware of any study examining associations between longitudinal myelin changes within deep GM using MTsat and disability progression in recently-diagnosed RRMS. Our results illustrate that deep GM demyelination occurs at an early stage of disease and contributes to disability progression, albeit to a lesser extent than NAWM demyelination.

Although the thalamus is often classified as a GM structure, it is has complex internal anatomy and contains significant myelinated WM. 80 A recent study showed no difference in two-year change in thalamic MTsat-derived myelin volume fraction (MVF) between healthy controls and pwRRMS of mixed disease duration. 42 Previous work in early RRMS found that thalamic MTR was negatively associated with timepoint-averaged EDSS; the rate of MTR change was not associated with EDSS at two-year follow-up however. 81 In later disease, reduced thalamic myelin density compared with healthy controls has been observed with MTR, 82, 83 and inhomogeneous (ih)MTR. 83 Our finding of a relationship between thalamic MTsat and disability progression over one year, but not five years, broadly accords with these findings. Although myelin loss within the thalamus appears relevant to early disability progression, our results do not support the view that early thalamic demyelination predicts sustained disability progression over a longer time period.

In the basal ganglia, which comprise the caudate, putamen and pallidum, greater demyelination was associated with one-year disability progression in our early RRMS cohort.

We are not aware of any other studies examining disability progression and demyelination measured with MTsat within the basal ganglia, although some evidence supports crosssectional associations between disability and myelin proton fraction (MPF) within the caudate nucleus and putamen in MS. 84 Basal ganglia demyelination however did not differentiate between those who did and did not progress at five-year follow-up, and is therefore not a stratifier of future disease trajectory.

Decreasing MTsat in the hippocampus appeared to significantly increase the likelihood of disability progression at one year in our newly-diagnosed RRMS cohort. Hippocampal demyelination is a known histopathological feature of MS, 85 and significant associations between EDSS and myelin-sensitive χ-separation quantitative susceptibility dependent MRI of the hippocampi have been reported. 86 Lower hippocampal sub-field volumes have also been reported in early RRMS compared with healthy controls 87 and with MS diagnosis in people with clinically isolated syndrome (CIS). 88 There are, however, a number of confounds that may contribute to our findings. The morphology of the hippocampus and adjacent CSF and choroid plexus in the temporal horn of the lateral ventricle make reliable segmentation difficult, and a small number of contributing voxels and partial volume effects from adjacent structures make MTsat signal vulnerable to subtle volume change. Moreover, susceptibility effects from the sphenoid bone and sinus may also influence signal return. The hippocampus primarily subserves memory function, and mechanisms underlying any direct causal relationship between hippocampal dysfunction and EDSS which is substantially motorweighted should also be considered. Cognitive testing of specific memory domains is needed to elucidate any relationship between early hippocampal demyelination and progression of memory deficits, which appear more prevalent in MS with longer disease duration. 89 Although our findings suggest possible disability-relevant hippocampal changes in RRMS, we therefore interpret these with caution.

Baseline microstructural metrics and disability progression

We found no significant association between baseline MTsat and subsequent disability progression. This accords with previous cross-sectional studies which found no association between myelin measures and EDSS; 28, 30, 32 although those studies examined EDSS at a single time point rather than change over time.

Our data from a sizeable cohort of recently diagnosed pwRRMS support the view that a single time point MRI measure of microstructural integrity is insufficient to predict EDSS clinical disability evolution over one year or five years. It is, however, possible that such associations may become apparent with longer follow-up, or with the development of more nuanced disability measures.

T 1 measures

In contrast to MTsat, we found no evidence of associations between disability and NAWM T 1, nor of prolonged T 1 WML voxels and disability progression in our exploratory analyses.

While we have previously reported a relationship between NAWM T 1 and prolonged T 1 WML and EDSS disability progression in our cohort using a ≥ 0.5 point threshold, 50 here we show that, unlike associations with MTsat, this relationship does not persist with more stringent clinical criteria. We also previously reported relationships between longitudinal T 1 measures in deep GM and one-year disability progression; 50 again, these are not seen with more stringent progression criteria or as predictors of five-year disability worsening.

Floor effects have been observed previously with T 1 prolongation in lesions, 48 which may contribute to our null findings, and T 1 changes in sparsely-myelinated cortex are likely to be dominated by factors other than myelin density.

We have previously reported longitudinal diffusion tensor imaging (DTI) or Neurite Orientation Dispersion and Density Imaging 60 findings over one year in this cohort, 37 and note that we also found no significant relationships between disability progression and any diffusion metrics for any brain region (Supplementary Material 2).

Our current results suggest that MTsat is a more sensitive measure than T 1 for detecting subtle diffuse demyelination that causes more pronounced and longer-term disability progression. MTsat may therefore be more appropriate as a clinical trial surrogate endpoint, using widely accepted definitions of disability progression.

Limitations

The FutureMS study was designed to recruit a cohort at a homogeneous disease stage; variation in recruitment with regard to the time of first reported symptom onset was not explicitly included in our analyses due to the poor reliability of determining first symptom onset compared with date of diagnosis, and a strong association with age. We also did not account for possible bias introduced by exclusion of subjects at recruitment, nor due to missing data; it is difficult to establish in which direction this may have biased our conclusions.

We acknowledge the limitations of the EDSS as a measure of disability, including the noncontinuous and non-normal distribution of scores within MS cohorts. 67 More nuanced, longitudinal cognitive testing, particularly with respect to memory deficits , may be required to fully elucidate the contribution of deep GM demyelination to disability progression.

All participants were treatment-naïve at baseline, and dichotomised use of DMTs between time points was included as a covariate in our models. FutureMS is, however, a 'real world' observational cohort and participants may initiate or switch DMTs between time points for a variety of reasons (including interval disease activity, risk profiles and adverse effects).

B 1 + correction was not performed; MTsat, however, inherently corrects B 1 + inhomogeneities to some degree. Although longitudinal measurements will mitigate the impact of residual B 1 + inhomogeneities, and the occurrence of a systematic difference in B 1 + distribution between disability groups is unlikely, the accuracy of cross-sectional T 1 , and to a certain extent MTsat, may be reduced. Our future studies will include acquisition of B 1 + maps. Lesion filling prior to brain tissue segmentation was not performed. Comparisons between segmentations performed with and without lesion filling (data not shown) demonstrate the impact on resulting brain tissue masks is minimal-to-none. Understanding technique reproducibility is important for establishing sensitivity to longitudinal biological change. While changes in MTsat over one year were significant at the group level, test-retest limits of agreement established in healthy control WM indicate that they will not necessarily distinguish between individuals with stable/improving and those with worsening disability (see Supplementary Results). Moreover, technique reproducibility measured in healthy control data over a two-week period may underestimate test-retest variability over the one-year interval studied here in pwRRMS.

Conclusion

Conclusion imaging is associated with one-year disability progression in early RRMS, independently of interval radiological disease activity.

Ongoing diffuse NAWM demyelination detected by longitudinal myelin-sensitive MTsat

Widespread ongoing disability-relevant demyelination in WML and GM is also seen over the year following MS diagnosis. None of our microstructural measures predict future disability progression, and indeed myelin changes over the subsequent four years were modest and not associated with disability progression.

Our findings provide potential mechanisms driving early disability progression beyond NELs, and suggest that microstructural evaluation of NAWM (and perhaps GM) may be at least as important as WML features for assessing disease trajectory. Quantitative myelin measures therefore provide an important adjunct to conventional indicators of activity for assessing otherwise 'hidden' disease evolution and therapeutic response in RRMS. Greater myelin changes over the first year but not subsequently suggest a disease tempo change and point towards a potentially important window of therapeutic opportunity. MTsat shows promise as a clinically-applicable disease stratifier and surrogate endpoint in future therapeutic trials, especially those targeted at preventing progression in those without radiological inflammatory disease activity.
