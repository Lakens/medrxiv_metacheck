An a priori power analysis for an independent samples t-test, conducted using the pwr.t.test function from pwr (Champely, 2020), indicated that for a Cohen’s d = 0.5, an alpha level of 0.05, and a desired power level of 80% required at least 64 participants in each group.

For a sensitivity power analysis, this sentence would look like:

A sensitivity power analysis for an independent samples t-test, conducted using the pwr.t.test function from pwr (Champely, 2020), indicated that with 64 participants in each group, and an alpha level of 0.05, a desired power level of 80% was reached for an effect size of d = 0.5.

This module searches for statements of ethics approval, IRB approval, institutional review board approval, and related terms.

How Exact P-Values works

List any p-values reported with insufficient precision (e.g., p < .05 or p = n.s.), reported as exactly zero (e.g., p = .000), or impossible (below 0 or above 1, e.g., p = -.22).

This module uses regular expressions to identify p-values. It will flag any values reported as p > ? or p < numbers greater than .001. It will also flag p-values reported as exactly zero (e.g., p = .000, p = 0.00), which are mathematically impossible — p-values are never exactly zero and should instead be reported as p < .001.

A p-value that is not the result of a test is not flagged: a table note (“* p < .05, ** p < .01”), a figure legend (“Asterisks indicate significant differences (p < .05)”, “Values in bold are significant at p < .05”) or a stated threshold (“p < .05 was considered significant”, “thresholded at p < .001”). GROBID often puts such notes into the running text, so each p-value is judged by the words in its own clause (the text up to a “;” or a full stop), and never left out when a test statistic belongs to it (“F(1, 7) = 8.03, # p < .05”). The column not_a_test of the table says why a p-value was left out (“marker”, “threshold”, “legend” or “named”).

A p-value with the name of a correction or a test after the p (“pFWE < .05”, “padj < 0.05”, “p Wilcoxon = .02”) is flagged only when a test statistic comes before it in its clause (“t(37) = 7.17, p FWE < .05”). Without one it is mostly the rule that decided what was significant (“genes with padj < 0.05 were selected”); such a p-value is “named” in not_a_test. Notes in other forms, such as a marker after the p-value (“p < .05 (*)“), are still flagged.

A p-value below 0 or above 1 is impossible; it is listed apart and not also as imprecise. Often the statistic before it, or its minus sign, was copied into it (“t(134) = -2.32, p = -.13”, “Z = 3.091, P = 3.091”). A value above 1 is listed only after a test statistic in its clause: without one, a “P” above 1 was nearly always another quantity (a proportion, pH, a group’s mean, a model parameter). A number in scientific notation whose power of ten was lost when the PDF was read (“p = 2.4 x 10 -9” read as 2.4) is not listed. A “p” that is the subscript of another symbol (“r p = .64”, “²p = .02” for partial eta squared, “Δp = .33”), or a quantity with a unit, a logarithm or a ratio (“P = 2.9 µm”, “-log10 P = 7.5”, “Ca/P = 1.67”), is not read as a p-value at all (see extract_p_values()). Each p-value has its own row, also when the same one is written twice in a sentence.

This module sometimes flags false positives when sentences discuss how p-value thresholds were set. It can also miss an imprecise p-value that is reported against a threshold (“decreased at the p < .05 significance threshold”).

This module only checks p-values reported in the running text of the manuscript. It cannot (yet) process p-values reported only in tables (as opposed to a table’s footnote text, which the module does see and tries to exclude — see above).

Listing a repository’s files never requires an API key, but some hosts answer faster or more completely with one: OSF allows 100 requests/hour unauthenticated versus 10,000/day with a token (see [osf_pat()]), and Dryad enforces a strict per-IP daily quota on repeated listing (see cache below). Dryad is a special case beyond rate limits: listing a Dryad dataset’s files works without a key, but actually downloading file CONTENTS from Dryad fails with HTTP 401 unless a key is set, even for a fully public dataset (see [dryad_pat()] or [dryad_auth()]). When a linked OSF page is a registration, its registered_from project (the one it was registered from, which the manuscript itself may never link directly) is also checked: if that project is public its files are listed under its own URL, and if it is closed or otherwise inaccessible the report flags it explicitly, since some registrations only describe their content rather than mirroring it.

Whose deposit is each link? The ownership table gives, for every repository linked in the text and (with references = TRUE) every deposit cited in the reference list, one of six labels: own_this (made by the authors for this paper), own_earlier_data or own_earlier_code (the authors’ own, from earlier work), others_data or others_code (made by other people, reused here), or not_data (a publication such as a preprint, not a deposit), with ownership_group (“own”, “others”, “not_data”) and the reason. It is decided without a language model, from the sentence or reference that cites the link, the paper’s authors (names, ORCID iDs, affiliations), and what the deposit’s own record and files say (who made it, what it names, when, whether it is a software package; for an OSF project cited only in the reference list, its record alone). On a round of labelled links the rules had not been written from, the three groups were right for 98% of links in the main text (93 of 95) and 90% in reference lists (74 of 82); the labels were made by Claude agents from each link’s evidence, and disputed ones checked against the deposits. Telling this paper’s own deposit from the authors’ earlier one is less certain.

Only the deposits that are this paper’s own are checked. A deposit linked in the text that holds other people’s work (others_data, others_code) or the authors’ earlier work (own_earlier_data, own_earlier_code) is listed in the report, with the reason, but its files are left out of table and kept in table_not_checked: they count toward nothing here (files that do not belong in a repository, naming, READMEs, studies, the traffic light), and code_check, data_check and reproducibility_check, which read table, do not check them either. reproducibility_check still puts the files of theirs that the paper’s code names in the folder the code runs in, as a re-analysis needs the data it re-analyses. When every linked deposit is set aside, the traffic light is “na”. A deposit that is the paper’s own is counted as such when its README, title or description names the paper (its title or DOI).

How Code Check works

This module retrieves information from repositories checked by repo_check about code files (R, Python, SAS, SPSS, Stata, Mplus, MATLAB).

The Code Check module checks R (also R Markdown and Quarto), Python (also Jupyter notebooks), SAS, SPSS, Stata, Mplus, and MATLAB files, using regular expressions to check the code; JASP files are listed but not read. The language of a Quarto document or a notebook is read from the file itself (its engine or kernel), not from its extension. The regular expression search will detect the number of comments, the lines at which libraries/imports are loaded, attempts to detect absolute paths to files, setwd() and install.packages() calls, and lists files that are loaded, and checks if these files are in the repository; R code is also parsed. The module was tried out internally on papers published in Psychological Science, but has not been formally validated. How Data Check works

This module classifies the files in a repository into semantic types (data, codebook, code, software, output, supplemental, readme, asset, other) and, for tabular data files, extracts each column’s type and summary statistics.

The Data Check module consumes the file list produced by repo_check (or any files added via local_path). Each file is classified with rule-based heuristics layered over metacheck’s file_category() and file_types: file names matching README / codebook patterns win first, then an extension crosswalk, then format-locked extension overrides. For every file classified as tabular data that is available locally, the module reads the file head, describes each column with data_col_facets() and computes summary statistics for numeric columns. Every sheet of a spreadsheet that holds a table is read: a file with several such sheets has its columns under source_file = "file.xlsx [sheet]", and the sheet column names the sheet of any spreadsheet with several sheets; a sheet of notes or a codebook is treated as documentation when the file has another table. Following DDI, a column is described by orthogonal facets rather than a single type: representation (numeric/text/datetime/code — how it is stored), measurement_level (Stevens: nominal/ordinal/interval/ratio), concept (what it measures: reaction_time/age/gender/likert/id/…), role (identifier/measure/condition/timestamp), unit, and a quality state (ok/empty/constant). Concepts are detected by name+value rules (the demographic concepts via data_check_demographic()); when llm_use(TRUE) the model fills concepts and measurement levels the rules left blank. Qualtrics survey exports are recognised (data_check_is_qualtrics()): their extra header rows are stripped so columns type correctly, and the reserved response-metadata columns (StartDate, Duration, Finished, …) are tagged.

The module defaults to rules-only when llm_use(FALSE): columns the rules cannot resolve (ambiguous 3–20-unique integers, ambiguous character columns) fall back to continuous / text respectively. When llm_use(TRUE), ambiguous columns and unresolved file types (other) are sent to llm() for optional refinement, and every file is assigned a study group (ex1, pilot2, shared, …) so that multi-study repositories can be recognised (used by psychds_check). Without an LLM the study group is left NA (unknown).

Column extraction requires files to be readable from disk. Files fetched by repo_check from OSF/GitHub/etc. without a local copy (file_location is NA) are classified but not column-extracted; pass local_path to point at a downloaded copy of the repository.

For a paper whose repository is on Dryad, this means column extraction never happens unless a Dryad API key is set: Dryad requires one to download file bytes, even from a fully public dataset (dataset listing and metadata do not need one). Without a key, every Dryad file stays classified but un-downloaded, column_n is 0, and a warning naming Dryad and ?dryad_pat/?dryad_auth is included among the download failures. A one-time session message is also shown (see repo_check) the first time a Dryad dataset is encountered with no key set.

Every downloaded text file the authors wrote (code, settings, survey definitions such as Qualtrics .qsf files, documentation, outputs) is searched for keys: API keys, access tokens and private keys, which let anyone who downloads the file use a paid service at the authors’ cost. Of a tabular data file only the column names and first 3 rows of the table as read are searched: its values come from participants, but a key the authors set for a whole survey (as embedded data in a Qualtrics survey flow) is exported in every response. The search uses the rules of the secret scanner betterleaks (https://github.com/betterleaks/betterleaks, MIT licence) of high and medium confidence. A key found turns the traffic light red; the report and the keys table give its file, line and type, and only its beginning. Other files over 25 MB and binary files are not searched. A key is never tested with its provider. Every module’s result has any whole key replaced by “keyremoved” (see module_run()).

How Reproducibility Check works

This module assesses whether a paper’s R and Python code can be run on its data. It works in two phases. The static phase (always run) collects the package dependencies the code declares, rewrites the data-file paths that do not work in the repository as the authors organised it, works out the order the scripts must run in, and diagnoses why any referenced input file is unavailable — reporting what a reproduction attempt would involve and where it is likely to break. The execution phase (opt-in, execute = TRUE) then actually runs the code: it copies the repository into a throwaway directory, optionally installs the declared dependencies into a throwaway library, runs each script in order in an isolated subprocess with a per-script timeout, and captures the outcome and full output of each run.

By default (execute = FALSE) the module does not run any code — it performs only static analysis: reading dependencies with the same extractors as code_check, finding the files the code references in the repository, and building a run-order dependency graph. It reports what would be installed and run rather than doing it.

When execute = TRUE, the module additionally runs the downloaded code on your machine — a deliberate, opt-in action gated behind that argument (callr is required for R code). Abstract

Importance. Heart-rate variability (HRV) is studied extensively as a prognostic marker in critical illness, yet the electrocardiographic sampling rate at which HRV is computed systematically distorts the resulting values. Whether the associations between HRV and clinical outcomes reported in the literature are partly a consequence of this distortion has not been examined directly. NOTE: This preprint reports new research that has not been certified by peer review and should not be used to guide clinical practice.

Setting and data sources. Two critical-care waveform databases with different native sampling rates (MIMIC-IV Waveform, approximately 250 Hz; MIMIC-III Waveform Matched p04, 125 Hz) and an independent 500-Hz reference cohort (PTB-XL) for mechanism validation. The outcome association was estimated in 1,445 ICU stays from MIMIC-III p04, of whom 141 died in hospital (9.8%).

Native ECG sampling rate as a negative-control exposure; SDNN, RMSSD and heart rate as the measured exposures whose associations with mortality are evaluated.

Main outcomes and measures. In-hospital mortality. Distortion coefficients were obtained by end-to-end reprocessing of 7,293 original waveform segments with a fixed QRS detector. Corrected odds ratios were reported as QBA sensitivity bands rather than point-identified effects. Misclassification was quantified as the proportion of recordings below a 20 ms HRV threshold reclassified above it by coarse sampling.

Results. End-to-end reprocessing gave an RMSSD distortion coefficient of 1.1575 (95% CI 1.0835-1.2492; 2,276 segments in 188 patients) for 250→62.5 Hz and 1.0588 (95% CI 1.0294-1.1033; 4,988 segments) for 125→62.5 Hz; high-frequency power was more affected than low-frequency power (1.2033 vs 1.0716). Under the multiplicative model, an observed crude RMSSD-mortality odds ratio of 1.802 corresponded to a corrected interval of 1.8335-1.915 across the coefficient's 95% CI. The correction was small relative to confounding: the same association fell to 1.116 after age adjustment. Coarse sampling reclassified 33.70% of low-HRV recordings in MIMIC-IV and 20.72% in MIMIC-III, a larger potential source of bias than the continuous-scale correction. The cross-database negative-control gradient was completed after linking both waveform cohorts to hospital outcomes: RMSSD inflation was reproducible (median ×1.101 at 125→62.5 Hz in MIMIC-III and ×1.270 at 250→62.5 Hz in MIMIC-IV), but the ageadjusted HRV-mortality risk ratio did not increase at lower rates (MIMIC-III 1.70→1.21; MIMIC-IV 1.31→1.29→1.20; all 95% CIs crossed 1). The falsification test was therefore negative in these cohorts, and we report it as such rather than as evidence that measurement bias is absent.

Sampling rate is a detectable and correctable source of bias in HRV-outcome research. Recording the sampling rate of each signal, stratifying effects by baseline variability, and reporting a QBA sensitivity band before dichotomising HRV would make published associations more interpretable. The object of inference here is the measurement-error method, not a new clinical biomarker; the proposed reporting steps require no additional data collection.

Objective.

To evaluate whether between-database differences in native ECG sampling rate can be used as a negative-control exposure to detect measurement-driven bias in HRV-outcome associations, and to quantify the sensitivity of a published association to an empirically measured distortion coefficient using quantitative bias analysis (QBA).

Design.

A methods investigation in three parts. Part I sets out the causal structure and states why a strict instrumental-variable (IV) design is inappropriate here. Part II derives a bias-correction factor under a multiplicative measurement-error model and propagates the empirical confidence interval of the distortion coefficient as a sensitivity band. Part III applies the procedure to an observed HRV-mortality association from a single ICU waveform database, and examines the separate bias arising from threshold-based categorisation.

1. Introduction

Reduced heart-rate variability (HRV) is one of the most widely reported physiological correlates of critical illness. Reviews in critical care describe inverse associations between HRV and severity or mortality across diagnostic groups [6, 9, 10], and cohort studies have reported that changes in HRV precede the clinical recognition of sepsis [7, 8]. These findings have encouraged proposals that HRV might serve as a prognostic biomarker at the bedside [6]. The literature is also heterogeneous. Sampling protocols, segment lengths, QRS detectors and frequency-band definitions differ substantially between studies, and reviews have noted that part of the apparent HRV-mortality association tracks heart rate rather than autonomic variability [9, 10].

A separate literature concerns how digital sampling affects HRV measurement. Hejjel and Roth, using model tachograms, showed that time-domain error rises steeply as the sampling interval widens: at a 10 ms interval, the relative accuracy error for SDNN exceeded 30% in low-variability series [2]. Burma and colleagues downsampled 1,000-Hz ECG recordings and found that RMSSD required at least 90 Hz, and SDNN at least 60 Hz, to agree with the reference recording [3]. Zhou and colleagues recently derived analytical error bounds for HR, RMSSD and SDNN and validated them in 58 volunteers, providing quantitative guidance for sampling-rate selection [1]. Other work has examined interpolation and detector choice [4, 5]. The magnitude of the distortion also depends on how downsampling is performed: a recent preprint showed that extremapreserving schemes retain QRS-detection accuracy and RMSSD down to 12 Hz in the MIT-BIH databases, whereas naïve decimation fails below 45 Hz [43]. Our reanalysis uses straight decimation, as in the original pipeline, so the coefficients reported here describe that specific processing choice rather than sampling rate alone. What these studies share is a focus on measurement accuracy. They stop at the question of how far a computed HRV value departs from its true value.

The two literatures have not been brought together. Although reviewers of critical-care HRV have noted sampling-rate heterogeneity as a source of between-study inconsistency [8, 10], we are aware of no study that treats the between-database difference in native sampling rate as a diagnostic instrument for bias in an HRVoutcome association, or that uses a measured distortion coefficient to correct such an association.

Here we make three claims. First, sampling rate can be used as a negative-control exposure in the sense used by Lipsitch and colleagues and elaborated by Arnold and colleagues: a variable that should not be related to the outcome through the biological pathway of interest, but that shares the measurement and selection processes capable of generating a spurious association [20, 21]. Second, because the distortion coefficient can be estimated directly from original waveforms, the magnitude of the resulting bias can be propagated formally rather than merely acknowledged, following the logic of quantitative bias analysis [11, 13, 14, 18]. Third, the categorisation of HRV at a fixed threshold introduces a distinct misclassification problem that may dominate the continuous-scale correction.

We also state one claim we do not make. We do not propose sampling rate as a valid instrumental variable. Recording rate is correlated with centre, device era and monitoring intensity, so both independence from confounders and the exclusion restriction fail. We therefore do not attempt causal identification. The design is a bias audit: we ask how sensitive an observed association is to a measured measurement-error process, and we report a sensitivity band rather than a corrected point estimate with a claim of validity.

The manuscript is organised in three parts. Part I defines the causal structure and the negative-control logic. Part II derives the correction factor and specifies how the distortion coefficient is propagated. Part III applies the procedure to a real outcome association and examines threshold misclassification. The same distortion coefficients are used throughout, and they were estimated from the waveforms before any outcome association was considered; this separation is the methodological discipline of the design.

2. Methods

>Methods

2.1 Causal structure and the negative-control exposure

Let S denote the native sampling rate of the ECG used to derive an RR-interval series, H* the underlying physiological HRV signal, Hobs the value computed from the digitised signal, C a set of common causes (age, illness severity, centre, device era, monitoring intensity, mean heart rate), and Y the clinical outcome. Sampling rate affects the observed value through R-peak time quantisation, S → Hobs → Y; the physiological signal enters the observation through H* → Hobs; and the common causes influence S, Hobs and Y.

The negative-control premise is that S has no pathway to Y other than through the measurement of H* and through its association with C. If the Hobs-Y association is entirely physiological, conditioning on C should remove any dependence on S. An association that persists, and whose gradient across sampling-rate tiers matches the direction and magnitude of the independently measured distortion coefficients, is evidence that measurement artifact contributes to the estimate. Negative controls of this form are best understood as a falsification test, not as a proof: as Arnold and colleagues emphasise, they can indicate the presence of bias without determining its direction or magnitude [21], and a null result cannot establish that bias is absent [20, 22]; methods that exploit negative controls for partial identification, such as the control-outcome calibration approach [23], require assumptions we are not in a position to make here.

The choice rules out a strict IV analysis. For S to be a valid instrument it would need to be independent of C, which is contradicted by the clustering of recording equipment within centres and device generations, and it would need to affect Y only through the measured HRV, which is contradicted by the fact that sampling rate is a marker of the surrounding monitoring environment. Causal diagrams for measurement bias [28, 29] and for monitoring-driven confounding in intensive care [30] make the same point from different directions: the monitoring process is itself related to patient state. We therefore use S only as a bias scale, and we interpret the resulting estimates as sensitivity analyses in the sense of Greenland and of Lash and colleagues [11, 14].

2.2 Estimation of the distortion coefficients

The distortion coefficients were estimated by end-to-end reprocessing of original waveforms, using the same detection and HRV pipeline at each sampling rate. A fixed QRS detector (wfdb gqrs) was applied to 7,293 segments: 2,294 from MIMIC-IV at native 250 Hz and 4,999 from MIMIC-III p04 at native 125 Hz. Segments were then downsampled in stages to 62.5 Hz, and HRV indices were recomputed from the detected beat times at each stage. All HRV values used in this analysis were recomputed in this way; none were read from the intermediate tables used for the earlier submission. The procedure, its known limitations (45 segments without a standard ECG lead fell back to the first available channel; a stated ≥60 s exclusion was not applied in the original pipeline), and full statistics are documented in the companion direction-1 reanalysis and in the archived code and aggregates [41].

The primary coefficient for RMSSD was 1.1575 (95% CI 1.0835-1.2492; 2,276 segments in 188 patients) for 250→62.5 Hz, and 1.0588 (95% CI 1.0294-1.1033; 4,988 segments) for 125→62.5 Hz. Low-frequency power increased by a factor of 1.0716 and high-frequency power by 1.2033 in the MIMIC-IV material (1,405 valid segments); in MIMIC-III the corresponding high-frequency coefficient was 1.0913 (3,103 segments). Because HF is more affected than LF, the LF/HF ratio is not rate-invariant, a point that follows directly from band-resolved measurement error rather than from any physiological claim.

As a check on the mechanism, an independent 500-Hz reference cohort (PTB-XL, 21,755 recordings from 18,844 patients [34]) reproduced the dose-response (1.0039, 1.0224 and 1.1217 at 250, 125 and 62.5 Hz). Replacing crude integer R-peak timing with parabolic sub-sample peak refinement reduced the 62.5-Hz ratio from 1.1217 to 1.0195, consistent with timing quantisation rather than anti-alias filtering as the dominant mechanism.

The analytic dataset used for the outcome association was the MIMIC-III p04 cohort [32, 33]: 1,445 ICU stays, of which 141 ended in hospital death (9.8%), with HRV features extracted from 40,595 successfully processed segments (24,518 segments of at least five minutes in 1,064 subjects). The sampling rate of this database is 125 Hz, which is why the 1.0588 coefficient is the relevant one for the main correction. MIMIC-III, MIMIC-IV and PTB-XL are cited according to their PhysioNet records [31] [32] [33] [34] [35], and HRV computation follows the Task Force conventions where applicable [36].

2.3 Quantitative bias analysis under multiplicative error

Suppose the measured exposure is a multiplicative distortion of the physiological one, Hobs = δ H*. Under a logistic model in the true exposure, logit Pr(Y) = β + β H*, fitting against Hobs yields a slope of approximately β/δ when the error is non-differential and the model is correctly specified. On the odds-ratio scale this gives OR_true = OR_obs ^ δ.

The derivation assumes a constant multiplicative factor over the exposure range; in practice δ varies with baseline variability and frequency band, so the result should be read as a first-order approximation. The direction of the adjustment is worth stating explicitly. Because δ > 1 inflates the exposure scale, the slope estimated against the inflated values is compressed towards the null; the correction therefore moves the odds ratio away from 1 on the multiplicative scale. That the correction increases an already positive odds ratio is not evidence that the association is an artifact; it is a consequence of the error model, and it is why the size of the correction must be compared with the size of the association and with changes under confounding adjustment.

Following the good-practice recommendations for QBA [12, 13], we treat δ as a bias parameter with an empirical distribution rather than a fixed constant. The 95% confidence interval of the measured coefficient is used as the sensitivity band, giving OR_true(δ_lo) to OR_true(δ_hi). This is a sensitivity analysis, not probabilistic bias analysis: we do not assign a probability distribution to δ, and we do not report a single "corrected" estimate as if it were identified. No external validation data were needed because the bias parameter came from the end-to-end waveform reprocessing described above [11, 18].

For SDNN, which has no separately estimated coefficient, the RMSSD time-domain coefficient is borrowed and the approximation is flagged in the results. Heart rate is retained as a negative control exposure in the strict sense: its measurement depends on R-R interval counting and should not be distorted by the sampling rates considered here, so δ = 1 and no correction is applied. If sampling rate were generating associations indiscriminately, the heart-rate association would move as well; it does not.

2.4 Threshold misclassification

Separate from the continuous-scale correction, we examined the effect of coarse sampling on a common reporting practice: classifying HRV as low when it falls below a 20 ms threshold. Using the reprocessed waveforms, we computed the proportion of recordings below the threshold at the reference rate that were moved above it by downsampling. This is an outcome-independent misclassification of the exposure, and its consequences for an odds ratio depend on the prevalence of low HRV and on the true association; we therefore report the reclassification fractions as the primary quantity and treat their effect on association estimates as a sensitivity consideration rather than a precise correction [18, 38, 39, 40].

2.5 What this analysis does not do

We report the cross-database gradient using the waveform subsets that could be linked to hospital outcomes, and we report it as a negative result: the linked cohorts were small (10 and 35 deaths), so the test is descriptive rather than confirmatory. Two further omissions are deliberate. We do not construct a negative-control outcome, because a candidate would need to share the confounders of HRV without lying on the autonomic pathway to mortality; none could be constructed credibly from the available tables, and inventing one would defeat the purpose of the test [20, 21]. We do not present a clinical recommendation: the cohort association used here is counter-intuitive in direction and collapses under age adjustment, a finding already documented in the source report, and it is used because it is a demanding test case for the method, not because it is a candidate biomarker.

Our approach is complementary to recent work that combines negative controls with empirical calibration to attribute a share of an observed association to systematic bias [19, 26, 27]. That work targets residual confounding and selection processes in treatment-effect studies and reports a bias fraction on a bounded scale. A related line uses panels of negative-control outcomes to diagnose and calibrate shared systematic error in real-world evidence [42]: the negative controls there are clinical endpoints chosen to share the confounders of the exposure, whereas ours is a physical property of the signal that has no clinical pathway to mortality. Ours targets a specified physical measurement process with an externally measured bias parameter and reports a corrected interval. External adjustment [16] and bounding approaches [17] likewise require an assumed magnitude for a confounder and return an adjusted estimate; the multiple-bias framework of Greenland [15] addresses several such sources jointly. It is also distinct from methods for informative monitoring in longitudinal EHR data [30]: those methods address the timing and frequency of clinical measurements as timevarying confounding, whereas we address the sampling rate of the ECG signal itself. Finally, the E-value [24, 25] answers a different question -how strong an unmeasured confounder would need to be -and is not a substitute for a bias parameter measured from the data.

3. Results

>Results

3.1 Distortion coefficients

Table 1 summarises the measured coefficients. RMSSD inflation ranged from 1.0588 at 125→62.5 Hz to 1.1575 at 250→62.5 Hz. The frequency-domain contrast was larger: HF power increased by 1.2033 in MIMIC-IV against 1.0716 for LF over the same downsampling step. Heart rate, used as the negative-control exposure, had a coefficient of 1.0000 by construction of the detection method.

3.2 Corrected association estimates

Table 2 gives the observed and corrected odds ratios. For the crude RMSSD-mortality association (OR_obs = 1.802), QBA gave OR_true = 1.8655 at δ = 1.0588, with a sensitivity band of 1.8335-1.915 over δ = 1.0294-1.1033. For SDNN the corresponding interval was 1.4181-1.4541 around a point estimate of 1.4323, using the borrowed timedomain coefficient. After age adjustment, the RMSSD association was 1.116 and the corrected interval was 1.1196-1.1287; under the stricter g-computation adjustment it was 1.154, corrected to 1.1589-1.1712. Heart rate was unchanged at 1.350, 1.609 and 1.451 in the three models.

The multiplicative correction scaled with the magnitude of the observed association: the proportional shift was about 3.5% at the crude RMSSD estimate and under 1% at the age-adjusted estimate. In other words, the measurement correction is largest where the crude association is largest, and it becomes negligible once the association has been reduced by confounding adjustment. This ordering matters for interpretation: in these data, adjustment for measured confounders changed the estimate far more than the sampling-rate correction did.

3.3 Threshold misclassification

Coarse sampling moved 33.70% of MIMIC-IV recordings initially below 20 ms above the threshold (182 of 540 segments), and 20.72% of MIMIC-III recordings (246 of 1,187). Because a threshold defines the exposed group in many published HRV studies, this form of bias is not equivalent to the continuous-scale correction and can be larger in its effect on a reported odds ratio. Reporting the sampling rate of every signal is therefore a prerequisite for comparing studies that use the same nominal threshold.

3.4 Negative-control gradient

The direction required by the negative-control test is available from the distortion coefficients: lower sampling rates and lower baseline variability produce larger inflation, and HF is affected more than LF. Having linked both waveform cohorts to hospital outcomes, we estimated the outcome association within each sampling-rate tier. End-toend segments were restricted to durations of at least 60 s, aggregated to the median RMSSD per subject per tier, and split at the tertiles; the age-adjusted risk ratio for high versus low variability was obtained by marginal standardisation from a logistic model, with 95% confidence intervals from 1,500 subject-level bootstrap resamples. The measurement gradient was reproducible -median RMSSD rose by ×1.101 from 125 to 62.5 Hz in MIMIC-III and by ×1.270 from 250 to 62.5 Hz in MIMIC-IV -but the association gradient was not: the risk ratio fell from 1.70 to 1.21 in MIMIC-III and from 1.31 to 1.20 in MIMIC-IV, and every interval crossed unity (Table 3, Figure 2). We report this as a negative falsification test, not as evidence that measurement bias is absent.

4. Discussion

We asked whether a known measurement artifact could account for part of the HRVoutcome associations that appear in the critical-care literature. Using sampling rate as a negative-control exposure and a measured distortion coefficient as a bias parameter, we found that the correction to a crude RMSSD-mortality odds ratio was small (1.802 to an interval of 1.8335-1.915), that it shrank to under 1% after confounder adjustment, and that threshold-based classification was a more substantial source of potential bias, moving around one fifth to one third of low-HRV recordings across the threshold. The results do not show that published HRV associations are artifacts. They show that the artifact has a measurable, bounded effect, and that the effect can be reported rather than ignored.

The negative-control framing is useful precisely because it separates two hypotheses. A genuinely physiological HRV-outcome association should not depend on the recording equipment's sampling rate. An association that strengthens at lower rates, and by an amount compatible with δ, would implicate measurement. With the outcome linkage now in place, the falsification test could be run in full. It returned a negative result: although the measurement inflation was reproducible, the HRV-mortality association did not strengthen at lower sampling rates in either cohort, and none of the tier-specific risk ratios excluded unity. Read as a falsification test, this does not confirm a measurement-driven association; nor, with 10 and 35 deaths in the two cohorts, does it exclude one. The defensible reading is that the sampling-rate gradient is not a sensitive diagnostic at the sample sizes available here, which is precisely why the QBA sensitivity band -rather than the gradient -carries the quantitative argument.

Several features of the design merit emphasis. The bias parameter was estimated from original waveforms rather than assumed, which is the condition under which QBA is most informative [11, 18, 19]. Negative-control and QBA approaches were used as diagnostics and sensitivity tools rather than as instruments for identification [20] [21] [22] [23]. Heart rate, which should be rate-invariant under the detection method, was carried through every model as a control exposure and remained unchanged. And the two bias mechanisms -continuous inflation and threshold misclassification -were quantified separately, because a single correction would obscure the larger of the two.

The limitations are substantial. Sampling rate is collinear with centre and device generation in these databases, so the negative-control exposure is not independent of the care environment; this is the reason for avoiding an IV interpretation and for presenting a sensitivity band rather than a causal effect. The benchmark HRV-outcome association used for the QBA comes from one database at one native rate. The crossdatabase gradient that we were able to run is underpowered: the linked waveform subsets contained 97 subjects with 10 deaths in MIMIC-III and 163 subjects with 35 deaths in MIMIC-IV, and the tier-specific confidence intervals were wide and all crossed unity. Sampling rate is also strongly confounded with centre and device generation in these databases, and the sampling-rate tiers within a cohort arise from reprocessing the same recordings rather than from independent devices, so the gradient is a withinrecording sensitivity analysis and not a between-device comparison. The exposure units of the source odds ratios are not documented in enough detail in the source report to make the correction more precise than a first-order approximation, and the SDNN coefficient is borrowed from RMSSD. PTB-XL segments are ten seconds long and cannot support LF/HF analysis, so frequency-domain validation rests on the ICU waveforms alone. Finally, the source association is counter-intuitive in direction and attenuates sharply with age adjustment; we use it as a test case for the method, not as evidence for a clinical claim.

These constraints point to a modest reporting recommendation rather than a new analytical standard. Studies reporting HRV-outcome associations could state the sampling rate of each signal, report effects stratified by baseline variability where sample size allows, name the QRS detector and interpolation method, and show a QBA sensitivity band before presenting a dichotomised HRV analysis. Each step uses information already available to the analyst. The goal is not to establish a universal sampling-rate threshold -the appropriate rate depends on the HRV index and the variability range, as Zhou and colleagues and Burma and colleagues show [1, 3] -but to make the influence of the chosen rate visible.

5. Conclusion

Differences in ECG sampling rate are a measurable source of bias in HRV-outcome research. Using sampling rate as a negative-control exposure and an empirically estimated distortion coefficient, we found a bounded effect on a continuous association and a larger effect on threshold-based classification. The method is a bias audit, not a causal design and not a clinical test. Reporting sampling rate, baseline-stratified effects and a quantitative sensitivity analysis would allow readers to judge how much of an HRV association survives the measurement process.
